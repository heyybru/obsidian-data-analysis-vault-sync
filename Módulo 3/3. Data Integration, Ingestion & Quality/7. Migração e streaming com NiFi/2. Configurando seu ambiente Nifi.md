### 🛠️ Passo a Passo para Configuração Local (Docker)

A forma mais rápida e isolada de rodar o Apache NiFi na sua máquina é utilizando o Docker.

Crie um arquivo `docker-compose.yml` simples:

```yaml
version: '3'
services:
  nifi:
    image: apache/nifi:latest
    ports:
      - "8443:8443" # Porta padrão HTTPS do NiFi
    environment:
      - SINGLE_USER_CREDENTIALS_USERNAME=admin
      - SINGLE_USER_CREDENTIALS_PASSWORD=SenhaSeguraDe12Caracteres!
```

**Para rodar:**

1. Salve o código acima como `docker-compose.yml`.
2. No terminal, execute: `docker-compose up -d`.
3. Abra o navegador e acesse: `https://localhost:8443/nifi`.
4. Faça login com o usuário `admin` e a senha configurada.
