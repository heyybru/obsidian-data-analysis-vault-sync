### 🔶 O que são dados dummies?

- **Definição curta**: Dados artificiais criados para simular cenários reais. Servem para **testar funções**, **treinar modelos** ou **exemplificar análises** sem expor informações confidenciais.
- **Por quê usar?** Evita problemas de privacidade (LGPD), acelera desenvolvimento e permite replicar erros/problemas.

### 1️⃣ Como criar no Pandas (exemplos rápidos)

Use `pd.DataFrame()` com dicionários ou listas. Fácil e direto!

**Exemplo RH (candidatos fictícios):**

```python
import pandas as pd
import numpy as np  # Para números aleatórios

df_candidatos = pd.DataFrame({
    'nome': ['Ana Silva', 'Bruno Costa', 'Carla Lima', 'Diego Souza'],
    'idade': np.random.randint(22, 45, 4),  # Idades aleatórias
    'salario_pretendido': np.random.uniform(3000, 8000, 4).round(2),
    'nota_teste': np.random.uniform(60, 100, 4).round(1)
})

print(df_candidatos)
```

Saída exemplo:

```
         nome  idade  salario_pretendido  nota_teste
0   Ana Silva    28             4500.23        85.2
1  Bruno Costa    35             6200.45        92.1
...
```

**Exemplo QA (logs de testes fictícios):**

```python
df_testes = pd.DataFrame({
    'teste_id': ['T001', 'T002', 'T003', 'T004'],
    'status': ['Pass', 'Fail', 'Pass', 'Fail'],
    'tempo_execucao': np.random.uniform(1.2, 5.8, 4).round(2),
    'num_bugs': np.random.randint(0, 3, 4)
})
print(df_testes)
```

### 2️⃣ Bibliotecas para gerar mais dados

- **Faker** (instale com `pip install faker`): Nomes reais, CPFs, e-mails falsos.
    
    ```python
    from faker import Faker
    fake = Faker('pt_BR')
    df['nome'] = [fake.name() for _ in range(10)]
    ```
    
- **NumPy**: Para números aleatórios (como nos exemplos acima).

### 3️⃣ Dicas práticas pro seu dia a dia

- **Teste funções Pandas**: Use dummies para validar `groupby`, `apply` ou `concat` sem bagunçar dados reais.
- **QA/Automação**: Crie cenários de "falhas comuns" (ex: 70% Pass, 30% Fail) pra simular relatórios.
- **Validação**: Sempre compare com dados reais depois (fonte: **Cappra Institute** enfatiza "dados sintéticos como baseline").
