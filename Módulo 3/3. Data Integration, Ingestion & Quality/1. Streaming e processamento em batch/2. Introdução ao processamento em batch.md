### 📦 O que é Processamento em Batch?

É o processamento de grandes volumes de dados que foram coletados e armazenados durante um período. O sistema não processa o dado assim que ele chega; ele espera acumular uma quantidade específica (lote) ou um horário agendado para rodar a tarefa.

#### Conceitos Chave:

- **Janela de Processamento**: O intervalo de tempo em que o sistema "acorda" para trabalhar (ex: toda madrugada às 02:00).
- **Latência Alta**: Você não tem o resultado na hora. Se o lote roda uma vez por dia, o dado que entrou às 08:00 só será processado à noite.
- **Eficiência**: É muito mais eficiente processar 1 milhão de registros de uma vez do que abrir e fechar a conexão com o banco 1 milhão de vezes.

| Característica           | Processamento em Batch (Lote)                                 |
| ------------------------ | ------------------------------------------------------------- |
| <b>Unidade de Dados</b>  | Grandes conjuntos (datasets) acumulados.                      |
| <b>Tempo de Execução</b> | Periódico (diário, semanal, mensal) ou sob demanda.           |
| <b>Estado do Dado</b>    | Dados em repouso (armazenados em DB ou HDFS).                 |
| <b>Complexidade</b>      | Alta capacidade de processamento para cálculos complexos.     |
| <b>Exemplo Real</b>      | Fechamento de folha de pagamento ou relatório mensal de KPIs. |

### 💼 Aplicação Prática: QA e Recrutamento

#### 1. No Quality Assurance (QA)

- **Testes de Regressão Noturnos**: Em vez de rodar todos os testes a cada pequeno commit (que seria caro), muitas empresas rodam o "Batch de Testes" completo durante a madrugada.
- **Sanitização de Dados**: Rodar um script para limpar CPFs duplicados ou formatar nomes em toda a base de dados PostgreSQL de uma só vez.

#### 2. No Recrutamento Global

- **Relatórios Mensais de Performance**: Calcular o _Time-to-Hire_ (tempo médio de contratação) de todos os processos do mês passado.
- **Sincronização de Bases**: Uma vez por dia, o sistema "Batch" lê todos os currículos novos do LinkedIn e atualiza o seu banco de dados interno.

### 🧪 Insight do Especialista (Metodologia & Business)

- **Metricas Boss**: No marketing, o Batch é usado para calcular o **LTV (Lifetime Value)**. Como é um cálculo que envolve todo o histórico do cliente, não faz sentido (e é muito caro) tentar calcular isso em tempo real a cada clique.
- **Preditiva.ai**: Modelos de Machine Learning complexos geralmente são treinados em **Batch**. Você pega meses de dados históricos para ensinar a IA a identificar o "candidato ideal".
- **Snaq.co**: Para startups, o Batch é a forma mais barata de começar. Implementar Streaming exige uma infraestrutura mais cara e complexa (como Kafka). O Batch pode ser feito com um simples script Python e um agendador (_Cron job_).

### 💡 Dica de Ouro para o Bruno

Como você já conhece **Hadoop** e **Spark**, lembre-se: o Hadoop (MapReduce) é o pai do processamento em Batch moderno. O Spark também faz Batch, mas de forma muito mais rápida por usar a memória RAM. Se o seu `dataset_recrutamento` tem milhões de linhas e você precisa de um relatório estatístico complexo, o Batch é o seu melhor amigo.
