**Listas são como "gavetas numeradas" onde você guarda várias coisas**.  
Em vez de ter 10 variáveis separadas (`candidato1`, `candidato2`, `candidato3`...), você tem **uma lista** com todos os candidatos.

✅ **No seu contexto (RH + QA)**:

- **RH**: Lista de candidatos, vagas abertas, etapas do processo
- **QA**: Lista de bugs, builds, testes a executar

---

## 🔷 Sintaxe

### ✅ **Criar lista**

```python
# Colchetes [] com elementos separados por vírgula
candidatos = ["Ana", "Bruno", "Carla", "Daniel"]
bugs = [15, 22, 8, 3, 12]
misturado = ["bug", 42, True, 3.14]
```

### ✅ **Lista vazia**

```python
vagas_abertas = []
bugs_criticos = list()  # Outra forma
```

---

## 🔷 Acessando elementos (índices)

Listas são **indexadas por posição**, começando em **0**:

```python
candidatos = ["Ana", "Bruno", "Carla", "Daniel"]

print(candidatos[0])   # "Ana" (primeiro)
print(candidatos[1])   # "Bruno" (segundo)
print(candidatos[-1])  # "Daniel" (último)
print(candidatos[-2])  # "Carla" (penúltimo)
```

**Visual mental**:

```
Índice:   0       1       2       3
Lista:  ["Ana", "Bruno", "Carla", "Daniel"]
```

## 🔷 Operações básicas (o que você mais vai usar)

### ✅ **Adicionar elementos**

```python
candidatos = ["Ana", "Bruno"]

# Adiciona no FINAL
candidatos.append("Carla")  # ["Ana", "Bruno", "Carla"]

# Adiciona em POSIÇÃO específica
candidatos.insert(1, "Daniel")  # ["Ana", "Daniel", "Bruno", "Carla"]
```

### ✅ **Remover elementos**

```python
candidatos = ["Ana", "Bruno", "Carla", "Daniel"]

# Remove por VALOR
candidatos.remove("Bruno")  # ["Ana", "Carla", "Daniel"]

# Remove por POSIÇÃO (e retorna o removido)
removido = candidatos.pop(0)  # removido = "Ana", lista = ["Carla", "Daniel"]

# Remove do FINAL
ultimo = candidatos.pop()  # ultimo = "Daniel", lista = ["Carla"]
```

### ✅ **Tamanho da lista**

```python
candidatos = ["Ana", "Bruno", "Carla"]
total = len(candidatos)  # 3
```

## 🔷 Exemplos práticos (RH + QA)

### ✅ **Exemplo 1: Gerenciamento de candidatos**

```python
# Lista de candidatos para vaga de QA
candidatos_qa = ["Bruno", "Ana", "Carlos", "Mariana"]

# Adiciona novo candidato
candidatos_qa.append("Roberto")

# Remove quem desistiu
candidatos_qa.remove("Carlos")

# Conta total
total_candidatos = len(candidatos_qa)  # 4

print(f"Candidatos ativos: {candidatos_qa}")
print(f"Total: {total_candidatos}")
```

### ✅ **Exemplo 2: Controle de bugs por severidade**

```python
# Bugs por severidade
bugs_criticos = ["BUG-001", "BUG-005", "BUG-012"]
bugs_altos = ["BUG-003", "BUG-008"]
bugs_medios = ["BUG-002", "BUG-004", "BUG-006"]

# Adiciona novo bug crítico
bugs_criticos.append("BUG-015")

# Remove bug resolvido
bugs_criticos.remove("BUG-005")

# Total de bugs
total_bugs = len(bugs_criticos) + len(bugs_altos) + len(bugs_medios)

print(f"Bugs críticos: {bugs_criticos}")
print(f"Total bugs: {total_bugs}")
```

### ✅ **Exemplo 3: Etapas do processo seletivo**

```python
# Etapas fixas (não muda ordem)
etapas_rh = ["Inscrição", "Triagem", "Entrevista Técnica", "Proposta", "Contratação"]

# Acessa etapas específicas
primeira_etapa = etapas_rh[0]  # "Inscrição"
ultima_etapa = etapas_rh[-1]   # "Contratação"

# Quantas etapas?
total_etapas = len(etapas_rh)  # 5

print(f"Processo tem {total_etapas} etapas")
print(f"Primeira: {primeira_etapa}, Última: {ultima_etapa}")
```

## 🔷 Operações avançadas (úteis)

### ✅ **Fatiamento (slicing)**

```python
candidatos = ["Ana", "Bruno", "Carla", "Daniel", "Eduardo"]

# Pega do índice 1 ao 3 (não inclui 4)
primeiros = candidatos[1:4]  # ["Bruno", "Carla", "Daniel"]

# Pega do início ao índice 2
inicio = candidatos[:3]  # ["Ana", "Bruno", "Carla"]

# Pega do índice 2 ao final
final = candidatos[2:]  # ["Carla", "Daniel", "Eduardo"]

# Pega cada 2 elementos
pulando = candidatos[::2]  # ["Ana", "Carla", "Eduardo"]
```

### ✅ **Concatenar listas**

```python
rh_sp = ["Ana", "Bruno"]
rh_rj = ["Carla", "Daniel"]

# Junta tudo
todos_candidatos = rh_sp + rh_rj  # ["Ana", "Bruno", "Carla", "Daniel"]
```

### ✅ **Verificar se elemento existe**

```python
candidatos = ["Ana", "Bruno", "Carla"]

# Verifica se está na lista
tem_bruno = "Bruno" in candidatos  # True
tem_roberto = "Roberto" in candidatos  # False

# Conta quantas vezes aparece
candidatos.append("Bruno")  # Duplicado
quantos_bruno = candidatos.count("Bruno")  # 2
```

## 🔷 Métodos úteis para dados

### ✅ **Ordenar**

```python
# Ordem alfabética
candidatos = ["Bruno", "Ana", "Daniel", "Carla"]
candidatos.sort()  # ["Ana", "Bruno", "Carla", "Daniel"]

# Ordem inversa
candidatos.sort(reverse=True)  # ["Daniel", "Carla", "Bruno", "Ana"]
```

### ✅ **Copiar lista (cuidado!)**

```python
original = ["Ana", "Bruno"]
copia_errada = original  # NÃO copia, só referencia!
copia_certa = original.copy()  # Agora sim é cópia

original.append("Carla")
print(copia_errada)  # ["Ana", "Bruno", "Carla"] ← alterou!
print(copia_certa)   # ["Ana", "Bruno"] ← preservou
```

## 🔷 Listas dentro de listas (matrizes)

```python
# Matriz de bugs por módulo
bugs_por_modulo = [
    ["Login", "BUG-001", "BUG-005"],      # Módulo 0
    ["Perfil", "BUG-002", "BUG-003"],     # Módulo 1
    ["Pagamento", "BUG-004"]              # Módulo 2
]

# Acessa
modulo_login = bugs_por_modulo[0]        # ["Login", "BUG-001", "BUG-005"]
primeiro_bug_login = bugs_por_modulo[0][1]  # "BUG-001"
```

## 🔷 Exercício prático

**Crie um sistema simples de triagem de bugs**:

```python
# 1. Lista inicial de bugs
bugs = ["BUG-001", "BUG-002", "BUG-003"]

# 2. Adiciona novos bugs
bugs.append("BUG-004")
bugs.append("BUG-005")

# 3. Remove bug resolvido
bugs.remove("BUG-002")

# 4. Verifica se bug específico existe
if "BUG-003" in bugs:
    print("BUG-003 ainda pendente")

# 5. Conta total
print(f"Total bugs pendentes: {len(bugs)}")
print(f"Lista: {bugs}")
```
