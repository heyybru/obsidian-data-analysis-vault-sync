### Pré-requisitos

Pra rodar Sqoop, você precisa de:

1. **Java 8+** (Sqoop roda na JVM)
2. **Hadoop** (HDFS + MapReduce configurados)
3. **Banco relacional** (MySQL, PostgreSQL, etc.) com driver JDBC
4. **O próprio Sqoop** (baixar o binário)

### Instalação básica

```bash
# 1. Baixar o Sqoop (versão 1.4.7 - última estável)
wget https://archive.apache.org/dist/sqoop/1.4.7/sqoop-1.4.7.bin__hadoop-2.6.0.tar.gz

# 2. Descompactar
tar -xzf sqoop-1.4.7.bin__hadoop-2.6.0.tar.gz
sudo mv sqoop-1.4.7.bin__hadoop-2.6.0 /usr/local/sqoop

# 3. Configurar variáveis de ambiente (~/.bashrc)
export SQOOP_HOME=/usr/local/sqoop
export PATH=$PATH:$SQOOP_HOME/bin

# 4. Colocar o driver JDBC do seu banco na pasta lib/
# Exemplo para MySQL:
cp mysql-connector-java-8.x.x.jar $SQOOP_HOME/lib/

# 5. Verificar instalação
sqoop version
```
