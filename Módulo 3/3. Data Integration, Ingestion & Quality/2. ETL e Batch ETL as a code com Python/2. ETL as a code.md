**"As Code"** = escrever o pipeline ETL como **código Python** em vez de usar ferramentas visuais de clicar e arrastar (como Power Query, Pentaho, Talend).

### Por que isso importa?

|Abordagem Visual (clique)|Abordagem As Code (Python)|
|:--|:--|
|Difícil versionar (Git não funciona)|Código no GitHub → versionado ✅|
|Difícil testar automatizado|Pytest + unittest validam cada etapa ✅|
|Difícil revisar em PR|Code review normal ✅|
|Dependente de ferramenta paga|Python é gratuito e roda em qualquer lugar ✅|

### Estrutura de um ETL as Code

```python
# pipeline_candidatos.py

import pandas as pd

def extract():
    return pd.read_excel("workbook_v1.xlsx", sheet_name="db")

def transform(df):
    df["experiencia_anos"] = pd.to_numeric(df["experiencia_anos"], errors="coerce")
    df["faixa_exp"] = pd.cut(df["experiencia_anos"], 
                             bins=[0, 2, 5, 10, 20], 
                             labels=["JR", "PL", "SR", "Master"])
    return df.dropna(subset=["experiencia_anos"])

def load(df):
    df.to_csv("candidatos_tratados.csv", index=False)
    print(f"{len(df)} registros carregados.")

# Pipeline
if __name__ == "__main__":
    dados = extract()
    dados_tratados = transform(dados)
    load(dados_tratados)
```

Cada função é **independente**, **testável** e **reutilizável** — isso é ETL as Code.
