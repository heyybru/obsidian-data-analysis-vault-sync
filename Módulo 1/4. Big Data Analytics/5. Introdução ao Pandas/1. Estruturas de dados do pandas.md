## 🔷 Series e DataFrame

**Series é como uma "coluna do Excel" com superpoderes**, e **DataFrame é como uma "planilha inteira" que você pode manipular com código**.  
São as duas estruturas fundamentais que tornam o Pandas tão poderoso.

✅ **No seu contexto (RH + QA)**:

- **Series**: Uma coluna de salários, uma lista de nomes de candidatos
- **DataFrame**: Tabela completa de candidatos, planilha de bugs com todas as informações

---

## 🔷 1. Series: A Unidade Básica

### ✅ **O que é uma Series?**

- **Array 1-dimensional** com índice
- **Pode conter qualquer tipo de dado** (int, float, string, datetime)
- **Índice personalizável** (não apenas 0, 1, 2...)

### ✅ **Criando Series**:

```python
import pandas as pd
import numpy as np

# De lista Python
salarios = pd.Series([5000, 6000, 7000, 5500])
print(salarios)
# 0    5000
# 1    6000
# 2    7000
# 3    5500
# dtype: int64

# Com índice personalizado
salarios_nomeados = pd.Series([5000, 6000, 7000, 5500], 
                              index=['Ana', 'Bruno', 'Carla', 'Daniel'])
print(salarios_nomeados)
# Ana       5000
# Bruno     6000
# Carla     7000
# Daniel    5500
# dtype: int64

# De dicionário
idades = pd.Series({'Ana': 25, 'Bruno': 30, 'Carla': 35, 'Daniel': 28})
print(idades)
# Ana       25
# Bruno     30
# Carla     35
# Daniel    28
# dtype: int64

# De array NumPy
tempos_resolucao = pd.Series(np.array([2.5, 3.1, 1.8, 4.2]))
print(tempos_resolucao)
# 0    2.5
# 1    3.1
# 2    1.8
# 3    4.2
# dtype: float64
```

### ✅ **Atributos importantes**:

```python
s = pd.Series([5000, 6000, 7000, 5500], index=['A', 'B', 'C', 'D'])

print(s.index)      # Index(['A', 'B', 'C', 'D'], dtype='object')
print(s.values)     # array([5000, 6000, 7000, 5500])
print(s.dtype)      # int64
print(s.shape)      # (4,)
print(s.size)       # 4
print(s.name)       # None (pode ser definido)
```

### ✅ **Operações com Series**:

```python
# Aritmética
s1 = pd.Series([10, 20, 30, 40])
s2 = pd.Series([1, 2, 3, 4])

print(s1 + s2)      # 11, 22, 33, 44
print(s1 * 2)       # 20, 40, 60, 80
print(s1 > 25)      # False, False, True, True

# Métodos estatísticos
print(s1.mean())    # 25.0
print(s1.std())     # 12.91
print(s1.sum())     # 100
print(s1.min())     # 10
print(s1.max())     # 40
```

### ✅ **Indexação e Slicing**:

```python
s = pd.Series([5000, 6000, 7000, 5500], index=['A', 'B', 'C', 'D'])

# Por índice posicional
print(s.iloc[0])     # 5000
print(s.iloc[1:3])   # B:6000, C:7000

# Por índice label
print(s.loc['A'])    # 5000
print(s.loc[['A', 'C']])  # A:5000, C:7000

# Por condição
print(s[s > 5500])   # B:6000, C:7000
```

## 🔷 2. DataFrame: A Estrutura Principal

### ✅ **O que é um DataFrame?**

- **Tabela 2-dimensional** com linhas e colunas
- **Cada coluna é uma Series**
- **Índices para linhas e nomes para colunas**
- **Pode conter diferentes tipos por coluna**

### ✅ **Criando DataFrames**:

```python
# De dicionário (mais comum)
candidatos = pd.DataFrame({
    'nome': ['Ana', 'Bruno', 'Carla', 'Daniel'],
    'idade': [25, 30, 35, 28],
    'experiencia': [3, 5, 8, 2],
    'salario': [5000, 6000, 7000, 5500],
    'status': ['aprovado', 'pendente', 'aprovado', 'reprovado']
})
print(candidatos)
#     nome  idade  experiencia  salario     status
# 0    Ana     25            3     5000   aprovado
# 1  Bruno     30            5     6000   pendente
# 2  Carla     35            8     7000   aprovado
# 3 Daniel     28            2     5500  reprovado

# De lista de listas
bugs = pd.DataFrame([
    ['BUG-001', 'login', 'critico', 8],
    ['BUG-002', 'pagamento', 'alto', 4],
    ['BUG-003', 'perfil', 'medio', 2]
], columns=['id', 'modulo', 'severidade', 'horas'])
print(bugs)
#        id     modulo severidade  horas
# 0  BUG-001      login     critico      8
# 1  BUG-002  pagamento       alto      4
# 2  BUG-003     perfil      medio      2

# De lista de dicionários
logs = pd.DataFrame([
    {'timestamp': '2026-01-01 10:00', 'nivel': 'INFO', 'mensagem': 'Sistema iniciado'},
    {'timestamp': '2026-01-01 10:05', 'nivel': 'ERROR', 'mensagem': 'Falha no login'},
    {'timestamp': '2026-01-01 10:10', 'nivel': 'WARN', 'mensagem': 'Memória alta'}
])
print(logs)
#            timestamp nivel            mensagem
# 0  2026-01-01 10:00  INFO    Sistema iniciado
# 1  2026-01-01 10:05 ERROR    Falha no login
# 2  2026-01-01 10:10  WARN      Memória alta
```

### ✅ **Atributos importantes do DataFrame**:

```python
df = candidatos

print(df.shape)           # (4, 5) → 4 linhas, 5 colunas
print(df.columns)         # Index(['nome', 'idade', 'experiencia', 'salario', 'status'])
print(df.index)           # RangeIndex(start=0, stop=4, step=1)
print(df.dtypes)          # Tipos de cada coluna
print(df.info())          # Informações completas
print(df.describe())      # Estatísticas descritivas
```

### ✅ **Acessando colunas (retorna Series)**:

```python
# Uma coluna → Series
nomes = df['nome']
print(type(nomes))        # <class 'pandas.core.series.Series'>

# Múltiplas colunas → DataFrame
dados_basicos = df[['nome', 'idade', 'salario']]
print(type(dados_basicos)) # <class 'pandas.core.frame.DataFrame'>

# Com ponto (só funciona se nome não tem espaço)
idade = df.idade
```

### ✅ **Acessando linhas**:

```python
# Por índice posicional (iloc)
print(df.iloc[0])         # Primeira linha (Series)
print(df.iloc[0:2])       # Primeiras 2 linhas (DataFrame)
print(df.iloc[[0, 2]])    # Linhas 0 e 2

# Por índice label (loc)
print(df.loc[0])          # Linha com índice 0
print(df.loc[0:2])        # Linhas 0 a 2 (inclusive!)

# Com condições
print(df.loc[df['idade'] > 28])  # Linhas onde idade > 28
```

### ✅ **Modificando DataFrames**:

```python
# Adicionar coluna
df['salario_anual'] = df['salario'] * 13

# Modificar coluna existente
df['salario'] = df['salario'] * 1.1  # Aumento de 10%

# Remover coluna
df = df.drop(columns=['status'])

# Renomear colunas
df = df.rename(columns={'nome': 'Nome Completo', 
                        'idade': 'Idade (anos)'})

# Definir índice
df = df.set_index('nome')
print(df)
#         idade  experiencia  salario
# nome                               
# Ana        25            3     5500
# Bruno      30            5     6600
# Carla      35            8     7700
# Daniel     28            2     6050
```

## 🔷 3. Comparação: Series vs DataFrame

### ✅ **Semelhanças**:

- Ambos têm **índice**
- Ambos suportam **operações vetorizadas**
- Ambos têm **métodos similares** (mean(), sum(), etc.)

### ✅ **Diferenças**:

|Aspecto|Series|DataFrame|
|---|---|---|
|**Dimensões**|1D (coluna)|2D (tabela)|
|**Colunas**|1 coluna|Múltiplas colunas|
|**Tipos de dados**|Um tipo por Series|Diferentes tipos por coluna|
|**Uso típico**|Uma variável|Múltiplas variáveis|
|**Exemplo RH**|Coluna de salários|Tabela de candidatos|
|**Exemplo QA**|Tempos de resolução|Tabela de bugs|

### ✅ **Conversão entre eles**:

```python
# Series → DataFrame
s = pd.Series([5000, 6000, 7000], name='salario')
df_from_series = s.to_frame()
print(df_from_series)
#    salario
# 0     5000
# 1     6000
# 2     7000

# DataFrame → Series (uma coluna)
df = pd.DataFrame({'A': [1, 2, 3], 'B': [4, 5, 6]})
s_from_df = df['A']  # Ou df.A
print(type(s_from_df))  # <class 'pandas.core.series.Series'>
```

## 🔷 4. Index: O Sistema de Índices

### ✅ **Tipos de índice**:

```python
# RangeIndex (padrão)
df1 = pd.DataFrame({'A': [1, 2, 3]})
print(df1.index)  # RangeIndex(start=0, stop=3, step=1)

# Index com strings
df2 = pd.DataFrame({'A': [1, 2, 3]}, index=['a', 'b', 'c'])
print(df2.index)  # Index(['a', 'b', 'c'], dtype='object')

# DatetimeIndex
dates = pd.date_range('2026-01-01', periods=3)
df3 = pd.DataFrame({'A': [1, 2, 3]}, index=dates)
print(df3.index)  # DatetimeIndex(['2026-01-01', '2026-01-02', '2026-01-03'])

# MultiIndex (índice hierárquico)
arrays = [['TI', 'TI', 'RH', 'RH'], ['Ana', 'Bruno', 'Carla', 'Daniel']]
index = pd.MultiIndex.from_arrays(arrays, names=['departamento', 'nome'])
df4 = pd.DataFrame({'salario': [7000, 7500, 5500, 6000]}, index=index)
print(df4)
#                         salario
# departamento nome              
# TI           Ana           7000
#              Bruno         7500
# RH           Carla         5500
#              Daniel        6000
```

### ✅ **Operações com índices**:

```python
# Resetar índice
df_reset = df4.reset_index()
print(df_reset)
#   departamento    nome  salario
# 0           TI     Ana     7000
# 1           TI   Bruno     7500
# 2           RH   Carla     5500
# 3           RH  Daniel     6000

# Definir índice
df_new_index = df_reset.set_index('nome')
print(df_new_index)
#        departamento  salario
# nome                        
# Ana              TI     7000
# Bruno            TI     7500
# Carla            RH     5500
# Daniel           RH     6000

# Reindexar (alterar ordem)
df_reindexed = df_new_index.reindex(['Carla', 'Ana', 'Daniel', 'Bruno'])
print(df_reindexed)
```

## 🔷 5. Dtypes: Tipos de Dados

### ✅ **Tipos principais**:

```python
# Criar DataFrame com diferentes tipos
df = pd.DataFrame({
    'inteiro': pd.Series([1, 2, 3], dtype='int32'),
    'decimal': pd.Series([1.1, 2.2, 3.3], dtype='float64'),
    'texto': pd.Series(['a', 'b', 'c'], dtype='object'),
    'booleano': pd.Series([True, False, True], dtype='bool'),
    'data': pd.Series(pd.date_range('2026-01-01', periods=3)),
    'categoria': pd.Series(['A', 'B', 'C'], dtype='category')
})

print(df.dtypes)
# inteiro         int32
# decimal       float64
# texto          object
# booleano         bool
# data      datetime64[ns]
# categoria    category
```

### ✅ **Conversão de tipos**:

```python
# Converter coluna
df['inteiro'] = df['inteiro'].astype('int64')
df['texto'] = df['texto'].astype('str')

# Converter para categoria (economiza memória)
df['departamento'] = pd.Series(['TI', 'RH', 'TI', 'Vendas'])
df['departamento'] = df['departamento'].astype('category')
print(df['departamento'].cat.categories)  # ['RH', 'TI', 'Vendas']
```

## 🔷 6. Exemplos Práticos (RH + QA)

### ✅ **Exemplo RH: Análise de Candidatos**:

```python
# Criar DataFrame de candidatos
candidatos = pd.DataFrame({
    'id': [1, 2, 3, 4, 5],
    'nome': ['Ana Silva', 'Bruno Costa', 'Carla Lima', 'Daniel Santos', 'Eduarda Alves'],
    'idade': [25, 30, 35, 28, 32],
    'experiencia_anos': [3, 5, 8, 2, 6],
    'salario_pretendido': [5000, 6000, 7000, 5500, 6500],
    'departamento': ['TI', 'TI', 'RH', 'Vendas', 'TI'],
    'status': ['aprovado', 'pendente', 'aprovado', 'reprovado', 'aprovado']
})

# 1. Series: Salários
salarios = candidatos['salario_pretendido']
print(f"Média salarial: R$ {salarios.mean():.2f}")
print(f"Salário máximo: R$ {salarios.max():.2f}")
print(f"Salário mínimo: R$ {salarios.min():.2f}")

# 2. Series: Idades com filtro
jovens = candidatos.loc[candidatos['idade'] < 30, 'nome']
print(f"\nCandidatos jovens (<30): {list(jovens)}")

# 3. DataFrame: Agrupamento
por_departamento = candidatos.groupby('departamento').agg({
    'salario_pretendido': 'mean',
    'idade': 'mean',
    'id': 'count'
}).rename(columns={'id': 'total_candidatos'})
print(f"\nMétricas por departamento:\n{por_departamento}")
```
