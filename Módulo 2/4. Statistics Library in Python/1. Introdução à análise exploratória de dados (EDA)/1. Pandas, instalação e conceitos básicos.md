## Pandas: o que é e por que usar

**Pandas** é a biblioteca mais usada em Python para **trabalhar com dados em formato de tabela** (tipo Excel/SQL). O principal objeto é o **DataFrame** (tabela) e o **Series** (coluna).

Você usa Pandas para:

- carregar dados (CSV, Excel, SQL)
- limpar e transformar (tipos, nulos, textos)
- resumir (médias, contagens, agrupamentos)
- preparar pra gráficos e modelos

## Conceitos básicos: Series e DataFrame

### Series (uma coluna)

```python
import pandas as pd

s = pd.Series([10, 20, 30], name="idade")
print(s)
```

### DataFrame (tabela)

```python
df = pd.DataFrame({
    "nome": ["Ana", "Bruno", "Carla"],
    "idade": [28, 34, 25],
    "cidade": ["SP", "RJ", "BH"]
})
print(df)
```

---

## Carregar dados (o mais usado na EDA)

### Ler CSV

```python
import pandas as pd

df = pd.read_csv("dados.csv")  # separador padrão: vírgula
```

Se seu CSV for separado por `;` (muito comum no Brasil):

```python
df = pd.read_csv("dados.csv", sep=";")
```

### Ler Excel

```python
df = pd.read_excel("dados.xlsx", sheet_name=0)
```

---

## “Primeiros comandos” de EDA (checklist rápido)

### Ver as primeiras linhas

```python
df.head(10)
```

### Tamanho (linhas, colunas)

```python
df.shape
```

### Nomes e tipos das colunas

```python
df.columns
df.dtypes
```

### Info geral (nulos + tipos + memória)

```python
df.info()
```

### Estatísticas descritivas (numéricas)

```python
df.describe()
```

Para incluir colunas categóricas:

```python
df.describe(include="object")
```

---

## Seleção e filtros (dia a dia)

### Selecionar colunas

```python
df["idade"]          # Series
df[["nome", "idade"]]  # DataFrame
```

### Filtrar linhas

```python
df[df["idade"] >= 30]
```

### Filtrar com múltiplas condições

```python
df[(df["idade"] >= 30) & (df["cidade"] == "SP")]
```

---

## Valores ausentes (nulos): detectar e tratar

### Contar nulos por coluna

```python
df.isna().sum()
```

### Remover linhas com nulos (cuidado)

```python
df2 = df.dropna()
```

### Preencher nulos

```python
df["idade"] = df["idade"].fillna(df["idade"].median())
```

---

## Agrupamentos (o “power move” da EDA)

Exemplo: média de idade por cidade

```python
df.groupby("cidade")["idade"].mean()
```

Exemplo: contagem por categoria

```python
df["cidade"].value_counts()
```

## Resumindo

- **Pandas** = base da EDA em Python (DataFrame/Series)
- Instala com `pip install pandas` ou `conda install pandas`
- Comece sempre com: `head()`, `shape`, `info()`, `describe()`, `isna().sum()`
- Para insights rápidos: `value_counts()` e `groupby()`
