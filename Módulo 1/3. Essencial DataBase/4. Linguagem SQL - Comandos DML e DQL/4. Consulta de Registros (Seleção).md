## 📘 Comando SELECT + WHERE

### 🔹 O que é seleção?

👉 **Seleção** é quando você **filtra as linhas (registros)** da tabela, escolhendo **quais dados** serão retornados.

📌 Quem faz isso é a cláusula **WHERE**.

---

## 🧩 Sintaxe básica

```sql
SELECT colunas
FROM nome_tabela
WHERE condição;
```

---

## 🔹 Exemplo simples

```sql
SELECT *
FROM COLABORADOR
WHERE cargo = 'Analista';
```

👉 Retorna **apenas os registros** com cargo Analista.

---

## 🔹 Operadores mais usados

|Operador|Significado|
|---|---|
|=|igual|
|<>|diferente|
|>|maior|
|<|menor|
|>=|maior ou igual|
|<=|menor ou igual|

Exemplo:

```sql
SELECT *
FROM COLABORADOR
WHERE salario > 3000;
```

---

## 🔹 Seleção com AND / OR

```sql
SELECT *
FROM COLABORADOR
WHERE cargo = 'Analista'
AND salario > 4000;
```

```sql
SELECT *
FROM COLABORADOR
WHERE cargo = 'Analista'
OR cargo = 'QA';
```

---

## 🔹 BETWEEN (intervalo)

```sql
SELECT *
FROM COLABORADOR
WHERE salario BETWEEN 3000 AND 5000;
```

📌 Inclui os valores 3000 e 5000.

---

## 🔹 IN (lista de valores)

```sql
SELECT *
FROM COLABORADOR
WHERE cargo IN ('Analista', 'QA', 'Dev');
```

---

## 🔹 LIKE (padrão de texto)

```sql
SELECT *
FROM COLABORADOR
WHERE nome LIKE 'A%';
```

👉 Começa com A

```sql
WHERE nome LIKE '%a%';
```

👉 Contém a letra a

---

## 🔹 IS NULL / IS NOT NULL

```sql
SELECT *
FROM COLABORADOR
WHERE salario IS NULL;
```

---

## 🧠 Resumo rápido

- Seleção = filtrar registros
    
- Usa `WHERE`
    
- `AND` / `OR` combinam condições
    
- `BETWEEN`, `IN`, `LIKE` facilitam filtros
    
- Sem `WHERE` → traz tudo
