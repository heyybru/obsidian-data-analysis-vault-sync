ETL é um **processo**, não uma ferramenta. São 3 fases que levam dados brutos de uma fonte até um destino tratado:

```
┌──────────┐    ┌───────────┐    ┌──────────┐
│ EXTRACT  │ →  │ TRANSFORM │ →  │   LOAD   │
│ (extrair)│    │(transformar)│   │(carregar)│
└──────────┘    └───────────┘    └──────────┘
```

### ⚙️ Cada fase em detalhe

|Fase|O que acontece|Exemplo no seu dataset|
|:--|:--|:--|
|**Extract**|Ler dados de uma ou mais fontes (CSV, Excel, API, banco SQL, Google Sheets)|Ler a aba `db` do seu `workbook_v1.xlsx` com **100 candidatos**|
|**Transform**|Limpar, padronizar, filtrar, criar colunas, agregar, corrigir tipos|Converter `experiencia_anos` de texto pra número, criar faixa salarial, tratar nulos|
|**Load**|Gravar o resultado num destino final|Salvar num banco PostgreSQL, numa nova aba do Sheets, ou num CSV limpo|

### 🔁 ETL vs ELT

O material traz uma diferença importante:

|Característica|**ETL** (tradicional)|**ELT** (moderno)|
|:--|:--|:--|
|Ordem|Extract → **Transform** → Load|Extract → **Load** → Transform|
|Onde transforma|Num ambiente intermediário (staging)|Direto no data warehouse (ex: BigQuery, Snowflake)|
|Vantagem|Dados limpos antes de entrar no destino|Mais rápido, escala melhor com cloud|
|Quando usar|Sistemas legados, dados sensíveis que precisam de tratamento antes de armazenar|Big Data, cloud computing, streaming|

> 💡 **Resumo do material:** "ETL não é uma ferramenta específica, mas um conceito que pode ser automatizado usando Python."
