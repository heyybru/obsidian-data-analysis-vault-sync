## O que significa?

São consultas que **usam funções de grupo** (`COUNT`, `SUM`, `AVG`, `MIN`, `MAX`) **com filtros**.

📌 Importante:

- **`WHERE`** → filtra **linhas antes** do agrupamento
    
- **`HAVING`** → filtra **grupos depois** do agrupamento

---
## 🔹 Exemplo simples (sem `GROUP BY`)

```sql
SELECT AVG(salary)
FROM employee
WHERE department_id = 10;
```

👉 Primeiro filtra os funcionários do departamento 10  
👉 Depois calcula a média

---

## 🔹 Exemplo com `GROUP BY` + `HAVING`

```sql
SELECT department_id, AVG(salary)
FROM employee
GROUP BY department_id
HAVING AVG(salary) >= 6000;
```

📌 Retorna apenas os departamentos cuja **média salarial ≥ 6000**

---

## 🔹 `WHERE` + `GROUP BY` + `HAVING`

```sql
SELECT department_id, COUNT(*)
FROM employee
WHERE job_id = 'IT_PROG'
GROUP BY department_id
HAVING COUNT(*) > 3;
```

📌 Passo a passo:

1. `WHERE` → filtra apenas programadores
    
2. `GROUP BY` → agrupa por departamento
    
3. `HAVING` → mantém grupos com mais de 3 pessoas

---

## ❌ Erros comuns

❌ Usar função de grupo no `WHERE`

```sql
WHERE AVG(salary) > 5000
```

✔ Correto:

```sql
HAVING AVG(salary) > 5000
```

---

## 🧠 Dica de prova

- **Função de grupo → HAVING**
    
- **Filtro simples → WHERE**
    
- **Campo fora de função → precisa estar no GROUP BY**

---

## 📘 Resumo

- Restrições em funções de grupo usam `HAVING`
    
- `WHERE` filtra antes
    
- `HAVING` filtra depois
