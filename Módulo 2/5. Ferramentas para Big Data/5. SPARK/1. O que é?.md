### 🔶 O que é o Spark?

- **Definição**: É um framework de computação distribuída de **código aberto** projetado para processamento de dados em **larga escala**.
- **Diferencial Crítico**: Ao contrário do MapReduce, que grava dados no disco a cada etapa, o Spark processa quase tudo **em memória (RAM)**. Isso reduz drasticamente o tempo de leitura e escrita (I/O).
- **Versatilidade**: Ele não serve apenas para contar palavras; ele faz SQL, Streaming (tempo real), Machine Learning e processamento de grafos em uma única plataforma.

### 1️⃣ Por que ele é tão amado? (**Metricas Boss** / **Cappra Institute**)

- **Velocidade**: O processamento _in-memory_ permite análises iterativas rápidas.
- **Facilidade**: Você pode escrever código em **Python (PySpark)**, Scala, Java ou R. Para você que já tem noções de Python, o PySpark será seu melhor amigo.
- **Ecossistema Unificado**: Você não precisa de uma ferramenta para cada coisa. O Spark resolve quase tudo.

### 2️⃣ Componentes Principais

- **Spark SQL**: Para trabalhar com dados estruturados usando comandos SQL que você já conhece.
- **Spark Streaming**: Resolve o problema do "tempo real" que o MapReduce não conseguia (análise de dados enquanto eles chegam).
- **MLlib**: Biblioteca de Machine Learning para criar modelos preditivos em escala.
- **GraphX**: Para processamento de redes e conexões complexas.

### 3️⃣ Exemplo Prático no seu contexto (QA e RH)

- **No QA**: Imagine que você tem **terabytes** de logs de testes de API. Com Spark, você pode filtrar falhas de resposta em segundos para gerar um relatório de qualidade.
- **No RH**: Analisar milhares de currículos e cruzar competências (skills) com vagas abertas em tempo recorde, usando o **Spark SQL** para filtrar os melhores candidatos.
