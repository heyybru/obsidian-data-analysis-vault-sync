As duas estruturas parecem “coleções”, mas servem para coisas bem diferentes:

- **Tupla (`tuple`)**: “registro” **fixo** e **imutável** (ordem importa).
- **Conjunto (`set`)**: “coleção de únicos” **sem repetição** (ordem não importa).

---

## 🔷 1) O que muda na prática

**Tupla**

- ✅ Mantém **ordem**: `t[0]`, `t[1]`…
- ✅ Aceita **repetidos**
- ✅ É **imutável** (não dá pra alterar item)
- ✅ Pode ser **chave de dicionário** (se só tiver itens imutáveis)

**Conjunto**

- ❌ Não tem ordem garantida (não use índice)
- ❌ Não aceita repetidos (remove duplicados automaticamente)
- ✅ É mutável (você pode `add`, `remove`)
- ✅ Operações matemáticas: união/interseção/diferença
- ❌ Não pode ser chave de dict (mas `frozenset` pode)

---

## 🔷 2) Exemplos simples

### ✅ Tupla (ordem + “registro”)

```python
bug = (101, "CRITICO", "ABERTO")  # (id, severidade, status)
print(bug[0])  # 101
```

### ✅ Conjunto (únicos)

```python
severidades = {"CRITICO", "ALTO", "ALTO", "BAIXO"}
print(severidades)  # {'CRITICO', 'ALTO', 'BAIXO'}
```

---

## 🔷 3) Quando usar tupla (casos reais)

### ✅ 3.1) Retornar múltiplos valores de função

```python
def resumo_testes(resultados):
    total = len(resultados)
    passaram = sum(1 for r in resultados if r)
    falharam = total - passaram
    return total, passaram, falharam  # tupla

t, p, f = resumo_testes([True, False, True])
print(t, p, f)
```

### ✅ 3.2) “Chave composta” (id + ambiente) em dicionário

```python
resultado_por_ambiente = {
    ("Chrome", "Windows"): "PASSOU",
    ("Safari", "macOS"): "FALHOU",
}

print(resultado_por_ambiente[("Chrome", "Windows")])
```

---

## 🔷 4) Quando usar conjunto (casos reais)

### ✅ 4.1) Remover duplicados rápido

```python
candidatos = ["ana", "ana", "bruno", "carla"]
unicos = set(candidatos)
print(unicos)
```

### ✅ 4.2) Comparar listas: planejado vs executado (QA)

```python
planejados = {"Login", "Cadastro", "Pagamento", "Perfil"}
executados = {"Login", "Pagamento", "Busca"}

nao_executados = planejados - executados
extras = executados - planejados
ok = planejados & executados

print("OK:", ok)
print("Não executados:", nao_executados)
print("Extras:", extras)
```

## 🔷 5) Juntando os dois (muito útil)

Um padrão bem comum: usar **tuplas dentro de conjuntos** para guardar pares únicos.

### ✅ Ex.: pares únicos (severidade, status) encontrados num dataset

```python
bugs = [
    {"sev": "CRITICO", "status": "ABERTO"},
    {"sev": "CRITICO", "status": "ABERTO"},
    {"sev": "ALTO", "status": "FECHADO"},
]

pares_unicos = set()

for b in bugs:
    pares_unicos.add((b["sev"], b["status"]))  # tupla dentro do set

print(pares_unicos)  # {('CRITICO', 'ABERTO'), ('ALTO', 'FECHADO')}
```

👉 Por que isso funciona bem?

- A **tupla** é imutável → pode entrar no set.
- O **set** garante que o par não repita.

## 🔷 6) Pegadinhas que caem em prova

### ⚠️ Tupla com 1 elemento precisa de vírgula

```python
x = (10,)  # tupla
y = (10)   # int
```

### ⚠️ Set vazio não é `{}` (isso é dict)

```python
s = set()  # set vazio
d = {}     # dict vazio
```

### ⚠️ Set não tem índice

```python
s = {"a", "b"}
# s[0]  # ❌ erro
```
