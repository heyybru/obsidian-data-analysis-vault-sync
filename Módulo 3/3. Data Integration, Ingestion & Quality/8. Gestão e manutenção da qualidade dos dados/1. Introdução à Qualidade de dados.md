O material começa esclarecendo uma confusão comum: **Integridade de Dados** e **Qualidade de Dados** não são sinônimos. A integridade é o guarda-chuva que abrange 3 pilares:

```text
┌─────────────────────────────────────────┐
│           INTEGRIDADE DE DADOS           │
│                                          │
│  ┌─────────────┐ ┌─────────────┐ ┌──────┐│
│  │  QUALIDADE  │ │  INTEGRAÇÃO │ │ENRI- ││
│  │  DE DADOS   │ │  DE DADOS   │ │QUECI-││
│  │             │ │             │ │MENTO ││
│  └─────────────┘ └─────────────┘ └──────┘│
└─────────────────────────────────────────┘
```

### 🔍 Cada pilar na prática

|Pilar|O que é|Exemplo no seu dataset|
|:--|:--|:--|
|**Qualidade de Dados**|Dados corretos, completos e confiáveis|Garantir que `experiencia_anos` não tenha texto onde deveria ter número|
|**Integração de Dados**|Visão unificada entre departamentos|RH usa o mesmo ID de candidato que o Financeiro usa pra folha|
|**Enriquecimento de Dados**|Adicionar camadas de informação|Cruzar `localizacao` com dados do IBGE pra adicionar dados demográficos da região|

> 💡 **Frase do material:** _"Quando trabalhamos dados para gerar determinadas respostas e insights, precisamos enriquecê-los com outras fontes para dar mais profundidade à análise."_
