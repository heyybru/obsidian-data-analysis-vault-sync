### 🔶 O que faz `np.array()`?

- Transforma listas, tuplas ou dados em **arrays NumPy** (estruturas rápidas pra cálculos).
- **Vantagem**: Vetorizado (operações 50x mais rápidas que listas Python, per **Cappra Institute**).

**Sintaxe básica:**

```python
import numpy as np

array = np.array([lista_de_dados])
```

---

### 1️⃣ Exemplo simples (QA: tempos de teste)

```python
tempos = [2.1, 3.5, 1.8, 4.2]  # Lista Python
tempos_np = np.array(tempos)

print(tempos_np.mean())  # 2.9 (rápido!)
```

**Saída:** `2.9`

---

### 2️⃣ Exemplo RH: notas de candidatos

```python
notas = np.array([85, 92, 78, 95])
notas_normalizadas = (notas - notas.mean()) / notas.std()  # Z-score
print(notas_normalizadas.round(2))
```

**Saída exemplo:** `[ 0.78 1.56 -1.56 1.56]`

---

### 3️⃣ Parâmetros úteis

- `dtype=np.float64`: Define tipo (números decimais).
- `shape=(linhas, colunas)`: Pra arrays 2D (matrizes).

👉 **Array 2D (tabela mini):**

```python
matriz = np.array([[90, 85], [88, 92]])  # Candidato x critério
print(matriz.mean(axis=1))  # Média por linha: [87.5 90. ]
```
