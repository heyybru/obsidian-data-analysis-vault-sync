Esses três aparecem muito em **cálculos**, **estatística** e **validação** (inclusive em QA: checar periodicidade, ciclos, “é par?”, etc.).

## 🔷 1) Potência (exponenciação)

### ✅ Operador: `**`

```python
print(2 ** 3)   # 8
print(10 ** 2)  # 100
print(9 ** 0.5) # 3.0 (porque é a raiz quadrada)
```

👉 Exemplo (dados/estatística): elevar ao quadrado para variância, distância etc.  
👉 Exemplo (QA): crescimento exponencial de carga em testes de stress.

---

## 🔷 2) Raiz quadrada

Em Python não existe um operador “raiz” dedicado, mas você tem 2 jeitos principais:

### ✅ Opção A: usando potência `** 0.5`

```python
x = 49
raiz = x ** 0.5
print(raiz)  # 7.0
```

### ✅ Opção B (melhor prática): `math.sqrt()`

```python
import math

x = 49
raiz = math.sqrt(x)
print(raiz)  # 7.0
```

⚠️ Observação importante:

- `math.sqrt(x)` **não aceita** número negativo (dá erro).
- Se precisar raiz de negativos (números complexos), usa `cmath`:

```python
import cmath
print(cmath.sqrt(-1))  # 1j
```

## 🔷 3) Módulo (resto da divisão)

### ✅ Operador: `%`

O módulo retorna o **resto** da divisão inteira.

```python
print(10 % 3)  # 1
print(8 % 2)   # 0
```

### ✅ Uso clássico: par/ímpar

```python
n = 7
if n % 2 == 0:
    print("par")
else:
    print("ímpar")
```

### ✅ Uso clássico em ciclos (a cada N itens)

👉 Exemplo QA: “a cada 10 testes, salvar checkpoint”

```python
for i in range(1, 51):
    if i % 10 == 0:
        print(f"Checkpoint no teste {i}")
```

### ✅ Módulo com números negativos (ponto que confunde)

Em Python, o resultado do `%` segue o sinal do **divisor**:

```python
print(-7 % 3)  # 2
```

Isso é útil para normalizar valores em intervalos.

## 🔷 Mini exemplos práticos (bem diretos)

### ✅ Potência: juros compostos (bem comum em administração)

```python
principal = 1000
taxa = 0.02
meses = 12

montante = principal * ((1 + taxa) ** meses)
print(montante)
```

### ✅ Raiz quadrada: desvio padrão (ideia)

```python
import math

variancia = 25
desvio_padrao = math.sqrt(variancia)
print(desvio_padrao)  # 5.0
```

### ✅ Módulo: validar periodicidade (ex.: rodar job semanal)

```python
dia = 14
if dia % 7 == 0:
    print("Dia de executar tarefa semanal")
```
