**Tratamento de I/O** é basicamente: **evitar que seu programa quebre** quando:

- o usuário digita algo errado,
- o arquivo não existe,
- o CSV vem com separador diferente,
- tem dado faltando,
- a codificação dá erro (acentos),
- o disco está cheio / sem permissão.

Vou te mostrar o que mais cai na prática, com exemplos bem diretos (RH/QA).

## 🔷 1) Tratamento de entrada via `input()` (usuário)

### ✅ Validar e converter com loop (padrão ouro)

```python
def ler_int(msg, minimo=None, maximo=None):
    while True:
        valor = input(msg).strip()
        try:
            n = int(valor)
            if minimo is not None and n < minimo:
                print(f"⚠️ Digite um número >= {minimo}.")
                continue
            if maximo is not None and n > maximo:
                print(f"⚠️ Digite um número <= {maximo}.")
                continue
            return n
        except ValueError:
            print("⚠️ Entrada inválida. Digite um número inteiro.")
```

👉 Uso:

```python
idade = ler_int("Idade: ", minimo=18, maximo=80)
print(f"Idade válida: {idade}")
```

### ✅ Para `float` (ex.: salário)

```python
def ler_float(msg, minimo=None):
    while True:
        valor = input(msg).strip().replace(",", ".")
        try:
            x = float(valor)
            if minimo is not None and x < minimo:
                print(f"⚠️ Digite um valor >= {minimo}.")
                continue
            return x
        except ValueError:
            print("⚠️ Entrada inválida. Digite um número (ex.: 3500.50).")
```

## 🔷 2) Tratamento de leitura de arquivo (`open`)

### ✅ Leitura segura (com mensagens claras)

```python
from pathlib import Path

def ler_texto(caminho):
    caminho = Path(caminho)
    try:
        return caminho.read_text(encoding="utf-8")
    except FileNotFoundError:
        print(f"❌ Arquivo não encontrado: {caminho}")
    except PermissionError:
        print(f"❌ Sem permissão para ler: {caminho}")
    except UnicodeDecodeError:
        print(f"❌ Erro de codificação. Tente 'latin-1': {caminho}")
    return None
```

👉 Uso:

```python
conteudo = ler_texto("log_teste.txt")
if conteudo:
    print(conteudo[:200])
```

### ✅ Fallback de encoding (muito comum em CSV “quebrado”)

```python
def ler_texto_com_fallback(caminho, encodings=("utf-8", "latin-1")):
    for enc in encodings:
        try:
            with open(caminho, "r", encoding=enc) as f:
                return f.read()
        except UnicodeDecodeError:
            continue
    raise UnicodeDecodeError("Falha ao decodificar com utf-8/latin-1", b"", 0, 1, "encoding")
```

## 🔷 3) Tratamento de escrita de arquivo (saída)

### ✅ Escrita segura + criação de pasta

```python
from pathlib import Path

def escrever_texto(caminho, conteudo):
    caminho = Path(caminho)
    try:
        caminho.parent.mkdir(parents=True, exist_ok=True)  # cria pastas
        caminho.write_text(conteudo, encoding="utf-8")
        return True
    except PermissionError:
        print(f"❌ Sem permissão para escrever: {caminho}")
    except OSError as e:
        print(f"❌ Erro do sistema ao escrever ({e}): {caminho}")
    return False
```

👉 Uso:

```python
ok = escrever_texto("saida/relatorio_qa.txt", "Relatório OK\n")
print("✅ Salvo" if ok else "❌ Falhou")
```

## 🔷 4) Tratamento de CSV/Excel com Pandas (entrada e saída)

### ✅ Leitura robusta de CSV

Erros comuns: separador errado `;` vs `,`, encoding, colunas faltando.

```python
import pandas as pd

def ler_csv_robusto(caminho):
    erros = []
    for enc in ("utf-8", "latin-1"):
        for sep in (",", ";"):
            try:
                df = pd.read_csv(caminho, encoding=enc, sep=sep)
                return df
            except Exception as e:
                erros.append((enc, sep, str(e)))
    print("❌ Não consegui ler o CSV. Tentativas:")
    for enc, sep, msg in erros[:4]:
        print(f"  - encoding={enc}, sep='{sep}': {msg[:120]}")
    return None
```

### ✅ Validação do schema (colunas obrigatórias)

```python
def validar_colunas(df, obrigatorias):
    faltando = [c for c in obrigatorias if c not in df.columns]
    if faltando:
        raise ValueError(f"Colunas obrigatórias ausentes: {faltando}")
```

👉 Exemplo QA (bugs):

```python
df = ler_csv_robusto("bugs.csv")
if df is not None:
    validar_colunas(df, ["id", "severidade", "modulo"])
```

### ✅ Escrita segura (CSV/Excel)

```python
def salvar_csv(df, caminho):
    try:
        df.to_csv(caminho, index=False, encoding="utf-8")
        return True
    except Exception as e:
        print(f"❌ Falha ao salvar CSV: {e}")
        return False

def salvar_excel(df, caminho, aba="Dados"):
    try:
        df.to_excel(caminho, index=False, sheet_name=aba)
        return True
    except Exception as e:
        print(f"❌ Falha ao salvar Excel: {e}")
        return False
```

## 🔷 5) Tratamento de I/O em APIs (requests)

### ✅ Timeout + checagem de status + JSON seguro

```python
import requests

def get_json(url, timeout=10):
    try:
        r = requests.get(url, timeout=timeout)
        r.raise_for_status()  # dispara erro se 4xx/5xx
        return r.json()
    except requests.exceptions.Timeout:
        print("❌ Timeout na requisição.")
    except requests.exceptions.HTTPError as e:
        print(f"❌ HTTP error: {e}")
    except ValueError:
        print("❌ Resposta não é JSON válido.")
    except requests.exceptions.RequestException as e:
        print(f"❌ Erro de rede: {e}")
    return None
```

## 🔷 7) Mini “checklist” de I/O profissional

✅ **Entrada (Input)**

- Validar tipo (`int`, `float`, datas)
- Tratar vazio e espaços (`strip`)
- Definir faixa mínima/máxima
- Mensagens claras de erro

✅ **Arquivos (Input/Output)**

- `try/except` para FileNotFound, Permission, Unicode
- Criar pastas automaticamente antes de salvar
- Tratar `encoding` e `sep` em CSV
- Validar colunas antes de processar

✅ **Automação**

- Usar `logging`
- Guardar outputs em `data/processed/` e `reports/`
- Nunca “engolir” erro silenciosamente (logar!)
