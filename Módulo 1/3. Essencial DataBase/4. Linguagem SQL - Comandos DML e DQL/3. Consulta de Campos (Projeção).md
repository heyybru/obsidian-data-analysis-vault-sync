## 📘 Comando SELECT

### 🔹 O que é projeção?

👉 **Projeção** é quando você escolhe **quais colunas (campos)** quer ver no resultado da consulta.

📌 Diferente de trazer tudo, você traz **só o que interessa**.

---

## 🧩 Sintaxe básica

```sql
SELECT coluna1, coluna2
FROM nome_tabela;
```

---

## 🔹 Exemplo simples

Tabela: **COLABORADOR**

```sql
SELECT nome, cargo
FROM COLABORADOR;
```

👉 Retorna **apenas** nome e cargo.

---

## 🔹 SELECT * (todas as colunas)

```sql
SELECT *
FROM COLABORADOR;
```

📌 Não é projeção específica, pois traz **todos os campos**.

---

## 🔹 Projeção com alias (apelido - comando ~={red}AS=~)

```sql
SELECT nome AS Nome_Colaborador,
       cargo AS Funcao
FROM COLABORADOR;
```

👉 Só muda o **nome exibido**, não o nome real da coluna.

---

## 🔹 Projeção com cálculo

```sql
SELECT nome,
       salario,
       salario * 1.10 AS salario_com_aumento
FROM COLABORADOR;
```

---

## 🔹 Projeção com função

```sql
SELECT COUNT(*) AS total_colaboradores
FROM COLABORADOR;
```

---

## 🧠 Resumo rápido

- Projeção = escolher colunas
    
- `SELECT coluna1, coluna2`
    
- `SELECT *` traz tudo
    
- `AS` cria apelidos
    
- Pode usar cálculos e funções
