## 🔷 Laços e Variáveis: Como interagem

Vamos explorar como **variáveis se comportam dentro e fora de loops**, um conceito crucial para evitar bugs e escrever código eficiente.

---

## 🔷 1) **Variáveis dentro vs fora do loop**

### ✅ **Exemplo 1: Contador dentro do loop** (reinicia a cada iteração)

```python
for i in range(3):
    contador = 0  # Reinicia a cada iteração!
    contador += 1
    print(f"Iteração {i}: contador = {contador}")
# Saída: contador sempre será 1
```

### ✅ **Exemplo 2: Contador fora do loop** (acumula)

```python
contador = 0  # Fora do loop - mantém valor
for i in range(3):
    contador += 1
    print(f"Iteração {i}: contador = {contador}")
# Saída: 1, 2, 3
```

---

## 🔷 2) **Escopo de variáveis em loops**

### ✅ **`for` loop cria nova variável a cada iteração**:

```python
bugs = ["CRITICO", "ALTO", "MEDIO"]

for severidade in bugs:
    # 'severidade' é uma NOVA variável a cada iteração
    print(f"Processando: {severidade}")

# Após o loop, 'severidade' mantém o ÚLTIMO valor
print(f"Última severidade processada: {severidade}")  # "MEDIO"
```

### ✅ **`while` loop reusa a mesma variável**:

```python
contador = 0
while contador < 3:
    # 'contador' é a MESMA variável modificada
    contador += 1
    print(f"Contador: {contador}")
```

## 🔷 3) **Acumuladores padrão (muito comuns)**

### ✅ **RH: Somar salários**:

```python
salarios = [5000, 6000, 7000, 5500]

# Acumulador FORA do loop
total_salarios = 0

for salario in salarios:
    total_salarios += salario  # Acumula

print(f"Total salários: R$ {total_salarios}")
print(f"Média: R$ {total_salarios / len(salarios):.2f}")
```

### ✅ **QA: Contar bugs por tipo**:

```python
bugs = ["CRITICO", "ALTO", "CRITICO", "BAIXO", "ALTO", "CRITICO"]

# Múltiplos acumuladores
criticos = 0
altos = 0
outros = 0

for bug in bugs:
    if bug == "CRITICO":
        criticos += 1
    elif bug == "ALTO":
        altos += 1
    else:
        outros += 1

print(f"Críticos: {criticos}, Altos: {altos}, Outros: {outros}")
```

## 🔷 4) **Variáveis de controle de fluxo**

### ✅ **Encontrar primeiro bug crítico**:

```python
bugs = ["BAIXO", "MEDIO", "CRITICO", "ALTO", "CRITICO"]

primeiro_critico_encontrado = None
indice_primeiro_critico = -1

for indice, bug in enumerate(bugs):
    if bug == "CRITICO" and primeiro_critico_encontrado is None:
        primeiro_critico_encontrado = bug
        indice_primeiro_critico = indice
        break  # Para no primeiro encontrado

print(f"Primeiro crítico: {primeiro_critico_encontrado} no índice {indice_primeiro_critico}")
```

## 🔷 5) **Variáveis booleanas como flags**

### ✅ **Verificar se TODOS os testes passaram**:

```python
resultados_testes = [True, True, True, False, True]

todos_passaram = True  # Flag inicial

for resultado in resultados_testes:
    if not resultado:  # Se algum falhar
        todos_passaram = False
        break  # Não precisa continuar

print(f"Todos os testes passaram? {todos_passaram}")
```

### ✅ **Verificar se ALGUM teste falhou**:

```python
resultados_testes = [True, True, True, False, True]

algum_falhou = False  # Flag inicial

for resultado in resultados_testes:
    if not resultado:  # Se algum falhar
        algum_falhou = True
        break  # Já sabemos que algum falhou

print(f"Algum teste falhou? {algum_falhou}")
```

## 🔷 6) **Variáveis temporárias vs permanentes**

### ✅ **Processar lote de bugs**:

```python
bugs_por_dia = [
    ["CRITICO", "ALTO", "BAIXO"],    # Dia 1
    ["MEDIO", "BAIXO"],              # Dia 2
    ["CRITICO", "CRITICO", "ALTO"],  # Dia 3
]

# Variável PERMANENTE (fora dos loops)
total_bugs_criticos = 0

for dia, bugs_do_dia in enumerate(bugs_por_dia, start=1):
    # Variável TEMPORÁRIA (dentro do loop externo)
    criticos_no_dia = 0
    
    for bug in bugs_do_dia:
        if bug == "CRITICO":
            criticos_no_dia += 1
    
    # Acumula no total permanente
    total_bugs_criticos += criticos_no_dia
    
    print(f"Dia {dia}: {criticos_no_dia} bugs críticos")

print(f"\nTotal geral: {total_bugs_criticos} bugs críticos")
```

## 🔷 7) **Variáveis com `global` (cuidado!)**

### ✅ **Modificar variável global dentro do loop**:

```python
total_processado = 0

def processar_bugs(bugs):
    global total_processado  # Declara que vamos modificar a global
    
    for bug in bugs:
        # Modifica a variável global
        total_processado += 1
        print(f"Processando bug {total_processado}: {bug}")

bugs = ["Bug1", "Bug2", "Bug3"]
processar_bugs(bugs)
print(f"Total processado: {total_processado}")
```

## 🔷 8) **Padrão: Coletor de resultados**

### ✅ **RH: Coletar candidatos aprovados**:

```python
candidatos = [
```

## 🔷 9) **Erros comuns com variáveis em loops**

### ❌ **Erro 1: Reiniciar acumulador dentro do loop**:

```python
# ❌ ERRADO
for i in range(5):
    total = 0  # Reinicia a cada iteração!
    total += i
    print(total)  # Sempre 0, 1, 2, 3, 4

# ✅ CORRETO
total = 0  # Fora do loop
for i in range(5):
    total += i
    print(total)  # 0, 1, 3, 6, 10
```

### ❌ **Erro 2: Modificar lista enquanto itera**:

```python
bugs = ["CRITICO", "ALTO", "BAIXO", "MEDIO"]

# ❌ ERRADO (pode pular elementos)
for i, bug in enumerate(bugs):
    if bug == "BAIXO":
        del bugs[i]  # Modifica a lista durante iteração

# ✅ CORRETO (cria nova lista)
bugs_filtrados = []
for bug in bugs:
    if bug != "BAIXO":
        bugs_filtrados.append(bug)
```

## 🔷 10) **Exercício prático: Sistema de análise QA**

```python
class AnalisadorQA:
    def __init__(self):
        self.metricas = {
            "total_bugs": 0,
            "bugs_criticos": 0,
            "bugs_abertos": 0,
            "tempo_total_resolucao": 0
        }
    
    def processar_relatorio(self, relatorio):
        """Processa relatório de bugs usando variáveis em loops"""
        
        # Variáveis temporárias para cálculo
        dias_resolucao = []
        
        for bug in relatorio:
            # Atualiza métricas
            self.metricas["total_bugs"] += 1
            
            if bug["severidade"] == "CRITICO":
                self.metricas["bugs_criticos"] += 1
            
            if bug["status"] == "ABERTO":
                self.metricas["bugs_abertos"] += 1
            
            # Coleta dados para cálculo posterior
            if "dias_para_resolver" in bug:
                dias_resolucao.append(bug["dias_para_resolver"])
        
        # Calcula estatísticas após loop
        if dias_resolucao:
            self.metricas["tempo_total_resolucao"] = sum(dias_resolucao)
            self.metricas["media_resolucao"] = sum(dias_resolucao) / len(dias_resolucao)
        
        return self.metricas

# Dados de exemplo
relatorio_bugs = [
    {"id": 1, "severidade": "CRITICO", "status": "FECHADO", "dias_para_resolver": 2},
    {"id": 2, "severidade": "ALTO", "status": "ABERTO"},
    {"id": 3, "severidade": "CRITICO", "status": "FECHADO", "dias_para_resolver": 5},
    {"id": 4, "severidade": "BAIXO", "status": "FECHADO", "dias_para_resolver": 1},
]

# Executar análise
analisador = AnalisadorQA()
resultados = analisador.processar_relatorio(relatorio_bugs)

print("📊 Métricas QA:")
for metrica, valor in resultados.items():
    print(f"  {metrica}: {valor}")
```

## 📋 **Resumo: Boas práticas**

1. **Acumuladores**: Declare **fora** do loop
2. **Flags booleanas**: Use para controle de fluxo
3. **Coletores**: Use listas para coletar resultados
4. **Escopo**: Entenda onde a variável "vive"
5. **Não modifique**: Listas durante iteração
6. **Use `enumerate`**: Quando precisar do índice
7. **Break cedo**: Para otimizar performance
