### **O Que é Combinar/Mesclar Datasets?**

- **Combinar (Concat)**: Empilhar linhas (ex: 2 sheets vendas Jan+Fe v → 1 dataset).
- **Mesclar (Merge/Join)**: Juntar colunas por chave comum (ex: vendas + clientes por ID).
- **Por quê?**: Integra fontes, evita duplicatas, enriquece dados (**Metricas Boss** benchmarks: +50% acurácia).

### **Tipos de Mesclagem (Joins)**

- **Inner**: Só registros comuns (ex: vendas com cliente ID).
- **Left**: Tudo do esquerdo + match direito.
- **Right/Full**: Tudo dos dois. Ex: Dataset1 (ID, vendas) + Dataset2 (ID, nome) → Inner: só IDs válidos.

### **Como Fazer no Google Sheets (Manual/Fácil)**

1. Abra 2 sheets (ex: Vendas.xlsx + Clientes.xlsx).
2. Copie colunas chave (ID) lado a lado.
3. Inserir > Função VLOOKUP: `=VLOOKUP(A2, Clientes!A:B, 2, FALSE)` – puxa nome por ID.
4. QUERY pra mesclar: `=QUERY({Vendas!A:D; Clientes!A:B}, "select *")`. Ex: No workbook_v1.xlsx, mescle "Processos" + "Notas" por id_candidato → salário + nota.

### **Exemplo Prático em Pandas (Python)**

```python
import pandas as pd

df1 = pd.read_excel('vendas.xlsx')  # Cols: ID, valor
df2 = pd.read_excel('clientes.xlsx')  # Cols: ID, nome

# Concat linhas
df_concat = pd.concat([df1, df2], ignore_index=True)

# Merge inner
df_merge = pd.merge(df1, df2, on='ID', how='inner')

print(df_merge.head())  # ID, valor, nome
```

**Insight**: Dataset mesclado revela top clientes (ROI +40%, **Snaq.co**).

### **Dicas e Cuidados**

- **Limpe antes**: Duplicatas/nulls (df.drop_duplicates()).
- **Chaves**: Garanta match (string/float padronize).
- **Performance**: Grandes dados? Use Dask ou SQL (**AILabs** tip).
