## 🔹 O que são funções de uma única linha?

👉 São funções que **atuam em cada registro individualmente**.

📌 Para **cada linha da tabela**, a função gera **um resultado**.

---

## 🧩 Tipos mais comuns

- Funções **numéricas**
    
- Funções de **texto**
    
- Funções de **data**
    
- Funções de **conversão**
    
- **Operações entre campos**

---

## 🔢 Operações entre campos

Permitem fazer **cálculos usando colunas da tabela**.

### 🔹 Exemplo básico

Tabela: **PRODUTO**

```sql
SELECT nome_produto,
       preco,
       quantidade,
       preco * quantidade AS valor_total
FROM PRODUTO;
```

👉 Calcula o valor total **linha por linha**.

---

## 🔹 Operações matemáticas comuns

|Operação|Símbolo|
|---|---|
|Soma|+|
|Subtração|-|
|Multiplicação|*|
|Divisão|/|

Exemplo:

```sql
SELECT salario,
       salario + 500 AS salario_reajustado
FROM COLABORADOR;
```

---

## 🔹 Funções numéricas (uma linha)

```sql
SELECT salario,
       ROUND(salario, 2)
FROM COLABORADOR;
```

Outras comuns:

- `ROUND()` → arredonda
    
- `TRUNC()` → corta casas decimais
    
- `ABS()` → valor absoluto

---

## 🔤 Funções de texto

```sql
SELECT UPPER(nome),
       LOWER(cargo),
       LENGTH(nome)
FROM COLABORADOR;
```

- `UPPER()` → maiúsculo
    
- `LOWER()` → minúsculo
    
- `LENGTH()` → tamanho

---

## 📅 Funções de data (Oracle)

```sql
SELECT SYSDATE FROM dual;
```

```sql
SELECT nome,
       data_admissao,
       data_admissao + 30 AS fim_experiencia
FROM COLABORADOR;
```

---

## 🔁 Funções de conversão

```sql
SELECT TO_CHAR(salario, '9999.99')
FROM COLABORADOR;
```

```sql
SELECT TO_NUMBER('1500')
FROM dual;
```

---

## 🧠 Diferença importante

|Tipo|Atua em|
|---|---|
|Função de uma linha|Cada registro|
|Função de grupo|Conjunto de registros|

---

## 📌 Resumo rápido

- Funções de uma linha → linha a linha
    
- Operações entre campos usam + - * /
    
- Podem usar alias (`AS`)
    
- Muito comum em SELECT
