## 🔷 1. O Básico: O Que é Multiplicação de Matriz?

### ✅ **Definição simples**:

Dadas duas matrizes **A** (m×n) e **B** (n×p), o produto **C = A × B** é uma matriz **m×p** onde:

```
C[i][j] = soma(A[i][k] × B[k][j]) para k = 1 até n
```

### ✅ **Regra fundamental**:

- **A** deve ter **n** colunas
- **B** deve ter **n** linhas
- Resultado tem dimensões: **(linhas de A) × (colunas de B)**

```
A (3×2) × B (2×4) = C (3×4)  ✅
A (2×3) × B (2×3) = ❌ (não compatível)
```

## 🔷 3. Implementação em Python

### ✅ **Implementação básica (puro Python)**:

```python
def multiplicar_matrizes(A, B):
    """Multiplica duas matrizes A e B"""
    # Verificar compatibilidade
    linhas_A, colunas_A = len(A), len(A[0])
    linhas_B, colunas_B = len(B), len(B[0])
    
    if colunas_A != linhas_B:
        raise ValueError(f"Matrizes incompatíveis: A({linhas_A}x{colunas_A}) × B({linhas_B}x{colunas_B})")
    
    # Criar matriz resultado com zeros
    C = [[0 for _ in range(colunas_B)] for _ in range(linhas_A)]
    
    # Multiplicação
    for i in range(linhas_A):           # Para cada linha de A
        for j in range(colunas_B):      # Para cada coluna de B
            soma = 0
            for k in range(colunas_A):  # Para cada elemento na linha/coluna
                soma += A[i][k] * B[k][j]
            C[i][j] = soma
    
    return C

# Teste
A = [[1, 2], [3, 4]]
B = [[5, 6], [7, 8]]
C = multiplicar_matrizes(A, B)
print("Resultado manual:", C)
# [[19, 22], [43, 50]]
```

## 🔷 4. Propriedades Importantes

### ✅ **NÃO comutativa**:

```python
A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])

print("A × B:")
print(A @ B)
# [[19 22]
#  [43 50]]

print("\nB × A:")
print(B @ A)
# [[23 34]
#  [31 46]]

print("\nA × B ≠ B × A:", not np.array_equal(A @ B, B @ A))
```

### ✅ **Associativa**:

```python
A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])
C = np.array([[9, 10], [11, 12]])

# (A × B) × C = A × (B × C)
esquerda = (A @ B) @ C
direita = A @ (B @ C)

print("(A × B) × C:")
print(esquerda)
print("\nA × (B × C):")
print(direita)
print("\nSão iguais?", np.array_equal(esquerda, direita))
```

### ✅ **Distributiva**:

```python
A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])
C = np.array([[9, 10], [11, 12]])

# A × (B + C) = A×B + A×C
esquerda = A @ (B + C)
direita = (A @ B) + (A @ C)

print("A × (B + C):")
print(esquerda)
print("\nA×B + A×C:")
print(direita)
print("\nSão iguais?", np.array_equal(esquerda, direita))
```

### ✅ **Elemento neutro (matriz identidade)**:

```python
I = np.eye(2)  # Matriz identidade 2×2
A = np.array([[1, 2], [3, 4]])

print("Matriz identidade I:")
print(I)
print("\nA × I:")
print(A @ I)
print("\nI × A:")
print(I @ A)
print("\nA × I = I × A = A?", np.array_equal(A @ I, I @ A) and np.array_equal(A @ I, A))
```

## 🔷 5. Tipos Especiais de Multiplicação

### ✅ **Multiplicação elemento a elemento (Hadamard)**:

```python
A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])

# Elemento a elemento (não é multiplicação de matriz!)
C = A * B
print("Multiplicação elemento a elemento (A * B):")
print(C)
# [[ 5 12]
#  [21 32]]
```

### ✅ **Produto escalar (dot product)**:

```python
# Vetores
v1 = np.array([1, 2, 3])
v2 = np.array([4, 5, 6])

# Produto escalar
dot_product = np.dot(v1, v2)  # 1×4 + 2×5 + 3×6 = 32
print(f"Produto escalar v1·v2 = {dot_product}")

# Ou usando @ para vetores
dot_product = v1 @ v2
print(f"v1 @ v2 = {dot_product}")
```

### ✅ **Produto externo (outer product)**:

```python
v1 = np.array([1, 2, 3])
v2 = np.array([4, 5, 6])

outer = np.outer(v1, v2)
print("Produto externo v1 ⊗ v2:")
print(outer)
# [[ 4  5  6]
#  [ 8 10 12]
#  [12 15 18]]
```

### ✅ **Produto de Kronecker**:

```python
A = np.array([[1, 2], [3, 4]])
B = np.array([[0, 5], [6, 7]])

kron = np.kron(A, B)
print("Produto de Kronecker A ⊗ B:")
print(kron)
# [[ 0  5  0 10]
#  [ 6  7 12 14]
#  [ 0 15  0 20]
#  [18 21 24 28]]
```

import numpy as np

# Matriz de habilidades (candidatos × habilidades)

habilidades_candidatos = np.array([
    [1, 0, 1, 0, 1],  # Candidato 1: Python, SQL, Git

    [1, 1, 0, 0, 1],  # Candidato 3: Python, Java, Git
    [0, 0, 1, 1, 1],  # Candidato 4: SQL, Docker, Git
    [1, 0, 0, 1, 0]   # Candidato 5: Python, Docker

# Matriz de requisitos da vaga (habilidades × pesos)
# Quanto mais importante a habilidade, maior o peso

    [3.0],  # Python: peso 3

    [1.5],  # SQL: peso 1.5

    [0.5]   # Git: peso 0.5

# Calcular score de cada candidato
scores = habilidades_candidatos @ pesos_vaga

print("📊 SCORES DOS CANDIDATOS PARA A VAGA:")

    print(f"Candidato {i+1}: {score[0]:.1f} pontos")

candidatos_ordenados = np.argsort(scores.flatten())[::-1] + 1

# Matriz de transição de estados (Cadeia de Markov)
# Estados: [Ativo, Desligado, Promovido]
transicao = np.array([
    [0.85, 0.10, 0.05],  # Ativo → Ativo: 85%, Desligado: 10%, Promovido: 5%
    [0.00, 1.00, 0.00],  # Desligado → Sempre desligado (estado absorvente)
    [0.90, 0.05, 0.05]   # Promovido → Ativo: 90%, Desligado: 5%, Promovido: 5%
])

# Estado inicial: 1000 funcionários ativos
estado_inicial = np.array([[1000, 0, 0]])

# Prever após 12 meses (1 ano)
estado_12_meses = estado_inicial @ np.linalg.matrix_power(transicao, 12)

print("📈 PREVISÃO DE TURNOVER APÓS 12 MESES:")
print(f"Ativos: {estado_12_meses[0, 0]:.0f} funcionários")
print(f"Desligados: {estado_12_meses[0, 1]:.0f} funcionários")
print(f"Promovidos: {estado_12_meses[0, 2]:.0f} funcionários")
print(f"Taxa de turnover: {(estado_12_meses[0, 1] / 1000 * 100):.1f}%")
