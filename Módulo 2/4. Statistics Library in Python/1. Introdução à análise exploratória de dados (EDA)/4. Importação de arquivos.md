No **Pandas**, importar arquivo significa **ler dados externos** e transformar em um **DataFrame**.  
É um dos primeiros passos da **análise exploratória de dados**.

A lógica é sempre:

1. **importar o pandas**
2. **ler o arquivo**
3. **guardar em uma variável**
4. **inspecionar com `head()`, `info()` e `describe()`**

---

## 1. Importando o Pandas

```python
import pandas as pd
```

Esse `pd` é só um apelido padrão da biblioteca.

---

## 2. Importando arquivos CSV

### CSV simples

```python
import pandas as pd

df = pd.read_csv("arquivo.csv")
df.head()
```

### CSV com separador `;`

Muito comum no Brasil:

```python
df = pd.read_csv("arquivo.csv", sep=";")
df.head()
```

### CSV com encoding diferente

Às vezes o arquivo vem com caracteres estranhos. Tente:

```python
df = pd.read_csv("arquivo.csv", sep=";", encoding="latin1")
```

ou:

```python
df = pd.read_csv("arquivo.csv", sep=";", encoding="utf-8")
```

---

## 3. Importando arquivos Excel

### Excel `.xlsx`

```python
import pandas as pd

df = pd.read_excel("arquivo.xlsx")
df.head()
```

### Escolhendo uma aba específica

```python
df = pd.read_excel("arquivo.xlsx", sheet_name="Plan1")
```

ou pela posição da aba:

```python
df = pd.read_excel("arquivo.xlsx", sheet_name=0)
```

### Ver nomes das abas

```python
arquivo = pd.ExcelFile("arquivo.xlsx")
print(arquivo.sheet_names)
```

---

## 4. Importando arquivo TXT

Se estiver separado por tabulação:

```python
df = pd.read_csv("arquivo.txt", sep="\t")
```

---

## 5. Importando JSON

```python
import pandas as pd

df = pd.read_json("arquivo.json")
df.head()
```

---

## 6. Importando de URL

Se o arquivo estiver em um link direto:

```python

df = pd.read_csv("https://exemplo.com/dados.csv")
```

## 8. Como saber qual função usar

### Regra prática

- **`.csv`** → `pd.read_csv()`
- **`.xlsx`** → `pd.read_excel()`
- **`.json`** → `pd.read_json()`
- **`.txt`** → `pd.read_csv()` com separador adequado

---

## 9. Principais problemas na importação

### Arquivo não encontrado

Erro comum:

```python
FileNotFoundError
```

**Causa:** caminho errado ou nome diferente.

### Separador errado

Quando tudo vem em uma única coluna.

Exemplo:

```python
df = pd.read_csv("arquivo.csv", sep=";")
```

se o separador real for `,`, o DataFrame fica errado.

### Encoding errado

Caracteres como:

- `Ã£`
- `Ã§`
- `�`

Isso geralmente se resolve com:

```python
encoding="latin1"
```

ou

```python
encoding="utf-8"
```

## 10. Diagnóstico inicial depois de importar

Depois de ler um arquivo, rode sempre:

```python
df.head()
df.shape
df.info()
df.describe()
```

### O que cada um faz

- `head()` → mostra primeiras linhas
- `shape` → quantidade de linhas e colunas
- `info()` → tipos e nulos
- `describe()` → resumo estatístico

---

## Exemplo completo com CSV

```python
import pandas as pd

df = pd.read_csv("/Users/brunosouza/Downloads/clientes.csv", sep=";")

print(df.head())
print(df.shape)
print(df.info())
print(df.describe())
```

---

## Exemplo completo com Excel

```python
import pandas as pd

df = pd.read_excel("/Users/brunosouza/Downloads/relatorio.xlsx")

print(df.head())
print(df.shape)
print(df.info())
print(df.describe())
```

---

## Boas práticas

- sempre verificar a **extensão do arquivo**
- sempre testar `head()` logo após importar
- usar `info()` para validar tipos
- checar se as colunas vieram separadas corretamente
- se tudo vier em uma coluna no CSV, revisar o `sep`
