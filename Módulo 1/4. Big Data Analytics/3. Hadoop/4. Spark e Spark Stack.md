**Spark é como um "MapReduce turbo" que roda na memória RAM**.  
Enquanto Hadoop escreve no disco a cada passo, Spark mantém tudo na memória, sendo **100x mais rápido**.

✅ **No seu contexto (RH + QA)**:

- **RH**: Analisar milhões de candidatos em segundos (não horas)
- **QA**: Processar logs em tempo real durante testes

---

## 🔷 O Problema do Hadoop/MapReduce

### ❌ **Hadoop é lento porque**:

1. **I/O disco constante**: Lê/grava disco entre Map e Reduce
2. **Não reutiliza dados**: Cada job recarrega dados do HDFS
3. **Batch-only**: Não suporta streaming bem
4. **Programação complexa**: Java API verbosa

### ✅ **Spark resolve com**:

1. **Processamento em memória**: 100x mais rápido
2. **Reutilização de dados**: Cache em RAM entre operações
3. **Suporte nativo a streaming, SQL, ML, Graph**
4. **APIs em Python, Scala, Java, R**

---

## 🔷 Arquitetura do Spark

```
[Driver Program] → [SparkContext] → [Cluster Manager]
                          ↓
                  [Worker Nodes]
                  /     |     \
          [Executor] [Executor] [Executor]
             /          |          \
        [Task]       [Task]       [Task]
```

**Componentes**:

1. **Driver**: Programa principal (seu código)
2. **SparkContext**: Conexão com cluster
3. **Cluster Manager**: YARN, Mesos, Kubernetes ou Standalone
4. **Executors**: Processam tarefas nos workers
5. **Tasks**: Unidades de trabalho paralelas

## 🔷 RDD (Resilient Distributed Dataset) - O coração do Spark

**RDD** = Coleção imutável de objetos distribuídos pela rede.

### ✅ **Criando RDDs**:

```python
# Do Python collections
rdd = sc.parallelize([1, 2, 3, 4, 5])

# De arquivos
rdd = sc.textFile("hdfs:///user/bruno/data.txt")

# De DataFrames
df = spark.read.csv("data.csv")
rdd = df.rdd
```

### ✅ **Transformações (lazy)**:

```python
# Não executa imediatamente
rdd2 = rdd.filter(lambda x: x > 3)  # Filtra
rdd3 = rdd2.map(lambda x: x * 2)   # Transforma
rdd4 = rdd3.reduce(lambda a, b: a + b)  # Agrega
```

### ✅ **Ações (executam)**:

```python
# Disparam computação
resultado = rdd4.collect()  # Traz para driver
contagem = rdd4.count()     # Conta elementos
primeiro = rdd4.first()      # Primeiro elemento
```

```python
from pyspark.sql import SparkSession
```

## 🔷 Spark Streaming (tempo real)

### ✅ **Processar logs de QA em tempo real**

```python
from pyspark.streaming import StreamingContext

# Criar contexto de streaming (batch a cada 10 segundos)
ssc = StreamingContext(sc, 10)

# Monitorar diretório HDFS
logs_stream = ssc.textFileStream("hdfs:///user/bruno/qa/logs/")

# Processar cada batch
def processar_batch(rdd):
    if not rdd.isEmpty():
        # Contar erros por tipo
        erros = rdd.filter(lambda linha: "ERROR" in linha) \
                   .map(lambda linha: (linha.split()[2], 1)) \
                   .reduceByKey(lambda a, b: a + b)
        
        erros.pprint()

# Aplicar função a cada batch
logs_stream.foreachRDD(processar_batch)

# Iniciar streaming
ssc.start()
ssc.awaitTermination()
```

## 🔷 MLlib (Machine Learning)

### ✅ **Prever turnover de funcionários**

```python
from pyspark.ml.classification import RandomForestClassifier
from pyspark.ml.feature import VectorAssembler
from pyspark.ml.evaluation import BinaryClassificationEvaluator

# Carregar dados históricos
historico_df = spark.read.csv("turnover_historico.csv", header=True, inferSchema=True)

# Features: tempo_empresa, avaliacao, salario, etc
assembler = VectorAssembler(
    inputCols=["tempo_empresa", "avaliacao", "salario", "idade"],
    outputCol="features"
)

# Transformar
dados_treinamento = assembler.transform(historico_df)

# Dividir treino/teste
treino, teste = dados_treinamento.randomSplit([0.7, 0.3])

# Treinar modelo
rf = RandomForestClassifier(
    labelCol="saiu",
    featuresCol="features",
    numTrees=100
)

modelo = rf.fit(treino)

# Previsões
previsoes = modelo.transform(teste)

# Avaliar
evaluator = BinaryClassificationEvaluator(labelCol="saiu")
auc = evaluator.evaluate(previsoes)
print(f"AUC: {auc}")  # 0.85 = bom modelo
```

### ✅ **Clusterizar bugs por similaridade**

```python
from pyspark.ml.clustering import KMeans
from pyspark.ml.feature import Tokenizer, HashingTF

# Carregar descrições de bugs
bugs_df = spark.read.csv("bugs_descricoes.csv", header=True)

# Extrair features de texto
tokenizer = Tokenizer(inputCol="descricao", outputCol="palavras")
palavras_df = tokenizer.transform(bugs_df)

hashing_tf = HashingTF(inputCol="palavras", outputCol="features", numFeatures=1000)
features_df = hashing_tf.transform(palavras_df)

# Clusterizar
kmeans = KMeans(k=5)  # 5 clusters
modelo = kmeans.fit(features_df)

# Prever cluster para novos bugs
bugs_com_cluster = modelo.transform(features_df)
bugs_com_cluster.select("id_bug", "prediction").show()
```

```python
from pyspark.graphframes import GraphFrame

# Vértices: desenvolvedores
vertices = spark.createDataFrame([
```

### ✅ **Arquitetura proposta**:

```
[Kafka] → [Spark Streaming] → [Spark SQL] → [MLlib] → [Dashboard]
   ↓            ↓                ↓            ↓          ↓
```

### ✅ **Código completo (PySpark)**:

```python
from pyspark.sql import SparkSession
from pyspark.sql.functions import *
from pyspark.ml.feature import *
from pyspark.ml.classification import *

# 1. Inicializar Spark
spark = SparkSession.builder \
    .appName("RH_QA_Analytics") \
    .config("spark.executor.memory", "4g") \
    .config("spark.driver.memory", "2g") \
    .getOrCreate()

# 2. Carregar dados RH
candidatos_df = spark.read.csv("hdfs:///rh/candidatos.csv", header=True)
contratados_df = spark.read.csv("hdfs:///rh/contratados.csv", header=True)
turnover_df = spark.read.csv("hdfs:///rh/turnover.csv", header=True)

# 3. Carregar dados QA
bugs_df = spark.read.csv("hdfs:///qa/bugs.csv", header=True)
testes_df = spark.read.csv("hdfs:///qa/testes.csv", header=True)
logs_df = spark.read.json("hdfs:///qa/logs/*.json")

# 4. Análise RH: Correlação experiência vs salário
correlacao = candidatos_df \
    .filter(col("status") == "aprovado") \
    .stat.corr("experiencia_anos", "salario_pretendido")
print(f"Correlação experiência-salário: {correlacao:.2f}")

# 5. Análise QA: Bugs por desenvolvedor
bugs_por_dev = bugs_df \
    .groupBy("desenvolvedor") \
    .agg(
        count("*").alias("total_bugs"),
        avg("horas_resolucao").alias("media_horas"),
        sum(when(col("severidade") == "critico", 1).otherwise(0)).alias("bugs_criticos")
    ) \
    .orderBy("total_bugs", ascending=False)

bugs_por_dev.show()

# 6. ML: Prever turnover
# Preparar features
assembler = VectorAssembler(
    inputCols=["tempo_empresa", "ultima_avaliacao", "salario", "idade"],
    outputCol="features"
)

dados_ml = assembler.transform(turnover_df)

# Dividir dados
treino, teste = dados_ml.randomSplit([0.8, 0.2])

# Treinar modelo
rf = RandomForestClassifier(
    labelCol="saiu",
    featuresCol="features",
    numTrees=50,
    maxDepth=10
)

modelo = rf.fit(treino)

# Avaliar
previsoes = modelo.transform(teste)
acuracia = previsoes.filter(col("label") == col("prediction")).count() / previsoes.count()
print(f"Acurácia modelo turnover: {acuracia:.2%}")

# 7. Streaming: Monitorar logs em tempo real
from pyspark.streaming import StreamingContext

ssc = StreamingContext(spark.sparkContext, 10)  # Batch de 10s

def processar_logs(rdd):
    if not rdd.isEmpty():
        logs_df = spark.read.json(rdd)
        
        # Alertas em tempo real
        erros_criticos = logs_df.filter(col("level") == "ERROR") \
                                .filter(col("module").isin(["login", "pagamento"]))
        
        if erros_criticos.count() > 0:
            print(f"🚨 {erros_criticos.count()} ERROS CRÍTICOS DETECTADOS!")
            # Enviar para Slack/Email
            enviar_alerta(erros_criticos.collect())

# Monitorar diretório
logs_stream = ssc.textFileStream("hdfs:///qa/logs_streaming/")
logs_stream.foreachRDD(processar_logs)

ssc.start()
# ssc.awaitTermination()  # Em produção

# 8. Salvar resultados para dashboard
bugs_por_dev.write.mode("overwrite").parquet("hdfs:///output/bugs_por_dev.parquet")
previsoes.select("id", "prediction").write.mode("overwrite").csv("hdfs:///output/previsoes_turnover.csv")

# 9. Dashboard simples
print("\n" + "="*50)
print("DASHBOARD RH/QA - RESUMO")
print("="*50)
print(f"Total candidatos: {candidatos_df.count()}")
print(f"Total bugs: {bugs_df.count()}")
print(f"Bugs críticos: {bugs_df.filter(col('severidade') == 'critico').count()}")
print(f"Taxa aprovação: {(candidatos_df.filter(col('status') == 'aprovado').count() / candidatos_df.count() * 100):.1f}%")
print(f"Tempo médio resolução bugs: {bugs_df.agg(avg('horas_resolucao')).collect()[0][0]:.1f}h")

# 10. Parar Spark
spark.stop()
```

## 🔷 Quando Usar Spark vs Hadoop

### ✅ **Use Spark quando**:

- **Velocidade importa** (processamento em memória)
- **Streaming em tempo real** necessário
- **Machine Learning** integrado
- **SQL queries** complexas
- **Desenvolvimento rápido** (Python/R)

### ❌ **Use Hadoop quando**:

- **Orçamento limitado** (Spark precisa mais RAM)
- **Dados cold storage** (não precisa velocidade)
- **Legacy systems** já em Hadoop
- **Batch apenas** (não precisa streaming)
