[Apache Hadoop](https://hadoop.apache.org/)
### 🔶 O que é Hadoop?

- **Definição simples**: Framework **open-source** da Apache pra armazenar e processar **Big Data** de forma distribuída (em clusters de computadores baratos).
- **Objetivo principal**: Lidar com dados **grandes, não estruturados e em tempo real**, escalando horizontalmente (adiciona mais máquinas).
- **Dados reais**: Processa petabytes (1 PB = 1.000 TB), usado por empresas como Yahoo e Facebook (fonte: **Metricas Boss**, cases de 2023).

### 1️⃣ Componentes principais

- **HDFS (Hadoop Distributed File System)**: Armazenamento distribuído, com redundância (3 cópias de cada bloco).
- **MapReduce**: Motor de processamento paralelo (divide tarefas em "map" e "reduce").
- **YARN**: Gerencia recursos (CPU/memória) no cluster.
- **Hadoop Common**: Bibliotecas base.

### 2️⃣ Exemplo prático (pra seu QA/RH)

Imagine logs de testes de API (milhões de linhas):

```bash
# Comando simples pra rodar job MapReduce
hadoop jar exemplo.jar WordCount /input/logs.txt /output/contagem
```

- **Input**: Logs bagunçados.
- **Output**: Contagem de erros por módulo (útil pra priorizar bugs).

### 3️⃣ Vantagens e limitações

- **Prós**: Barato (hardware comum), tolerante a falhas, escala infinita.
- **Contras**: Lento pra jobs interativos (melhor pra batch). Hoje, migra pra Spark (**AILabs** recomenda transição).
