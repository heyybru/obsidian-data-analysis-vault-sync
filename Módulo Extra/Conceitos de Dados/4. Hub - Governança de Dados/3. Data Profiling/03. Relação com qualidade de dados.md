# Relação com qualidade de dados

## A conexão é causal

O profiling é o **instrumento de medição** das dimensões de qualidade. Cada dimensão tem uma pergunta de profiling correspondente.

| Dimensão de qualidade | Pergunta de profiling |
|---|---|
| **Completude** | Qual o % de nulos por coluna? |
| **Unicidade** | Quantos valores duplicados existem? |
| **Precisão** | Os valores batem com a fonte da verdade? |
| **Consistência** | O mesmo dado concorda entre tabelas? |
| **Validade** | Os valores respeitam tipo, formato e faixa? |
| **Temporalidade** | Qual a data do registro mais recente? |

## Insight prático

O profiling **não cria** qualidade. Ele **revela** onde a qualidade falta. É a etapa que transforma um problema difuso em uma lista priorizada de correções.

## Ordem correta

⚠️ **Perfile primeiro, limpe depois.** Limpar sem perfil é apagar incêndio no escuro — você gasta esforço onde não precisa e deixa passar o que importa.
