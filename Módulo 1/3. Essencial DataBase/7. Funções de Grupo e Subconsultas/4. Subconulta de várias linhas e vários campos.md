
## 🔹 1️⃣ Subconsulta de **Várias Linhas**
### O que é?

É uma subconsulta que retorna **mais de um valor** (várias linhas).

👉 Por isso, **não pode** usar operadores simples (`=`, `>`).

---

### 🔹 Operadores usados

Para **várias linhas**, usamos:

- `IN`
    
- `ANY`
    
- `ALL`

---

### 📌 Exemplo com `IN`

```sql
SELECT name, department_id
FROM employee
WHERE department_id IN (
    SELECT department_id
    FROM department
    WHERE location = 'SP'
);
```

✔ Retorna funcionários de **todos os departamentos em SP**

---

### 📌 Exemplo com `ANY`

```sql
SELECT name, salary
FROM employee
WHERE salary > ANY (
    SELECT salary
    FROM employee
    WHERE department_id = 10
);
```

👉 Maior que **pelo menos um** salário do depto 10

---

### 📌 Exemplo com `ALL`

```sql
SELECT name, salary
FROM employee
WHERE salary > ALL (
    SELECT salary
    FROM employee
    WHERE department_id = 10
);
```

👉 Maior que **todos** os salários do depto 10

---

### 🧠 Resumo 

- `IN` → pertence à lista
    
- `ANY` → maior/menor que **algum**
    
- `ALL` → maior/menor que **todos**

---

## 🔹 2️⃣ Subconsulta de **Vários Campos**

### O que é?

É uma subconsulta que retorna **mais de uma coluna**.

👉 Normalmente usada para comparação **par a par**.

---

### 📌 Exemplo clássico (várias colunas)

```sql
SELECT name, department_id, salary
FROM employee
WHERE (department_id, salary) IN (
    SELECT department_id, MAX(salary)
    FROM employee
    GROUP BY department_id
);
```

✔ Retorna o funcionário com **maior salário de cada departamento**

---

### 🔹 Regra importante

- O número de campos da consulta principal **deve ser igual**
    
- A ordem dos campos **precisa bater**
    

❌ Isso dá erro:

```sql
WHERE (department_id, salary) IN (
    SELECT salary, department_id
    FROM employee
);
```

---

## 🔹 Subconsulta com várias linhas **e** vários campos

Sim, isso é possível 👇

```sql
SELECT *
FROM employee
WHERE (department_id, job_id) IN (
    SELECT department_id, job_id
    FROM job_history
);
```

---

## ❌ Erros comuns em prova

- Usar `=` com várias linhas ❌
    
- Quantidade de colunas diferente ❌
    
- Ordem de colunas diferente ❌

---

## 📘 Resumo

Tipo Usa  
Uma linha =, >, <  
Várias linhas IN, ANY, ALL  
Vários campos Comparação em pares  
Várias linhas + campos IN (tuplas)
