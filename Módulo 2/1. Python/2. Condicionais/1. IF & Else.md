## 🔷 `if` e `else` em Python

`if` e `else` servem para o programa **tomar uma decisão**:

- se a condição for **True** → executa o bloco do `if`
- senão (**False**) → executa o bloco do `else`

---

## 🔷 1) Estrutura básica

```python
idade = 17

if idade >= 18:
    print("Maior de idade")
else:
    print("Menor de idade")
```

---

## 🔷 2) Regras importantes

### ✅ Indentação (obrigatória)

O que “define” o bloco é o recuo (geralmente 4 espaços):

```python
x = 10
if x > 5:
    print("x é maior que 5")
    print("ainda estou dentro do if")
else:
    print("x não é maior que 5")
```

### ✅ A condição precisa virar **True/False**

Normalmente com operadores relacionais: `>`, `<`, `==`, `!=`, `>=`, `<=`.

---

## 🔷 3) Exemplos práticos (RH + QA)

### ✅ RH: validação simples de idade

```python
idade = int(input("Idade: "))

if idade >= 18:
    print("Pode se candidatar")
else:
    print("Não pode se candidatar")
```

### ✅ QA: priorização simples de bug

```python
severidade = input("Severidade (CRITICO/ALTO/MEDIO/BAIXO): ").upper()

if severidade == "CRITICO":
    print("Prioridade máxima")
else:
    print("Prioridade normal")
```

---

## 🔷 4) `if/else` em uma linha (ternário)

Quando é bem simples:

```python
idade = 20
msg = "Maior" if idade >= 18 else "Menor"
print(msg)
```
