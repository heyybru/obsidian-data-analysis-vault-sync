No **Mac M1/M2/M3**, o ideal é baixar a versão para **Apple Silicon**. O processo é simples:

### No macOS

1. Acesse o site da **JetBrains** e baixe o **PyCharm**.
2. Escolha a versão:
    - **Community**: gratuita, ótima para estudar Python
    - **Professional**: paga, com mais recursos para web, banco e ciência de dados
3. Baixe a versão **macOS Apple Silicon**.
4. Abra o arquivo `.dmg`.
5. Arraste o **PyCharm** para a pasta **Applications**.
6. Abra o app pelo Launchpad ou Applications.

#### Na primeira abertura

- O macOS pode pedir permissão de segurança.
- Se bloquear, vá em **System Settings > Privacy & Security** e permita a abertura.

---

## Configuração inicial

Quando abrir o PyCharm pela primeira vez:

1. Clique em **New Project**
2. Escolha a pasta do projeto
3. Em **Python Interpreter**, selecione:
    - **New environment using venv** para criar um ambiente novo
    - ou um Python já instalado no seu Mac
4. Clique em **Create**

Se você já tiver **Anaconda** ou **Python instalado**, o PyCharm pode detectar automaticamente.

---

## Como verificar se está funcionando

Crie um arquivo `main.py` com:

```python
print("Olá, Bruno!")
```

Depois clique no botão de **Run**.

Se aparecer a mensagem no console, está tudo certo.

---

## Dica importante para Mac M1

Se você estiver estudando **Pandas, Jupyter e ciência de dados**, o PyCharm funciona bem, mas:

- **PyCharm Community** tem suporte mais limitado para notebooks
- para ciência de dados, muita gente usa também **VS Code** ou **Jupyter Lab**

Se sua prioridade agora é **Python puro, automação, testes com Pytest e Selenium**, o **PyCharm Community** já atende muito bem.

---

## Resumindo

- Baixe o **PyCharm para macOS Apple Silicon**
- Instale arrastando para **Applications**
- Crie um projeto com **venv**
- Teste com um `print("Olá, Bruno!")`
