## Exercício prático (Python): população, amostra e estatística descritiva

### Objetivo

1. Criar uma **população** (todos os candidatos)
2. Tirar uma **amostra** aleatória
3. Calcular **média, mediana, desvio padrão** e comparar população vs amostra
4. Ver como a amostra pode “variar” por sorte/azar

### Código (pode rodar no Jupyter/VS Code)

```python
import random
import statistics as stats

# 1) População: time-to-hire (dias) de 2.000 candidatos
# Vamos simular um processo onde a maioria fecha entre 20 e 45 dias,
# mas com alguns casos extremos (outliers).
random.seed(42)

populacao = []
for _ in range(2000):
    base = random.randint(20, 45)              # maioria
    ruido = random.choice([0, 0, 0, 1, 2, 3])   # pequenas variações
    populacao.append(base + ruido)

# adicionando outliers (processos longos)
populacao += [90, 95, 110, 120, 150]

# 2) Amostra aleatória
amostra = random.sample(populacao, 100)

# 3) Função para descrever um conjunto de dados
def resumo(nome, dados):
    media = stats.mean(dados)
    mediana = stats.median(dados)
    desvio = stats.pstdev(dados)  # desvio padrão da população (pstdev)
    minimo = min(dados)
    maximo = max(dados)
    
    print(f"\n{nome}")
    print(f"- n: {len(dados)}")
    print(f"- média: {media:.2f}")
    print(f"- mediana: {mediana:.2f}")
    print(f"- desvio padrão: {desvio:.2f}")
    print(f"- mínimo: {minimo}")
    print(f"- máximo: {maximo}")

# 4) Comparar população vs amostra
resumo("População (time-to-hire em dias)", populacao)
resumo("Amostra (100 candidatos)", amostra)

# 5) Repetir amostras para ver variação (inferência na prática)
medias = []
for _ in range(30):
    amostra_temp = random.sample(populacao, 100)
    medias.append(stats.mean(amostra_temp))

print("\nVariação das médias amostrais (30 amostras de 100):")
print(f"- menor média: {min(medias):.2f}")
print(f"- maior média: {max(medias):.2f}")
print(f"- média das médias: {stats.mean(medias):.2f}")
```

### O que observar (interpretação)

- A **população** é a “verdade total” (aqui, simulada).
- A **amostra** dá uma estimativa, mas pode variar.
- Se a distribuição tiver **outliers**, a **média** é mais afetada que a **mediana**.
