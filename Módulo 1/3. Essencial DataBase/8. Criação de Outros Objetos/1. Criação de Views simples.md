### 🔹 O que é uma VIEW?

Uma **VIEW** é uma **consulta salva** no banco de dados.

- Parece uma tabela
    
- Não armazena dados
    
- Sempre mostra dados atualizados
    
- Baseada em um `SELECT`

---
## 🔹 Sintaxe básica

```sql
CREATE VIEW nome_da_view AS
SELECT colunas
FROM tabela
WHERE condição;
```

---

## 🔹 Exemplo 1 – View simples (sem filtro)

Tabela: **COLABORADOR**

```sql
CREATE VIEW vw_colaboradores AS
SELECT id_colaborador, nome, cargo
FROM colaborador;
```

📌 Uso:

```sql
SELECT * FROM vw_colaboradores;
```

---

## 🔹 Exemplo 2 – View com filtro

Somente colaboradores do departamento TI (id = 2):

```sql
CREATE VIEW vw_colab_ti AS
SELECT nome, cargo
FROM colaborador
WHERE id_departamento = 2;
```

---

## 🔹 Exemplo 3 – View com JOIN simples

```sql
CREATE VIEW vw_colab_departamento AS
SELECT c.nome, c.cargo, d.nome_departamento
FROM colaborador c
JOIN departamento d
ON c.id_departamento = d.id_departamento;
```

---

## 🔹 Por que usar VIEW?

✔ Simplifica consultas  
✔ Reutiliza SQL  
✔ Aumenta segurança (mostra só algumas colunas)  
✔ Evita repetir JOINs complexos

---

## 🔹 Alterar uma VIEW

```sql
CREATE OR REPLACE VIEW vw_colaboradores AS
SELECT id_colaborador, nome
FROM colaborador;
```

---

## 🔹 Excluir uma VIEW

```sql
DROP VIEW vw_colaboradores;
```

---

## 🧠 Resumo 

- VIEW = SELECT salvo
    
- Não guarda dados
    
- Pode ter `WHERE` e `JOIN`
    
- Usada como tabela
