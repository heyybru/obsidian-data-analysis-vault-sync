### Requisitos do ambiente

O material sugere que você pode configurar Spark de duas formas:

|Opção|Descrição|Ideal pra|
|:--|:--|:--|
|**Local**|Instalar Spark no seu computador|Testes e aprendizado|
|**Nuvem**|Usar clusters gerenciados (Databricks, EMR, Glue)|Produção e grandes volumes|

### Pré-requisitos técnicos:

- **Python 3.8+**
- **Java 8 ou 11** (Spark roda na JVM)
- **Apache Spark** (baixar em: [https://spark.apache.org/downloads.html](https://spark.apache.org/downloads.html))
- **PySpark** (a API Python do Spark)

### Instalação rápida via pip:

```bash
# Instalar PySpark
pip install pyspark

# Verificar instalação
python -c "from pyspark import SparkContext; print('PySpark OK!')"
```
