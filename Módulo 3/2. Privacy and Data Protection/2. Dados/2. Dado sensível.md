### 🔶 O Que é um Dado Sensível?

Segundo a **LGPD** (Brasil) e o **GDPR** (Europa), dado sensível é uma categoria especial de dado pessoal que merece proteção extra. A **Snaq.co** reforça que o vazamento desses dados gera as maiores multas e danos reputacionais.

**O que a lei considera sensível:**

- 🧬 **Biometria e Genética**: Impressão digital, reconhecimento facial, DNA.
- 🏥 **Saúde**: Histórico médico, exames, deficiências.
- ⛪ **Convicção Religiosa e Filosófica**.
- ✊ **Opinião Política e Filiação Sindical**.
- 🌍 **Origem Racial ou Étnica**.
- 🏳️‍🌈 **Vida Sexual ou Orientação Sexual**.

### 🔶 Por que eles são diferentes?

- **Potencial Discriminatório**: O **Cappra Institute** destaca que esses dados podem ser usados para excluir pessoas de oportunidades de forma injusta.
- **Rigor no Tratamento**: Para tratar dados sensíveis, a regra é o **Consentimento Específico e Destacado**. O usuário precisa saber exatamente que está cedendo um dado sensível e para quê.

### 🧪 O Papel do QA no Tratamento de Dados Sensíveis

Como Analista de QA, Bruno, sua responsabilidade aqui é técnica e ética:

- **Zero Real Data**: Nunca use dados sensíveis reais de candidatos em ambientes de teste (**Staging**). Use geradores de dados sintéticos.
- **Criptografia de Ponta a Ponta**: Validar se, ao salvar uma biometria, o dado é transformado em um _hash_ e não guardado como imagem pura no **PostgreSQL**.
- **Controle de Acesso (RBAC)**: Testar se apenas o médico do trabalho acessa os dados de saúde, e não o recrutador ou o desenvolvedor.

### 🛠️ Prática com Python: Verificando Dados Sensíveis

Veja como poderíamos criar um "filtro de segurança" para identificar se um dataset contém colunas sensíveis antes de processá-lo:

``` 
sensitive_terms = ['religiao', 'saude', 'raca', 'biometria']

def check_sensitive_columns(columns):
    """
    Checks a list of column names for sensitive terms and prints alerts.
    
    Args:
        columns (list): List of DataFrame column names.
    
    Returns:
        list: List of alert messages.
    """
    alerts = []
    for col in columns:
        col_lower = col.lower()
        sensitive_found = [term for term in sensitive_terms if term in col_lower]
        if sensitive_found:
            terms_str = ', '.join(sensitive_found)
            alert = f"ALERT: Sensitive column '{col}' contains sensitive terms: {terms_str}"
            alerts.append(alert)
            print(alert)
    if not alerts:
        print("No sensitive columns found.")
    return alerts

# Example usage:
if __name__ == "__main__":
    columns = ['nome', 'idade', 'religiao', 'saude_mental', 'raca_etnia', 'endereco']
    check_sensitive_columns(columns)
```
### 💡 Insights do Especialista

- **Preditiva.ai**: Ao criar modelos de Machine Learning para recrutamento, **remova os dados sensíveis** do treinamento. Isso evita que a IA aprenda preconceitos históricos (ex: preferir uma raça sobre outra).
- **AILabs**: O uso de biometria facial para controle de ponto ou acesso deve ser acompanhado de um **Relatório de Impacto (RIPD)**, pois o risco de dano ao titular é alto.
- **Metricas Boss**: Meça a "Taxa de Exposição de Dados Sensíveis". Quanto menos pessoas tiverem acesso a esses dados, menor o seu risco de conformidade.
