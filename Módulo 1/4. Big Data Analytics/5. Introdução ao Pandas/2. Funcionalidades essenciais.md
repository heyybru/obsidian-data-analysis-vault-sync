## 🔷 1. Leitura e Escrita de Dados (I/O)

### ✅ **Carregar dados de diferentes fontes**:

```python
import pandas as pd

# CSV (mais comum)
df_csv = pd.read_csv('dados.csv')
df_csv.to_csv('resultados.csv', index=False)

# Excel
df_excel = pd.read_excel('dados.xlsx', sheet_name='Planilha1')
df_excel.to_excel('resultados.xlsx', sheet_name='Análise')

# JSON
df_json = pd.read_json('dados.json')
df_json.to_json('resultados.json', orient='records')

# Banco de dados SQL
import sqlite3
conn = sqlite3.connect('database.db')

# Parquet (otimizado para big data)
df_parquet = pd.read_parquet('dados.parquet')

```

## 🔷 3. Seleção e Indexação

### ✅ **Seleção de colunas**:

```python
# Uma coluna → Series
coluna = df['nome']

# Múltiplas colunas → DataFrame
colunas = df[['nome', 'idade', 'salario']]

# Com .loc (label-based)
coluna_loc = df.loc[:, 'nome']           # Todas linhas, coluna 'nome'
colunas_loc = df.loc[:, ['nome', 'idade']] # Múltiplas colunas

# Com .iloc (position-based)
coluna_iloc = df.iloc[:, 0]              # Todas linhas, primeira coluna
colunas_iloc = df.iloc[:, 0:3]           # Colunas 0, 1, 2
```

### ✅ **Seleção de linhas**:

```python
# Por índice
linha = df.loc[0]                        # Linha com índice 0
linhas = df.loc[0:2]                     # Linhas 0, 1, 2

# Por posição
linha_iloc = df.iloc[0]                  # Primeira linha
linhas_iloc = df.iloc[0:3]               # Linhas 0, 1, 2

# Por condição
filtro = df[df['idade'] > 30]            # Idade > 30
filtro_multiplo = df[(df['idade'] > 30) & (df['salario'] > 6000)]

# Com .query() (similar a SQL)
filtro_query = df.query('idade > 30 and salario > 6000')
```

### ✅ **Seleção mista (linhas e colunas)**:

```python
# .loc para linhas e colunas
subset = df.loc[df['idade'] > 30, ['nome', 'salario']]

# .iloc para posições
subset_iloc = df.iloc[0:3, 1:4]          # Linhas 0-2, colunas 1-3

# Misturando
subset_misto = df.loc[df.index[0:3], ['nome', 'idade']]
```

```python
metricas = df.groupby('departamento').agg({
```

## 🔷 7. Combinação de DataFrames

### ✅ **Concatenação**:

```python
# Empilhar verticalmente
df1 = pd.DataFrame({'A': [1, 2], 'B': [3, 4]})
df2 = pd.DataFrame({'A': [5, 6], 'B': [7, 8]})
resultado = pd.concat([df1, df2], ignore_index=True)
#    A  B
# 0  1  3
# 1  2  4
# 2  5  7
# 3  6  8

# Juntar horizontalmente
resultado_h = pd.concat([df1, df2], axis=1)
#    A  B  A  B
# 0  1  3  5  7
# 1  2  4  6  8
```

### ✅ **Merge (join)**:

```python
# Dados de funcionários
funcionarios = pd.DataFrame({
    'id': [1, 2, 3, 4],
    'nome': ['Ana', 'Bruno', 'Carla', 'Daniel'],
    'departamento_id': [101, 102, 101, 103]
})

# Dados de departamentos
departamentos = pd.DataFrame({
    'id': [101, 102, 103],
    'nome': ['TI', 'RH', 'Vendas']
})

# Inner join (padrão)
inner = pd.merge(funcionarios, departamentos, 
                 left_on='departamento_id', right_on='id',
                 suffixes=('_func', '_dept'))

# Left join
left = pd.merge(funcionarios, departamentos,
                left_on='departamento_id', right_on='id',
                how='left')

# Right join
right = pd.merge(funcionarios, departamentos,
                 left_on='departamento_id', right_on='id',
                 how='right')

# Outer join
outer = pd.merge(funcionarios, departamentos,
                 left_on='departamento_id', right_on='id',
                 how='outer')
```

### ✅ **Join por índice**:

```python
# Definir índices
funcionarios_idx = funcionarios.set_index('departamento_id')
departamentos_idx = departamentos.set_index('id')

# Join por índice
resultado = funcionarios_idx.join(departamentos_idx, rsuffix='_dept')
```

```python
    columns='severidade',
```


## 🔷 10. Tratamento de Valores Ausentes

```python
# Verificar por coluna
nulos_por_coluna = df.isnull().sum()
print(nulos_por_coluna)

# Verificar por linha
linhas_com_nulos = df.isnull().any(axis=1)
print(df[linhas_com_nulos])

# Porcentagem de nulos

print(porcentagem_nulos)
```

### ✅ **Tratamento**:

```python
# Remover
df_sem_nulos = df.dropna()                    # Remove linhas com qualquer NaN
df_sem_todos_nulos = df.dropna(how='all')     # Remove se todas colunas são NaN
df_sem_colunas_nulas = df.dropna(axis=1)      # Remove colunas com NaN

# Preencher
df_preenchido = df.fillna({
    'idade': df['idade'].mean(),
    'salario': 0,
    'departamento': 'Desconhecido'

df_ffill = df.fillna(method='ffill')          # Preenche com valor anterior

# Preencher com estatísticas do grupo
```
