### 🔶 Conceito rápido

- **Transformações**: Mudam forma, tipo ou valores de arrays (reshape, transpose, flatten, etc.).
- **Por quê?** Adapta arrays pra modelos ou visualizações, sem perda de dados.

---

### 1️⃣ **Reshape** (muda forma)

Transforma linhas/colunas.

```python
import numpy as np

array = np.array([1,2,3,4,5,6])
novo = array.reshape(2,3)  # De 1D pra 2x3
print(novo)
# [[1 2 3]
#  [4 5 6]]
```

**Ex QA:** Matriz de testes x módulos.

---

### 2️⃣ **Transpose** (inverte eixos)

Troca linhas por colunas.

```python
matriz = np.array([[1,2], [3,4]])
transposta = matriz.T  # Ou .transpose()
print(transposta)
# [[1 3]
#  [2 4]]
```

**Ex RH:** Candidatos x critérios → Critérios x candidatos.

---

### 3️⃣ **Flatten/Ravel** (achata pra 1D)

Desfaz matrizes.

```python
matriz = np.array([[1,2], [3,4]])
plano = matriz.flatten()  # Ou .ravel()
print(plano)  # [1 2 3 4]
```

---

### 4️⃣ **Outras top: Stack e Split**

- **Stack**: Une arrays.
    
    ```python
    a = np.array([1,2])
    b = np.array([3,4])
    pilha = np.stack([a,b])  # [[1 2] [3 4]]
    ```
    
- **Split**: Divide.
    
    ```python
    array = np.array([1,2,3,4])
    partes = np.split(array, 2)  # [array([1,2]), array([3,4])]
    ```
