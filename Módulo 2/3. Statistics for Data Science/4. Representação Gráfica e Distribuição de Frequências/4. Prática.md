## 1) Dataset de exemplo (simulado)

```python
import pandas as pd
import numpy as np

rng = np.random.default_rng(42)

n = 300
df = pd.DataFrame({
    "candidate_id": np.arange(1, n+1),
    "canal_origem": rng.choice(["LinkedIn", "Indicação", "Site", "Outro"], size=n, p=[0.5, 0.2, 0.2, 0.1]),
    "etapa_funil": rng.choice(["Triagem", "Técnica", "Final", "Oferta"], size=n, p=[0.45, 0.35, 0.15, 0.05]),
    "tempo_para_primeiro_contato_horas": rng.gamma(shape=2.2, scale=6.0, size=n).round(1)  # variável contínua
})

df.head()
```

---

## 2) Tabela de frequência (qualitativo): absoluto + relativo (%)

Ex.: `canal_origem` (nominal)

```python
freq_canal = (
    df["canal_origem"]
    .value_counts(dropna=False)
    .rename("freq_abs")
    .to_frame()
)

freq_canal["freq_rel"] = (freq_canal["freq_abs"] / len(df)).round(4)
freq_canal["perc"] = (freq_canal["freq_rel"] * 100).round(1)

freq_canal
```

**Aplicação típica:**

- descobrir qual canal domina
- checar “categoria rara”
- base para gráfico de barras/pizza (se poucas categorias)

## 3) Frequência para ordinal (opcional): mantendo ordem lógica

Se a variável tem ordem (ex.: etapa do funil), vale **ordenar manualmente**:

```python
ordem_etapas = ["Triagem", "Técnica", "Final", "Oferta"]

freq_etapa = (
    df["etapa_funil"]
    .value_counts()
    .reindex(ordem_etapas)
    .rename("freq_abs")
    .to_frame()
)

freq_etapa["perc"] = (freq_etapa["freq_abs"] / len(df) * 100).round(1)
freq_etapa
```

## 4) Tabela de frequência (quantitativo contínuo): por **classes** + acumulada

Ex.: `tempo_para_primeiro_contato_horas`

### 4.1) Definir classes (bins)

Aqui vai um conjunto de faixas bem “operacional” (SLA):

```python
bins = [0, 6, 12, 24, 48, np.inf]
labels = ["0-6h", "6-12h", "12-24h", "24-48h", "48h+"]

df["tempo_classe"] = pd.cut(
    df["tempo_para_primeiro_contato_horas"],
    bins=bins,
    labels=labels,
    right=False,          # inclui o limite inferior
    include_lowest=True
)
```

### 4.2) Montar tabela com: abs, %, acumulada e % acumulada

```python
freq_tempo = (
    df["tempo_classe"]
    .value_counts(sort=False)   # respeita ordem dos labels
    .rename("freq_abs")
    .to_frame()
)

freq_tempo["perc"] = (freq_tempo["freq_abs"] / len(df) * 100).round(1)
freq_tempo["freq_acum"] = freq_tempo["freq_abs"].cumsum()
freq_tempo["perc_acum"] = freq_tempo["perc"].cumsum().round(1)

freq_tempo
```

**Como interpretar (aplicação):**

- `perc_acum` te diz “qual % foi atendida até X”.
- Ex.: se até **24h** o `perc_acum` for 82,0 → “**82%** receberam 1º contato em até 24h”.

## 5) Aplicações que mais aparecem

- **Resumo rápido**: ver concentração e distribuição.
- **Qualidade dos dados**: detectar categorias estranhas (ex.: “linkedin” vs “LinkedIn”).
- **Definição de metas/SLA**: usar a acumulada para dizer “X% até 24h”.
- **Base para gráficos**:
    - qualitativo → barras
    - contínuo por classes → histograma (bins)
    - acumulada → ogiva (curva acumulada)

---

## Resumindo

- Qualitativo: `value_counts()` → frequência absoluta e %.
- Contínuo: `pd.cut()` cria classes → dá para fazer frequência e **acumulada**.
- Acumulada é perfeita para metas tipo “% até X”.
