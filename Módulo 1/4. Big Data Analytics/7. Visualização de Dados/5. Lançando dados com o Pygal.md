## 🔷 Visualizações Interativas

**Pygal é como um "artista de gráficos" que cria visualizações bonitas e interativas**.  
Enquanto Matplotlib faz gráficos estáticos, Pygal cria **SVG interativos** que você pode explorar no navegador.

✅ **No seu contexto (RH + QA)**:

- **RH**: Dashboard interativo de métricas de contratação
- **QA**: Gráficos dinâmicos de bugs por severidade, tempo de resolução

---

## 🔷 O que é Pygal?

### ✅ **Características principais**:

- **Gráficos SVG**: Vetoriais, escaláveis, interativos
- **Interatividade nativa**: Tooltips, zoom, hover effects
- **Estilo bonito por padrão**: Não precisa customizar muito
- **Exporta para SVG/PNG**: Fácil de incorporar em web
- **Simples de usar**: API intuitiva

### ✅ **Instalação**:

```bash
pip install pygal
```

### ✅ **Import**:

```python
import pygal
from pygal.style import Style
```

## 🔷 1. Gráficos Básicos

### ✅ **Gráfico de Barras (RH: Salários por Departamento)**:

```python
import pygal

# Dados
departamentos = ['TI', 'RH', 'Vendas', 'Marketing', 'Financeiro']
salarios_medios = [7500, 5500, 6000, 5200, 6800]

# Criar gráfico
bar_chart = pygal.Bar(
    title='Salário Médio por Departamento',
    x_title='Departamento',
    y_title='Salário Médio (R$)',
    show_legend=False,
    style=pygal.style.LightStyle
)

# Adicionar dados
bar_chart.x_labels = departamentos
bar_chart.add('Salário', salarios_medios)

# Personalizar
bar_chart.value_formatter = lambda x: f'R$ {x:,.0f}'

# Renderizar para arquivo
bar_chart.render_to_file('salarios_departamento.svg')
bar_chart.render_to_png('salarios_departamento.png')

# Mostrar no Jupyter
# bar_chart.render_in_browser()  # Abre no navegador
# bar_chart  # Em Jupyter, mostra inline
```

### ✅ **Gráfico de Pizza (QA: Bugs por Severidade)**:

```python
# Dados
severidades = ['Crítico', 'Alto', 'Médio', 'Baixo']
quantidades = [15, 35, 80, 120]
cores = ['#FF0000', '#FF6600', '#FFCC00', '#00CC00']  # Vermelho, Laranja, Amarelo, Verde

# Criar gráfico
pie_chart = pygal.Pie(
    title='Distribuição de Bugs por Severidade',
    inner_radius=0.4,  # Donut chart
    style=pygal.style.LightStyle
)

# Adicionar dados
for severidade, quantidade, cor in zip(severidades, quantidades, cores):
    pie_chart.add(
        severidade, 
        quantidade,
        color=cor
    )

# Personalizar
pie_chart.value_formatter = lambda x: f'{x} bugs'

# Renderizar
pie_chart.render_to_file('bugs_severidade.svg')
```

## 🔷 2. Gráficos de Linha (Séries Temporais)

### ✅ **Bugs por Mês (QA)**:

```python
import pygal
from datetime import datetime

# Dados temporais
meses = ['Jan', 'Fev', 'Mar', 'Abr', 'Mai', 'Jun', 
         'Jul', 'Ago', 'Set', 'Out', 'Nov', 'Dez']

line_chart = pygal.Line(
    title='Bugs Reportados por Mês',
    x_title='Mês',
    y_title='Número de Bugs',
    show_dots=True,
    dots_size=5,
    style=pygal.style.LightStyle
)

# Adicionar dados
line_chart.x_labels = meses
line_chart.add('2025', bugs_2025)
line_chart.add('2024', bugs_2024)

# Personalizar
line_chart.value_formatter = lambda x: f'{x:.0f} bugs'

# Adicionar linha de média
media_2025 = sum(bugs_2025) / len(bugs_2025)
line_chart.add(
    'Média 2025', 
    [media_2025] * len(meses),
    stroke_style={'width': 2, 'dasharray': '5, 5'},
    show_dots=False
)

# Renderizar
line_chart.render_to_file('bugs_mensal.svg')
```

### ✅ **Dashboard RH: Métricas ao Longo do Tempo**:

```python
# Dados trimestrais

multi_line.secondary_value_formatter = lambda x: f'{x:.1f}%'

multi_line.render_to_file('rh_trimestral.svg')
```

## 🔷 3. Gráficos de Dispersão (Scatter Plots)

### ✅ **Experiência vs Salário (RH)**:

```python
import numpy as np

# Gerar dados simulados
np.random.seed(42)
n = 50
experiencia = np.random.normal(5, 2, n)
salario = 3000 + 500 * experiencia + np.random.normal(0, 300, n)

# Criar scatter plot
scatter_plot = pygal.XY(
    title='Experiência vs Salário',
    x_title='Anos de Experiência',
    y_title='Salário (R$)',
    stroke=False,
    style=pygal.style.LightStyle
)

# Adicionar pontos
points = [(exp, sal) for exp, sal in zip(experiencia, salario)]
scatter_plot.add('Candidatos', points)

# Adicionar linha de tendência (regressão linear)
# Calcular regressão
coef = np.polyfit(experiencia, salario, 1)
trend_x = [min(experiencia), max(experiencia)]
trend_y = [coef[0] * x + coef[1] for x in trend_x]

trend_points = [(x, y) for x, y in zip(trend_x, trend_y)]
scatter_plot.add(
    'Tendência', 
    trend_points,
    stroke=True,
    stroke_style={'width': 3}
)

scatter_plot.render_to_file('experiencia_salario.svg')
```

### ✅ **Complexidade vs Tempo de Resolução (QA)**:

```python
# Dados de bugs
complexidade = np.random.uniform(1, 10, 30)
tempo_resolucao = 0.5 * complexidade**1.5 + np.random.normal(0, 1, 30)

# Scatter plot com cores por severidade
severidade = np.random.choice(['Baixo', 'Médio', 'Alto', 'Crítico'], 30)

# Criar gráfico
scatter = pygal.XY(
    title='Complexidade vs Tempo de Resolução',
    x_title='Complexidade (1-10)',
    y_title='Tempo (horas)',
    stroke=False,
    style=pygal.style.LightStyle
)

# Separar por severidade
cores = {'Baixo': '#00CC00', 'Médio': '#FFCC00', 'Alto': '#FF6600', 'Crítico': '#FF0000'}

for sev in ['Baixo', 'Médio', 'Alto', 'Crítico']:
    mask = [s == sev for s in severidade]
    pontos = [(c, t) for c, t, m in zip(complexidade, tempo_resolucao, mask) if m]
    
    if pontos:
        scatter.add(
            sev,
            pontos,
            color=cores[sev]
        )

scatter.render_to_file('complexidade_tempo.svg')
```

### ✅ **Dashboard QA: Métricas por Módulo**:

```python
# Módulos do sistema
modulos = ['Login', 'Pagamento', 'Perfil', 'Carrinho', 'Checkout', 'Busca']

# Métricas
bugs = [15, 8, 5, 12, 10, 3]
tempo_medio = [4.2, 3.8, 2.1, 5.5, 6.2, 1.8]
severidade_media = [2.8, 3.2, 1.5, 2.5, 3.0, 1.2]  # 1-4 escala

# Normalizar para radar (0-1)
bugs_norm = [b / max(bugs) * 10 for b in bugs]
tempo_norm = [t / max(tempo_medio) * 10 for t in tempo_medio]
severidade_norm = [s / 4 * 10 for s in severidade_media]

# Radar chart
radar = pygal.Radar(
    title='Análise de Qualidade por Módulo',
    show_legend=True,
    style=pygal.style.LightStyle,
    fill=True,
    fill_opacity=0.3
)

radar.x_labels = modulos
radar.add('Bugs (normalizado)', bugs_norm)
radar.add('Tempo Médio (normalizado)', tempo_norm)
radar.add('Severidade Média (normalizado)', severidade_norm)

radar.range = (0, 10)
radar.render_to_file('qa_modulos_radar.svg')
```

## 🔷 6. Gráficos de Área

### ✅ **Acumulação de Bugs ao Longo do Tempo**:

```python
# Bugs acumulados por mês
meses = ['Jan', 'Fev', 'Mar', 'Abr', 'Mai', 'Jun']
bugs_novos = [45, 52, 38, 61, 49, 55]
bugs_resolvidos = [40, 48, 35, 55, 45, 50]

# Calcular acumulado
bugs_acumulados = []
acumulado = 0
for novos, resolvidos in zip(bugs_novos, bugs_resolvidos):
    acumulado += novos - resolvidos
    bugs_acumulados.append(acumulado)

# Gráfico de área
area_chart = pygal.StackedLine(
    title='Bugs Acumulados ao Longo do Tempo',
    x_title='Mês',
    y_title='Bugs Acumulados',
    fill=True,
    style=pygal.style.LightStyle
)

area_chart.x_labels = meses
area_chart.add('Bugs Acumulados', bugs_acumulados)

area_chart.render_to_file('bugs_acumulados.svg')
```
