## 🔷 1) Função de validação (input/entrada)

### ✅ Validar idade

```python
def idade_valida(idade):
    return isinstance(idade, int) and 18 <= idade <= 80

print(idade_valida(25))   # True
print(idade_valida("25")) # False
```

## 🔷 2) Função de “limpeza” de texto (dados)

### ✅ Normalizar string (remove espaços, padroniza maiúsculas/minúsculas)

```python
def normalizar_texto(txt):
    if txt is None:
        return None
    return str(txt).strip().lower()

print(normalizar_texto("  QA Manual  "))  # "qa manual"
```

## 🔷 3) Função para classificar severidade (QA)

```python
def peso_severidade(severidade):
    severidade = (severidade or "").strip().upper()
    pesos = {"CRITICO": 1, "ALTO": 2, "MEDIO": 3, "BAIXO": 4}
    return pesos.get(severidade, 99)

print(peso_severidade("critico"))  # 1
print(peso_severidade("x"))        # 99
```

👉 Isso ajuda a ordenar bugs por prioridade.

## 🔷 4) Função para calcular métricas (dados/QA)

### ✅ Taxa de aprovação (pass rate)

```python
def pass_rate(passaram, total):
    if total <= 0:
        return 0.0
    return passaram / total

print(pass_rate(80, 100))  # 0.8
```

Se quiser em porcentagem:

```python
def pass_rate_percent(passaram, total):
    return pass_rate(passaram, total) * 100

print(pass_rate_percent(80, 100))  # 80.0
```

## 🔷 5) Função para filtrar registros (RH/QA)

### ✅ Filtrar bugs críticos abertos

```python
def filtrar_criticos_abertos(bugs):
    return [
        b for b in bugs
        if b.get("severidade") == "CRITICO" and b.get("status") == "ABERTO"
    ]

bugs = [
    {"id": 1, "severidade": "CRITICO", "status": "ABERTO"},
    {"id": 2, "severidade": "ALTO", "status": "ABERTO"},
    {"id": 3, "severidade": "CRITICO", "status": "FECHADO"},
]

print(filtrar_criticos_abertos(bugs))  # só o bug 1
```

## 🔷 6) Função para gerar relatório (string pronta pra salvar/print)

```python
def gerar_relatorio_bugs(bugs):
    total = len(bugs)
    por_severidade = {}
    for b in bugs:
        sev = b.get("severidade", "DESCONHECIDA")
        por_severidade[sev] = por_severidade.get(sev, 0) + 1

    linhas = [f"Total de bugs: {total}"]
    for sev, qtd in sorted(por_severidade.items()):
        linhas.append(f"- {sev}: {qtd}")
    return "\n".join(linhas)

print(gerar_relatorio_bugs(bugs))
```

## 🔷 7) Função com parâmetros opcionais (bem comum)

### ✅ Triagem RH (experiência mínima configurável)

```python
def aprovado_triagem(idade, experiencia, experiencia_minima=2):
    return idade >= 18 and experiencia >= experiencia_minima

print(aprovado_triagem(25, 3))        # True (min 2)
print(aprovado_triagem(25, 3, 4))     # False (min 4)
```

## 🔷 8) Função que retorna múltiplos valores (tupla)

### ✅ Resumo de execução de testes

```python
def resumo_testes(resultados):
    total = len(resultados)
    passaram = sum(1 for r in resultados if r is True)
    falharam = total - passaram
    return total, passaram, falharam

resultados = [True, True, False, True]
total, passaram, falharam = resumo_testes(resultados)
print(total, passaram, falharam)
```
