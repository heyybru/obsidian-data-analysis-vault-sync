---

## 🎯 Resumão dos 4 Temas

|Tema|Principal aprendizado|
|:--|:--|
|**1. Apresentação**|Spark é um motor de processamento **100x mais rápido** que Hadoop MapReduce, processa em memória RAM, usa Lazy Evaluation com Transformações/Ações e DAGs, e tem 4 módulos: Core, SQL, Streaming e MLlib|
|**2. Configuração**|Instalar PySpark via `pip install pyspark`, Java 8/11, e clonar o repositório da disciplina no GitHub|
|**3. Início do Projeto**|SparkSession → Source (CSV/JSON) → Pipeline de Transformações (filter, select, withColumn) → Ação (show, count) → Sink (write)|
|**4. Execução**|Rodar scripts com PySpark localmente (ou na nuvem), explorar códigos do repositório, evoluir pra projetos reais no Kaggle/GitHub|

### 🧠 Conexão com o que você já estudou

|Conceito anterior|Equivalente em Spark|
|:--|:--|
|**Pandas** `df = pd.read_csv()`|**PySpark** `spark.read.csv()`|
|`df[df["col"] > 5]`|`df.filter(df["col"] > 5)`|
|`df.groupby("col").agg()`|`df.groupBy("col").agg()`|
|**ETL Batch** (roda e termina)|**Spark Batch** (processa em memória, muito mais rápido)|
|**Flink Streaming** (evento a evento)|**Spark Streaming** (micro-batches)|
