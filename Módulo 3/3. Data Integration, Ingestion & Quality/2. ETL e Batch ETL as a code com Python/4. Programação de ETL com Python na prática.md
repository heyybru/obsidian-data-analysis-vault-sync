Aqui vou **complementar o material** com um exemplo prático usando seus dados do `workbook_v1.xlsx`. O material do Descomplica fala de acessar repositórios GitHub com códigos — mas nada melhor que aplicar no seu dataset real.

### Pipeline Batch Completo

```python
import pandas as pd
import numpy as np
from datetime import datetime

# ═══════════════════════════════
# 1. EXTRACT
# ═══════════════════════════════
def extract(file_path):
    """Extrai dados da planilha"""
    print(f"[EXTRACT] Lendo {file_path}...")
    df = pd.read_excel(file_path, sheet_name="db")
    print(f"  → {len(df)} registros extraídos")
    return df

# ═══════════════════════════════
# 2. TRANSFORM
# ═══════════════════════════════
def transform(df):
    """Limpa, padroniza e enriquece os dados"""
    print("[TRANSFORM] Iniciando transformações...")
    
    # 2.1 Converter texto para número
    df["experiencia_anos"] = pd.to_numeric(df["experiencia_anos"], errors="coerce")
    
    # 2.2 Criar faixa de experiência
    bins = [0, 2, 5, 10, 20, 30]
    labels = ["Estágio", "JR", "PL", "SR", "Master"]
    df["nivel_exp"] = pd.cut(df["experiencia_anos"], bins=bins, labels=labels)
    
    # 2.3 Padronizar fonte de recrutamento
    df["fonte_recrutamento"] = df["fonte_recrutamento"].str.strip().str.title()
    
    # 2.4 Flag de candidato contratado (booleano)
    df["foi_contratado"] = df["foi_contratado"].astype(bool)
    
    # 2.5 Criar coluna de data do pipeline
    df["data_processamento"] = datetime.now()
    
    # 2.6 Remover duplicatas (se houver)
    df = df.drop_duplicates(subset=["email_candidato"])
    
    print(f"  → {len(df)} registros após transformação")
    print(f"  → Colunas criadas: nivel_exp, data_processamento")
    return df

# ═══════════════════════════════
# 3. LOAD
# ═══════════════════════════════
def load(df, destino):
    """Salva dados tratados"""
    print(f"[LOAD] Salvando em {destino}...")
    df.to_csv(destino, index=False)
    print(f"  → {len(df)} registros carregados com sucesso! ✅")
    return True

# ═══════════════════════════════
# EXECUÇÃO DO PIPELINE
# ═══════════════════════════════
if __name__ == "__main__":
    pipeline = extract("workbook_v1.xlsx")
    pipeline = transform(pipeline)
    load(pipeline, "candidatos_tratados.csv")
    
    # Relatório de qualidade
    print("\n📊 RELATÓRIO DE QUALIDADE:")
    print(f"  Total de registros: {len(pipeline)}")
    print(f"  Nulos em experiencia_anos: {pipeline['experiencia_anos'].isna().sum()}")
    print(f"  Distribuição por nível:")
    print(pipeline["nivel_exp"].value_counts().to_string())
```

## 🧰 Ecossistema Python para ETL

|Biblioteca|Pra que serve no pipeline|
|:--|:--|
|**pandas**|⭐ O coração — ler CSVs/Excel, limpar, agrupar, transformar|
|**sqlalchemy**|Conectar e escrever em bancos SQL (Postgres, MySQL)|
|**requests**|Extract de APIs REST (ex: puxar dados de uma API de RH)|
|**openpyxl / xlsxwriter**|Ler/escrever arquivos Excel com formatação|
|**google-auth / gspread**|Conectar no Google Sheets direto|
|**schedule / cron**|Agendar a execução do pipeline batch|
|**Apache Airflow / Prefect**|Orquestração profissional de pipelines|
