### 1) Teste t — comparar médias de dois grupos

**Quando usar:** comparar a média de duas amostras independentes.

**Exemplo — Recrutamento:**

- **Pergunta:** O tempo médio de contratação difere entre candidatos de LinkedIn vs Indicação?
- **Dados:**
    - LinkedIn: $$n_1 = 50$$, $$\bar{x}_1 = 35$$ dias, $$s_1 = 10$$
    - Indicação: $$n_2 = 30$$, $$\bar{x}_2 = 28$$ dias, $$s_2 = 8$$

**Hipóteses:**

- $$H_0$$: $$\mu_1 = \mu_2$$ (sem diferença)
- $$H_1$$: $$\mu_1 \neq \mu_2$$ (há diferença)

**Resultado:** se valor-p < 0,05 → rejeita $$H_0$$ → há diferença significativa.

**Aplicação:** se Indicação for significativamente mais rápido, vale investir em programa de referral.

---

### 2) Teste qui-quadrado — associação entre variáveis categóricas

**Quando usar:** verificar se duas variáveis categóricas estão associadas.

**Exemplo — QA:**

- **Pergunta:** O tipo de bug está associado à severidade?
- **Dados (tabela de contingência):**

|Tipo/Severidade|Baixa|Média|Alta|Crítica|
|---|---|---|---|---|
|UI|15|8|2|0|
|Backend|5|10|12|8|
|Integração|3|7|6|4|

**Hipóteses:**

- $$H_0$$: tipo de bug e severidade são independentes
- $$H_1$$: há associação entre tipo e severidade

**Resultado:** se valor-p < 0,05 → rejeita $$H_0$$ → bugs de Backend tendem a ser mais severos.

**Aplicação:** priorizar testes em Backend para prevenir bugs críticos.

---

### 3) Teste z para proporções — comparar taxas

**Quando usar:** comparar proporções entre dois grupos (amostras grandes).

**Exemplo — Recrutamento:**

- **Pergunta:** A taxa de contratação de Indicação é maior que LinkedIn?
- **Dados:**
    - LinkedIn: 200 candidatos, 30 contratados (15%)
    - Indicação: 50 candidatos, 20 contratados (40%)

**Hipóteses:**

- $$H_0$$: $$p_1 = p_2$$
- $$H_1$$: $$p_2 > p_1$$ (Indicação maior)

**Resultado:** se valor-p < 0,05 → Indicação tem taxa significativamente maior.

**Aplicação:** justificar investimento em programa de referral com dados.

---

### 4) ANOVA — comparar 3+ grupos

**Quando usar:** comparar médias de três ou mais grupos simultaneamente.

**Exemplo — QA:**

- **Pergunta:** O tempo médio de correção de bugs difere entre as 3 equipes de desenvolvimento?
- **Dados:**
    - Equipe A: $$\bar{x}_A = 4$$ horas
    - Equipe B: $$\bar{x}_B = 6$$ horas
    - Equipe C: $$\bar{x}_C = 8$$ horas

**Hipóteses:**

- $$H_0$$: $$\mu_A = \mu_B = \mu_C$$ (todas iguais)
- $$H_1$$: pelo menos uma difere

**Resultado:** se valor-p < 0,05 → há diferença. Depois, usa teste post-hoc (Tukey) para identificar quais pares diferem.

**Aplicação:** identificar equipe que precisa de mais suporte ou treinamento.

---

### 5) Teste de Mann-Whitney — dados não normais

**Quando usar:** comparar dois grupos quando os dados **não seguem distribuição normal** (comum em tempo, salário, bugs).

**Exemplo — Recrutamento:**

- **Pergunta:** O tempo para primeiro contato difere entre dias úteis e finais de semana?
- **Dados:** altamente assimétricos (outliers, cauda longa)

**Vantagem:** não exige normalidade, é robusto a outliers.

**Aplicação:** validar se SLA deve ser diferente para fins de semana.

---

### 6) Teste de Shapiro-Wilk — verificar normalidade

**Quando usar:** antes de escolher o teste, verificar se os dados são normais.

**Exemplo:**

- Você quer usar teste t, mas precisa confirmar normalidade.
- Aplica Shapiro-Wilk:
    - valor-p > 0,05 → dados normais → pode usar teste t
    - valor-p < 0,05 → dados não normais → use Mann-Whitney

**Aplicação:** escolher o teste correto e evitar conclusões erradas.

---

## Resumindo

- **Teste t**: comparar médias de dois grupos (dados normais)
- **Qui-quadrado**: associação entre categorias
- **Teste z**: comparar proporções (amostras grandes)
- **ANOVA**: comparar 3+ grupos
- **Mann-Whitney**: comparar dois grupos (dados não normais)
- **Shapiro-Wilk**: verificar normalidade antes de escolher o teste
