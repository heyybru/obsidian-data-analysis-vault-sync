### 🔶 O que é mapeamento?

- **Simples**: Função que lê input do HDFS e gera **pares (chave, valor)** pra cada linha/item.
- **Objetivo**: Paralelizar – roda em múltiplos DataNodes simultaneamente (fonte: paper Google MapReduce 2004).

### 1️⃣ Como funciona (passo a passo)

1. **Input**: Linhas de texto/arquivo gigante.
2. **Processo**: Sua função Map() aplicada em cada pedaço.
3. **Output**: Lista de (chave, valor) → vai pro Shuffle.

### 2️⃣ Exemplo prático (QA: logs de bugs JIRA)

Input: "erro404: linha1 | ok: linha2 | erro404: linha3"

**Código Java/Map simples:**

```java
public class Map {
  public void map(LongWritable key, Text value, Context context) {
    String[] palavras = value.toString().split(" ");  // Divide
    for (String p : palavras) {
      context.write(new Text(p), new IntWritable(1));  // (chave="erro404", valor=1)
    }
  }
}
```

- **Resultado**: ("erro404", 1), ("ok", 1), ("erro404", 1) → pronto pro Reduce somar.
