### Estrutura básica de um Job Flink (que o material sugere)

Um job Flink segue sempre esta arquitetura de 3 blocos:

```text
┌──────────┐    ┌───────────────┐    ┌──────────┐
│  SOURCE  │ →  │ TRANSFORMATION│ →  │   SINK   │
│ (fonte)  │    │  (operadores) │    │ (destino)│
└──────────┘    └───────────────┘    └──────────┘
```

**Exemplo mínimo que o material ensina:**

```python
from pyflink.datastream import StreamExecutionEnvironment
from pyflink.common.typeinfo import Types

# Cria o ambiente
env = StreamExecutionEnvironment.get_execution_environment()

# SOURCE: dados de exemplo (coleção)
dados = env.from_collection([
    "candidato1:10.9",
    "candidato2:4.6",
    "candidato3:1.4"
])

# TRANSFORMATION: extrair experiência
def extrair_exp(linha):
    nome, exp = linha.split(":")
    return (nome, float(exp))

stream = dados.map(extrair_exp, output_type=Types.TUPLE([Types.STRING(), Types.FLOAT()]))

# SINK: imprimir
stream.print()

# Executa
env.execute("Meu Primeiro Job Flink")
```
