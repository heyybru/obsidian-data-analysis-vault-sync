O **coeficiente de variação** mostra **o quanto os dados variam em relação à média**, em **porcentagem**.  
Ele ajuda a comparar a **dispersão** de conjuntos de dados diferentes, mesmo quando as médias são diferentes.

👉 Em resumo:  
**mostra se os dados são homogêneos (parecidos) ou heterogêneos (muito espalhados).**

---

## **Fórmula do Coeficiente de Variação**

CV = Desvio Padrao / Media

---

## **Como interpretar o CV**

- **CV baixo** → dados mais próximos da média (mais homogêneos)
    
- **CV alto** → dados mais espalhados (mais heterogêneos)
    

Regra prática mais usada:

- **CV ≤ 15%** → baixa dispersão
    
- **15% < CV ≤ 30%** → dispersão média
    
- **CV > 30%** → alta dispersão
    

---

## **Exemplo simples**

Suponha:

- Média das notas = **7**
    
- Desvio padrão = **1,4**
    

Cálculo:

CV = Desvio Padrao / Media
CV = 1,4 / 7

### **Interpretação**

O CV é **20%**, então existe uma **dispersão média** das notas em relação à média.

---

## **Por que o CV é importante?**

- Permite **comparar variabilidade** entre diferentes grupos
    
- Muito usado em **educação, RH, economia e pesquisas**
    
- Ajuda a entender se a média é **representativa** dos dados

---

## **Resumo rápido**

- **Desvio padrão** → mostra o espalhamento em valores absolutos
    
- **Coeficiente de variação** → mostra o espalhamento em **percentual**
