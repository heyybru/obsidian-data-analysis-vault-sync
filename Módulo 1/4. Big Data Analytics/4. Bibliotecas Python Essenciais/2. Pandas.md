## 🔷 Estruturas Básicas: Series e DataFrame

### ✅ **Series**: Coluna com índice

```python

salarios = pd.Series([5000, 6000, 7000, 5500], 
                     index=['Ana', 'Bruno', 'Carla', 'Daniel'])
```


## 🔷 Merge/Join (Combinar DataFrames)

### ✅ **Tipos de join**:

```python
# Dados de RH
rh = pd.DataFrame({
    'id': [1, 2, 3, 4],
    'nome': ['Ana', 'Bruno', 'Carla', 'Daniel'],
    'departamento_id': [101, 102, 101, 103]
})

# Dados de departamentos
departamentos = pd.DataFrame({
    'id': [101, 102, 103],
    'nome': ['TI', 'RH', 'Vendas']
})

# Inner join (padrão)
merged = pd.merge(rh, departamentos, 
                  left_on='departamento_id', 
                  right_on='id',
                  suffixes=('_func', '_dept'))

# Left join (mantém todos do RH)
merged_left = pd.merge(rh, departamentos, 
                       left_on='departamento_id', 
                       right_on='id',
                       how='left')
```

### ✅ **Exemplo RH+QA: Correlação**:

```python
# Dados de funcionários
funcionarios = pd.DataFrame({

    'experiencia': [3, 5, 8],

    'experiencia': 'first',
    'departamento': 'first',
```

## 🔷 Time Series (Séries Temporais)

```python
# Converter para datetime
bugs['data_abertura'] = pd.to_datetime(bugs['data_abertura'])
```

## 🔷 Performance e Otimização

### ✅ **Dicas de performance**:

```python
# Use .loc[] para seleção (mais rápido que chaining)
lento = candidatos[candidatos['idade'] > 25]['nome']  # Chaining
rapido = candidatos.loc[candidatos['idade'] > 25, 'nome']  # .loc

# Use operações vetorizadas (não apply quando possível)
lento = candidatos['salario'].apply(lambda x: x * 1.1)  # Apply
rapido = candidatos['salario'] * 1.1  # Vetorizado

# Especifique dtypes para economizar memória
candidatos['idade'] = candidatos['idade'].astype('int8')
candidatos['salario'] = candidatos['salario'].astype('float32')
```

### ✅ **Chunking para arquivos grandes**:

```python
# Processar CSV grande em pedaços
chunk_size = 10000
chunks = []

for chunk in pd.read_csv('candidatos_grande.csv', chunksize=chunk_size):
    # Processar cada chunk
    chunk_processado = chunk[chunk['experiencia'] > 3]
    chunks.append(chunk_processado)

# Combinar resultados
resultado = pd.concat(chunks, ignore_index=True)
```
