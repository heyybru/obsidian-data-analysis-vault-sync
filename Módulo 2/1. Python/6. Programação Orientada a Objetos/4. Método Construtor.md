O **método construtor** é o método que roda **automaticamente quando você cria um objeto**.  
Em Python, ele é (na prática) o **`__init__`**.

> Tecnicamente, quem “cria” o objeto é o `__new__`, mas no dia a dia/POO iniciante, quando falamos “construtor” em Python, quase sempre estamos falando do `__init__`.

---

## 1) Pra que serve o construtor?

- **inicializar atributos** do objeto (`self.nome = ...`)
- **definir valores padrão**
- **validar dados** na entrada
- deixar o objeto pronto para uso

---

## 2) Exemplo básico

```python
class Pessoa:
    def __init__(self, nome, idade):
        self.nome = nome
        self.idade = idade

p1 = Pessoa("Bruno", 30)  # __init__ é chamado aqui
print(p1.nome, p1.idade)
```

- `Pessoa("Bruno", 30)` cria a instância
- o Python chama `__init__(self, "Bruno", 30)`
- `self` é o próprio objeto (a instância recém-criada)

---

## 3) Construtor com valores padrão

```python
class Bug:
    def __init__(self, bug_id, severidade, status="ABERTO"):
        self.bug_id = bug_id
        self.severidade = severidade
        self.status = status

b = Bug(101, "CRITICO")  # status vira "ABERTO" por padrão
```

---

## 4) Construtor com validação (bem comum)

```python
class Conta:
    def __init__(self, saldo_inicial=0):
        saldo_inicial = float(saldo_inicial)
        if saldo_inicial < 0:
            raise ValueError("saldo inicial não pode ser negativo")
        self.saldo = saldo_inicial
```

✅ Assim você evita criar objetos em estado inválido.

---

## 5) Erro comum: esquecer o `self`

```python
class Exemplo:
    def __init__(self, x):
        self.x = x  # ✅ certo
        # x = x     # ❌ errado: não vira atributo do objeto
```
