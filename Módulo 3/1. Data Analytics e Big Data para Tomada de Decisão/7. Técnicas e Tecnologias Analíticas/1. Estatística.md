## 📊 1. Estatística Descritiva: O "O que aconteceu?"

É a base de tudo. Ela resume e descreve os dados que já temos.

- **Medidas de Tendência Central**:
    - **Média ($$\bar{x}$$)**: A soma de todos os valores dividida pela quantidade. Cuidado: ela é sensível a _outliers_ (valores muito fora da curva).
    - **Mediana**: O valor central. Se você organizar os salários de uma vaga de TI, a mediana mostra o valor que divide o grupo ao meio.
    - **Moda**: O valor que mais se repete. Útil para saber qual o erro mais comum no seu JIRA.
- **Medidas de Dispersão**:
    - **Desvio Padrão ($$\sigma$$)**: Indica o quanto os dados estão "espalhados". No QA, um desvio padrão alto no tempo de resposta de uma API indica instabilidade.
    - **Variância**: O quadrado do desvio padrão.

## 🧪 2. Estatística Inferencial: O "O que vai acontecer?"

Aqui usamos uma **amostra** para tirar conclusões sobre uma **população** inteira.

- **Teste de Hipóteses**: Usado para validar se uma mudança (como um novo fluxo de recrutamento) realmente surtiu efeito ou se foi apenas sorte.
- **P-Value (Valor-p)**: Se o `$$p < 0,05$$`, a probabilidade de o resultado ser por acaso é menor que `$$5\%$$`. Ou seja, o resultado é estatisticamente significante.
- **Intervalo de Confiança**: A margem de erro. "O tempo médio de contratação é de 20 dias, com `$$95\%$$` de confiança e erro de `$$\pm 2$$` dias".

## 📈 3. Distribuição de Frequência

Como vimos em suas memórias de estudo, a **Frequência Absoluta** é a contagem simples.

- **Exemplo**: Se em 100 testes de API, 5 falharam, a frequência absoluta de falhas é 5. A **Frequência Relativa** seria `$$5\%$$`.

## 💡 Insights do Especialista

- **Nada de Achismo**: Segundo a **Preditiva.ai**, decisões baseadas em estatística aumentam a precisão operacional em até `$$70\%$$`. No seu papel de Coordenador, usar o **Intervalo de Confiança** para prever prazos de entrega de vagas dá muito mais credibilidade.
- **Alfabetização de Dados (Data Literacy)**: O **Cappra Institute** reforça que entender a diferença entre média e mediana é o primeiro passo para não ser enganado por gráficos tendenciosos.
- **Qualidade dos Dados**: A **Snaq.co** alerta que a estatística só funciona se o dado estiver limpo. Se você tiver _bugs_ duplicados no JIRA, sua média de MTTR estará errada.
