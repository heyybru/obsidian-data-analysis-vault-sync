# 📘 Atualização de Dados – SQL (UPDATE)

### 🔹 Para que serve?

O comando **UPDATE** é usado para **alterar dados que já existem** em uma tabela.

---

## 🧩 Sintaxe básica

```sql
UPDATE nome_tabela
SET coluna1 = valor1,
    coluna2 = valor2
WHERE condição;
```

⚠️ **O WHERE é fundamental**.

---

## 🔹 Exemplo simples

```sql
UPDATE COLABORADOR
SET cargo = 'Analista'
WHERE id_colaborador = 1;
```

👉 Atualiza o cargo **somente** do colaborador com id 1.

---

## 🔹 Atualizando mais de uma coluna

```sql
UPDATE COLABORADOR
SET cargo = 'QA',
    salario = 3500
WHERE id_colaborador = 2;
```

---

## 🔹 Atualizar vários registros

```sql
UPDATE COLABORADOR
SET salario = salario * 1.10
WHERE cargo = 'Analista';
```

👉 Dá aumento apenas para analistas.

---

## ⚠️ Atualização sem WHERE (muito perigoso)

```sql
UPDATE COLABORADOR
SET cargo = 'Funcionário';
```

🚨 **Altera TODOS os registros da tabela**.

---

## 🔹 UPDATE com subconsulta

```sql
UPDATE COLABORADOR
SET salario = 4000
WHERE id_departamento =
      (SELECT id_departamento
       FROM DEPARTAMENTO
       WHERE nome_departamento = 'TI');
```

---

## 🧠 Erros comuns

- Esquecer o `WHERE`
    
- Tentar atualizar PK usada como FK em outra tabela
    
- Informar tipo de dado errado (texto sem aspas)
    

---

## 📌 Resumo rápido

- `UPDATE` altera dados
    
- `SET` define o novo valor
    
- `WHERE` define quem será alterado
    
- Sem `WHERE` → altera tudo

---
# 📘 Eliminação de Registros – SQL (DELETE)

### 🔹 Para que serve?

O comando **DELETE** é usado para **remover registros (linhas)** de uma tabela.

👉 A **estrutura da tabela continua existindo**.

---

## 🧩 Sintaxe básica

```sql
DELETE FROM nome_tabela
WHERE condição;
```

⚠️ **O WHERE é essencial**.

---

## 🔹 Exemplo simples

```sql
DELETE FROM COLABORADOR
WHERE id_colaborador = 3;
```

👉 Remove **apenas** o colaborador com id 3.

---

## 🔹 Excluir vários registros

```sql
DELETE FROM COLABORADOR
WHERE cargo = 'Estagiário';
```

---

## ⚠️ DELETE sem WHERE (perigoso)

```sql
DELETE FROM COLABORADOR;
```

🚨 **Apaga todos os registros da tabela**  
📌 A tabela continua existindo.

---

## 🔹 DELETE com subconsulta

```sql
DELETE FROM COLABORADOR
WHERE id_departamento =
      (SELECT id_departamento
       FROM DEPARTAMENTO
       WHERE nome_departamento = 'RH');
```

---

## 🔹 DELETE x TRUNCATE (diferença importante)

|DELETE|TRUNCATE|
|---|---|
|Remove linhas|Remove todas as linhas|
|Pode usar WHERE|Não usa WHERE|
|Pode dar ROLLBACK|Não permite ROLLBACK|
|É DML|É DDL|

---

## ⚠️ Regras com FK

- Não é possível deletar um registro **referenciado por FK**
    
- A menos que exista:
    
    - `ON DELETE CASCADE`
        
    - Ou exclusão prévia dos registros dependentes
        

---

## 🧠 Resumo rápido

- `DELETE` remove registros
    
- Sempre usar `WHERE`
    
- Sem `WHERE` → apaga tudo
    
- TRUNCATE ≠ DELETE
