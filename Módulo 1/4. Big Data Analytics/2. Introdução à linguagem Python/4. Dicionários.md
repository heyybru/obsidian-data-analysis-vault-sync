**Dicionários são como "fichários" onde cada coisa tem uma etiqueta**.  
Em vez de buscar por posição (como nas listas), você busca por **chave** (nome da etiqueta).

✅ **No seu contexto (RH + QA)**:

- **RH**: Ficha do candidato (nome, email, experiência, status)
- **QA**: Registro de bug (ID, título, severidade, módulo, status)

---

## 🔷 Sintaxe 

### ✅ **Criar dicionário**

```python
# Chaves {} com pares chave:valor
candidato = {
    "nome": "Bruno Silva",
    "email": "bruno@email.com",
    "experiencia": 4,
    "aprovado": True
}
```

### ✅ **Dicionário vazio**

```python
bug = {}
candidato = dict()  # Outra forma
```

## 🔷 Acessando valores (por chave, não por posição)

```python
candidato = {
    "nome": "Bruno Silva",
    "email": "bruno@email.com",
    "experiencia": 4
}

# Acesso direto
print(candidato["nome"])        # "Bruno Silva"
print(candidato["experiencia"]) # 4

# Acesso com get() (mais seguro)
print(candidato.get("email"))   # "bruno@email.com"
print(candidato.get("telefone", "Não informado"))  # "Não informado" (valor padrão)
```

**Visual mental**:

```
Chave:    "nome"         "email"            "experiencia"
Valor:    "Bruno Silva"  "bruno@email.com"  4
```

## 🔷 Operações básicas (o que você mais vai usar)

### ✅ **Adicionar/Atualizar**

```python
candidato = {"nome": "Bruno"}

# Adiciona nova chave
candidato["email"] = "bruno@email.com"

# Atualiza valor existente
candidato["nome"] = "Bruno Silva"

# Atualiza múltiplas chaves
candidato.update({"experiencia": 4, "cargo": "QA"})
```

### ✅ **Remover**

```python
candidato = {"nome": "Bruno", "email": "bruno@email.com", "experiencia": 4}

# Remove por chave (e retorna valor)
email = candidato.pop("email")  # email = "bruno@email.com"

# Remove último item (Python 3.7+ mantém ordem)
ultimo = candidato.popitem()  # ("experiencia", 4)

# Remove tudo
candidato.clear()  # {}
```

### ✅ **Verificar existência**

```python
candidato = {"nome": "Bruno", "email": "bruno@email.com"}

# Verifica se chave existe
tem_email = "email" in candidato  # True
tem_telefone = "telefone" in candidato  # False

# Verifica se valor existe
tem_bruno = "Bruno" in candidato.values()  # True
```

## 🔷 Métodos úteis

### ✅ **Obter todas chaves/valores**

```python
candidato = {"nome": "Bruno", "email": "bruno@email.com", "experiencia": 4}

chaves = candidato.keys()    # dict_keys(['nome', 'email', 'experiencia'])
valores = candidato.values() # dict_values(['Bruno', 'bruno@email.com', 4])
itens = candidato.items()    # dict_items([('nome', 'Bruno'), ('email', 'bruno@email.com'), ...])
```

### ✅ **Tamanho do dicionário**

```python
candidato = {"nome": "Bruno", "email": "bruno@email.com"}
total = len(candidato)  # 2
```

## 🔷 Percorrendo dicionários (iteração)

### ✅ **Percorrer chaves**

```python
candidato = {"nome": "Bruno", "email": "bruno@email.com", "experiencia": 4}

for chave in candidato:
    print(chave)  # nome, email, experiencia

# Ou explicitamente
for chave in candidato.keys():
    print(chave)
```

### ✅ **Percorrer valores**

```python
for valor in candidato.values():
    print(valor)  # Bruno, bruno@email.com, 4
```

### ✅ **Percorrer chave e valor juntos**

```python
for chave, valor in candidato.items():
    print(f"{chave}: {valor}")
# nome: Bruno
# email: bruno@email.com  
# experiencia: 4
```

## 🔷 Dicionários vs Listas (quando usar cada)

|Quando usar|Lista|Dicionário|
|---|---|---|
|**Busca por**|Posição (0, 1, 2...)|Nome/chave|
|**Ordenação**|Mantém ordem|Mantém ordem (Python 3.7+)|
|**Exemplo RH**|Lista de candidatos|Ficha de UM candidato|
|**Exemplo QA**|Lista de bugs IDs|Detalhes de UM bug|
|**Performance**|Busca O(n)|Busca O(1) (rápida)|

**Exemplo combinado**:

```python
# Lista de dicionários (COMUM em dados)
candidatos = [
    {"nome": "Bruno", "experiencia": 4, "status": "aprovado"},
    {"nome": "Ana", "experiencia": 2, "status": "pendente"},
    {"nome": "Carlos", "experiencia": 5, "status": "aprovado"}
]

# Filtra aprovados com experiência > 3
aprovados_experientes = [
    c for c in candidatos 
    if c["status"] == "aprovado" and c["experiencia"] > 3
]
```

## 🔷 Exercício prático

**Crie um sistema de triagem de bugs**:

```python
print("=== Sistema de Triagem de Bugs ===")

# Bug inicial
bug = {
    "id": "BUG-001",
    "titulo": "Erro no login",
    "severidade": "medio",
    "status": "novo"
}

# Adiciona informações
bug["reporter"] = "usuário123"
bug["data"] = "2026-01-22"
bug["modulo"] = "autenticacao"

# Atualiza severidade baseado no módulo
if bug["modulo"] == "autenticacao":
    bug["severidade"] = "alto"

# Mostra informações
print(f"Bug {bug['id']}: {bug['titulo']}")
print(f"Severidade: {bug['severidade'].upper()}")
print(f"Módulo: {bug['modulo']}")

# Verifica se precisa atenção imediata
if bug["severidade"] in ["alto", "critico"]:
    print("⚠️ ATENÇÃO: Bug de alta prioridade!")
```
