A federação permite que um usuário use uma única credencial para acessar recursos em diferentes domínios ou organizações parceiras.

- **SSO (Single Sign-On) Federado:** Permite que você se autentique uma vez e acesse vários sistemas (ex: usar seu e-mail corporativo do Google para logar no Slack ou no Jira).
- **SAML:** É o padrão de comunicação (linguagem) usado para trocar essas informações de autenticação de forma segura entre os domínios.
- **Benefício:** Reduz a sobrecarga administrativa e melhora a experiência do usuário, mantendo uma postura de segurança robusta.
