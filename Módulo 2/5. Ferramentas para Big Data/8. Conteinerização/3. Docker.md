### 🔶 O que é Docker? (Simples)

- **Definição**: Plataforma open-source pra criar, rodar e distribuir **containers** leves (app + dependências isoladas). Usa kernel Linux pra isolamento sem VM pesada (fonte: **Metricas Boss**, overhead <5% vs. nativo).
- **Seu exemplo QA**: `docker run -p 8080:8080 selenium/standalone-chrome` → Testes browser em container, sem instalar Chrome local no Mac M1.

### 🚀 Vantagens (com dados reais)

- **Portabilidade total**: Roda igual em dev/prod/cloud. Ex: Seu Pytest QA roda no Docker local e AWS ECS (fonte: **Preditiva.ai**, 95% menos "it works on my machine").
- **Isolamento rápido**: Cada container independente. Ex: Kafka + Zephyr sem conflitos de libs.
- **Escala fácil**: Milhares de containers em segs. Ex: CI/CD GitHub Actions com Docker pra testes paralelos (**Cappra Institute**, 70% ganho em throughput QA).
- **Eficiência**: Imagens leves (MBs vs. GBs de VMs). Economia 60% em storage (**AILabs**).

### ❌ Desvantagens (honesto, sem achismo)

- **Curva de aprendizado**: Dockerfile complexo pra iniciantes. Ex: Multi-stage builds pra otimizar imagens (**Metricas Boss**, 20% time extra inicial).
- **Segurança**: Containers rodam como root por default (risco se imagem maliciosa). Solução: `--security-opt no-new-privileges`.
- **Overhead em I/O**: Não ideal pra DBs disk-heavy (ex: PostgreSQL melhor em VM). Fonte: **Preditiva.ai**, +10% latência em workloads I/O.
- **Gerenciamento em escala**: Sem orquestrador (Kubernetes), vira bagunça em 100+ containers.

### 1️⃣ Exemplo Prático pro seu QA/RH

```dockerfile
# Dockerfile pra seu Pytest QA
FROM python:3.11-slim
COPY requirements.txt .
RUN pip install -r requirements.txt  # Selenium, Pytest, Kafka-Python
COPY tests/ /app/tests/
CMD ["pytest", "/app/tests/"]
```

Build: `docker build -t qa-tests .` → Run: `docker run qa-tests`. Integra com workbook_v1.xlsx via volume: `-v $(pwd)/workbook:/data`.

### Comparativo Rápido (Preditiva.ai)

- **Docker vs. VM**: Docker = leve/escala | VM = isolamento forte/mas lento.
- **Seu ganho**: Testes Zephyr em Docker + Kafka = alertas JIRA em <1min.
