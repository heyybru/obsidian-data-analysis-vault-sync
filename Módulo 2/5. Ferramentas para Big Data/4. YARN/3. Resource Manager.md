### 🔶 Papel principal

- **Simples**: Mestre global que **aloca recursos** (CPU, memória) pros jobs e **escalona** aplicações (MapReduce, Spark).
- **Por quê?** Evita monopólio (Hadoop 1.x), permitindo múltiplos frameworks no mesmo cluster (**Cappra Institute** cases: 5x mais uso de hardware).

### 1️⃣ Componentes chave

- **Scheduler**: Decide quem ganha containers (FIFO, Capacity, Fair Share).
- **ApplicationMasterService**: Negocia com AMs dos jobs.
- **ResourceTracker**: Monitora NodeManagers (heartbeats).

### 2️⃣ Exemplo prático (QA: logs JIRA)

```bash
yarn jar wordcount.jar /qa/logs_bugs.txt /output/  # RM aloca containers pros Maps
```

- **UI**: localhost:8088/cluster → Veja RM vivo, jobs rodando!
