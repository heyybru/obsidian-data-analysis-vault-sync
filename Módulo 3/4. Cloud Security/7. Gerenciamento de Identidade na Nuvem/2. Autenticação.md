É o processo de validar se quem está tentando acessar o sistema é realmente quem diz ser.

- **As Duas Etapas:**
    1. **Identificação:** Apresentar um identificador (ex: nome de usuário).
    2. **Verificação:** Apresentar algo que comprove o vínculo (ex: senha).
- **Os 4 Meios de Autenticação:**
    - **Algo que você sabe:** Senha, PIN, perguntas de segurança.
    - **Algo que você possui:** Token físico, chave criptográfica, smart card.
    - **Algo que você é (Biometria Estática):** Digital, reconhecimento facial, retina.
    - **Algo que você faz (Biometria Dinâmica):** Padrão de voz, ritmo de digitação.
- **MFA (Multifator):** O material recomenda o uso de mais de um fator para contas críticas.
