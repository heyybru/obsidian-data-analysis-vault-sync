👉 Servem para **trabalhar com textos (VARCHAR / CHAR)** em consultas SQL.  
São **funções de uma única linha**.

---
## 🔠 UPPER / LOWER / INITCAP

```sql
SELECT UPPER(nome),
       LOWER(email),
       INITCAP(nome)
FROM USUARIO;
```

- `UPPER` → tudo MAIÚSCULO
    
- `LOWER` → tudo minúsculo
    
- `INITCAP` → Primeira letra de cada palavra em maiúsculo

---

## 📏 LENGTH

```sql
SELECT nome,
       LENGTH(nome) AS tamanho
FROM USUARIO;
```

👉 Retorna a quantidade de caracteres.

---

## ✂ SUBSTR

```sql
SELECT SUBSTR(nome, 1, 4)
FROM USUARIO;
```

- Posição inicial começa em **1**
    
- Também aceita tamanho:

```sql
SUBSTR(nome, 2, 3)
```

---

## 🔍 INSTR

```sql
SELECT INSTR(email, '@')
FROM USUARIO;
```

👉 Retorna a posição onde o texto foi encontrado.

---

## 🔄 REPLACE

```sql
SELECT REPLACE(telefone, '-', '')
FROM USUARIO;
```

👉 Substitui caracteres ou textos.

---

## 🧩 CONCAT / ||

```sql
SELECT CONCAT(nome, sobrenome)
FROM USUARIO;
```

Ou (mais usado):

```sql
SELECT nome || ' ' || sobrenome
FROM USUARIO;
```

---

## 🚫 TRIM / LTRIM / RTRIM

```sql
SELECT TRIM(nome)
FROM USUARIO;
```

- `TRIM` → remove espaços dos dois lados
    
- `LTRIM` → esquerda
    
- `RTRIM` → direita
    

---

## ⚠ NVL 

```sql
SELECT NVL(telefone, 'Não informado')
FROM USUARIO;
```

👉 Substitui **NULL** por um valor.

---

## 📌 Exemplo completo

```sql
SELECT INITCAP(nome) AS nome_formatado,
       SUBSTR(email, 1, INSTR(email, '@') - 1) AS usuario_email,
       LENGTH(nome) AS qtd_letras
FROM USUARIO;
```

---

## 🧠 Dicas 

- Funções de caracteres **não alteram a tabela**, só a consulta
    
- `SUBSTR` começa em 1, não em 0
    
- `||` é concatenação no Oracle
    
- `NVL` evita erro com NULL
    
---

## 📘 Resumo rápido

- Manipulam textos
    
- Funcionam linha a linha
    
- Muito usadas em `SELECT`
    
- Caem bastante em exercícios práticos
