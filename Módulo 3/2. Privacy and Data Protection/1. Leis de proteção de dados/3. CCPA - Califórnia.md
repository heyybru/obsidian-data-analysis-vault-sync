### 🌉 O que é a CCPA?

A **CCPA (2018)**, atualizada pela **CPRA (2020)**, é a lei que concede aos residentes da Califórnia um controle sem precedentes sobre suas informações pessoais.

- **Foco**: Diferente do GDPR (foco em privacidade como direito humano), a CCPA foca no **Direito do Consumidor** e na transparência comercial.
- **Extraterritorialidade**: Aplica-se a qualquer empresa no mundo que faça negócios na Califórnia e atenda a critérios de receita ou volume de dados.

### 📊 CCPA vs. GDPR/LGPD: A Diferença Crucial

A maior diferença técnica que você encontrará no seu `dataset_recrutamento` é o modelo de consentimento.

| Característica            | GDPR / LGPD                                    | CCPA (Califórnia)                                                 |
| ------------------------- | ---------------------------------------------- | ----------------------------------------------------------------- |
| <b>Modelo Base</b>        | <b>Opt-in</b> (Precisa de autorização prévia). | <b>Opt-out</b> (Pode coletar, mas deve permitir parar).           |
| <b>Direito de Venda</b>   | Restrito pela finalidade.                      | Foco total no direito de dizer "Não venda meus dados".            |
| <b>Definição de Dados</b> | Dados que identificam a pessoa.                | Dados que identificam o <b>indivíduo ou a residência</b>.         |
| <b>Multas</b>             | Baseadas no faturamento global.                | Baseadas em <b>valor fixo por violação</b> (ex: $2.500 a $7.500). |

### 🧪 O Olhar do QA: O Botão "Do Not Sell"

Na CCPA, existe uma exigência visual e funcional obrigatória: o link **"Do Not Sell My Personal Information"**. Como Analista de QA, seus testes devem garantir:

- **Funcionalidade**: Ao clicar, o sistema deve marcar o perfil do usuário como "Opt-out" no banco de dados (**PostgreSQL**).
- **Sincronização**: Esse status deve ser propagado para todos os parceiros de dados e ferramentas de terceiros (ex: ferramentas de Analytics).
- **Acessibilidade**: O link deve estar visível e fácil de encontrar, sem "dark patterns" (técnicas de design para enganar o usuário).

### 🛠️ Prática com Python: Filtrando Opt-outs

Imagine que você recebeu um dataset de candidatos e precisa garantir que não vai processar dados de quem solicitou o "Opt-out" sob a CCPA:

``` 
import pandas as pd

# Sample DataFrame of candidates
candidates_data = {
    'name': ['Alice', 'Bob', 'Charlie', 'Diana', 'Eve', 'Frank', 'Grace'],
    'ccpa_opt_out': [True, False, True, False, False, True, False]
}
df = pd.DataFrame(candidates_data)

print("Original number of candidates:", len(df))
print("Original DataFrame:")
print(df)

# Filter: remove candidates where ccpa_opt_out is True
filtered_df = df[~df['ccpa_opt_out']]

print("\nFiltered DataFrame (ccpa_opt_out == False):")
print(filtered_df)
print("Remaining candidates:", len(filtered_df))

# Calculate percentage that remained
percentage_remaining = (len(filtered_df) / len(df)) * 100
print(f"\nPercentage of candidates that remained: {percentage_remaining:.2f}%")
```

### 💡 Insights do Especialista

- **Gestão de Riscos**: A **Preditiva.ai** alerta que o risco financeiro da CCPA é calculado por titular. Se você vazar dados de 10.000 californianos, a multa pode chegar a `$$10.000 \times \$7.500 = \$75.000.000$$`.
- **Snaq.co Tip**: Verifique se os seus provedores de nuvem (**Cloud Computing**) têm o selo de conformidade com a CCPA. Se eles falharem, a responsabilidade pode recair sobre a sua empresa.
- **Cultura de Dados**: O **Cappra Institute** reforça que a CCPA mudou a relação de poder. O dado não é da empresa; ela apenas tem uma "licença de uso" revogável pelo consumidor a qualquer momento.
