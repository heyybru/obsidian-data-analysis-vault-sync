### 🔶 Pub x Sub: Diferenças Simples

- **Pub (Publisher/Producer)**: Envia mensagens pra um **tópico** (categoria lógica). Não sabe quem recebe. Ex.: Seu app Zephyr publica "Bug #123".
- **Sub (Subscriber/Consumer)**: Inscreve-se no tópico e **puxa** mensagens. Múltiplos subs por tópico. Ex.: JIRA e workbook_v1.xlsx leem o mesmo evento.

**Fluxo**: Pub → Tópico (intermediário) → Subs (paralelo). Desacoplado total (fonte: **Métricas Boss**, 99,99% de durabilidade).

### 🚀 Exemplo Prático pro seu QA

```python
# Pub (envía log Zephyr)
producer.send('qa-alertas', value=b'Erro API 500')

# Sub (lê e processa)
consumer = KafkaConsumer('qa-alertas', group_id='qa-team')
for msg in consumer: print(msg.value)  # JIRA + Excel
```
