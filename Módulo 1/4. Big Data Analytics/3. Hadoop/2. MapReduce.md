**MapReduce é como "dividir para conquistar" em dados gigantes**.  
Em vez de processar 1TB em uma máquina (impossível), você divide em 1000 pedaços e processa em 1000 máquinas paralelas.

✅ **No seu contexto (RH + QA)**:

- **RH**: Contar quantos candidatos por estado entre 10 milhões de registros
- **QA**: Calcular média de bugs por módulo em 1TB de logs

---

## 🔷 O Problema que MapReduce Resolve

### ❌ **Processamento tradicional (falha)**:

```python
# Tentar processar 1TB em uma máquina
dados = carregar_1TB_de_dados()  # ❌ Memória explode
resultado = processar_tudo(dados)  # ❌ Leva semanas
```

### ✅ **MapReduce (solução)**:

```
1TB de dados → Dividir em 1000 pedaços de 1GB → 
1000 máquinas processam paralelo → 
Juntar resultados → Resposta em minutos
```

---

## 🔷 Os 3 Passos do MapReduce

### ✅ **1. Map (mapear)**

- **Entrada**: Pedaço dos dados
- **Processa**: Extrai/transforma informação relevante
- **Saída**: Pares chave-valor `(chave, valor)`

### ✅ **2. Shuffle (embaralhar)**

- Agrupa todos os valores com mesma chave
- Envia para mesma máquina reducer

### ✅ **3. Reduce (reduzir)**

- **Entrada**: `(chave, [lista_de_valores])`
- **Processa**: Agrega/calcula resultado final
- **Saída**: Resultado final `(chave, resultado)`

## 🔷 Exemplo Clássico: Contar Palavras

**Problema**: Contar quantas vezes cada palavra aparece em 10GB de texto.

### ✅ **Sem MapReduce (impossível)**:

```python
texto = carregar_10GB()  # ❌ Não cabe na memória
contagem = {}
for palavra in texto.split():
    contagem[palavra] += 1  # ❌ Levaria horas
```

### ✅ **Com MapReduce**:

**Passo 1: Map (paralelo)**:

```python
# Cada máquina processa 1GB
def map(documento):
    for palavra in documento.split():
        yield (palavra, 1)  # ("python", 1), ("java", 1), ("python", 1)
```

**Passo 2: Shuffle (agrupa por chave)**:

```
Máquina 1: [("python", 1), ("java", 1)]
Máquina 2: [("python", 1), ("c++", 1)]
Máquina 3: [("java", 1), ("python", 1)]

Após shuffle:
("python", [1, 1, 1]) → Vai para Reducer 1
("java", [1, 1])      → Vai para Reducer 2  
("c++", [1])          → Vai para Reducer 3
```

**Passo 3: Reduce (soma)**:

```python
def reduce(palavra, contagens):
    total = sum(contagens)  # Soma todos os 1s
    return (palavra, total)

# Resultado final:
# ("python", 3), ("java", 2), ("c++", 1)
```

## 🔷 Analogia Prática (RH + QA)

### ✅ **Exemplo RH: Contar candidatos por estado**

**Dados**: 10 milhões de candidatos, cada um com estado

**Map (paralelo)**:

```python
# Cada máquina processa 100.000 candidatos
def map(candidato):
    estado = candidato["estado"]
    yield (estado, 1)  # ("SP", 1), ("RJ", 1), ("SP", 1)
```

**Shuffle**: Agrupa todos `("SP", [1, 1, 1, ...])`

**Reduce (soma)**:

```python
def reduce(estado, contagens):
    total = sum(contagens)
    return (estado, total)

# Resultado: ("SP", 5.200.000), ("RJ", 2.100.000), ...
```

### ✅ **Exemplo QA: Média de bugs por desenvolvedor**

**Dados**: 1 milhão de bugs, cada um com desenvolvedor responsável

**Map (paralelo)**:

```python
def map(bug):
    dev = bug["desenvolvedor"]
    severidade = bug["severidade"]
    # Conta 1 bug por desenvolvedor
    yield (dev, 1)
    # Também conta severidade
    yield (f"{dev}_{severidade}", 1)
```

**Shuffle**: Agrupa por desenvolvedor

**Reduce (média)**:

```python
def reduce(chave, contagens):
    total = sum(contagens)
    return (chave, total)

# Resultado: ("joao", 45), ("maria", 32), ...
```

## 🔷 Vantagens do MapReduce

### ✅ **1. Escalabilidade linear**

- 10 máquinas = 10x mais rápido
- 100 máquinas = 100x mais rápido
- Adiciona máquinas conforme necessidade

### ✅ **2. Tolerância a falhas**

- Se uma máquina falha, outra pega seu trabalho
- Hadoop redistribui automaticamente

### ✅ **3. Data locality**

- Processa dados **onde estão armazenados**
- Evita mover terabytes pela rede

### ✅ **4. Simplicidade**

- Programador só escreve Map e Reduce
- Hadoop cuida do resto (divisão, distribuição, falhas)

---

## 🔷 Limitações do MapReduce

### ❌ **1. Batch-only**

- Processa em lotes, não streaming
- Para dados em tempo real, use Spark Streaming

### ❌ **2. Muito I/O disco**

- Lê/escreve disco entre Map e Reduce
- Spark resolve com memória (RDDs)

### ❌ **3. Complexidade para algoritmos iterativos**

- Machine learning precisa de múltiplas iterações
- Cada iteração = novo MapReduce job (lento)

### ❌ **4. Programação de baixo nível**

- Escrever Map/Reduce manualmente é complexo
- Spark SQL/Hive são mais amigáveis

## 🔷 Exemplo de Código Hadoop (Java)

```java
// Contar candidatos por estado
public class CandidatosPorEstado {
    
    // MAP: Extrai estado de cada candidato
    public static class MapClass extends Mapper<LongWritable, Text, Text, IntWritable> {
        public void map(LongWritable key, Text value, Context context) {
            String linha = value.toString();
            String estado = linha.split(",")[3]; // Coluna estado
            context.write(new Text(estado), new IntWritable(1));
        }
    }
    
    // REDUCE: Soma contagens por estado
    public static class ReduceClass extends Reducer<Text, IntWritable, Text, IntWritable> {
        public void reduce(Text key, Iterable<IntWritable> values, Context context) {
            int soma = 0;
            for (IntWritable val : values) {
                soma += val.get();
            }
            context.write(key, new IntWritable(soma));
        }
    }
}
```

## 🔷 Evolução: MapReduce → Spark

**MapReduce (2004)**:

- ✅ Primeira solução para Big Data
- ❌ Muito I/O disco, lento para iterações

**Spark (2014)**:

- ✅ Processa em memória (100x mais rápido)
- ✅ Suporte a streaming, ML, gráficos
- ✅ APIs mais amigáveis (Scala, Python, Java)

**Hoje**: Spark é mais usado, mas MapReduce ainda é importante para entender os conceitos.

### ✅ **RH: People Analytics em escala**

```python
# Pseudocódigo MapReduce para análise de turnover
def map(registro_funcionario):
    departamento = registro["departamento"]
    anos_empresa = registro["anos_empresa"]
    saiu = 1 if registro["saiu"] else 0
    yield (departamento, (1, saiu, anos_empresa))

def reduce(departamento, valores):
    total_func, total_saiu, soma_anos = 0, 0, 0
    for v in valores:
        total_func += v[0]
        total_saiu += v[1]
        soma_anos += v[2]
    
    taxa_turnover = total_saiu / total_func * 100
    media_anos = soma_anos / total_func
    return (departamento, taxa_turnover, media_anos)
```

# Pseudocódigo MapReduce para bugs por módulo/hora
def map(log_bug):
    modulo = log_bug["modulo"]

## 🔷 Quando Usar MapReduce Hoje

### ✅ **Use quando**:

- Dados **muito grandes** para uma máquina
- Processamento **batch** (não tempo real)
- **Hadoop** já está instalado
- **Legacy** systems

### ❌ **Não use quando**:

- Precisa de **tempo real** (use Spark Streaming)
- **Iterações complexas** (use Spark MLlib)
- **Desenvolvimento rápido** (use Spark SQL/Pandas)
