No **Pandas**, as funções matemáticas servem para fazer **cálculos numéricos** nas colunas e nos dados do DataFrame.

Elas são muito usadas para:

- **somar valores**
- **calcular média**
- **achar mínimo e máximo**
- **contar registros**
- **calcular desvio padrão**
- **fazer operações entre colunas**

Na prática, elas ajudam a transformar dados brutos em **informação analisável**.

---

## Ideia principal

Se você tem uma coluna numérica, pode aplicar funções matemáticas nela.

Exemplo:

```python
df["salario"].mean()
```

Esse comando calcula a **média** da coluna `salario`.

---

## Funções matemáticas mais usadas

### `sum()`

Soma os valores.

```python
df["salario"].sum()
```

### `mean()`

Calcula a média.

```python
df["idade"].mean()
```

### `min()`

Retorna o menor valor.

```python
df["idade"].min()
```

### `max()`

Retorna o maior valor.

```python
df["idade"].max()
```

### `count()`

Conta quantos valores não nulos existem.

```python
df["idade"].count()
```

### `std()`

Calcula o desvio padrão.

```python
df["idade"].std()
```

### `median()`

Calcula a mediana.

```python
df["idade"].median()
```

### `mode()`

Retorna a moda, ou seja, o valor mais frequente.

```python
df["cidade"].mode()
```

---

## Exemplo prático

```python
import pandas as pd

df = pd.DataFrame({
    "idade": [22, 25, 30, 35, 40],
    "salario": [2000, 2500, 3000, 4000, 5000]
})

print(df["idade"].sum())
print(df["idade"].mean())
print(df["idade"].min())
print(df["idade"].max())
print(df["idade"].median())
```

---

## O que cada uma mostra

- **`sum()`** → total
- **`mean()`** → média
- **`min()`** → menor valor
- **`max()`** → maior valor
- **`median()`** → valor central
- **`std()`** → dispersão dos dados
- **`count()`** → quantidade de valores válidos

---

## Aplicando no DataFrame inteiro

Você também pode aplicar em todas as colunas numéricas:

```python
df.sum()
df.mean()
df.min()
df.max()
```

### Exemplo

```python
print(df.mean())
```

O Pandas calcula a média de cada coluna numérica.

---

## Operações matemáticas entre colunas

Além das funções prontas, você pode fazer contas diretamente.

### Exemplo: criar nova coluna

```python
df["bonus"] = df["salario"] * 0.10
```

### Exemplo: soma entre colunas

```python
df["total"] = df["salario"] + df["bonus"]
```

### Exemplo: diferença

```python
df["diferenca"] = df["meta"] - df["realizado"]
```

---

## Exemplo completo com novas colunas

```python
import pandas as pd

df = pd.DataFrame({
    "salario": [2000, 3000, 4000]
})

df["bonus"] = df["salario"] * 0.1
df["salario_total"] = df["salario"] + df["bonus"]

print(df)
```

---

## Cuidados importantes

### Dados faltantes

Se houver `NaN`, algumas funções ignoram esses valores automaticamente.

Exemplo:

```python
df["idade"].mean()
```

O Pandas normalmente calcula a média ignorando os nulos.

### Tipo da coluna

A função matemática precisa fazer sentido para a coluna.

Exemplo:

- `mean()` funciona em coluna numérica
- não faz sentido em coluna com nomes

---

## Relação com análise estatística

Do ponto de vista de **estatística descritiva**, essas funções resumem a distribuição dos dados.

### Medidas de tendência central

- **média**
- **mediana**
- **moda**

### Medidas de dispersão

- **desvio padrão**
- **mínimo**
- **máximo**
- **amplitude**
    - que você pode calcular como:

```python
df["idade"].max() - df["idade"].min()
```

---

## Exemplo aplicado à análise

Imagine uma base de salários:

```python
print("Média:", df["salario"].mean())
print("Mediana:", df["salario"].median())
print("Máximo:", df["salario"].max())
print("Mínimo:", df["salario"].min())
```

Isso já permite responder:

- qual é o salário médio?
- existe grande variação?
- há valores extremos?
- a mediana está muito distante da média?

Se estiver, pode ser indício de **assimetria** ou **outliers**.
