### 🔶 **Navegação e listagem**

- **`hdfs dfs -ls /caminho`**: Lista arquivos/pastas (como `ls`).
    
    ```bash
    hdfs dfs -ls /user/bruno/qa/  # Lista logs de testes
    ```
    
- **`hdfs dfs -mkdir /pasta`**: Cria pasta.
    
    ```bash
    hdfs dfs -mkdir /qa/logs_jira/  # Pasta pra bugs Zephyr
    ```
    

### 🔶 **Upload/Download (essenciais pro QA)**

- **`hdfs dfs -put local.txt /hdfs/`**: Envia arquivo local pro HDFS.
    
    ```bash
    hdfs dfs -put ~/logs_api_1GB.txt /qa/  # Logs de API pro HDFS
    ```
    
- **`hdfs dfs -get /hdfs/arquivo local/`**: Baixa do HDFS.
    
    ```bash
    hdfs dfs -get /qa/resultado_bugs.txt ~/relatorio/
    ```
    
- **`hdfs dfs -copyFromLocal`**: Mesmo que put, mas mais opções.

### 🔶 **Leitura e deleção**

- **`hdfs dfs -cat /arquivo`**: Mostra conteúdo (como `cat`).
    
    ```bash
    hdfs dfs -cat /qa/contagem_erros.txt  # Vê output MapReduce
    ```
    
- **`hdfs dfs -rm /arquivo`**: Deleta (cuidado!).
    
    ```bash
    hdfs dfs -rm /qa/logs_antigos.txt
    ```
    
- **`hdfs dfs -rm -r /pasta`**: Deleta recursivo.

### 🔶 **Administração e diagnóstico**

- **`hdfs dfsadmin -report`**: Status do cluster (espaço, nós vivos).
    
    ```bash
    hdfs dfsadmin -report  # Veja DataNodes e uso de disco
    ```
    
- **`hdfs fsck /caminho -files -blocks`**: Verifica integridade (blocos/réplicas).
    
    ```bash
    hdfs fsck /qa/logs_jira.txt -blocks  # Confere réplicas 3x
    ```
