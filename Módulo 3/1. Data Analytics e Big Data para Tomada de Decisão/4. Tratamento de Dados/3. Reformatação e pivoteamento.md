### **O Que é Reformatação e Pivoteamento?**

- **Reformatação**: Mudar estrutura (wide/long format, renomear cols, tipos dados).
- **Pivoteamento**: Transformar linhas em colunas (ou vice-versa) pra resumir/agrupar. Ex: Vendas por mês/produto → tabela com meses como cols.
- **Por quê?**: Facilita análise (dashboards, ML), reduz bagunça (**Metricas Boss** benchmarks: +40% eficiência).

### **Como Funciona (Passos Básicos)**

1. **Reformatação**: Padronize (str to date, fill nulls).
2. **Pivot**: Escolha index (grupo), columns (pivot var), values (métrica). Ex: Dataset vendas (data, produto, valor) → Pivot por data/produto = matriz resumo.

### **Como Fazer no Google Sheets (Manual)**

1. Selecione dados.
2. Inserir > Tabela Dinâmica (Pivot Table).
3. Linhas: Produto; Colunas: Mês; Valores: Soma Valor. Ex: Vendas Jan-Dez → Tabela "Valor por Produto/Mês" (rápido pra trends).

### **Exemplo Prático em Pandas (Python)**

```python
import pandas as pd

df = pd.read_excel('vendas.xlsx')  # Cols: data, produto, valor

# Reformatação
df['data'] = pd.to_datetime(df['data'])
df = df.fillna(0)

# Pivoteamento
pivot = df.pivot_table(values='valor', index='produto', columns='mes', aggfunc='sum')
print(pivot)
```

**Saída exemplo**:

```
mes     Jan   Fev   Mar
Produto
Laptop  10k   12k   8k
Mouse    2k    3k   1k
```

**Insight**: Laptop vende mais em Fev – estoque otimizado (**Snaq.co** análise).

### **Dicas e Cuidados**

- **Reformatação primeiro**: Evite erros pivot (tipos inconsistentes).
- **Limites**: Dados grandes? Use melt() pra long format.
- **Vantagem**: Dashboards voam (**AILabs** tip: +50% insights visuais).
