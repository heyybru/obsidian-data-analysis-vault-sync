### 🔶 Formas principais de monitorar

1. **Web UI (ResourceManager)**:
    
    - Acesse: `http://localhost:8088/cluster` (Mac M1) ou IP do RM.
    - Mostra: Jobs ativos, uso CPU/RAM, falhas, logs.
    - **Exemplo QA**: Veja progresso de wordcount em logs JIRA.
2. **CLI yarn (rápido)**:
    
    ```bash
    yarn application -list  # Lista jobs (ID, nome, estado)
    yarn application -status <app_id>  # Detalhes (containers, memória)
    yarn logs -applicationId <app_id>  # Logs completos
    ```
    
    - **Seu uso**: `yarn application -list | grep qa` pra jobs de bugs Zephyr.
3. **NodeManager logs**:
    
    ```bash
    yarn logs -nodeAddress localhost:8042 -all  # Logs por nó
    ```

### 🚀 Dica pro seu QA (**Cappra Institute** / **Metricas Boss**)

- Automatize com `watch -n 5 'yarn application -list'` pra refresh.
- **Preditiva.ai** recomenda: Monitore "Running" vs. "Failed" pra otimizar testes API (reduz tempo 40%).
