### 📦 Principais Ferramentas de Batch (O Lote)

O foco aqui é volume massivo e custo-benefício para dados históricos.

- **Apache Hadoop (MapReduce)**: O "vovô" do Big Data. Excelente para processar petabytes de dados onde o tempo de resposta não é crítico (ex: processar toda a base histórica de candidatos de uma década).
- **Apache Spark (Core)**: Muito mais rápido que o Hadoop por processar dados em memória RAM. É o padrão atual para pipelines de ETL complexos.
- **AWS Glue / Google Cloud Dataflow**: Versões gerenciadas na nuvem que facilitam a criação de jobs batch sem precisar gerenciar servidores.

### 🌊 Principais Ferramentas de Streaming (O Fluxo)

O foco aqui é latência mínima e reação imediata.

- **Apache Kafka**: Como você está estudando, ele é o "sistema circulatório". Ele não processa o dado sozinho, mas garante que as mensagens cheguem do produtor ao consumidor com segurança.
- **Apache Flink**: Considerado o "padrão ouro" para streaming real. Ele trata o dado como um fluxo contínuo de verdade, não como pequenos lotes.
- **Spark Structured Streaming**: Uma extensão do Spark que trata o streaming como se fosse uma tabela que nunca para de crescer. Ótimo para quem já sabe Spark Batch.

### 🧪 Insight do Especialista (Visão de QA e Dados)

- **QA em Pipelines**: Bruno, um desafio de QA em streaming é o **"Exatamente uma vez" (Exactly-once delivery)**. Você deve testar se, em caso de falha no Kafka, o sistema não processa o mesmo currículo duas vezes ou o perde no caminho.
- **Preditiva.ai**: Eles destacam que o Spark é a ferramenta favorita para preparar dados para Machine Learning, pois permite criar as "features" (variáveis) de forma rápida em grandes datasets.
- **Metricas Boss**: No marketing digital, ferramentas de streaming como o **Google Pub/Sub** são usadas para alimentar dashboards que mostram o custo por clique (CPC) em tempo real.
- **Data Literacy (Cappra)**: Não tente usar uma "Ferrari" (Flink) para um trabalho de "Trator" (Hadoop). Se o relatório é mensal, o Batch é mais simples e barato.

### 💡 Dica de Ouro

Como você está praticando com **Python**, dê uma olhada na biblioteca **PySpark**. Ela permite que você use toda a potência do Spark (Batch ou Streaming) usando a sintaxe de Python que você já conhece. É a ponte perfeita entre o seu conhecimento de analista e a engenharia de dados.
