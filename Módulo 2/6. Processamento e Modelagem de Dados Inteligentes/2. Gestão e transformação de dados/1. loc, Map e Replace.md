# Introdução

Transformar dados é a etapa em que dado bruto vira dado utilizável. O material trata isso como "uma das etapas mais importantes do processo", e a razão é simples: **todo o resto depende dela**. Um modelo de machine learning treinado com dados sujos aprende sujeira com precisão.

Os quatro tópicos não são quatro ferramentas soltas — são **cinco operações em sequência lógica**:

selecionar  →  transformar  →  ordenar/agrupar  →  limpar  →  otimizar
   (loc)        (map, replace)    (sort, groupby)   (dropna)   (downcast, dedup)

👉 **Por que a ordem importa:** se você limpa primeiro e depois transforma, o map pode recriar valores inválidos. Se otimiza (int8) antes de limpar, e depois aparece um valor 999, o tipo estoura. **Limpar antes de otimizar; transformar depois de selecionar.**

# loc, Map e Replace

Três operações com nomes parecidos e funções bem diferentes. O material as apresenta separadas; a comparação visual acima mostra o contraste.

## loc — selecionar por rótulo (não altera nada)

**O que é:** o método que filtra linhas e colunas usando **nomes e condições**, não posições.

**Como funciona:** a condição entre colchetes vira uma máscara de verdadeiro/falso, e o .loc devolve só as linhas em que a resposta é True.

```python
clientes = pd.DataFrame({
    'nome':  ['João', 'Maria', 'Pedro', 'Lucas'],
    'idade': [30, 25, 40, 20],
    'cidade': ['São Paulo', 'Rio de Janeiro', 'Belo Horizonte', 'Porto Alegre']
})

cliente_selecionado = clientes.loc[clientes['nome'] == 'João']
print(cliente_selecionado)
```

👉 **O que está acontecendo:** clientes['nome'] == 'João' produz [True, False, False, False]. O .loc usa esse vetor para escolher a linha 0. É a mesma lógica de um filtro de planilha.

**Onde se aplica:** na seleção, antes de qualquer cálculo. **Quando usar:** para responder "quais registros atendem a esta condição".

## map — transformar cada valor por uma regra

**O que é:** aplica uma função a **todos os valores** de uma Series, um por um.

**Como funciona:** a função recebe um valor e devolve o valor transformado. O resultado substitui o original.

```python 
funcionarios = pd.DataFrame({
    'nome':    ['João', 'Maria', 'Pedro', 'Lucas'],
    'salario': [3000, 2500, 4000, 2000]
})

novo_salario = funcionarios['salario'].map(lambda x: x * 1.1)
print(novo_salario)
```

👉 **Aqui o lambda é uma função anônima:** lambda x: x * 1.1 significa "para cada x, devolva x vezes 1,1". Aplicado à coluna inteira, funciona como um reajuste de 10% em todos de uma vez.

**Onde se aplica:** na transformação — criar ou alterar colunas por regra. **Quando usar:** quando existe uma **regra matemática ou lógica** aplicável a todos os valores.

## replace — trocar valores específicos

**O que é:** substitui um valor por outro, sem calcular nada.

```python 
vendas = pd.DataFrame({
    'produto': ['Camiseta', 'Calça', 'Tênis'],
    'preco':   [50, 80, 120]
})

vendas['produto'] = vendas['produto'].replace('Calça', 'Bermuda')
print(vendas)
```

**Onde se aplica:** na correção de categorias e padronização de rótulos. **Quando usar:** quando a troca é **pontual e nomeada** — corrigir "Calça" para "Bermuda", "SP" para "São Paulo", 'N/A' para NaN.

## A diferença que resolve a confusão

**map calcula; replace troca.** Se você consegue escrever a regra como uma função (x * 1.1, x.upper(), x + 2), é map. Se você consegue apenas listar "troque A por B", é replace.

⚠️ **Atenção ao replace do material anterior:** na aula de "Introdução ao Pandas", o exemplo de replace na verdade usava apply + str.replace(). Aqui o material usa o replace() real do Pandas. São coisas diferentes: str.replace() mexe em pedaços de texto dentro de uma string; pd.Series.replace() substitui o valor inteiro.
