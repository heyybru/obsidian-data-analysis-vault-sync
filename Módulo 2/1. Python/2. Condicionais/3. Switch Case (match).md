## 🔷 Switch-case em Python: `match` / `case`

Em Python, o “switch-case” existe a partir do **Python 3.10** com o comando **`match`**.  
Ele serve para escolher um caminho com base em um valor, deixando o código mais limpo do que muitos `elif`.

---

## 🔷 1) Sintaxe básica (equivalente ao switch)

```python
opcao = "A"

match opcao:
    case "A":
        print("Você escolheu A")
    case "B":
        print("Você escolheu B")
    case "C":
        print("Você escolheu C")
    case _:
        print("Opção inválida")
```

✅ O `case _` funciona como **default**.

---

## 🔷 2) Exemplo prático (QA): ação por severidade

```python
severidade = input("Severidade: ").strip().upper()

match severidade:
    case "CRITICO":
        prioridade = 1
    case "ALTO":
        prioridade = 2
    case "MEDIO":
        prioridade = 3
    case "BAIXO":
        prioridade = 4
    case _:
        prioridade = None

print(prioridade)
```

---

## 🔷 3) Vários valores no mesmo case

```python
status = "OPEN"

match status:
    case "OPEN" | "ABERTO":
        print("Em andamento")
    case "CLOSED" | "FECHADO":
        print("Finalizado")
    case _:
        print("Status desconhecido")
```

---

## 🔷 4) `match` com tuplas (bom para regras combinadas)

👉 Exemplo: (severidade, status)

```python
severidade = "CRITICO"
status = "ABERTO"

match (severidade, status):
    case ("CRITICO", "ABERTO"):
        acao = "Tratar agora"
    case ("CRITICO", "FECHADO"):
        acao = "Validar correção"
    case (_, "FECHADO"):
        acao = "Arquivar"
    case _:
        acao = "Analisar"

print(acao)
```

✅ O `_` aqui funciona como “coringa”.

---

## 🔷 5) Boas práticas e limitações

✅ Use `match` quando:

- você tem **muitos casos** por valor
- quer evitar `if/elif` longo
- quer **regras claras** (como mapeamento)

⚠️ Atenção:

- se seu Python for **< 3.10**, `match` **não funciona**.
- para casos simples de mapeamento, às vezes um **dict** é ainda mais direto:

```python
mapa = {"CRITICO": 1, "ALTO": 2, "MEDIO": 3, "BAIXO": 4}
prioridade = mapa.get(severidade)  # None se não existir
```
