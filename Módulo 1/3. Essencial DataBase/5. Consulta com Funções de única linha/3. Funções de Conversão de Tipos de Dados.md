👉 Servem para **converter um tipo de dado em outro** durante a consulta.

---
## 🔢 TO_CHAR

Converte **NUMBER ou DATE → VARCHAR**

### Número → Texto

```sql
SELECT TO_CHAR(salario, '9,999.99')
FROM EMP;
```

### Data → Texto

```sql
SELECT TO_CHAR(data_admissao, 'DD/MM/YYYY')
FROM EMP;
```

📌 Formatos comuns:

- `DD` → dia
    
- `MM` → mês
    
- `YYYY` → ano
    
- `HH24` → hora (24h)

---

## 🔢 TO_NUMBER

Converte **VARCHAR → NUMBER**

```sql
SELECT TO_NUMBER('1500')
FROM DUAL;
```

⚠ Cuidado: se tiver letras → erro.

---

## 📅 TO_DATE

Converte **VARCHAR → DATE**

```sql
SELECT TO_DATE('15/01/2025', 'DD/MM/YYYY')
FROM DUAL;
```

👉 O formato deve bater **exatamente** com o texto.

---

## 🔁 Conversão Implícita x Explícita

### 🔹 Implícita (automática – não recomendado)

```sql
SELECT * FROM EMP
WHERE salario = '3000';
```

### 🔹 Explícita (correta)

```sql
SELECT * FROM EMP
WHERE salario = TO_NUMBER('3000');
```

📌 Em prova, **prefira sempre conversão explícita**.

---

## ⚠ Pegadinhas comuns

### ❌ Errado

```sql
TO_DATE('2025-01-15')
```

### ✅ Correto

```sql
TO_DATE('2025-01-15', 'YYYY-MM-DD')
```

---

## 📌 Exemplo completo

```sql
SELECT nome,
       TO_CHAR(data_nascimento, 'DD/MM/YYYY') AS data_formatada,
       TO_CHAR(salario, 'L9,999.99') AS salario_formatado
FROM FUNCIONARIO;
```

---

## 📘 Resumo rápido

|Função|Converte|
|---|---|
|TO_CHAR|NUMBER / DATE → VARCHAR|
|TO_NUMBER|VARCHAR → NUMBER|
|TO_DATE|VARCHAR → DATE|

---

## 🧠 Dicas de prova

- Datas **sempre** com formato explícito
    
- Texto para número só funciona se for numérico
    
- TO_CHAR é a mais cobrada
    
- Conversão errada → erro de execução
