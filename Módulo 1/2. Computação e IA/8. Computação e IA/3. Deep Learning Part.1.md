> [!info] 
> **O que é:** um **ramo do Machine Learning** que usa redes neurais artificiais como base. As máquinas tentam aprender de forma **mais parecida com os humanos**, processando informações através de nós que representam neurônios. 

🔑 **Analogia:** se o Machine Learning é **aprender a cozinhar seguindo uma receita**, o Deep Learning é **descobrir a receita sozinho**, experimentando. Mais poderoso, mas precisa de mais dados e tempo.

**Por que é possível hoje (do material):** graças a uma **forte rede de nuvens de dados** que disponibiliza uma quantidade enorme de informações. Sem esses dados gigantes, o deep learning não funcionaria.

**O que ele faz (do material):**

- 🎭 Reconhecer objetos, vozes e imagens
- 🌍 Traduzir idiomas
- 🤔 Tomar decisões
- 💳 Detectar **fraude em cartão de crédito**

**Como trata os dados (do material):** usa redes neurais para criar **níveis de validação** dos dados. Os muitos dados vindos de fontes diversas demorariam muito para serem tratados um a um — o deep learning resolve isso em camadas.

> [!note] 
> **Ponto importante (do material):** a **qualidade do conjunto de dados é fundamental** para bons resultados. Dados ruins = resultados ruins. 

> [!important] 
> **Ferramentas para começar (do material):** Keras, TensorFlow, Theano e CMTK.
