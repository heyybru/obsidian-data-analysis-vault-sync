## 🔷 Funções em Python (o que são e por que importam)

Funções são blocos de código que você “empacota” para **reusar**, **organizar** e **testar** melhor.  
Em dados/QA isso é ouro porque evita repetição e deixa o código mais confiável.

---

## 🔷 1) Estrutura básica de uma função

```python
def saudacao(nome):
    return f"Olá, {nome}!"

msg = saudacao("Bruno")
print(msg)
```

- `def` cria a função
- `nome` é o **parâmetro**
- `return` devolve um valor (se não tiver `return`, ela retorna `None`)

---

## 🔷 2) Função sem `return` (só executa ações)

```python
def imprimir_relatorio(total, passaram, falharam):
    print(f"Total: {total}")
    print(f"Passaram: {passaram}")
    print(f"Falharam: {falharam}")

imprimir_relatorio(10, 8, 2)
```

👉 Isso é comum para **output** (relatórios no terminal/log).

---

## 🔷 3) Parâmetros obrigatórios vs opcionais (default)

```python
def calcular_bonus(salario, percentual=0.10):
    return salario * percentual

print(calcular_bonus(5000))        # 10% padrão
print(calcular_bonus(5000, 0.20))  # 20%
```

## 🔷 4) Argumentos nomeados (melhor leitura)

```python
def avaliar_candidato(idade, experiencia_minima=2):
    return idade >= 18 and experiencia_minima >= 2

aprovado = avaliar_candidato(idade=25, experiencia_minima=3)
print(aprovado)
```

## 🔷 5) Retornando múltiplos valores

Python retorna uma **tupla**:

```python
def resumo_bugs(bugs):
    total = len(bugs)
    criticos = sum(1 for b in bugs if b["sev"] == "CRITICO")
    abertos = sum(1 for b in bugs if b["status"] == "ABERTO")
    return total, criticos, abertos

bugs = [
    {"sev": "CRITICO", "status": "ABERTO"},
    {"sev": "ALTO", "status": "ABERTO"},
    {"sev": "CRITICO", "status": "FECHADO"},
]

total, criticos, abertos = resumo_bugs(bugs)
print(total, criticos, abertos)
```

## 🔷 6) Boas práticas que fazem diferença

✅ **Nome claro** (verbo + objeto): `calcular_media`, `validar_payload`  
✅ Função faz **1 coisa só** (Single Responsibility)  
✅ Evite `print` dentro se a função for “de negócio” → prefira `return`  
✅ Valide entradas (tipo/intervalo) quando fizer sentido

Exemplo de validação simples:

```python
def ler_int(valor):
    try:
        return int(valor)
    except ValueError:
        return None
```

## 🔷 7) Exemplos bem reais (QA / Dados)

### ✅ QA: validar status code

```python
def status_ok(status_code):
    return 200 <= status_code <= 299
```

### ✅ Dados: limpar texto

```python
def limpar_texto(txt):
    return txt.strip().lower()
```

### ✅ RH: regra de aprovação

```python
def aprovado_triagem(idade, experiencia, tem_portfolio=False):
    return idade >= 18 and (experiencia >= 2 or tem_portfolio)
```
