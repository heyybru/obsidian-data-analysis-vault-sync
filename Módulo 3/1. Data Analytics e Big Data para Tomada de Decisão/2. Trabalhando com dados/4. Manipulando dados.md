### **O Que é Manipulação de Dados?**

- **Definição curta**: Alterar dados pra facilitar análise (selecionar, filtrar, ordenar, calcular novas cols).
- **Objetivo negócio**: Preparar pro BI (ex: calcular % contratados por cargo).

### **Passos Manuais no Sheets (Hands-On)**

1. **Selecionar/Filtrar**: Dados > Criar filtro > clique seta col (ex: filtre `foi_contratado=TRUE`, veja 18 linhas).
2. **Ordenar**: Dados > Ordenar intervalo (ex: exp_anos decrescente – seniors no topo).
3. **Calcular Novas Cols**: Col Z "Taxa Sucesso" =SE(foi_contratado;"100%";"0%"). Arraste!
4. **Funções Básicas**: =CONT.SE(status_candidatura;"Contratado") = 18; =SOMA.SE(pretensao_salarial;experiencia_anos;">10") pra seniors.
5. **Concatenar**: =CONCATENAR(nome_candidato;" - ";cargo_pretendido) pra labels.
