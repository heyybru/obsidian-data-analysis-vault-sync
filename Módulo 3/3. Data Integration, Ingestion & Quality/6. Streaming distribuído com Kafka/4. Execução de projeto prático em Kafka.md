Vamos criar os dois lados da ponta usando Python.

### 📤 O Produtor (Producer)

Este script simula candidatos se inscrevendo na sua plataforma e enviando os dados para o Kafka.

```python
# producer_recrutamento.py
import json
import time
from kafka import KafkaProducer

# Inicializa o produtor conectado ao broker local
producer = KafkaProducer(
    bootstrap_servers=['localhost:9092'],
    value_serializer=lambda v: json.dumps(v).encode('utf-8')
)

# Simulação de candidatos reais do seu 'dataset_recrutamento'
candidatos_stream = [
    {"id": 1, "nome": "Dr. Vitor Hugo Borges", "cargo": "Engenheiro de Software", "experiencia_anos": 1.4},
    {"id": 2, "nome": "Gustavo Freitas", "cargo": "UX Designer", "experiencia_anos": 4.6},
    {"id": 3, "nome": "Pietra Casa Grande", "cargo": "Cientista de Dados", "experiencia_anos": 10.9}
]

print("🚀 Iniciando o envio de candidaturas para o Kafka...")

for candidato in candidatos_stream:
    # Envia a mensagem para o tópico 'novas_candidaturas'
    producer.send('novas_candidaturas', candidato)
    print(f"📤 Mensagem enviada: {candidato['nome']} ({candidato['cargo']})")
    time.sleep(2) # Simula um intervalo de tempo entre inscrições

producer.flush()
```

### 📥 O Consumidor (Consumer)

Este script fica rodando continuamente, escutando o tópico e aplicando uma regra de negócio (triagem de candidatos com mais de 3 anos de experiência).

```python
# consumer_triagem.py
import json
from kafka import KafkaConsumer

# Inicializa o consumidor escutando o tópico
consumer = KafkaConsumer(
    'novas_candidaturas',
    bootstrap_servers=['localhost:9092'],
    auto_offset_reset='earliest', # Lê desde o início se for a primeira vez
    value_deserializer=lambda x: json.loads(x.decode('utf-8'))
)

print("📥 Aguardando novas candidaturas no tópico...")

for message in consumer:
    candidato = message.value
    exp = candidato['experiencia_anos']
    
    # Regra de negócio / Validação de QA
    if exp >= 3.0:
        status = "Aprovado para Triagem Técnica ✅"
    else:
        status = "Retido (Experiência insuficiente) ❌"
        
    print(f"\n[NOVO EVENTO] Candidato: {candidato['nome']}")
    print(f"  Cargo: {candidato['cargo']} | Exp: {exp} anos")
    print(f"  Status do Processamento: {status}")
```
