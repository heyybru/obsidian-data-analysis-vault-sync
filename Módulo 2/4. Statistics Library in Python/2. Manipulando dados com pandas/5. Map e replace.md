## `map()` e `replace()` no Pandas

Os dois servem para substituir ou transformar valores, mas têm usos um pouco diferentes.

A ideia prática é:

- `map()` → muito usado em uma coluna
- `replace()` → mais flexível para substituições diretas

---

## 1. `map()`

O `map()` é usado principalmente em Series, ou seja, em uma coluna.

Ele serve para:

- trocar valores
- criar rótulos
- aplicar uma função simples

### Exemplo com dicionário

```
import pandas as pd

df = pd.DataFrame({
    "status": [1, 0, 1, 1, 0]
})

df["status_texto"] = df["status"].map({
    1: "Ativo",
    0: "Inativo"
})

print(df)
```
### Resultado

```
   status status_texto
0       1        Ativo
1       0      Inativo
2       1        Ativo
3       1        Ativo
4       0      Inativo
```
---

## 2. `replace()`

O `replace()` substitui valores diretamente.

### Exemplo

```
df["status"] = df["status"].replace({
    1: "Ativo",
    0: "Inativo"
})
```
---

## Diferença prática entre eles

### `map()`

- atua em uma coluna
- muito usado para traduzir/categorizar valores
- se encontrar valor fora do dicionário, retorna NaN

### `replace()`

- substitui valores sem transformar os demais em `NaN`
- pode ser usado em coluna ou DataFrame inteiro
- melhor quando você quer apenas trocar alguns valores e manter o resto

---

## Exemplo para entender bem

### Com `map()`

```
import pandas as pd

s = pd.Series([1, 2, 3])

print(s.map({1: "A", 2: "B"}))
``````

#### Resultado

```
0      A
1      B
2    NaN
dtype: object
```

O valor `3` virou `NaN` porque não estava no mapeamento.

---

### Com `replace()`

```
import pandas as pd

s = pd.Series([1, 2, 3])

print(s.replace({1: "A", 2: "B"}))
```
#### Resultado

```
0    A
1    B
2    3
dtype: object
````

O valor `3` foi mantido.

---

## 3. Quando usar `map()`

Use `map()` quando você quiser:

- criar uma nova coluna com rótulos
- transformar códigos em categorias
- aplicar uma função a uma coluna

### Exemplo: transformar siglas em nomes

```
df = pd.DataFrame({
    "uf": ["SP", "RJ", "MG"]
})

df["estado"] = df["uf"].map({
    "SP": "São Paulo",
    "RJ": "Rio de Janeiro",
    "MG": "Minas Gerais"
})
```
---

## 4. Quando usar `replace()`

Use `replace()` quando você quiser:

- substituir valores pontualmente
- manter o que não foi alterado
- trocar valores em várias colunas
- limpar textos ou categorias

#### Exemplo

```
df["cidade"] = df["cidade"].replace({
    "Sampa": "São Paulo",
    "Rio": "Rio de Janeiro"
})
```
---

## 5. `map()` com função

Você também pode usar função no `map()`:

`df["nome_maiusculo"] = df["nome"].map(str.upper)`

### Exemplo

```
import pandas as pd

df = pd.DataFrame({
    "nome": ["ana", "bruno", "carla"]
})

df["nome_maiusculo"] = df["nome"].map(str.upper)
print(df)
``````
---

## 6. `replace()` em várias colunas

```
df = df.replace({
    "SP": "São Paulo",
    "RJ": "Rio de Janeiro"
})
```

Isso procura esses valores no DataFrame e substitui.

---

## 7. Exemplo prático comparando os dois

```
import pandas as pd

df = pd.DataFrame({
    "status": [1, 0, 1, 2]
})

df["map"] = df["status"].map({
    1: "Ativo",
    0: "Inativo"
})

df["replace"] = df["status"].replace({
    1: "Ativo",
    0: "Inativo"
})

print(df)
```

#### Resultado esperado

```
   status      map   replace
0       1    Ativo    Ativo
1       0  Inativo  Inativo
2       1    Ativo    Ativo
3       2      NaN         2
```

Esse exemplo mostra a diferença principal.

---

## 8. Relação com limpeza e transformação de dados

Na manipulação de dados com pandas, `map()` e `replace()` aparecem muito em tarefas como:

- padronizar categorias
- trocar códigos por nomes legíveis
- corrigir inconsistências
- criar colunas derivadas
- preparar dados para análise

---

## 9. Resumo simples da diferença

### `map()`

- transforma valores de uma coluna
- ótimo para criar categorias
- valores não mapeados viram NaN

### `replace()`

- substitui valores sem afetar os outros
- mais seguro para trocas pontuais
- pode ser usado em coluna ou DataFrame

---

## 10. Mini cola

```
# map com dicionário
df["status_texto"] = df["status"].map({1: "Ativo", 0: "Inativo"})

# replace em coluna
df["status"] = df["status"].replace({1: "Ativo", 0: "Inativo"})

# map com função
df["nome"] = df["nome"].map(str.upper)

# replace no DataFrame
df = df.replace({"SP": "São Paulo"})
```

---

## Regra prática para decorar

- se a ideia é traduzir códigos em categorias, pense em `map()`
- se a ideia é substituir alguns valores e manter os demais, pense em `replace()`

---

## Exemplo bem realista

```
import pandas as pd

df = pd.DataFrame({
    "departamento": ["RH", "TI", "FIN", "TI"],
    "status": [1, 1, 0, 1]
})

df["departamento_nome"] = df["departamento"].map({
    "RH": "Recursos Humanos",
    "TI": "Tecnologia",
    "FIN": "Financeiro"
})

df["status"] = df["status"].replace({
    1: "Ativo",
    0: "Inativo"
})

print(df)
```

---

## Resumindo

- `map()` → transforma valores de uma coluna
- `replace()` → substitui valores mantendo os demais
- ambos são muito usados em limpeza e padronização de dados
