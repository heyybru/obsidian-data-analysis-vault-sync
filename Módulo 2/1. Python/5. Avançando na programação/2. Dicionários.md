**Dicionário** **(dict)** é uma estrutura de dados do tipo **chave → valor**.  
Você acessa um valor pela **chave**, não por posição (como lista/tupla). Em dados/QA é perfeito para representar **registros**, **JSON**, **payloads**, **configurações** e **métricas**.

---

## 🔷 1) Criar dicionários

```python
bug = {
    "id": 101,
    "severidade": "CRITICO",
    "status": "ABERTO",
    "descricao": "Falha no login"
}
```

Também dá para criar assim:

```python
config = dict(timeout=30, retries=3)
```

---

## 🔷 2) Acessar valores: `[]` vs `.get()`

### ✅ Com `[]` (erro se não existir)

```python
print(bug["status"])  # "ABERTO"
# print(bug["assignee"])  # KeyError
```

### ✅ Com `.get()` (mais seguro)

```python
print(bug.get("assignee"))              # None
print(bug.get("assignee", "N/A"))       # "N/A"
```

👉 Em QA isso evita quebrar script quando o campo não vem no payload.

---

## 🔷 3) Adicionar e atualizar campos

```python
bug["assignee"] = "Bruno"
bug["status"] = "EM ANDAMENTO"
```

Atualizar vários de uma vez:

```python
bug.update({"status": "FECHADO", "resolvido_por": "time-x"})
```

---

## 🔷 4) Remover campos

```python
del bug["descricao"]       # remove (KeyError se não existir)
assignee = bug.pop("assignee", None)  # remove e devolve (seguro)
```

---

## 🔷 5) Iterar (loops) em dicionários

### ✅ Chaves

```python
for chave in bug:
    print(chave)
```

### ✅ Valores

```python
for valor in bug.values():
    print(valor)
```

### ✅ Pares chave-valor

```python
for chave, valor in bug.items():
    print(chave, "->", valor)
```

---

## 🔷 6) Dicionário dentro de lista (padrão “dados tabulares”)

Muito comum pra simular “linhas”:

```python
bugs = [
    {"id": 1, "severidade": "CRITICO", "status": "ABERTO"},
    {"id": 2, "severidade": "ALTO", "status": "FECHADO"},
    {"id": 3, "severidade": "CRITICO", "status": "ABERTO"},
]

criticos_abertos = [
    b for b in bugs
    if b["severidade"] == "CRITICO" and b["status"] == "ABERTO"
]
print(criticos_abertos)
```

---

## 🔷 7) Contagens (muito usado em análise de dados)

### ✅ Contar por severidade

```python
bugs = ["CRITICO", "ALTO", "CRITICO", "BAIXO"]

contagem = {}
for sev in bugs:
    contagem[sev] = contagem.get(sev, 0) + 1

print(contagem)  # {'CRITICO': 2, 'ALTO': 1, 'BAIXO': 1}
```

---

## 🔷 8) Dicionário como “switch” (mapeamento)

Quando você quer trocar `if/elif` por mapeamento:

```python
pesos = {"CRITICO": 1, "ALTO": 2, "MEDIO": 3, "BAIXO": 4}
sev = "ALTO"
print(pesos.get(sev, 99))
```

---

## 🔷 9) Dicionários aninhados (parece JSON)

```python
release = {
    "versao": "1.2.0",
    "qa": {
        "passaram": 120,
        "falharam": 5
    }
}

print(release["qa"]["falharam"])  # 5
```

✅ Acesso “seguro” (sem quebrar) usando `.get()` em cadeia:

```python
falhas = release.get("qa", {}).get("falharam", 0)
print(falhas)
```

## 🔷 10) Pegadinhas comuns

### ⚠️ 1) Chaves precisam ser “hashable”

- Pode: `str`, `int`, `tuple` (imutáveis)
- Não pode: `list`, `dict`

```python
# d = {[1,2]: "x"}  # ❌ TypeError
d = {(1,2): "x"}    # ✅
```

### ⚠️ 2) `in` verifica chaves

```python
print("status" in bug)  # True
```
