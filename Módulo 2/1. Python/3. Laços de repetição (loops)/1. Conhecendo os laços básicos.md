## 🔷 `for` e `while`

Vamos entender os dois principais tipos de laços de repetição em Python, com exemplos práticos do seu dia a dia (RH + QA).

---

## 🔷 1) **`for`** - Quando você SABE quantas vezes repetir

### ✅ **Sintaxe básica**:

```python
for item in sequencia:
    # código que repete para cada item
```

### ✅ **Exemplo 1: Percorrer uma lista de bugs**

```python
bugs = ["CRITICO", "ALTO", "MEDIO", "BAIXO"]

for severidade in bugs:
    print(f"Bug com severidade: {severidade}")
```

### ✅ **Exemplo 2: Usando `range()` para repetir N vezes**

```python
# Executar 5 testes automatizados
for teste_numero in range(1, 6):  # 1, 2, 3, 4, 5
    print(f"Executando teste {teste_numero}...")
```

### ✅ **Exemplo 3: RH - Processar candidatos**

```python
candidatos = ["Ana", "Bruno", "Carla", "Daniel"]

for candidato in candidatos:
    print(f"Enviando email para {candidato}...")
```

---

## 🔷 2) **`while`** - Quando você NÃO SABE quantas vezes repetir

### ✅ **Sintaxe básica**:

```python
while condicao:
    # código que repete enquanto condição for True
```

### ✅ **Exemplo 1: Validar entrada do usuário**

```python
senha_correta = "1234"
tentativas = 0

while True:
    senha = input("Digite a senha: ")
    tentativas += 1
    
    if senha == senha_correta:
        print("Acesso concedido!")
        break
    elif tentativas >= 3:
        print("Número máximo de tentativas excedido!")
        break
    else:
        print(f"Senha incorreta. Tentativa {tentativas}/3")
```

### ✅ **Exemplo 2: QA - Processar bugs até não ter mais**

```python
bugs_para_analisar = 10
bugs_analisados = 0

while bugs_analisados < bugs_para_analisar:
    bugs_analisados += 1
    print(f"Analisando bug {bugs_analisados}/{bugs_para_analisar}...")
    
print("Todos os bugs foram analisados!")
```

---

## 🔷 3) **Diferença prática entre `for` e `while`**

|Característica|`for`|`while`|
|---|---|---|
|**Quando usar**|Sabe quantas vezes repetir|Não sabe quantas vezes repetir|
|**Controle**|Percorre sequência|Depende de condição|
|**Exemplo**|Lista de candidatos|Validação de senha|
|**Risco**|Menor risco de loop infinito|Pode virar loop infinito|

## 🔷 4) **Exemplo completo: Sistema de triagem RH**

```python
# Lista de candidatos com idade
candidatos = [
    {"nome": "Ana", "idade": 25, "experiencia": 3},
    {"nome": "Bruno", "idade": 17, "experiencia": 1},
    {"nome": "Carla", "idade": 30, "experiencia": 5},
]

# Usando FOR para processar todos
print("=== TRIAGEM DE CANDIDATOS ===")
for candidato in candidatos:
    if candidato["idade"] >= 18 and candidato["experiencia"] >= 2:
        print(f"✅ {candidato['nome']}: APROVADO")
    else:
        print(f"❌ {candidato['nome']}: REPROVADO")
```

## 🔷 5) **Exemplo completo: Sistema de testes QA**

```python
# Lista de cenários de teste
cenarios_teste = [
    {"nome": "Login", "status": "PASSOU"},
    {"nome": "Cadastro", "status": "FALHOU"},
    {"nome": "Pagamento", "status": "PASSOU"},
    {"nome": "Perfil", "status": "PASSOU"},
]

# Usando FOR para gerar relatório
print("=== RELATÓRIO DE TESTES ===")
total_testes = len(cenarios_teste)
testes_passaram = 0

for cenario in cenarios_teste:
    if cenario["status"] == "PASSOU":
        testes_passaram += 1
        print(f"✅ {cenario['nome']}: {cenario['status']}")
    else:
        print(f"❌ {cenario['nome']}: {cenario['status']}")

print(f"\n📊 Resultado: {testes_passaram}/{total_testes} testes passaram")
```

---

## 🔷 6) **Dicas para começar**

1. **Comece com `for`** - É mais seguro e previsível
2. **Use `while` para validação** - Quando precisa repetir até algo ser verdadeiro
3. **Sempre tenha um `break`** - No `while True`, tenha uma condição de saída
4. **Teste com números pequenos** - Antes de rodar em produção

---

## 📋 **Resumindo**

- **`for`** = "Para cada item nesta lista, faça..."
- **`while`** = "Enquanto esta condição for verdadeira, faça..."
