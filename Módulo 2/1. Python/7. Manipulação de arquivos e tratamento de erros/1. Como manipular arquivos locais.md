## ler, escrever, criar pastas, listar

A forma padrão e mais segura é combinar:

- **`pathlib`** (caminhos/pastas/arquivos)
- **`with open(...)`** (abre e fecha sozinho)
- **`try/except`** (tratar erros comuns)

---

## 1) Caminhos locais com `pathlib` (recomendado)

```python
from pathlib import Path

pasta = Path("dados")                 # relativo à pasta do seu projeto
arquivo = pasta / "entrada.txt"       # monta o caminho certinho
print(arquivo)                        # dados/entrada.txt (ou equivalente no Windows)
```

✅ Vantagens: funciona bem em Windows/Mac/Linux sem ficar montando path “na mão”.

---

## 2) Criar pasta (se não existir)

```python
from pathlib import Path

Path("dados").mkdir(exist_ok=True)
```

- `exist_ok=True` evita erro se a pasta já existir.

---

## 3) Criar/Escrever arquivo (substitui o conteúdo)

### Opção A: com `open` (mais “clássico”)

```python
from pathlib import Path

arquivo = Path("dados") / "saida.txt"
arquivo.parent.mkdir(exist_ok=True)

with open(arquivo, "w", encoding="utf-8") as f:
    f.write("Primeira linha\n")
    f.write("Segunda linha\n")
```

### Opção B: com `pathlib` direto (bem prático)

```python
from pathlib import Path

arquivo = Path("dados") / "saida.txt"
arquivo.parent.mkdir(exist_ok=True)

arquivo.write_text("Primeira linha\nSegunda linha\n", encoding="utf-8")
```

---

## 4) Adicionar no final (append)

```python
from pathlib import Path

arquivo = Path("dados") / "saida.txt"

with open(arquivo, "a", encoding="utf-8") as f:
    f.write("Mais uma linha\n")
```

---

## 5) Ler arquivo

### Ler tudo de uma vez

```python
from pathlib import Path

arquivo = Path("dados") / "entrada.txt"
texto = arquivo.read_text(encoding="utf-8")
print(texto)
```

### Ler linha por linha (melhor pra arquivos grandes)

```python
from pathlib import Path

arquivo = Path("dados") / "entrada.txt"

with open(arquivo, "r", encoding="utf-8") as f:
    for linha in f:
        print(linha.strip())
```

---

## 6) Verificar se existe + tratar erros

### Verificar antes

```python
from pathlib import Path

arquivo = Path("dados") / "entrada.txt"
if not arquivo.exists():
    print("Arquivo não existe.")
else:
    print(arquivo.read_text(encoding="utf-8"))
```

### Tratar com `try/except` (mais robusto)

```python
from pathlib import Path

arquivo = Path("dados") / "entrada.txt"

try:
    texto = arquivo.read_text(encoding="utf-8")
except FileNotFoundError:
    print("Arquivo não encontrado.")
except PermissionError:
    print("Sem permissão para acessar o arquivo.")
else:
    print(texto)
```

## 7) Listar arquivos de uma pasta

```python
from pathlib import Path

pasta = Path("dados")
for item in pasta.iterdir():
    print(item.name)
```

Filtrar só `.txt`:

```python
for item in Path("dados").glob("*.txt"):
    print(item.name)
```

---

## 8) Renomear, mover e apagar

### Renomear/mover (é o mesmo comando)

```python
from pathlib import Path

origem = Path("dados") / "saida.txt"
destino = Path("dados") / "saida_final.txt"
origem.rename(destino)
```

### Apagar arquivo

```python
from pathlib import Path

arquivo = Path("dados") / "temp.txt"
if arquivo.exists():
    arquivo.unlink()
```

## 9) Exemplo completo (bem “vida real”)

Ler um arquivo de entrada e salvar outro com linhas filtradas:

```python
from pathlib import Path

entrada = Path("dados") / "log.txt"
saida = Path("dados") / "erros.txt"
saida.parent.mkdir(exist_ok=True)

try:
    with open(entrada, "r", encoding="utf-8") as f_in, open(saida, "w", encoding="utf-8") as f_out:
        for linha in f_in:
            if "ERROR" in linha:
                f_out.write(linha)
except FileNotFoundError:
    print("Não achei o log.txt na pasta dados.")
else:
    print("Arquivo erros.txt gerado com sucesso.")
```
