## 1️⃣ Função Hash Criptográfica

**O que é:** uma função que transforma qualquer dado (texto, arquivo, vídeo) em uma "impressão digital" — uma sequência fixa de letras e números.

🔑 **Analogia:** batizar um documento. Muda 1 vírgula → a impressão digital muda toda.

[**As 3 propriedades (do material):**](obsidian://open?vault=Analise%20de%20Dados&file=M%C3%B3dulo%201%2F2.%20Computa%C3%A7%C3%A3o%20e%20IA%2F4.%20Fun%C3%A7%C3%B5es%20hash%20e%20Blockchain%2F1.%20Fun%C3%A7%C4%81o%20hash%20e%20blockchain%2F1.1.%20Propriedades)

- 🔒 **Unidirecional:** dá para gerar o hash, mas **nunca** voltar ao original
- 📏 **Tamanho fixo:** entrada gigante = saída do mesmo tamanho
- ⚡ **Eficiente:** rápida de calcular, mesmo em arquivos grandes

**Como funciona na prática:** O material explica que os dados de um arquivo são mapeados em uma **tabela hash**. Cada parte do material é transformada em uma linha dessa tabela. O resultado é chamado de **valor hash, código hash, checksum ou simplesmente hash**.

**Exemplo real (do material):** Para conferir se o download do Ubuntu veio certo, roda no terminal:

```
md5sum ubuntu-20.04.1-desktop-amd64.iso
```

Resultado: `77fc715a283e41d0ad33d6418a9ba128`

Se o arquivo for diferente (mesmo 1 byte), o hash muda completamente — como mostra o material com outro arquivo gerando `ea28c4fd933be55f9f01a5fa9e868490`. Isso garante que ninguém adulterou o download.

**Exemplo do material (exercício de aula):** O professor pede que os alunos enviem a resposta como hash, não como texto. Assim ninguém vê a resposta dos outros, mas o professor confere quem acertou comparando os hashes. A resposta fica escondida, mas verificável.

[**Principais funções (do material):**](obsidian://open?vault=Analise%20de%20Dados&file=M%C3%B3dulo%201%2F2.%20Computa%C3%A7%C3%A3o%20e%20IA%2F4.%20Fun%C3%A7%C3%B5es%20hash%20e%20Blockchain%2F1.%20Fun%C3%A7%C4%81o%20hash%20e%20blockchain%2F1.2.%20Principais%20fun%C3%A7%C3%B5es)

- **MD** (Message Digest): ex. MD5
- **SHA** (Secure Hash Function): ex. SHA-256, SHA-1
- **RIPEMD:** ex. RIPEMD-160
- **Whirlpool** e **Tiger**

**Usos comuns:** encontrar elementos em bases de dados, garantir originalidade de arquivos, armazenar e enviar senhas, validar transações.

> [!warning] 
> **⚠️ Limitação:** como é irreversível, a única forma de "quebrar" é o **ataque de força bruta** — testar cada entrada possível até achar a que gera o hash desejado. Lento e caro, mas possível para hashes fracos (por isso MD5 hoje é considerado frágil).
