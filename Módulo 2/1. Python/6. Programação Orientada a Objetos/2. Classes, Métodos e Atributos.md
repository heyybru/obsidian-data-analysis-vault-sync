### **Classe**

É o **molde**/modelo que define um “tipo” de coisa no seu sistema.  
Ela descreve **quais dados** os objetos vão ter e **quais ações** eles vão fazer.

👉 Ex.: `Bug`, `Usuario`, `Teste`, `Candidato`.

### **Objeto (instância)**

É a **coisa criada de verdade** a partir da classe.  
Você cria quando faz: `obj = Classe(...)`.

### **Atributos**

São os **dados** do objeto (variáveis dentro do objeto).  
Ex.: `id`, `nome`, `status`.

### **Métodos**

São as **funções** dentro da classe (o comportamento).  
Ex.: `fechar()`, `validar()`, `executar()`.

---

## Exemplo prático (QA): `Bug`

```python
class Bug:
    def __init__(self, bug_id, severidade, status="ABERTO"):
        # atributos (dados)
        self.bug_id = bug_id
        self.severidade = severidade
        self.status = status

    # métodos (ações)
    def fechar(self):
        self.status = "FECHADO"

    def reabrir(self):
        self.status = "ABERTO"

    def resumo(self):
        return f"Bug {self.bug_id} | {self.severidade} | {self.status}"


b1 = Bug(101, "CRITICO")
b2 = Bug(102, "ALTO", "EM_ANDAMENTO")

print(b1.status)      # atributo
b1.fechar()           # método alterando atributo
print(b1.resumo())    # método
print(b2.resumo())
```

### O que identificar aqui

- `Bug` = **classe**
- `b1`, `b2` = **objetos / instâncias**
- `bug_id`, `severidade`, `status` = **atributos**
- `fechar`, `reabrir`, `resumo` = **métodos**
- `self` = referência ao **próprio objeto** (ex.: `b1` dentro dos métodos)

## Atributo de instância vs atributo de classe (diferença importante)

### ✅ Atributo de instância (cada objeto tem o seu)

```python
class Pessoa:
    def __init__(self, nome):
        self.nome = nome

p1 = Pessoa("Ana")
p2 = Pessoa("Bruno")
print(p1.nome, p2.nome)  # Ana Bruno
```

### ✅ Atributo de classe (compartilhado por todos)

```python
class Bug:
    STATUS_VALIDOS = {"ABERTO", "EM_ANDAMENTO", "FECHADO"}  # atributo de classe

    def __init__(self, bug_id):
        self.bug_id = bug_id

print(Bug.STATUS_VALIDOS)
```

## 📋 Resumindo

- **Classe**: molde
- **Objeto/instância**: item criado do molde
- **Atributos**: dados do objeto
- **Métodos**: ações do objeto
