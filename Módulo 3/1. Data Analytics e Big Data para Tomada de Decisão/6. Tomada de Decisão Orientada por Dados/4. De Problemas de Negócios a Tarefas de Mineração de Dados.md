### 🔶 O Que é essa Transição?

- **Definição**: É o mapeamento de um objetivo comercial (ex: "vender mais") para uma tarefa técnica de mineração (ex: "classificação" ou "regressão").
- **Metodologia**: Utilizamos o **CRISP-DM** (fase 1: _Business Understanding_). Sem essa tradução, o cientista de dados pode criar um modelo perfeito para o problema errado.

### 🔶 Principais Tarefas de Mineração (Mapeamento)

|Problema de Negócio|Tarefa de Mineração|O que o dado responde?|
|:--|:--|:--|
|**Quem vai sair da empresa?**|**Classificação**|"Sim" ou "Não" (Binário).|
|**Quanto vamos vender amanhã?**|**Regressão**|Um valor numérico contínuo.|
|**Quais clientes são parecidos?**|**Agrupamento (Clustering)**|Grupos com características comuns.|
|**O que oferecer para este cliente?**|**Regras de Associação**|"Quem compra A, costuma levar B".|

### 🔶 Exemplo Prático (Fluxo de Eficiência)

Imagine que você, como Coordenador, identifica que o tempo de contratação está alto.

1. **Problema**: "O processo de recrutamento está lento."
2. **Tarefa de Mineração (Predição)**: "Prever o tempo de fechamento de uma vaga (_Time-to-Hire_) com base no perfil e canal de origem."
3. **Ação**: Se o modelo prever que a vaga X levará 60 dias, você pode agir preventivamente no funil.

### 🔶 O Papel do QA e Gestão nessa Fase

- **Validação de Hipóteses**: Antes de minerar, questione: "Temos dados históricos suficientes para essa tarefa?".
- **Métricas de Sucesso**: Segundo a **Metricas Boss**, não basta o modelo rodar; ele precisa impactar o KPI. Se a tarefa é classificação de churn, o sucesso é a redução real da perda de clientes.
- **Qualidade (Snaq.co)**: Garanta que a tarefa de mineração não use dados "viciados" (viés), o que invalidaria a solução técnica.

### 🔶 Dicas de Ouro

- **Comece Simples**: Muitas vezes, uma tarefa de **Estatística Descritiva** (Agregação) resolve o problema antes mesmo de precisar de Machine Learning complexo.
- **Pense no ROI**: A **Preditiva.ai** reforça que cada tarefa de mineração deve ter um custo/benefício claro.
