## 🔷 A Arte da Visualização

**Plotagem de dados é como "desenhar mapas" para navegar em oceanos de informação**.  
Cada tipo de gráfico é uma ferramenta diferente para explorar diferentes aspectos dos dados.

✅ **No seu contexto (RH + QA)**:

- **RH**: Plotar distribuições salariais, evolução de headcount, análise de diversidade
- **QA**: Visualizar bugs ao longo do tempo, métricas de qualidade, performance de testes

---

## 🔷 1. Tipos de Plotagem e Quando Usar

### ✅ **Guia Rápido de Escolha**:

|**O que você quer mostrar?**|**Gráfico Recomendado**|**Exemplo**|
|---|---|---|
|**Comparação entre categorias**|Barras/Colunas|Candidatos por departamento|
|**Distribuição de valores**|Histograma/Boxplot|Distribuição salarial|
|**Relação entre variáveis**|Scatter Plot|Experiência vs Salário|
|**Composição de um todo**|Pizza/Treemap|Bugs por severidade|
|**Tendência ao longo do tempo**|Linha/Área|Bugs reportados por mês|
|**Correlações múltiplas**|Heatmap|Matriz de correlação|
|**Dados geográficos**|Mapa|Candidatos por estado|
|**Hierarquia/estrutura**|Treemap/Sunburst|Organograma da empresa|

## 🔷 2. Plotagem Básica com Matplotlib

### ✅ **Configuração Inicial**:

```python
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd

# Configurações globais
plt.rcParams['figure.figsize'] = (10, 6)  # Tamanho padrão
plt.rcParams['font.size'] = 12            # Tamanho da fonte
plt.rcParams['axes.grid'] = True          # Grade ativada
plt.rcParams['grid.alpha'] = 0.3          # Transparência da grade
```

### ✅ **Gráfico de Linha Simples**:

```python
# Dados: Bugs reportados por semana
semanas = ['Sem 1', 'Sem 2', 'Sem 3', 'Sem 4', 'Sem 5']
bugs = [15, 22, 18, 25, 20]

plt.figure(figsize=(10, 6))
plt.plot(semanas, bugs, 
         marker='o',           # Marcadores
         linewidth=2,          # Espessura da linha
         color='#E63946',      # Cor hexadecimal
         markersize=8,         # Tamanho dos marcadores
         label='Bugs Reportados')

# Personalização
plt.title('🐛 Bugs Reportados por Semana', fontsize=14, fontweight='bold')
plt.xlabel('Semana', fontsize=12)
plt.ylabel('Número de Bugs', fontsize=12)
plt.legend()
plt.grid(True, alpha=0.3)

# Adicionar valores nos pontos
for i, valor in enumerate(bugs):
    plt.text(i, valor + 0.5, str(valor), 
             ha='center', va='bottom', 
             fontsize=10, fontweight='bold')

plt.tight_layout()
plt.show()
```

### ✅ **Gráfico de Barras**:

```python
# Dados: Candidatos por departamento
departamentos = ['TI', 'RH', 'Vendas', 'Marketing', 'Financeiro']
```

### ✅ **Histograma**:

```python
# Dados: Distribuição de salários
np.random.seed(42)
salarios = np.random.normal(6000, 1500, 1000)

plt.figure(figsize=(10, 6))
n, bins, patches = plt.hist(salarios, bins=30, 
                            edgecolor='black', 
                            alpha=0.7,
                            color='#2A9D8F')

# Linhas de referência
plt.axvline(np.mean(salarios), color='red', linestyle='--', 
            linewidth=2, label=f'Média: R$ {np.mean(salarios):.0f}')
plt.axvline(np.median(salarios), color='orange', linestyle='--', 
            linewidth=2, label=f'Mediana: R$ {np.median(salarios):.0f}')

# Personalização
plt.title('💰 Distribuição de Salários', fontsize=14, fontweight='bold')
plt.xlabel('Salário (R$)', fontsize=12)
plt.ylabel('Frequência', fontsize=12)
plt.legend()
plt.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

### ✅ **Scatter Plot**:

```python
# Dados: Experiência vs Salário
np.random.seed(42)
n = 100
experiencia = np.random.exponential(5, n)
salario = 3000 + 400 * experiencia + np.random.normal(0, 500, n)

plt.figure(figsize=(10, 6))
scatter = plt.scatter(experiencia, salario, 
                      c=experiencia,           # Cor por experiência
                      cmap='viridis',          # Mapa de cores
                      s=100,                   # Tamanho dos pontos
                      alpha=0.6,               # Transparência
                      edgecolors='black',      # Borda dos pontos
                      linewidth=0.5)

# Linha de regressão
z = np.polyfit(experiencia, salario, 1)
p = np.poly1d(z)
plt.plot(experiencia, p(experiencia), "r--", 
         linewidth=2, label='Tendência')

# Personalização
plt.title('📈 Experiência vs Salário', fontsize=14, fontweight='bold')
plt.xlabel('Anos de Experiência', fontsize=12)
plt.ylabel('Salário (R$)', fontsize=12)
plt.colorbar(scatter, label='Anos de Experiência')
plt.legend()
plt.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

## 🔷 3. Plotagem Avançada com Seaborn

### ✅ **Instalação e Configuração**:

```python
import seaborn as sns

# Configurar estilo
sns.set_style("whitegrid")
sns.set_palette("husl")
```

### ✅ **Boxplot**:

```python
# Dados: Salários por departamento
np.random.seed(42)
dados = []
departamentos = ['TI', 'RH', 'Vendas', 'Marketing']

for dept in departamentos:
    if dept == 'TI':
        salarios = np.random.normal(7000, 1000, 50)
    elif dept == 'RH':
        salarios = np.random.normal(5500, 800, 50)
    elif dept == 'Vendas':
        salarios = np.random.normal(6000, 1200, 50)
    else:
        salarios = np.random.normal(5000, 700, 50)
    
    for salario in salarios:
        dados.append({'Departamento': dept, 'Salário': salario})

df = pd.DataFrame(dados)

# Plot
plt.figure(figsize=(10, 6))
sns.boxplot(x='Departamento', y='Salário', data=df, palette='Set2')

# Personalização
plt.title('📊 Distribuição de Salários por Departamento', fontsize=14, fontweight='bold')
plt.xlabel('Departamento', fontsize=12)
plt.ylabel('Salário (R$)', fontsize=12)

plt.tight_layout()
plt.show()
```

### ✅ **Violin Plot**:

```python
plt.figure(figsize=(10, 6))
sns.violinplot(x='Departamento', y='Salário', data=df, 
               palette='muted', inner='quartile')

plt.title('🎻 Distribuição Detalhada de Salários', fontsize=14, fontweight='bold')
plt.xlabel('Departamento', fontsize=12)
plt.ylabel('Salário (R$)', fontsize=12)
```

### ✅ **Heatmap (Matriz de Correlação)**:

```python
# Criar dados correlacionados
np.random.seed(42)
n = 100
dados_corr = pd.DataFrame({
    'Experiência': np.random.normal(5, 2, n),
    'Idade': np.random.normal(30, 5, n),
    'Salário': 3000 + 400 * np.random.normal(5, 2, n) + np.random.normal(0, 500, n),
    'Bugs_Resolvidos': np.random.poisson(20, n),
    'Horas_Trabalhadas': np.random.normal(160, 20, n)
})

# Calcular correlação
correlacao = dados_corr.corr()

# Plot
plt.figure(figsize=(10, 8))
sns.heatmap(correlacao, 
            annot=True,        # Mostrar valores
            cmap='coolwarm',   # Mapa de cores
            center=0,          # Centro em 0
            square=True,       # Células quadradas
            linewidths=1,      # Linhas entre células
            cbar_kws={"shrink": 0.8})  # Barra de cores

plt.title('🔗 Matriz de Correlação', fontsize=14, fontweight='bold')
plt.tight_layout()
plt.show()
```

### ✅ **Pair Plot**:

```python
# Para datasets pequenos (≤ 10 colunas)
sns.pairplot(dados_corr, 
             diag_kind='kde',   # Kernel Density Estimation na diagonal
             corner=True,       # Mostrar apenas metade
             plot_kws={'alpha': 0.6})  # Transparência

plt.suptitle('Pair Plot - Relações entre Variáveis', 
             y=1.02, fontsize=14, fontweight='bold')
plt.tight_layout()
plt.show()
```

## 🔷 4. Plotagem com Pandas (Integração Nativa)

### ✅ **Plotagem direta do DataFrame**:

```python
# Criar DataFrame de exemplo
df_rh = pd.DataFrame({
    'Mês': ['Jan', 'Fev', 'Mar', 'Abr', 'Mai', 'Jun'],
    'Contratações': [8, 12, 10, 15, 14, 18],
    'Demissões': [3, 5, 4, 6, 5, 7],
    'Turnover': [8.5, 7.2, 9.1, 6.8, 7.5, 6.2]
})

# Plotar múltiplas colunas
ax = df_rh.plot(x='Mês', 
                y=['Contratações', 'Demissões'],
                kind='bar',
                figsize=(10, 6),
                color=['#2A9D8F', '#E63946'])

# Personalização
ax.set_title('📈 Contratações vs Demissões', fontsize=14, fontweight='bold')
ax.set_xlabel('Mês', fontsize=12)
ax.set_ylabel('Número de Pessoas', fontsize=12)
ax.legend(loc='upper left')
ax.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

### ✅ **Plotagem por grupo**:

```python
# Dados agrupados
df_qa = pd.DataFrame({
    'Módulo': ['Login', 'Login', 'Pagamento', 'Pagamento', 'Perfil', 'Perfil'],
    'Severidade': ['Alto', 'Baixo', 'Alto', 'Baixo', 'Alto', 'Baixo'],
    'Bugs': [15, 30, 12, 25, 8, 20]
})

# Pivot table para plotagem
pivot_df = df_qa.pivot(index='Módulo', columns='Severidade', values='Bugs')

# Plot
ax = pivot_df.plot(kind='bar', 
                   figsize=(10, 6),
                   color=['#E63946', '#2A9D8F'])

ax.set_title('🐛 Bugs por Módulo e Severidade', fontsize=14, fontweight='bold')
ax.set_xlabel('Módulo', fontsize=12)
ax.set_ylabel('Número de Bugs', fontsize=12)
ax.legend(title='Severidade')
ax.grid(True, alpha=0.3, axis='y')

plt.tight_layout()
plt.show()
```

## 🔷 5. Subplots (Múltiplos Gráficos)

### ✅ **Subplots lado a lado**:

```python
fig, axes = plt.subplots(2, 2, figsize=(14, 10))

# Gráfico 1: Linha
axes[0, 0].plot(df_rh['Mês'], df_rh['Contratações'], 'o-', color='#2A9D8F')
axes[0, 0].set_title('Contratações por Mês')
axes[0, 0].set_xlabel('Mês')
axes[0, 0].set_ylabel('Contratações')
axes[0, 0].grid(True, alpha=0.3)

# Gráfico 2: Barras
axes[0, 1].bar(df_rh['Mês'], df_rh['Demissões'], color='#E63946')
axes[0, 1].set_title('Demissões por Mês')
axes[0, 1].set_xlabel('Mês')
axes[0, 1].set_ylabel('Demissões')
axes[0, 1].grid(True, alpha=0.3)

# Gráfico 3: Linha (Turnover)
axes[1, 0].plot(df_rh['Mês'], df_rh['Turnover'], 's--', color='#1D3557')
axes[1, 0].set_title('Taxa de Turnover')
axes[1, 0].set_xlabel('Mês')
axes[1, 0].set_ylabel('Turnover (%)')
axes[1, 0].grid(True, alpha=0.3)

# Gráfico 4: Scatter (Contratações vs Demissões)
axes[1, 1].scatter(df_rh['Contratações'], df_rh['Demissões'], 
                   s=100, color='#A8DADC', edgecolors='black')
axes[1, 1].set_title('Relação: Contratações vs Demissões')
axes[1, 1].set_xlabel('Contratações')
axes[1, 1].set_ylabel('Demissões')
axes[1, 1].grid(True, alpha=0.3)

# Ajustar layout
plt.suptitle('📊 Dashboard RH - Análise de Movimentação', 
             fontsize=16, fontweight='bold', y=1.02)
plt.tight_layout()
plt.show()
```
