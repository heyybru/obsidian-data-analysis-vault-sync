### 🔶 Conceito rápido

Arrays NumPy suportam **operações elemento a elemento** (broadcasting): soma, multiplicação, etc., sem loops. Funciona como "matemática vetorial".

**Import:**

```python
import numpy as np
```

---

### 1️⃣ Operações básicas (elemento a elemento)

```python
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

print(a + b)  # [5 7 9]
print(a * 2)  # [2 4 6] (multiplica cada elemento)
print(a ** 2) # [1 4 9] (potência)
```

**Exemplo QA: Tempos de teste**

```python
tempos = np.array([2.1, 3.5, 1.8])
print(tempos * 1.1)  # Aumenta 10%: [2.31 3.85 1.98]
```

---

### 2️⃣ Funções matemáticas (vetorizadas)

- `np.sum()`, `np.mean()`, `np.std()`, `np.median()`.

```python
notas = np.array([85, 92, 78, 95])
print(np.mean(notas))     # 87.5
print(np.std(notas))      # Desvio padrão
print(np.sqrt(notas))     # Raiz quadrada de cada
```

**Exemplo RH: Z-score (normalização)**

```python
z_scores = (notas - np.mean(notas)) / np.std(notas)
print(z_scores.round(2))  # Padroniza pra análise
```

---

### 3️⃣ Broadcasting (arrays diferentes)

NumPy "estica" arrays menores automaticamente.

```python
a = np.array([1, 2, 3])  # 1D
escalar = 10
print(a * escalar)       # [10 20 30]
```

**Exemplo 2D (matriz candidatos x critérios):**

```python
matriz = np.array([[90, 85], [88, 92]])
print(np.mean(matriz, axis=1))  # Média por linha: [87.5 90. ]
```
