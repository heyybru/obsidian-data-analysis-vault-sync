Na ciência de dados e no "Data Wrangling" (limpeza de dados), as funções **Lambda** são como "ferramentas de bolso": rápidas, descartáveis e muito eficientes para resolver problemas pontuais sem precisar criar uma estrutura pesada de código.

Aqui está o resumo direto para você:

### 🔶 O que é uma Função Lambda?

- **Função Anônima:** É uma função que não tem nome (não usa o `def`).
- **Uma única linha:** Ela é escrita em apenas uma linha de código.
- **Sintaxe:** `lambda argumentos: expressão`.
- **Uso principal:** Quase sempre você a verá dentro do `apply()`, `map()` ou `filter()`.

---

### 1️⃣ Exemplo Simples: Matemática Rápida

Imagine que você quer apenas dobrar um valor.

👉 **Sem Lambda:**

```python
def dobrar(x):
    return x * 2
```

👉 **Com Lambda:**

```python
lambda x: x * 2
```

---

### 2️⃣ Aplicação no Pandas (Onde a mágica acontece)

Como especialista, vejo muito o uso de Lambdas para padronizar colunas vindas de fontes sujas (como planilhas de recrutamento manuais).

👉 **Exemplo: Limpar espaços em branco e padronizar nomes (QA/Recrutamento)**

```python
# Remove espaços extras e coloca a primeira letra em maiúsculo
df['nome_limpo'] = df['nome'].apply(lambda x: str(x).strip().title())
```

---

### 3️⃣ Lógica Condicional (If/Else) dentro da Lambda

Você pode tomar decisões rápidas em uma linha. Muito útil para categorizar candidatos ou resultados de testes.

👉 **Exemplo: Classificar pretensão salarial**

```python
# Se for maior que 5000 é 'Acima', senão é 'Dentro'
df['faixa_salarial'] = df['pretensao'].apply(lambda x: 'Acima' if x > 5000 else 'Dentro')
```

---

### 🚀 Visão de Especialista

- **Agilidade:** Segundo a **Preditiva.ai**, o uso de Lambdas acelera o processo de _Exploratory Data Analysis_ (EDA), pois você não "suja" seu notebook com dezenas de pequenas funções `def`.
- **Legibilidade:** O **Cappra Institute** reforça que dados devem ser legíveis. Se a sua lógica Lambda começar a ficar muito grande (mais de dois `if/else`), **pare**. Nesse caso, é melhor usar uma função normal (`def`) para que outros analistas entendam seu código.
- **QA e Automação:** No seu dia a dia de QA, Lambdas são ótimas para validar formatos de strings em massa ou converter tipos de dados de APIs (ex: transformar uma string "R$ 1.200" em um número real `1200.0` para cálculos).

### 💡 Dica para o Bruno:

Pense na Lambda como um **atalho**. Se você vai usar a lógica apenas uma vez naquela coluna, vá de **Lambda**. Se vai repetir a lógica em vários lugares do projeto, use **Def**.
