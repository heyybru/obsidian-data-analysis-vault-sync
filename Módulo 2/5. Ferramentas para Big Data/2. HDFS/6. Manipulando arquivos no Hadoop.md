### 🔶 Comandos básicos pra manipular arquivos

Todos com prefixo `hdfs dfs` (roda no terminal após `start-dfs.sh`).

1. **Criar/Upload (put/copyFromLocal)**:
    
    - Envia local pro HDFS (divide em blocos + réplicas).
    
    ```bash
    hdfs dfs -put ~/logs_qa_jira.txt /qa/logs/  # Seu log de bugs → HDFS
    hdfs dfs -copyFromLocal -f arquivo.csv /rh/candidatos/  # Sobrescreve se existir
    ```
    
2. **Ler/Visualizar (cat/head/tail)**:
    
    ```bash
    hdfs dfs -cat /qa/logs/contagem_bugs.txt  # Todo conteúdo
    hdfs dfs -head -10 /rh/dados.csv  # Primeiras 10 linhas
    ```
    
3. **Listar e navegar (ls/ls -R)**:
    
    ```bash
    hdfs dfs -ls /qa/  # Lista arquivos/pastas
    hdfs dfs -ls -R /qa/logs/  # Recursivo (tudo dentro)
    ```
    
4. **Mover/Copiar (mv/cp)**:
    
    ```bash
    hdfs dfs -mv /qa/logs_antigos/ /arquivo/  # Renomeia/move
    hdfs dfs -cp /qa/original.txt /qa/backup/  # Copia no HDFS
    ```
    
5. **Deletar (rm/rm -r)**:
    
    ```bash
    hdfs dfs -rm /qa/arquivo_temp.txt  # Um arquivo
    hdfs dfs -rm -r -skipTrash /qa/pasta_velha/  # Pasta recursiva (sem lixeira)
    ```
    
6. **Download (get)**:
    
    ```bash
    hdfs dfs -get /qa/resultado_mapreduce.txt ~/relatorios/
    ```
