https://livesql.oracle.com/landing/

**O que é:** um ambiente **em nuvem** mantido pela Oracle, onde você pode praticar comandos SQL **sem instalar nada** — basta ter conexão com a internet.

🔑 **Analogia:** é como uma **academia online**. Você não precisa comprar os equipamentos (instalar o banco) — a Oracle já deixa tudo pronto para você treinar (executar comandos) de qualquer lugar.

**Passo a passo de acesso (do material):**

1. Digite **Oracle Live** no navegador
2. Clique em **Start Coding** (mantenha o idioma em inglês, pois os comandos são em inglês)
3. Crie uma **conta** na Oracle (preencha os campos com `*`, que são obrigatórios)
4. Confirme a senha pelo **e-mail** que a Oracle envia
5. Faça **login** com e-mail e senha
6. Digite os comandos na tela e clique em **Run** para executar

**Vantagens:** grátis, sem instalação, acessível de qualquer lugar. **Limitação:** precisa de internet e de criar uma conta.
