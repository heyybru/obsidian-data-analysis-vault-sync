# 🔗 JOINS (Junções)

👉 **JOIN** serve para **consultar dados de duas ou mais tabelas relacionadas**, usando chaves (PK e FK).

---

## 🔹 Junção Idêntica (Equi Join)

### O que é?

É a junção mais comum.  
Usa o operador **= (igual)** para relacionar tabelas.

---

### Exemplo de tabelas

**CLIENTE**

- id_cliente (PK)
    
- nome
    

**PEDIDO**

- id_pedido (PK)
    
- id_cliente (FK)
    
- data_pedido
    

---

### Exemplo de consulta

```sql
SELECT c.nome, p.id_pedido, p.data_pedido
FROM CLIENTE c
JOIN PEDIDO p
  ON c.id_cliente = p.id_cliente;
```

📌 Mostra apenas registros que **existem nas duas tabelas**.

---

### Sintaxe antiga (ainda cai em prova)

```sql
SELECT c.nome, p.id_pedido
FROM CLIENTE c, PEDIDO p
WHERE c.id_cliente = p.id_cliente;
```

⚠ Atenção: se esquecer o WHERE → **produto cartesiano**.

---

## 🔹 Junção Tridimensional (3 tabelas)

### O que é?

É uma junção entre **três tabelas**, normalmente ligadas em cadeia.

---

### Exemplo de tabelas

**CLIENTE → PEDIDO → ITEM_PEDIDO**

- CLIENTE(id_cliente)
    
- PEDIDO(id_pedido, id_cliente)
    
- ITEM_PEDIDO(id_item, id_pedido, produto)
    

---

### Exemplo de consulta

```sql
SELECT c.nome,
       p.id_pedido,
       i.produto
FROM CLIENTE c
JOIN PEDIDO p
  ON c.id_cliente = p.id_cliente
JOIN ITEM_PEDIDO i
  ON p.id_pedido = i.id_pedido;
```

📌 Relacionamento:

- CLIENTE → PEDIDO
    
- PEDIDO → ITEM_PEDIDO
    

---

## 🧠 Regra importante

👉 Cada JOIN precisa de **uma condição de junção** (PK = FK).

---

## ⚠ Pegadinhas

- Junção idêntica = uso do operador `=`
    
- Junção tridimensional = **3 tabelas**
    
- Esquecer condição de junção → resultado errado
    
- JOIN moderno é preferível ao antigo
    

---

## 📘 Resumo

|Tipo|Característica|
|---|---|
|Junção Idêntica|PK = FK|
|Junção Tridimensional|3 tabelas relacionadas|
|JOIN|Relaciona tabelas|
|WHERE|Condição na sintaxe antiga|
