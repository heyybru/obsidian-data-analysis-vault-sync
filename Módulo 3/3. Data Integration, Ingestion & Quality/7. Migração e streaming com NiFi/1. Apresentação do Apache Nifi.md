[Apache Nifi](https://nifi.apache.org/)

O Apache NiFi é uma plataforma de **integração de dados, ingestão e distribuição** altamente escalável e robusta. Ele foi projetado para automatizar e gerenciar o fluxo de dados entre diferentes sistemas de forma visual e em tempo real.

### 🧠 Conceitos Fundamentais do Material

- **Evolução Histórica:** Antigamente, migrar dados entre diferentes SGBDs (Sistemas Gerenciadores de Bancos de Dados) e servidores remotos era um processo lento, complexo e propenso a falhas. O NiFi surge para simplificar isso, permitindo conexões seguras e compatíveis.
- **Interface Gráfica (Drag-and-Drop):** Diferente de ferramentas baseadas puramente em código (como scripts Python ou Spark), o NiFi utiliza uma interface visual intuitiva onde você desenha o fluxo de dados conectando caixas (Processors).
- **Conectividade Universal:** Ele utiliza drivers **JDBC (Java Database Connectivity)** para se conectar a praticamente qualquer banco de dados relacional (MySQL, PostgreSQL, Oracle) ou sistemas de arquivos (HDFS, S3, FTP).
- **Avaliação de Necessidade (ROI):** O material traz um alerta de negócio muito importante: antes de implementar uma tecnologia de streaming em tempo real como o NiFi, avalie se a empresa realmente precisa disso. Implementar tecnologias complexas sem justificativa de negócio gera custos desnecessários e perda de confiança.
