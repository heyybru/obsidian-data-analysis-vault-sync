`if` é como um "guarda de trânsito" para seu código**.  
Ele decide **qual caminho seguir** baseado em uma condição: "Se isso for verdade, faça aquilo".

✅ **No seu contexto (RH + QA)**:

- **RH**: "Se candidato tem experiência > 3 anos, aprovar para entrevista"
- **QA**: "Se bug é crítico, enviar alerta imediato"

---

## 🔷 Sintaxe

### ✅ **`if` simples**

```python
if condicao:
    # código que executa SE condição for True
```

**Exemplo**:

```python
salario = 5000

if salario > 3000:
    print("Salário acima da média")
```

### ✅ **`if` com `else`** (ou isso, ou aquilo)

```python
if condicao:
    # executa se True
else:
    # executa se False
```

**Exemplo**:

```python
idade = 25

if idade >= 18:
    print("Maior de idade")
else:
    print("Menor de idade")
```

### ✅ **`if` com `elif`** (várias condições)

```python
if condicao1:
    # executa se condicao1 True
elif condicao2:
    # executa se condicao2 True
else:
    # executa se todas False
```

**Exemplo**:

```python
nota = 7.5

if nota >= 9:
    print("Excelente")
elif nota >= 7:
    print("Bom")
elif nota >= 5:
    print("Regular")
else:
    print("Insuficiente")
```

## 🔷 Operadores de comparação (o que vai dentro do `if`)

|Operador|Significado|Exemplo|
|---|---|---|
|`==`|Igual a|`idade == 18`|
|`!=`|Diferente de|`status != "aprovado"`|
|`>`|Maior que|`salario > 3000`|
|`<`|Menor que|`bugs < 10`|
|`>=`|Maior ou igual|`experiencia >= 3`|
|`<=`|Menor ou igual|`tempo <= 30`|

**Exemplos**:

```python
# RH: Verifica experiência
experiencia = 4
if experiencia >= 3:
    print("Experiência suficiente")

# QA: Verifica severidade
severidade = "critico"
if severidade == "critico":
    print("BUG CRÍTICO! Atender imediatamente")
```

---

## 🔷 Operadores lógicos (combinar condições)

|Operador|Significado|Exemplo|
|---|---|---|
|`and`|E (ambas verdadeiras)|`idade >= 18 and experiencia >= 2`|
|`or`|OU (pelo menos uma)|`tem_graduacao or tem_certificacao`|
|`not`|NÃO (inverte)|`not candidato_reprovado`|

**Exemplos**:

```python
# RH: Candidato precisa ter graduação E experiência
tem_graduacao = True
experiencia = 3

if tem_graduacao and experiencia >= 2:
    print("Atende requisitos mínimos")

# QA: Bug é crítico OU bloqueante
severidade = "critico"
eh_bloqueante = False

if severidade == "critico" or eh_bloqueante:
    print("Prioridade máxima")
```

## 🔷 Exemplos práticos (RH + QA)

### ✅ **Exemplo 1: Triagem de candidatos**

```python
# Dados do candidato
experiencia = 4
tem_ingles = True
salario_pretendido = 6000

# Regras de triagem
if experiencia >= 3 and tem_ingles:
    if salario_pretendido <= 7000:
        print("✅ Candidato aprovado para entrevista")
    else:
        print("⚠️ Salário acima do budget")
else:
    print("❌ Não atende requisitos mínimos")
```

### ✅ **Exemplo 2: Classificação de bugs**

```python
# Dados do bug
severidade = "alto"
modulo = "pagamento"
tempo_aberto = 48  # horas

# Classificação
if severidade == "critico":
    print("🔴 BUG CRÍTICO - Parar tudo e corrigir")
elif severidade == "alto" and modulo == "pagamento":
    print("🟠 BUG ALTO em módulo crítico - Prioridade 1")
elif tempo_aberto > 72:
    print("🟡 Bug aberto há mais de 3 dias - Follow up")
else:
    print("🟢 Bug normal - Processar na fila")
```

### ✅ **Exemplo 3: Cálculo de bônus (RH)**

```python
# Dados do funcionário
tempo_empresa = 2  # anos
avaliacao = 8.5
metas_atingidas = True

# Cálculo de bônus
if tempo_empresa >= 1:
    if avaliacao >= 9 and metas_atingidas:
        bonus = 2000
        print(f"Bônus máximo: R$ {bonus}")
    elif avaliacao >= 7 and metas_atingidas:
        bonus = 1000
        print(f"Bônus regular: R$ {bonus}")
    else:
        bonus = 500
        print(f"Bônus mínimo: R$ {bonus}")
else:
    print("Sem direito a bônus (menos de 1 ano)")
```

## 🔷 `if` com listas (muito útil)

### ✅ **Verificar se item está na lista**

```python
candidatos_aprovados = ["Ana", "Bruno", "Carla"]
candidato_atual = "Bruno"

if candidato_atual in candidatos_aprovados:
    print(f"{candidato_atual} já foi aprovado")
else:
    print(f"{candidato_atual} ainda não aprovado")
```

### ✅ **Verificar lista vazia**

```python
bugs_pendentes = []

if bugs_pendentes:  # True se lista NÃO vazia
    print(f"Há {len(bugs_pendentes)} bugs pendentes")
else:
    print("Nenhum bug pendente 🎉")
```

## 🔷 `if` em uma linha (ternário)

Para condições simples:

```python
# Forma longa
idade = 20
if idade >= 18:
    status = "maior"
else:
    status = "menor"

# Forma curta (ternário)
status = "maior" if idade >= 18 else "menor"
```

**Exemplo prático**:

```python
# QA: Status do bug
bug_critico = True
prioridade = "ALTA" if bug_critico else "normal"
print(f"Prioridade: {prioridade}")
```

## 🔷 Erros comuns (para evitar)

### ❌ **Erro 1: Esquecer `:`**

```python
# ERRADO
if idade >= 18
    print("Maior")

# CORRETO
if idade >= 18:
    print("Maior")
```

### ❌ **Erro 2: Indentação errada**

```python
# ERRADO (sem indentação)
if True:
print("Olá")  # SyntaxError

# CORRETO
if True:
    print("Olá")  # 4 espaços ou tab
```

### ❌ **Erro 3: `=` em vez de `==`**

```python
# ERRADO (atribuição, não comparação)
if status = "aprovado":  # SyntaxError

# CORRETO
if status == "aprovado":
    print("Aprovado")
```

## 🔷 Exercício prático

**Crie um sistema de classificação de bugs**:

```python
print("=== Classificador de Bugs ===")

# Entrada de dados
severidade = input("Severidade (critico/alto/medio/baixo): ").lower()
modulo = input("Módulo (login/pagamento/perfil/outro): ").lower()
reproduzivel = input("Reproduzível? (s/n): ").lower() == 's'

# Lógica de classificação
if severidade == "critico":
    print("🔴 PARAR TUDO - Corrigir imediatamente")
elif severidade == "alto" and modulo in ["login", "pagamento"]:
    print("🟠 Alta prioridade - Corrigir hoje")
elif not reproduzivel:
    print("🟡 Prioridade baixa - Investigar primeiro")
else:
    print("🟢 Prioridade normal - Processar na fila")
```
