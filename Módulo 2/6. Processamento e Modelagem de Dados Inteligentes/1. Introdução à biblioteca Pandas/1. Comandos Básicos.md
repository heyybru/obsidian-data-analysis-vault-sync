# 1. Introdução

Pandas é uma biblioteca de código aberto do Python para **análise e manipulação de dados estruturados**. Ela resolve um problema específico: trabalhar com tabelas na mão em Python puro é lento e verboso. O Pandas entrega uma estrutura de tabela pronta, com operações de filtro, agregação, ordenação e leitura de arquivos já implementadas.

Os quatro tópicos do material não são quatro assuntos soltos — são **quatro estágios de um mesmo fluxo**. Pense na ordem em que o dado caminha:

```text
1. Comandos básicos   → criar a estrutura (a "tabela")
2. Gestão de arquivos → trazer o dado de fora para dentro dessa estrutura
3. Gestão de colunas  → escolher o que interessa dentro da estrutura
4. Funções matem. e iloc → calcular sobre o que foi escolhido
```

Cada estágio entrega o insumo do próximo. É por isso que o material segue essa ordem e é por isso que, sem o tópico 1, os outros três não funcionam.

# 2. Tópico 1 — Comandos Básicos

## O que é

O ponto de partida: instalar a biblioteca e conhecer as **duas estruturas de dados** que ela oferece.

- **Series** → uma dimensão (uma coluna de valores com um índice).
- **DataFrame** → duas dimensões (linhas e colunas, como uma planilha).

## Como funciona

A instalação acontece pelo gerenciador de pacotes do Python, no terminal:

```bash
pip install pandas
```

Depois, a convenção universal é importar com o apelido `pd` — é o padrão que você vai encontrar em toda documentação, tutorial e código de mercado:

```python
import pandas as pd
```

Uma **Series** nasce de uma lista simples. Note que o Pandas cria automaticamente um índice numérico à esquerda (0, 1, 2...) e identifica o tipo dos dados (`dtype`):

```python
s = pd.Series([1, 3, 5, 7, 9])
print(s)
```

```text
0    1
1    3
2    5
3    7
4    9
dtype: int64
```

Um **DataFrame** nasce de um dicionário: cada **chave** vira o nome de uma coluna, cada **lista** vira os valores dessa coluna. O Pandas alinha tudo pela posição dentro das listas.

```python
dados = {
    'nome':  ['João', 'Maria', 'José', 'Ana', 'Pedro'],
    'idade': [20, 25, 30, 35, 40],
    'cidade': ['São Paulo', 'Rio de Janeiro', 'Belo Horizonte',
               'Curitiba', 'Porto Alegre']
}
df = pd.DataFrame(dados)
print(df)
```

```text
    nome  idade           cidade
0   João     20        São Paulo
1  Maria     25   Rio de Janeiro
2   José     30  Belo Horizonte
3    Ana     35         Curitiba
4  Pedro     40      Porto Alegre
```

## Onde se aplica

Na **etapa de estruturação** — o momento em que o dado deixa de ser um arquivo bruto e passa a existir como objeto manipulável dentro do Python.

## Quando usar

Sempre. Todo script de análise começa com o `import` e com a criação ou carregamento de um DataFrame. É o alicerce dos outros três tópicos.

## Complemento (além do material)

A primeira coisa que se faz ao receber um DataFrame é **inspecioná-lo**, e o material não cobre isso. Quatro comandos cobrem 90% da inspeção inicial, conforme o tutorial do W3Schools:

```python
df.head()        # primeiras 5 linhas
df.shape         # (linhas, colunas) → ex.: (5, 3)
df.info()        # tipos de cada coluna e contagem de não-nulos
df.describe()    # estatísticas descritivas das colunas numéricas
```

👉 **Por que importa:** `dtypes` errados são a causa número um de erro em análise. Uma coluna de preço lida como texto não soma e não calcula média. Verificar o tipo logo no início economiza horas de depuração.

# 3. Tópico 2 — Gestão de Arquivos

## O que é

A capacidade de **ler e escrever** dados em diferentes formatos. Segundo o material, o Pandas suporta CSV, Excel, SQL, JSON, HTML, entre outros.

## Como funciona

**Ler um CSV** — o resultado é um DataFrame, exatamente a estrutura do tópico 1:

```python
df = pd.read_csv('arquivo.csv')
print(df)
```

**Escrever um CSV** — parte de um DataFrame e grava em disco:

```python
df.to_csv('arquivo.csv', index=False)
```

O detalhe mais importante aqui é o `index=False`. Sem ele, o Pandas grava também o índice numérico (0, 1, 2...) como uma coluna extra dentro do arquivo. Ao reabrir, você teria uma coluna fantasma chamada `Unnamed: 0`. O `index=False` diz: **grave só os dados, não a numeração interna**.

## Onde se aplica

Na **ingestão** — a primeira etapa do pipeline de dados. É quando o dado entra no processo.

## Quando usar

Sempre que a origem não for um banco conectado diretamente. No projeto prático da disciplina (valores de aluguel), é aqui que a base entra no ambiente.

## Complemento (além do material)

O material cita vários formatos mas exemplifica só CSV. Pela documentação, o padrão de nome se repete — o que muda é o prefixo:

```python
pd.read_excel('dados.xlsx', sheet_name='Vendas')
pd.read_json('dados.json')
pd.read_sql('SELECT * FROM vendas', conexao)
```

Dois parâmetros que evitam dor de cabeça no mundo real, e que o material não menciona:

- `sep=';'` → o Excel em português costuma exportar CSV com ponto e vírgula, não vírgula. Sem isso, tudo vira uma coluna só.
- `encoding='utf-8'` ou `encoding='latin-1'` → resolve acentuação corrompida.

## Conexão com o tópico 1

`read_csv` **não retorna texto** — retorna um DataFrame. Por isso o tópico 2 depende do tópico 1: o formato de saída do carregamento é o formato de entrada de todas as operações seguintes.

# 4. Tópico 3 — Gestão de Colunas Específicas

## O que é

Selecionar apenas parte das colunas de um DataFrame. Em bases grandes, você raramente quer todas as colunas — quer as relevantes para a pergunta.

## Como funciona

**Uma coluna** → usa colchetes com o nome em string. O resultado é uma **Series**, não um DataFrame:

```python
data = {'fruta': ['maçã', 'banana', 'laranja', 'uva'],
        'preço': [1.50, 0.50, 2.20, 0.75],
        'quantidade': [100, 200, 50, 75]}
df = pd.DataFrame(data)

precos = df['preço']
print(precos)
```

```text
0    1.50
1    0.50
2    2.20
3    0.75
Name: preço, dtype: float64
```

Repare no `Name: preço` e no `dtype: float64` — são as marcas de que isto é uma Series, com uma única dimensão e um tipo definido.

**Várias colunas** → colchetes com uma **lista** de nomes. Note os dois pares de colchetes: o de fora é a seleção, o de dentro é a lista. O resultado é um **DataFrame**:

```python
selecao = ['fruta', 'quantidade']
result = df[selecao]
print(result)
```

```text
     fruta  quantidade
0     maçã         100
1   banana         200
2  laranja          50
3      uva          75
```

## Onde se aplica

Na **seleção de atributos** — etapa de transformação, em que você reduz o conjunto ao que a análise exige.

## Quando usar

Antes de qualquer cálculo ou modelagem. Reduzir colunas economiza memória, acelera o processamento e evita que colunas de texto interfiram em operações numéricas.

## O detalhe que mais confunde

**Uma coluna retorna Series. Uma lista de colunas retorna DataFrame.** Visualmente são parecidos, mas o comportamento é diferente. `df['preço'].mean()` funciona; `df[['preço']].mean()` também, mas o resultado é uma Series de um elemento, não um número. Essa distinção se conecta diretamente ao tópico 4.

# 5. Tópico 4 — Funções Matemáticas e iloc

## O que é

Duas coisas que o material trata em pontos diferentes, mas que se encontram na prática:

- **Funções matemáticas** → agregações que resumem uma coluna em um número: `mean()`, `median()`, `max()`, `min()`, `sum()`.
- **`.iloc[]`** → seleção por **posição numérica** (linha e coluna pelo número, começando em 0).

## Como funciona — funções matemáticas

Aplicadas a uma coluna, retornam um valor único:

```python
media_idade = dados["idade"].mean()
```

As cinco funções listadas no material, com o que cada uma responde:

- `mean()` → qual o **valor médio** (sensível a valores extremos)
- `median()` → qual o **valor central** (resistente a valores extremos)
- `max()` / `min()` → qual o **maior** e o **menor** valor
- `sum()` → qual o **total**

👉 **mean vs median, na prática:** em uma base de aluguel, se existe um imóvel de luxo muito acima dos demais, a média sobe e distorce a leitura. A mediana fica estável. Comparar as duas é o teste mais rápido de assimetria em uma variável — e isso é exatamente Análise Exploratória de Dados, o próximo tópico da disciplina.

## Como funciona — iloc

`.iloc` localiza por **posição inteira**. A sintaxe é `[linhas, colunas]`:

```python
result2 = df.iloc[:, [0, 2]]
```

Lendo em voz alta: "todas as linhas (`:` significa tudo), colunas nas posições 0 e 2". Como `fruta` é a coluna 0 e `quantidade` é a coluna 2, o resultado é idêntico ao da seleção por nome:

```text
     fruta  quantidade
0     maçã         100
1   banana         200
2  laranja          50
3      uva          75
```

O material mostra `.loc` e `.iloc` lado a lado porque eles fazem a **mesma coisa por caminhos diferentes**: `.loc` usa o **nome/rótulo**, `.iloc` usa a **posição numérica**. A comparação visual acima resume as diferenças.

## Por que "Funções Matemáticas" e "iloc" aparecem juntos

Porque na prática eles se combinam constantemente. O padrão mais comum em análise é **recortar e depois calcular**:

```python
# média de preço apenas dos 3 primeiros registros
df.iloc[0:3]['preço'].mean()
```

`iloc` escolhe o pedaço; `mean()` resume o pedaço. Um prepara, o outro conclui. É o mesmo encadeamento dos tópicos 2 e 3: **selecionar → calcular**.

## Complemento (além do material)

**Agregação com `axis`.** Sem `axis`, a função desce pelas colunas (calcula por coluna). Com `axis=1`, atravessa as linhas (calcula por linha):

```python
df[['preço', 'quantidade']].mean(axis=1)
```

**Agrupamento.** O material apresenta `groupby` com `agg`, que é o passo seguinte natural das funções matemáticas — calcular a estatística **dentro de cada grupo**:

```python
vendas_por_fruta = frutas.groupby('fruta').agg({'vendas': 'sum', 'preco': 'mean'})
```

Isso responde "qual fruta vendeu mais" em vez de "quanto vendeu no total". É a operação que sustenta praticamente todo relatório de BI.

**⚠️ Ponto de atenção real (não no material):** nas versões atuais do Pandas, aplicar `.mean()` ou `.sum()` a um DataFrame que mistura texto e números gera erro ou resultado sem sentido — `sum()` em coluna de texto **concatena** strings. A prática segura é sempre selecionar as colunas numéricas antes:

```python
df[['preço', 'quantidade']].sum()
```

## Dois pontos de imprecisão no material

Sinalizo objetivamente, porque vão te confundir se você reproduzir sem entender:

1. **A seção se chama "Map e Replace", mas o exemplo de `replace` não usa o método `.replace()` do Pandas.** Ele usa `.apply()` combinado com `str.replace()`. São coisas distintas: `str.replace()` troca pedaços de texto _dentro_ de uma string; `pd.Series.replace()` substitui valores inteiros. O efeito no exemplo é converter `2.99` em `'2,99'`.
    
2. **Esse mesmo exemplo transforma uma coluna numérica em texto.** `str(x)` converte o número em string, e a coluna passa a ter `dtype` object. Depois disso, `mean()` e `sum()` deixam de funcionar. É uma armadilha silenciosa — válida para exibir no padrão brasileiro, ruim para calcular.
    
3. **O material não menciona tratamento de valores ausentes (`NaN`)**, que é etapa obrigatória do EDA e do projeto prático da disciplina. Lacuna a suprir com `df.isna().sum()` e `df.dropna()` / `df.fillna()`.

# 6. Conclusão

Os quatro tópicos formam um único raciocínio, não quatro lições isoladas. O Pandas é, na prática, um **encadeamento de decisões sobre dados**: onde os dados estão (arquivo), em que forma entram (DataFrame), o que interessa (colunas) e o que isso significa em número (agregação). Aprender os comandos sem essa linha de raciocínio produz alguém que sabe digitar sintaxe; aprender com a linha produz alguém que sabe resolver problema.

O ponto mais valioso do material é a comparação entre `.loc` e `.iloc`, porque ela força uma distinção conceitual que aparece em toda a engenharia de dados: **nome versus posição**. Nomes são legíveis e estáveis; posições são frágeis, porque mudam quando a ordem das colunas muda. Prefira nome no código de produção; use posição para exploração rápida.

# 7. Síntese

- **Series é 1D, DataFrame é 2D** — e a diferença muda o retorno de cada operação.
- **`read_csv` já entrega um DataFrame**: ingestão e estrutura são a mesma etapa.
- **`index=False`** evita a coluna fantasma ao salvar.
- **Uma coluna → Series; lista de colunas → DataFrame.**
- **`.loc` usa nome e inclui o fim do intervalo; `.iloc` usa posição e exclui o fim.**
- **Sempre confira `dtypes` antes de calcular** — coluna como texto não soma.

**# Pandas — Introdução à Biblioteca**

> [!abstract] Objetivo Dominar as estruturas de dados do Pandas e o fluxo carregar → selecionar → transformar → calcular.

**## 1. Comandos básicos**

- **O que é:** instalação e as duas estruturas — Series (1D) e DataFrame (2D).
- **Como funciona:** `pip install pandas` → `import pandas as pd` → `pd.Series([lista])` / `pd.DataFrame({dict})`.
- **Onde se aplica:** estruturação do dado.
- **Quando usar:** início de todo script.
- **Inspeção:** `head()`, `shape`, `info()`, `describe()`.

**## 2. Gestão de arquivos**

- **O que é:** leitura e escrita em CSV, Excel, SQL, JSON, HTML.
- **Como funciona:** `pd.read_csv('arquivo.csv')` → DataFrame; `df.to_csv('arquivo.csv', index=False)`.
- **Onde se aplica:** ingestão.
- **Quando usar:** sempre que a origem não for conexão direta.
- **Atenção:** `sep=';'` e `encoding='utf-8'` resolvem CSV brasileiro.

**## 3. Gestão de colunas específicas**

- **O que é:** selecionar subconjunto de colunas.
- **Como funciona:** `df['col']` → Series; `df[['a','b']]` → DataFrame.
- **Onde se aplica:** seleção de atributos.
- **Quando usar:** antes de calcular ou modelar.

**## 4. Funções matemáticas e iloc**

- **O que é:** agregações (`mean`, `median`, `max`, `min`, `sum`) e seleção por posição (`.iloc`).
- **Como funciona:** `df['col'].mean()`; `df.iloc[:, [0, 2]]`; `.loc` por nome (fim incluído), `.iloc` por posição (fim excluído).
- **Onde se aplica:** análise e EDA.
- **Quando usar:** para resumir e para recortar antes de resumir.
- **Padrão combinado:** `df.iloc[0:3]['preço'].mean()`.

**## ⚠️ Cuidados**

- `df.mean()` em DataFrame misto → erro. Selecione colunas numéricas primeiro.
- `sum()` em coluna de texto → concatena strings.
- `str.replace()` ≠ `Series.replace()`.
- Conferir `dtypes` antes de qualquer cálculo.

## Resumindo

- Os 4 tópicos são **um fluxo único**: criar estrutura → carregar → selecionar → calcular.
- `.loc` = nome (fim incluído) · `.iloc` = posição (fim excluído) · colchetes = nome de coluna.
- O material tem **duas imprecisões** (o exemplo de `replace` usa `apply` + `str.replace`) e **uma lacuna** (não trata `NaN`).
- O hábito que mais protege seu código: **verificar `dtypes` antes de calcular**.
