> _"A manutenção de dados é um processo complexo de busca e limpeza de erros, mantendo limpa e organizada a base de dados."_

Não é uma ação pontual — é um **processo contínuo**. Os dois focos principais:

### 🔹 Deduplicação (Deduplication)

Remover registros duplicados **sem eliminar dados com propósitos distintos**.

**Exemplo real:** Um mesmo candidato (`bhenriquealves520@gmail.com`) aparece duas vezes — uma pra vaga de QA e outra pra Data Scientist. Isso é duplicata? **Depende.** Se for a mesma candidatura duplicada → deleta. Se forem candidaturas legítimas pra vagas diferentes → mantém, mas unifica os dados de cadastro.

```text
ANTES:
│ id=23 │ bruno@email │ QA Engineer  │ 4 anos │
│ id=47 │ bruno@email │ Cient. Dados │ 6 anos │

DEPOIS (dedup inteligente):
│ id=23 │ bruno@email │ QA Engineer, Cient. Dados │ 6 anos │
```

### 🔹 Limpeza Contínua

|Ação|Frequência|Exemplo no dataset|
|:--|:--|:--|
|**Correção de formato**|A cada ingestão|Telefones: `(21) 84739-884` vs `(+5) 58495-8444` — padronizar|
|**Validação de domínio**|A cada ingestão|`pretensao_salarial` negativa? Rejeita|
|**Atualização de cadastro**|Trimestral|Disparar e-mail automático pedindo atualização|
|**Descarte (purge)**|Semestral|Candidaturas > 2 anos sem movimentação|
|**Cross-validation**|Mensal|Conferir `nivel_educacional` × `universidade` (Doutorado na Unesp existe?)|
