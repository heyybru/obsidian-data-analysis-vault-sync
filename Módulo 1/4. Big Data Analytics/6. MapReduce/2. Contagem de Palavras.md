## 🔷 O "Hello World" do Big Data

**Contagem de palavras é como "contar grãos de areia na praia" - você divide em baldes, conta cada balde, depois soma tudo**.  
É o exemplo clássico que ensina todos os conceitos fundamentais do processamento distribuído.

✅ **No seu contexto (RH + QA)**:

- **RH**: Contar palavras-chave em currículos, analisar descrições de vagas
- **QA**: Contar erros em logs, analisar mensagens de commit, processar documentação

## 🔷 1. O Problema Clássico

**Problema**: Você tem **10GB de texto** (livros, artigos, logs) e quer saber:

- Quantas vezes cada palavra aparece
- Quais são as palavras mais frequentes
- Distribuição de frequência

**Desafio**: 10GB não cabem na memória de uma máquina!

---

## 🔷 3. Solução MapReduce (Funciona!)

### ✅ **Arquitetura**:

```
10GB de texto
    ↓
Dividir em 100 pedaços de 100MB
    ↓
Distribuir para 100 máquinas
    ↓
Cada máquina conta palavras no seu pedaço
    ↓
Agrupar contagens por palavra
    ↓
Somar contagens de cada palavra
    ↓
Resultado final
```

## 🔷 4. Implementação Passo a Passo

### ✅ **Passo 1: Preparar dados**:

```python
# Dados de exemplo (em produção seriam GBs)
textos = [
    "python java python scala java",
    "java scala kotlin python",
    "python python python java",
    "scala kotlin kotlin"
]

# Salvar em arquivos separados (simulando divisão)
for i, texto in enumerate(textos):
    with open(f'parte_{i}.txt', 'w') as f:
        f.write(texto)
```

### ✅ **Passo 2: Função Map (paralela)**:

```python
def map_function(arquivo):
    """Lê um arquivo e emite (palavra, 1) para cada palavra"""
    with open(arquivo, 'r') as f:
        texto = f.read()
    
    contagem_local = {}
    for palavra in texto.lower().split():
        # Remove pontuação básica
        palavra = palavra.strip('.,!?;:"\'()[]{}')
        if palavra:  # Ignora strings vazias
            yield (palavra, 1)
    
    # Em produção: salvar em disco intermediário
    return contagem_local
```

### ✅ **Passo 3: Shuffle (agrupar)**:

```python
def shuffle(map_results):
    """Agrupa todos os valores com mesma chave"""
    agrupado = {}
    
    for resultado in map_results:
        for palavra, contagem in resultado:
            if palavra not in agrupado:
                agrupado[palavra] = []
            agrupado[palavra].append(contagem)
    
    return agrupado
```

### ✅ **Passo 4: Função Reduce (somar)**:

```python
def reduce_function(palavra, contagens):
    """Soma todas as contagens de uma palavra"""
    return (palavra, sum(contagens))
```

### ✅ **Passo 5: Executar pipeline**:

```python
# 1. Executar Map em paralelo (simulado)
map_results = []
for i in range(len(textos)):
    resultado = list(map_function(f'parte_{i}.txt'))
    map_results.append(resultado)

# 2. Shuffle (agrupar)
agrupado = shuffle(map_results)

# 3. Executar Reduce
resultado_final = {}
for palavra, contagens in agrupado.items():
    palavra, total = reduce_function(palavra, contagens)
    resultado_final[palavra] = total

# 4. Ordenar por frequência
resultado_ordenado = sorted(resultado_final.items(), 
                           key=lambda x: x[1], 
                           reverse=True)

print("📊 CONTAGEM DE PALAVRAS:")
for palavra, contagem in resultado_ordenado:
    print(f"{palavra}: {contagem}")
```

**Saída**:

```

python: 6
java: 4
scala: 3
kotlin: 3
```

## 🔷 5. Implementação Real com Hadoop (Java)

```java
import java.io.IOException;
import java.util.StringTokenizer;
import org.apache.hadoop.conf.Configuration;
import org.apache.hadoop.fs.Path;
import org.apache.hadoop.io.IntWritable;
import org.apache.hadoop.io.Text;
import org.apache.hadoop.mapreduce.Job;
import org.apache.hadoop.mapreduce.Mapper;
import org.apache.hadoop.mapreduce.Reducer;
import org.apache.hadoop.mapreduce.lib.input.FileInputFormat;
import org.apache.hadoop.mapreduce.lib.output.FileOutputFormat;

public class WordCount {

    // MAPPER: Lê texto, emite (palavra, 1)
    public static class TokenizerMapper 
        extends Mapper<Object, Text, Text, IntWritable>{
        
        private final static IntWritable one = new IntWritable(1);
        private Text word = new Text();
        
        public void map(Object key, Text value, Context context
                       ) throws IOException, InterruptedException {
            
            StringTokenizer itr = new StringTokenizer(value.toString());
            while (itr.hasMoreTokens()) {
                word.set(itr.nextToken().toLowerCase()
                        .replaceAll("[^a-zA-Z]", "")); // Remove não-letras
                if (word.getLength() > 0) {
                    context.write(word, one);
                }
            }
        }
    }
    
    // REDUCER: Soma contagens
    public static class IntSumReducer 
        extends Reducer<Text, IntWritable, Text, IntWritable> {
        
        private IntWritable result = new IntWritable();
        
        public void reduce(Text key, Iterable<IntWritable> values,
                          Context context
                          ) throws IOException, InterruptedException {
            
            int sum = 0;
            for (IntWritable val : values) {
                sum += val.get();
            }
            result.set(sum);
            context.write(key, result);
        }
    }
    
    // MAIN: Configura e executa job
    public static void main(String[] args) throws Exception {
        Configuration conf = new Configuration();
        Job job = Job.getInstance(conf, "word count");
        
        job.setJarByClass(WordCount.class);
        job.setMapperClass(TokenizerMapper.class);
        job.setCombinerClass(IntSumReducer.class); // Otimização local
        job.setReducerClass(IntSumReducer.class);
        
        job.setOutputKeyClass(Text.class);
        job.setOutputValueClass(IntWritable.class);
        
        FileInputFormat.addInputPath(job, new Path(args[0]));
        FileOutputFormat.setOutputPath(job, new Path(args[1]));
        
        System.exit(job.waitForCompletion(true) ? 0 : 1);
    }
}
```

**Como executar**:

```bash

# Criar JAR

# Executar no Hadoop

# Ver resultado
```

## 🔷 6. Implementação com Spark (Python)

```python
from pyspark import SparkContext, SparkConf

# Configurar Spark
conf = SparkConf().setAppName("WordCount")
sc = SparkContext(conf=conf)

# 1. Carregar dados (distribuído automaticamente)
texto_rdd = sc.textFile("hdfs:///input/textos/*.txt")

# 2. Map: Separar palavras e contar 1
palavras_rdd = texto_rdd.flatMap(lambda linha: linha.lower().split())

# Limpar palavras
palavras_limpas_rdd = palavras_rdd.map(
    lambda palavra: ''.join(c for c in palavra if c.isalpha())
).filter(lambda palavra: len(palavra) > 0)

# 3. Map: (palavra, 1)
contagem_rdd = palavras_limpas_rdd.map(lambda palavra: (palavra, 1))

# 4. Reduce: Soma por palavra
resultado_rdd = contagem_rdd.reduceByKey(lambda a, b: a + b)

# 5. Ordenar por frequência
resultado_ordenado_rdd = resultado_rdd.sortBy(lambda x: x[1], ascending=False)

# 6. Coletar resultado (ou salvar em arquivo)
resultado = resultado_ordenado_rdd.collect()

# Mostrar top 10
print("🔝 TOP 10 PALAVRAS MAIS FREQUENTES:")
for palavra, contagem in resultado[:10]:
    print(f"{palavra}: {contagem}")

# Salvar em HDFS
resultado_ordenado_rdd.saveAsTextFile("hdfs:///output/wordcount")

# Parar Spark
sc.stop()
```

## 🔷 9. Desafios e Soluções

### ❌ **Desafio 1: Palavras compostas**

```python
# Solução: N-grams (sequências de N palavras)
def gerar_ngrams(texto, n=2):
    palavras = texto.split()
    ngrams = []
    for i in range(len(palavras) - n + 1):
        ngram = ' '.join(palavras[i:i+n])
        ngrams.append(ngram)
    return ngrams

# Contar bigrams: ("machine learning", 45), ("data science", 32)
```

```python
# Solução: Limpeza cuidadosa
import re

def limpar_palavra(palavra):
    # Remove pontuação mas mantém hífens e apóstrofos válidos
    palavra = re.sub(r'[^\w\s\'-]', '', palavra)
    # Remove apóstrofos no início/fim
    palavra = palavra.strip("'")
    return palavra
```

### ❌ **Desafio 4: Palavras muito frequentes (stop words)**

```python
# Solução: Lista dinâmica de stop words
from collections import Counter

def detectar_stop_words_dinamico(contagem, percentil=0.01):
    total_palavras = sum(contagem.values())
    limite = total_palavras * percentil
    
    stop_words = set()
    for palavra, freq in contagem.items():
        if freq > limite:
            stop_words.add(palavra)
    
    return stop_words
```
