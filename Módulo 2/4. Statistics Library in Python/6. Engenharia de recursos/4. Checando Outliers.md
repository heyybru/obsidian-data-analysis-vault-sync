### 🔶 O que são outliers?

- Valores **muito distantes** do padrão (ex: salário de R$ 1 milhão em uma lista de R$ 3-5 mil).
- Podem ser **erros** (dados sujos) ou **sinais reais** (ex: candidato sênior top).
- Fontes: **Preditiva.ai** recomenda sempre investigar antes de remover.

### 1️⃣ Método IQR (Mais simples e robusto)

- Calcula **Q1** (25%), **Q3** (75%) e **IQR = Q3 - Q1**.
- Outlier: abaixo de **Q1 - 1.5*IQR** ou acima de **Q3 + 1.5*IQR**.

**Exemplo no Pandas (salários):**

```python
import pandas as pd
import numpy as np

df = pd.DataFrame({'salario': [3000, 3500, 4000, 4500, 5000, 100000]})  # 100k é outlier

Q1 = df['salario'].quantile(0.25)
Q3 = df['salario'].quantile(0.75)
IQR = Q3 - Q1

lim_inf = Q1 - 1.5 * IQR
lim_sup = Q3 + 1.5 * IQR

outliers = df[(df['salario'] < lim_inf) | (df['salario'] > lim_sup)]
print(outliers)  # Mostra o 100k
```

### 2️⃣ Z-Score (Estatístico)

- Mede quantos desvios padrão um valor está da média.
- Outlier: **|Z| > 3** (regra comum, per **Metricas Boss**).

**Exemplo:**

```python
from scipy import stats

df['z_score'] = np.abs(stats.zscore(df['salario']))
outliers_z = df[df['z_score'] > 3]
print(outliers_z)
```

### 3️⃣ Visual (Boxplot - Rápido pra ver)

```python
import matplotlib.pyplot as plt

df.boxplot(column='salario')
plt.show()  # Pontos fora das "caixinhas" são outliers
```
