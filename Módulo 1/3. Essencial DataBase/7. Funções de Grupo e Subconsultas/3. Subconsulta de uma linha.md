## O que é?

É uma **subconsulta que retorna apenas um único valor** (uma linha e uma coluna).

👉 Esse valor é usado pela consulta principal para comparação.

---

## 🔹 Quando usar?

Quando você precisa comparar um campo com:

- um valor calculado
    
- um resultado único vindo de outra tabela

---

## 🔹 Operadores usados

Subconsulta de **uma linha** usa operadores simples:

- `=`
    
- `>`
    
- `<`
    
- `>=`
    
- `<=`
    
- `<>`
    

❌ Não usa `IN`, `ANY`, `ALL` (esses são para várias linhas)

---

## 🔹 Exemplo clássico

```sql
SELECT name, salary
FROM employee
WHERE salary > (
    SELECT AVG(salary)
    FROM employee
);
```

📌 O que acontece:

- A subconsulta calcula a **média salarial**
    
- A consulta principal retorna quem ganha **acima da média**

---

## 🔹 Outro exemplo

```sql
SELECT name
FROM employee
WHERE department_id = (
    SELECT department_id
    FROM department
    WHERE name = 'TI'
);
```

👉 A subconsulta retorna **um único department_id**

---

## ❌ Erro comum

Subconsulta retornar **mais de uma linha** usando operador simples:

```sql
WHERE salary = (SELECT salary FROM employee);
```

💥 ERRO: subconsulta retorna várias linhas

---

## ✔ Como corrigir?

- Garantir que a subconsulta retorne **um único valor**
    
- Ou usar `IN` se forem vários resultados

---

## 🧠 Dica de prova

- Se retorna **1 valor → subconsulta de uma linha**
    
- Operadores simples (`=`, `>`, `<`)
    
- Subconsulta executa **primeiro**

---

## 📘 Resumo

- Retorna **um único valor**
    
- Usa operadores simples
    
- Muito cobrada em prova
