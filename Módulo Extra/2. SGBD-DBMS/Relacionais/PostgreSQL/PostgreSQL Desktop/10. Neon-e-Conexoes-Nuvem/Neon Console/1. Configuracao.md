## Passo 1 — Criar a conta e o projeto no Neon

1. Acesse **neon.com** → botão **Sign up** → cadastre com e-mail, GitHub ou Google.
2. Confirme o e-mail e entre no console.
3. Clique em **Create a project** (criar projeto).
4. Preencha:
    - **Project name:** `curso-postgres` (ou o nome que quiser)
    - **Region:** escolha a mais próxima de você (ex.: US East ou EU — qualquer uma funciona para estudo)
    - **Database name:** `northwind` ← anote isso! Vamos usar na conexão
5. Clique em **Create project**.
6. O Neon gera e mostra uma **connection string** (a "senha de acesso") — **copie e guarde agora**, porque ela só é exibida nesse momento. Ela tem o formato:
    
    ```
    postgresql://usuario:senha@ep-xxxx.us-east-2.aws.neon.tech/northwind
    ```
    

## Passo 2 — Entender a connection string

Ela carrega os 4 dados de conexão que vimos antes, mas todos de uma vez. Exemplo:

```
postgresql://neondb_owner:SUA_SENHA@ep-azul-123.us-east-2.aws.neon.tech/northwind
```

|Parte|Valor da conexão|
|---|---|
|`neondb_owner`|**User**|
|`SUA_SENHA`|**Password**|
|`ep-azul-123.us-east-2.aws.neon.tech`|**Host**|
|`northwind`|**Database**|
|(padrão)|**Port 5432**|

> ⚠️ **Importante:** o Neon oferece dois tipos de connection string (direta e com pooler). Para importar com `psql`/`pg_dump`, **use a direta** (a que aparece primeiro no console), não a que contém `-pooler` no host.

## Passo 3 — Gerar o dump do Northwind local

No terminal, exporte o banco que você já criou no curso (com o PostgreSQL local rodando):

```sql
pg_dump -U postgres -h localhost -d northwind --no-owner -f northwind.sql
```

**Explicação linha por linha:**

- `pg_dump` → ferramenta do PostgreSQL que exporta um banco inteiro como arquivo.
- `-U postgres` → usuário de conexão.
- `-h localhost -d northwind` → onde o banco está (sua máquina) e qual banco exportar.
- `--no-owner` → **importante para nuvem**: remove comandos de "dono" da tabela, evitando erro de permissão no Neon.
- `-f northwind.sql` → salva a saída no arquivo `northwind.sql`.

> 💡 **Não tem o Northwind local?** Use o script pronto da comunidade: [pthom/northwind_psql](https://github.com/pthom/northwind_psql) — baixe o `northwind.sql` do repositório e pule para o Passo 4. É o mesmo banco Northwind de exemplo, adaptado ao PostgreSQL.

## Passo 4 — Importar o dump no Neon

No terminal, rode o comando abaixo trocando pela **sua** connection string (a do Passo 1):

```sql
psql "postgresql://neondb_owner:SUA_SENHA@ep-xxxx.us-east-2.aws.neon.tech/northwind" -f northwind.sql
```

**Explicação:**

- `psql "connection string"` → conecta no banco da nuvem (com a connection string toda entre aspas).
- `-f northwind.sql` → executa o arquivo que acabamos de exportar, criando as tabelas e inserindo os dados.

Durante a execução você pode ver avisos (warnings) — isso é normal, desde que não apareçam erros `ERROR`.

> ⚠️ **Regras do Neon que evitam dor de cabeça:** não use `pg_dumpall` e nem a opção `-C`/`--create` (o Neon não aceita criar o banco via dump — o banco já existe no projeto). Por isso o `--no-owner` no Passo 3 e por isso importamos **dentro** do banco `northwind` já existente.

## Passo 5 — Verificar se deu certo

Conecte de novo e confira as tabelas:

```sql
psql "postgresql://neondb_owner:SUA_SENHA@ep-xxxx.us-east-2.aws.neon.tech/northwind"
```

Dentro do prompt do Neon, rode:

```sql
\dt
```

Você deve ver as tabelas do Northwind (`customers`, `orders`, `products`, etc.). Teste uma consulta:

```sql
SELECT COUNT(*) FROM customers;
```

> Esperado: **91 clientes** (o mesmo valor do curso). Se aparecer, o carregamento funcionou! 💚

**Alternativa sem terminal:** o console do Neon tem um **SQL Editor** no menu esquerdo — você pode colar o conteúdo do `northwind.sql` lá e clicar em **Run**. Funciona para arquivos desse tamanho, mas o terminal costuma ser mais confiável.

## Passo 6 — Conectar no Google Sheets (SyncWith)

Com o banco na nuvem, volte ao conector e preencha com os dados da nuvem:

- **Host:** `ep-xxxx.us-east-2.aws.neon.tech` (da sua connection string)
- **Port:** `5432`
- **Database:** `northwind`
- **Username:** `neondb_owner`
- **Password:** a senha da connection string
- **SSL Enabled:** `True` ✅ ← o Neon exige SSL ativo

Clique em **Test connection** — agora deve conectar, porque o servidor está acessível na internet.

## Resumindo

- **Neon** é a escolha recomendada: Postgres na nuvem, grátis, sem cartão.
- A **connection string** entregue na criação do projeto é a chave de tudo — guarde com cuidado.
- **Exporte** o Northwind local com `pg_dump --no-owner` e **importe** com `psql -f`.
- No conector do Sheets: valores da nuvem + **SSL True**.
- Verifique com `\dt` e `SELECT COUNT(*) FROM customers;` (91 registros).
