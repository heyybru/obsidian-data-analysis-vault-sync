## Dados faltantes no Pandas

**Dados faltantes** são valores que estão **ausentes** no conjunto de dados.

No Pandas, eles normalmente aparecem como:

- **`NaN`**
- **`None`**
- células vazias

Isso é muito importante na **análise exploratória de dados**, porque valores faltantes podem:

- distorcer médias e estatísticas
- causar erro em análises
- prejudicar gráficos e modelos
- esconder problemas de coleta de dados

---

## Como identificar dados faltantes

### Ver o DataFrame

```python
df.head()
```

Às vezes já dá para perceber células vazias.

### Ver quantos faltam por coluna

```python
df.isna().sum()
```

ou:

```python
df.isnull().sum()
```

Os dois fazem praticamente a mesma coisa.

### Exemplo

```python
import pandas as pd

df = pd.DataFrame({
    "nome": ["Ana", "Bruno", "Carla"],
    "idade": [25, None, 30],
    "cidade": ["SP", "RJ", None]
})

print(df.isna().sum())
```

#### Saída esperada

```python
nome      0
idade     1
cidade    1
dtype: int64
```

---

## Ver a porcentagem de dados faltantes

Isso ajuda a entender a gravidade do problema.

```python
(df.isna().sum() / len(df)) * 100
```

### Exemplo

```python
percentual_nulos = (df.isna().sum() / len(df)) * 100
print(percentual_nulos)
```

---

## Filtrar linhas com valores faltantes

### Mostrar linhas com qualquer nulo

```python
df[df.isna().any(axis=1)]
```

### Mostrar linhas sem nulo

```python
df[df.notna().all(axis=1)]
```

---

## Remover dados faltantes

### Remover linhas com qualquer valor faltante

```python
df = df.dropna()
```

### Remover linhas com nulo em coluna específica

```python
df = df.dropna(subset=["idade"])
```

### Remover colunas totalmente vazias

```python
df = df.dropna(axis=1, how="all")
```

---

## Preencher dados faltantes

Em vez de remover, muitas vezes faz mais sentido **preencher**.

### Preencher com valor fixo

```python
df["idade"] = df["idade"].fillna(0)
```

### Preencher texto vazio

```python
df["cidade"] = df["cidade"].fillna("Não informado")
```

### Preencher com média

```python
df["idade"] = df["idade"].fillna(df["idade"].mean())
```

### Preencher com mediana

```python
df["idade"] = df["idade"].fillna(df["idade"].median())
```

### Preencher com moda

```python
df["cidade"] = df["cidade"].fillna(df["cidade"].mode()[0])
```

---

## Quando usar cada estratégia

### Remover linhas

Use quando:

- há poucos nulos
- os registros faltantes não são importantes
- a remoção não prejudica a análise

### Preencher com média

Use quando:

- a variável é numérica
- os dados não têm muitos outliers

### Preencher com mediana

Use quando:

- há outliers
- a distribuição é assimétrica

### Preencher com moda

Use quando:

- a coluna é categórica
- quer manter a categoria mais comum

### Preencher com texto padrão

Use quando:

- quer sinalizar ausência
- a coluna é descritiva

---

## Exemplo prático

```python
import pandas as pd

df = pd.DataFrame({
    "nome": ["Ana", "Bruno", "Carla", "Diego"],
    "idade": [25, None, 30, 28],
    "cidade": ["SP", "RJ", None, "BH"]
})

print("Nulos por coluna:")
print(df.isna().sum())

df["idade"] = df["idade"].fillna(df["idade"].mean())
df["cidade"] = df["cidade"].fillna("Não informado")

print("\nDataFrame tratado:")
print(df)
```

---

## Verificando se ainda existem nulos

Depois do tratamento:

```python
df.isna().sum()
```

Se tudo deu certo, os valores faltantes devem ter sido reduzidos ou zerados.

---

## Boas práticas na análise de dados faltantes

### 1. Medir antes de agir

```python
df.isna().sum()
(df.isna().sum() / len(df)) * 100
```

### 2. Entender o contexto

Nem todo nulo é erro.  
Às vezes a ausência é uma informação importante.

Exemplo:

- campo “data de desligamento” vazio pode significar que a pessoa **ainda está ativa**

### 3. Não preencher automaticamente sem critério

Preencher sem pensar pode distorcer a análise.

## Leitura analítica

Em ciência de dados, **dados faltantes** não são só um problema técnico.  
Eles podem indicar:

- falha de coleta
- problema de integração
- preenchimento opcional
- comportamento do processo de negócio

Ou seja, antes de tratar, vale perguntar:

- **quanto está faltando?**
- **em quais colunas?**
- **isso é aleatório ou tem padrão?**
- **remover vai enviesar a análise?**
