### 🔹 1. Comunicação

> _"A gestão e manutenção de dados pode ser algo simples quando a empresa possui boa comunicação."_

**Na prática:** O time de RH coleta `experiencia_anos` como texto livre ("1 ano e meio"). O time de Dados precisa como número (1.5). Se não houver comunicação, o pipeline quebra.

**Ação:** Criar um **dicionário de dados** compartilhado — cada campo com tipo esperado, exemplos válidos, e dono responsável.

### 🔹 2. Ferramentas

O material indica o GitHub da disciplina com os códigos:

> 🔗 [https://github.com/FaculdadeDescomplica/Data-Integration-Ingestion-e-Quality](https://github.com/FaculdadeDescomplica/Data-Integration-Ingestion-e-Quality)

**Stack de qualidade pra você começar:**

|Ferramenta|Pra que serve|Nível|
|:--|:--|:--|
|**Great Expectations**|Validar expectativas nos dados (tipo, range, nulidade)|Pipeline|
|**Pandas profiling / ydata-profiling**|Relatório automático de qualidade|Análise|
|**dbt tests**|Testes de qualidade no data warehouse|Transformação|
|**Python (pytest)**|Testes customizados de qualidade|Código|
|**SQL (constraints)**|`NOT NULL`, `CHECK`, `UNIQUE` no banco|Armazenamento|

### 🔹 3. Liderança Técnica

Implementar qualidade não é só ferramenta — é **processo e cultura**. O material sugere:

- **Data Quality Owner:** uma pessoa responsável por cada domínio de dados
- **SLAs de qualidade:** "95% dos candidatos devem ter email válido em até 24h do cadastro"
- **Data Quality Dashboard:** métricas visíveis pra toda a empresa (não esconda os problemas)

### 🎯 Conexão com seu perfil (RH + QA)

|Seu papel|Como aplicar qualidade de dados|
|:--|:--|
|**Coordenador de Talentos**|Dono da qualidade dos dados de candidatos — definir o que é obrigatório, o que é opcional, e qual o prazo de atualização|
|**Analista de QA**|Automatizar testes de qualidade: `assert df['email'].str.contains('@').all()`, validar schemas, testar pipelines de ingestão|

### 📋 Mini Checklist — Qualidade no seu Dataset

```
✅ Precisão: experiencia_anos é numérico? Não tem "1 ano e meio"?
✅ Completude: nota_entrevista_tecnica existe quando status = "Entrevista Realizada"?
✅ Confiabilidade: nivel_educacional confere com universidade?
✅ Relevância: todos os campos têm propósito de negócio?
✅ Pontualidade: candidaturas de 2023 ainda são válidas?
✅ Deduplicação: emails duplicados com propósitos diferentes estão unificados?
```
