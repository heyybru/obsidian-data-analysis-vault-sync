De forma simples, uma **função** é um bloco de código que executa uma tarefa específica.  
No contexto do **Pandas**, as funções são usadas para **manipular, analisar, transformar e resumir dados**.

---

## Ideia principal

Pense assim:

- você tem um **DataFrame**
- quer fazer alguma operação nele
- usa uma **função** para executar essa operação

No Pandas, várias ações do dia a dia são feitas com funções, por exemplo:

- ver as primeiras linhas
- resumir estatísticas
- filtrar dados
- preencher valores faltantes
- ordenar colunas
- agrupar informações

---

## Estrutura geral

Em Python, uma função normalmente recebe **argumentos** e retorna um resultado.

Exemplo fora do Pandas:

```python
def soma(a, b):
    return a + b
```

No Pandas, você usa funções já prontas da biblioteca, como:

```python
df.head()
df.describe()
df.info()
```

Essas funções atuam sobre o DataFrame.

---

## Exemplos de funções no Pandas

### `head()`

Mostra as primeiras linhas:

```python
df.head()
```

### `describe()`

Mostra resumo estatístico:

```python
df.describe()
```

### `info()`

Mostra informações da estrutura:

```python
df.info()
```

### `sum()`

Soma os valores:

```python
df["salario"].sum()
```

### `mean()`

Calcula a média:

```python
df["idade"].mean()
```

---

## O que uma função faz no Pandas

As funções ajudam a:

- **consultar** os dados
- **transformar** colunas
- **limpar** valores
- **resumir** informações
- **automatizar** tarefas repetitivas

---

## Funções aplicadas em colunas

Você também pode aplicar funções em uma coluna específica.

### Exemplo

```python
df["idade"].mean()
```

Aqui:

- `df["idade"]` seleciona a coluna
- `.mean()` calcula a média dessa coluna

---

## Funções com argumentos

Algumas funções aceitam parâmetros para mudar o comportamento.

### Exemplo com `head()`

```python
df.head(10)
```

Isso mostra **10 linhas**, em vez de 5.

### Exemplo com `sort_values()`

```python
df.sort_values("idade")
```

Ordena pela coluna `idade`.

---

## Diferença entre função e método

Na prática da matéria, muitas vezes isso aparece junto, mas existe uma diferença técnica:

- **função** → estrutura geral que executa uma tarefa
- **método** → função associada a um objeto

No Pandas, quando você faz:

```python
df.head()
```

o `head()` é tecnicamente um **método** do DataFrame.

Mas em cursos introdutórios, é muito comum chamar tudo de “função”, e para fins de entendimento inicial isso costuma ser aceito.

---

## Exemplo prático

```python
import pandas as pd

df = pd.DataFrame({
    "nome": ["Ana", "Bruno", "Carla"],
    "idade": [28, 34, 25],
    "salario": [3000, 4500, 2800]
})

print(df.head())
print(df["idade"].mean())
print(df["salario"].sum())
```

### O que acontece aqui

- `head()` mostra as primeiras linhas
- `mean()` calcula a média da idade
- `sum()` soma os salários

---

## Por que funções são importantes no Pandas

Porque praticamente tudo que você faz na análise de dados depende delas.

Sem funções, você não conseguiria de forma simples:

- importar dados
- tratar nulos
- filtrar registros
- calcular métricas
- agrupar resultados
- criar transformações

---
