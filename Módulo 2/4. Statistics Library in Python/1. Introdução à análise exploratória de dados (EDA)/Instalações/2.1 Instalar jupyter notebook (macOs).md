No seu Mac M1, os dois caminhos mais comuns são: **via Anaconda** ou **via pip**.  
Se você já instalou o **Anaconda**, esse é o jeito mais simples.

### Opção 1: com Anaconda

No Terminal, rode:

```bash
conda install notebook
```

Depois, para abrir:

```bash
jupyter notebook
```

Isso vai abrir o Jupyter no navegador.

---

## Opção 2: com pip

Se você estiver usando Python com `venv` ou instalação comum:

```bash
pip install notebook
```

Depois:

```bash
jupyter notebook
```

---

## Melhor prática no seu caso

Se você quer estudar **Pandas, análise exploratória de dados e Python**, eu recomendo criar um ambiente separado.

### Com conda

```bash
conda create -n eda python=3.11
conda activate eda
conda install notebook pandas matplotlib seaborn
jupyter notebook
```

### Com venv

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install notebook pandas matplotlib seaborn
jupyter notebook
```

---

## Como verificar se deu certo

Quando rodar:

```bash
jupyter notebook
```

deve acontecer isso:

- o terminal mostra uma URL local
- o navegador abre automaticamente
- você consegue clicar em **New > Python 3**

Se abrir isso, está funcionando.

---

## Se aparecer erro “command not found”

Tente:

```bash
python3 -m notebook
```

ou:

```bash
python3 -m jupyter notebook
```

Se estiver em ambiente conda, confirme antes:

```bash
conda activate eda
```

Se estiver em `venv`:

```bash
source .venv/bin/activate
```

---

## Instalação mais completa para EDA

Se seu foco é análise de dados, já vale instalar o pacote básico:

```bash
pip install notebook pandas numpy matplotlib seaborn
```

ou com conda:

```bash
conda install notebook pandas numpy matplotlib seaborn
```

Essas bibliotecas cobrem:

- **pandas**: tabelas e análise
- **numpy**: operações numéricas
- **matplotlib**: gráficos básicos
- **seaborn**: gráficos mais bonitos e estatísticos

---

## Resumindo
