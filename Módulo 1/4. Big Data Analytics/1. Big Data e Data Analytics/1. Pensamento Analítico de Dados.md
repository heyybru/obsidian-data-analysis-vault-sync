## 🔷 **O que é Big Data? 

Pense assim: você tem **uma planilha Excel** com 100 linhas → isso é **dados normais**.  
Agora imagine **10 milhões de planilhas**, atualizadas a cada segundo, com textos, fotos, vídeos → isso é **Big Data**.

### ✅ **Os 5 Vs do Big Data** (regra mnemônica)

1. **Volume** → Quantidade enorme (terabytes, petabytes)
2. **Velocidade** → Dados chegando rápido (streaming, tempo real)
3. **Variedade** → Diferentes formatos (texto, áudio, vídeo, JSON, logs)
4. **Veracidade** → Qualidade/confiabilidade dos dados
5. **Valor** → O que você consegue extrair disso

> 👉 **Exemplo no RH**:
> 
> - **Volume**: 1 milhão de currículos
> - **Velocidade**: 100 novos candidatos por hora
> - **Variedade**: LinkedIn, formulários, vídeo-entrevistas, testes online
> - **Veracidade**: Dados limpos vs. currículos "inflados."
> - **Valor**: Encontrar o candidato ideal mais rápido

## 🔷 **O que é Data Analytics?

É o processo de **pegar dados** e **responder perguntas**:

1. **O que aconteceu?** → Analytics Descritivo
2. **Por que aconteceu?** → Analytics Diagnóstico
3. **O que vai acontecer?** → Analytics Preditivo
4. **O que devemos fazer?** → Analytics Prescritivo

### ✅ **Exemplo prático (QA + RH)**

|Tipo de Analytics|Exemplo RH|Exemplo QA|
|---|---|---|
|**Descritivo**|"Quantos candidatos passaram para 2ª etapa?"|"Quantos bugs foram abertos no mês?"|
|**Diagnóstico**|"Por que a taxa de desistência aumentou?"|"Por que o build X falhou mais?"|
|**Preditivo**|"Qual candidato tem maior chance de aceitar oferta?"|"Qual módulo terá mais bugs no próximo sprint?"|
|**Prescritivo**|"Oferecer benefício Y para aumentar retenção"|"Refatorar módulo Z antes do próximo release"|

## 🔷 **Pensamento Analítico de Dados 

É uma **mentalidade**, não só ferramentas. Você precisa:

### ✅ **1. Fazer as perguntas certas**

- Em vez de: "Os candidatos estão satisfeitos?"
- Pergunte: "Qual etapa do processo tem maior taxa de abandono e por quê?"

### ✅ **2. Questionar os dados**

- "Esses dados são confiáveis?"
- "Tem viés?" (ex.: só entrevistamos homens para vagas de tech)

### ✅ **3. Procurar padrões e outliers**

- **Padrão**: "Candidatos com experiência X têm 30% mais chance de passar"
- **Outlier**: "Um candidato fez 10 entrevistas e não passou → investigar"

### ✅ **4. Testar hipóteses**

- "Se reduzirmos o tempo de feedback de 7 para 2 dias, a taxa de aceitação aumenta?"
- Coleta dados → testa → analisa → decide

## 🔷 **Ferramentas (do simples ao complexo)**

### ✅ **Nível 1: SQL + Planilhas**

- **SQL**: Para buscar, filtrar, agregar (PostgreSQL, MySQL)
- **Excel/Google Sheets**: Para análise rápida, gráficos simples

### ✅ **Nível 2: BI + Visualização**

- **Power BI, Tableau, Metabase**: Dashboards, gráficos interativos
- **Python/R**: Para análise estatística mais avançada

### ✅ **Nível 3: Big Data**

- **Hadoop/Spark**: Processar volumes gigantes
- **Data Lakes**: Armazenar dados brutos de vários tipos
- **Kafka**: Streaming de dados em tempo real

## 🔷 **Fluxo prático: como aplicar no seu dia (RH + QA)**

### 🔴 **Passo 1: Coleta**

- RH: Formulários, ATS, LinkedIn, pesquisas de satisfação
- QA: Logs de erro, resultados de teste, feedback de usuários

### 🟡 **Passo 2: Processamento**

- Limpar dados (remover duplicados, padronizar formatos)
- RH: Unificar "São Paulo", "SP", "S.Paulo" → "SP"
- QA: Classificar bugs por severidade automaticamente

### 🟢 **Passo 3: Análise**

- SQL para agregar: `COUNT`, `AVG`, `GROUP BY`
- RH: "Tempo médio por etapa do funil"
- QA: "Taxa de sucesso por tipo de teste"

### 🔵 **Passo 4: Visualização**

- Gráfico de funil (RH)
- Heatmap de bugs por módulo (QA)
- Dashboard com KPIs principais

### 🟣 **Passo 5: Tomada de decisão**

- RH: "Reduzir etapas do processo em X"
- QA: "Priorizar testes no módulo Y"

## 🔷 **Exemplo concreto: Análise de Funil de Recrutamento**

Vamos usar **SQL + pensamento analítico**:

```sql
-- 1. Dados brutos
SELECT 
  etapa,
  COUNT(*) AS candidatos,
  COUNT(*) * 100.0 / SUM(COUNT(*)) OVER() AS percentual_total
FROM entrevistas
GROUP BY etapa
ORDER BY 
  CASE etapa 
    WHEN 'inscricao' THEN 1
    WHEN 'triagem' THEN 2
    WHEN 'entrevista_tecnica' THEN 3
    WHEN 'proposta' THEN 4
    WHEN 'contratacao' THEN 5
  END;
```

**Pensamento analítico:**

- "Onde está o maior gargalo?" → etapa com maior queda percentual
- "Por que candidatos desistem na triagem?" → analisar feedbacks
- "Como melhorar?" → testar novo processo A/B

## 🔷 **Checklist do Pensamento Analítico**

✅ **Antes de analisar:**

- Qual pergunta quero responder?
- Quais dados preciso?
- Esses dados são confiáveis?

✅ **Durante a análise:**

- Estou vendo padrões ou outliers?
- Tem viés nos dados?
- Posso testar uma hipótese?

✅ **Depois da análise:**

- Minha conclusão faz sentido?
- Posso tomar uma ação com base nisso?
- Como medir se a ação funcionou?
