## O que é

Selecionar apenas parte das colunas de um DataFrame. Em bases grandes, você raramente quer todas as colunas — quer as relevantes para a pergunta.

## Como funciona

**Uma coluna** → usa colchetes com o nome em string. O resultado é uma **Series**, não um DataFrame:

```python
data = {'fruta': ['maçã', 'banana', 'laranja', 'uva'],
        'preço': [1.50, 0.50, 2.20, 0.75],
        'quantidade': [100, 200, 50, 75]}
df = pd.DataFrame(data)

precos = df['preço']
print(precos)
```

```text
0    1.50
1    0.50
2    2.20
3    0.75
Name: preço, dtype: float64
```

Repare no `Name: preço` e no `dtype: float64` — são as marcas de que isto é uma Series, com uma única dimensão e um tipo definido.

**Várias colunas** → colchetes com uma **lista** de nomes. Note os dois pares de colchetes: o de fora é a seleção, o de dentro é a lista. O resultado é um **DataFrame**:

```python
selecao = ['fruta', 'quantidade']
result = df[selecao]
print(result)
```

```text
     fruta  quantidade
0     maçã         100
1   banana         200
2  laranja          50
3      uva          75
```

## Onde se aplica

Na **seleção de atributos** — etapa de transformação, em que você reduz o conjunto ao que a análise exige.

## Quando usar

Antes de qualquer cálculo ou modelagem. Reduzir colunas economiza memória, acelera o processamento e evita que colunas de texto interfiram em operações numéricas.

## O detalhe que mais confunde

**Uma coluna retorna Series. Uma lista de colunas retorna DataFrame.** Visualmente são parecidos, mas o comportamento é diferente. `df['preço'].mean()` funciona; `df[['preço']].mean()` também, mas o resultado é uma Series de um elemento, não um número. Essa distinção se conecta diretamente ao tópico 4.
