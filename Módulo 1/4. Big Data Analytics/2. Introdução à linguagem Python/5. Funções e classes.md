**Funções são como "receitas" que você reutiliza**, e **classes são como "máquinas" que guardam dados e ações**.  
Funções evitam repetir código, classes organizam dados relacionados.

✅ **No seu contexto (RH + QA)**:

- **Funções**: Calcular taxa de aprovação, validar bug, gerar relatório
- **Classes**: Candidato (dados + métodos), Bug (status + ações)

---

## 🔷 Funções (receitas reutilizáveis)

### ✅ **Sintaxe básica**

```python
def nome_funcao(parametro1, parametro2):
    # código aqui
    return resultado  # opcional
```

### ✅ **Função simples**

```python
def saudacao(nome):
    return f"Olá, {nome}!"

mensagem = saudacao("Bruno")  # "Olá, Bruno!"
```

### ✅ **Parâmetros**

```python
# Parâmetros obrigatórios
def calcular_taxa(total, aprovados):
    return (aprovados / total) * 100

# Parâmetros com valor padrão
def enviar_email(destinatario, assunto="Atualização", urgente=False):
    if urgente:
        print(f"URGENTE: {assunto} para {destinatario}")
    else:
        print(f"{assunto} para {destinatario}")

# Parâmetros nomeados
calcular_taxa(total=100, aprovados=75)  # 75.0
```

### ✅ **Retorno múltiplo**

```python
def analisar_candidato(experiencia, tem_ingles):
    aprovado = experiencia >= 3 and tem_ingles
    motivo = "Experiência insuficiente" if experiencia < 3 else "Falta inglês" if not tem_ingles else "Aprovado"
    return aprovado, motivo

status, razao = analisar_candidato(4, True)
# status = True, razao = "Aprovado"
```

### ✅ **Função RH: Calcular bônus**

```python
def calcular_bonus(salario, avaliacao, metas_atingidas):
    """Calcula bônus baseado em avaliação e metas."""
    if avaliacao >= 9 and metas_atingidas:
        return salario * 0.2  # 20%
    elif avaliacao >= 7 and metas_atingidas:
        return salario * 0.1  # 10%
    else:
        return 0

bonus = calcular_bonus(5000, 8.5, True)  # 500.0
```

### ✅ **Função QA: Classificar bug**

```python
def classificar_bug(severidade, modulo, tempo_aberto):
    """Classifica prioridade do bug."""
    if severidade == "critico":
        return "CRÍTICA"
    elif severidade == "alto" and modulo in ["login", "pagamento"]:
        return "ALTA"
    elif tempo_aberto > 72:
        return "MÉDIA (atrasado)"
    else:
        return "BAIXA"

prioridade = classificar_bug("alto", "login", 50)  # "ALTA"
```

## 🔷 Classes (máquinas organizadas)

```python
class NomeClasse:

        self.atributo = parametro   # Atributo
    
    def metodo(self):               # Método
```

## 🔷 Exemplos práticos de classes (RH + QA)

### ✅ **Classe RH: Candidato**

```python
class Candidato:
    def __init__(self, nome, email, experiencia):
        self.nome = nome
        self.email = email
        self.experiencia = experiencia
        self.status = "inscrito"
        self.entrevistas = 0
    
    def realizar_entrevista(self):
        self.entrevistas += 1
        if self.entrevistas >= 2:
            self.status = "em_entrevista"
    
    def aprovar(self):
        self.status = "aprovado"
    
    def get_info(self):
        return f"{self.nome} ({self.email}) - {self.status}"

bruno = Candidato("Bruno Silva", "bruno@email.com", 4)
bruno.realizar_entrevista()
bruno.realizar_entrevista()
bruno.aprovar()
print(bruno.get_info())  # "Bruno Silva (bruno@email.com) - aprovado"
```

### ✅ **Classe QA: Bug**

```python
class Bug:
    def __init__(self, id_bug, titulo, severidade):
        self.id = id_bug
        self.titulo = titulo
        self.severidade = severidade
        self.status = "aberto"
        self.assignee = None
    
    def assignar(self, desenvolvedor):
        self.assignee = desenvolvedor
        self.status = "em_andamento"
    
    def resolver(self):
        self.status = "resolvido"
    
    def reabrir(self):
        self.status = "reaberto"
    
    def get_prioridade(self):
        prioridades = {"critico": 1, "alto": 2, "medio": 3, "baixo": 4}
        return prioridades.get(self.severidade, 5)

bug1 = Bug("BUG-001", "Erro no login", "critico")
bug1.assignar("Carlos Dev")
print(f"Bug {bug1.id}: {bug1.status} (prioridade {bug1.get_prioridade()})")
# "Bug BUG-001: em_andamento (prioridade 1)"
```

### ✅ **Classe com herança**

```python
class Funcionario:
    def __init__(self, nome, salario):
        self.nome = nome
        self.salario = salario
    
    def calcular_bonus(self):
        return self.salario * 0.1

class QA(Funcionario):  # Herda de Funcionario
    def __init__(self, nome, salario, certificacoes):
        super().__init__(nome, salario)  # Chama construtor pai
        self.certificacoes = certificacoes
    
    def calcular_bonus(self):  # Sobrescreve método
        bonus_base = super().calcular_bonus()
        return bonus_base + (len(self.certificacoes) * 100)

qa = QA("Bruno", 5000, ["ISTQB", "CTFL"])
print(qa.calcular_bonus())  # 500 + 200 = 700
```

## 🔷 Escopo (onde as variáveis existem)

### ✅ **Variáveis locais vs globais**

```python
total_candidatos = 100  # Global

def processar_candidatos():
    aprovados = 75  # Local (só existe dentro da função)
    return (aprovados / total_candidatos) * 100

taxa = processar_candidatos()  # 75.0
print(aprovados)  # NameError (não existe fora da função)
```

### ✅ **`global` para modificar global**

```python
contador = 0

def incrementar():
    global contador
    contador += 1

incrementar()
print(contador)  # 1
```

## 🔷 Exercício prático

**Crie um sistema de RH com classes e funções**:

```python
class Candidato:
    def __init__(self, nome, experiencia):
        self.nome = nome
        self.experiencia = experiencia
        self.status = "inscrito"
    
    def aprovar(self):
        self.status = "aprovado"
    
    def get_info(self):
        return f"{self.nome} - {self.status}"

def filtrar_por_experiencia(candidatos, min_experiencia):
    return [c for c in candidatos if c.experiencia >= min_experiencia]

# Criar candidatos
bruno = Candidato("Bruno", 4)
ana = Candidato("Ana", 2)
carlos = Candidato("Carlos", 5)

candidatos = [bruno, ana, carlos]

# Filtrar e aprovar
experientes = filtrar_por_experiencia(candidatos, 3)
for c in experientes:
    c.aprovar()

# Mostrar resultados
for c in candidatos:
    print(c.get_info())
```
