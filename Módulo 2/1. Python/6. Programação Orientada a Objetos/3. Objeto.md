**Objeto** é uma “coisa” criada a partir de uma **classe**, que guarda **dados (atributos)** e sabe executar **ações (métodos)**.

**Instância** é exatamente esse objeto “concreto” em memória, criado quando você chama a classe (como se fosse um construtor). Na prática, **objeto e instância quase sempre são usados como sinônimos**.

### Exemplo bem simples

```python
class Bug:
    def __init__(self, bug_id):
        self.bug_id = bug_id

b1 = Bug(101)
b2 = Bug(102)
```

- `Bug` = **classe** (o molde)
- `b1` = **objeto / instância** da classe `Bug`
- `b2` = **outro objeto / outra instância** da mesma classe
- Cada instância tem seu próprio estado: `b1.bug_id` é `101`, `b2.bug_id` é `102`

### Um jeito rápido de memorizar

- **Classe** = “planta”
- **Objeto/instância** = “casa construída a partir da planta”
