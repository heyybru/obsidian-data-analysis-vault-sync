### **1. Estadística Descritiva

- **Objetivo principal**: Resumir e descrever os dados observados sem generalizações.
- **Etapas sequenciais** (central: Descrição dos dados):
    1. **Coleta dos dados** – precisa dos dados brutos.
    2. **Organização dos dados** – limpa e estrutura os dados.
    3. **Descrição dos dados** – resume características (média, desvio padrão).
    4. **Análise dos dados** – identifica padrões básicos.
    5. **Interpretação e decisão** – visualiza em gráficos simples.
- **Observações-chave**: Não faz inferência; foca no "como os dados são?" (**Métricas Boss**).

**Resumo Invertido**: Coleta → Organização → **Descrição** → Análise → Interpretação.

### **2. Estatística Inferencial**

- **Objetivo principal**: Tirar conclusões sobre populações a partir de amostras.
- **Etapas sequenciais** (central: Análise dos dados):
    1. **Coleta dos dados** – seleciona amostra representativa.
    2. **Organização dos dados** – prepara pra testes.
    3. **Descrição dos dados** – calcula estatísticas amostrais.
    4. **Análise dos dados** – aplica testes (t-test, intervalos).
    5. **Interpretação e decisão** – generaliza pra população.
- **Observações-chave**: Usa uma amostra pra prever; responde "o que podemos concluir?" (**Preditiva.ai**).

**Resumo Invertido**: Coleta (amostra) → Organização → Descrição → **Análise** → Interpretação (população).

### **3. Probabilidade**

- **Objetivo principal**: Estudar chances e incertezas pra modelar riscos.
- **Etapas sequenciais** (central: Análise dos dados):
    1. **Coleta dos dados** – observa eventos passados.
    2. **Organização dos dados** – categoriza cenários.
    3. **Descrição dos dados** – estima frequências relativas.
    4. **Análise dos dados** – calcula probabilidades (Bayes).
    5. **Interpretação e decisão** – avalia riscos/decisões.
- **Observações-chave**: Estuda chances; responde "Qual a chance disso acontecer?" (**AILabs**).

**Resumo Invertido**: Coleta (eventos) → Organização → Descrição → **Análise** (prob.) → Interpretação (risco).

### **Resumo Geral Invertido**

Descritiva: Coleta → Org. → **Descr.** → Anál. → Int.  
Inferencial: Coleta (amostra) → Org. → Descr. → **Anál.** → Int. (pop.)  
Probabilidade: Coleta → Org. → Descr. → **Anál.** (chance) → Int. (risco).
