> [!info] 
> O que é:** o campo que trata de conjuntos de dados **tão grandes e complexos** que as ferramentas tradicionais (tabelas, planilhas, bancos de dados comuns) não conseguem lidar. 

🔑 **Analogia:** pense na evolução do armazenamento:

- Poucos dados → **tabela** (caderno)
- Muitos dados → **planilha** (Excel)
- Muito mais dados → **banco de dados** (arquivo organizado)
- Dados gigantescos → **Big Data** (um "oceano" que precisa de ferramentas especiais)

**A quantidade de dados que geramos cresceu muito:** números de telefone, placas de carro, e-mails, redes sociais, sensores... tudo vira dado.

**Os 5 Vs do Big Data (do material):**

- **Volume:** quantidade enorme de dados
- **Velocidade:** dados chegam muito rápido
- **Variedade:** dados de muitos tipos diferentes
- **Valor:** precisam gerar valor
- **Veracidade:** precisam ser confiáveis

**Tipos de dados (do material):**

- **Estruturados:** organizados em tabelas (ex.: planilha)
- **Semi-estruturados:** têm alguma organização (ex.: e-mail, JSON)
- **Não estruturados:** sem formato definido (ex.: vídeos, posts, imagens)

**Aplicações reais (do material):** indústria, bancos, trânsito, operadoras de saúde, seguradoras, logística e entretenimento.
