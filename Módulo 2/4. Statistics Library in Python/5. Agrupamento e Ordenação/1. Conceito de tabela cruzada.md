A **tabela cruzada** é uma forma de **resumir e comparar dados entre categorias**.

Ela serve para mostrar a relação entre **duas ou mais variáveis categóricas**, organizando os resultados em formato de tabela.

No Pandas, isso geralmente é feito com:

```python
pd.crosstab()
```

---

## Ideia principal

Pense assim:

você quer saber, por exemplo:

- quantas pessoas há por **cidade**
- e dentro de cada cidade, quantas são de cada **sexo**

A tabela cruzada organiza isso de forma clara.

---

## Exemplo simples

```python
import pandas as pd

df = pd.DataFrame({
    "cidade": ["SP", "SP", "RJ", "RJ", "BH", "SP"],
    "sexo": ["F", "M", "F", "F", "M", "F"]
})

tabela = pd.crosstab(df["cidade"], df["sexo"])
print(tabela)
```

---

## O que essa tabela mostra

Ela vai cruzar:

- **linhas** → `cidade`
- **colunas** → `sexo`

E o resultado será a **contagem** de ocorrências em cada combinação.

### Exemplo de saída

```python
sexo    F  M
cidade      
BH      0  1
RJ      2  0
SP      2  1
```

---

## Interpretação

Essa tabela quer dizer:

- em **BH**, há 1 registro do sexo M
- em **RJ**, há 2 registros do sexo F
- em **SP**, há 2 do sexo F e 1 do sexo M

---

## Para que serve a tabela cruzada

Ela é muito usada para:

- comparar categorias
- resumir frequências
- analisar distribuição de grupos
- fazer análise exploratória
- identificar padrões entre variáveis

---

## Relação com agrupamento

A tabela cruzada é uma forma de **agrupamento resumido**.

Ela lembra um `groupby`, mas é mais direta quando o objetivo é **cruzar categorias**.

### Exemplo parecido com `groupby`

```python
df.groupby(["cidade", "sexo"]).size()
```

Mas com `crosstab()` o resultado fica mais visual para comparação.

---

## Sintaxe básica

```python
pd.crosstab(linhas, colunas)
```

### Estrutura

- primeiro argumento → variável das **linhas**
- segundo argumento → variável das **colunas**

---

## Exemplo com nomes mais claros

```python
pd.crosstab(df["departamento"], df["status"])
```

Isso pode mostrar:

- quantos funcionários ativos e inativos existem em cada departamento

---

## Tabela cruzada com totais

Você pode adicionar totais com `margins=True`:

```python
pd.crosstab(df["cidade"], df["sexo"], margins=True)
```

### Isso adiciona

- total por linha
- total por coluna
- total geral

---

## Exemplo

```python
tabela = pd.crosstab(df["cidade"], df["sexo"], margins=True)
print(tabela)
```

Saída esperada:

```python
sexo    F  M  All
cidade           
BH      0  1   1
RJ      2  0   2
SP      2  1   3
All     4  2   6
```

---

## Tabela cruzada com proporção

Você também pode pedir valores normalizados:

```python
pd.crosstab(df["cidade"], df["sexo"], normalize=True)
```

Ou por linha:

```python
pd.crosstab(df["cidade"], df["sexo"], normalize="index")
```

Ou por coluna:

```python
pd.crosstab(df["cidade"], df["sexo"], normalize="columns")
```

---

## Diferença entre os tipos de normalização

### `normalize=True`

Mostra proporção sobre o total geral.

### `normalize="index"`

Mostra proporção dentro de cada linha.

### `normalize="columns"`

Mostra proporção dentro de cada coluna.

---

## Exemplo prático

```python
import pandas as pd

df = pd.DataFrame({
    "curso": ["Python", "Python", "SQL", "SQL", "Python", "Excel"],
    "status": ["Aprovado", "Reprovado", "Aprovado", "Aprovado", "Aprovado", "Reprovado"]
})

print(pd.crosstab(df["curso"], df["status"]))
```

### Possível saída

```python
status  Aprovado  Reprovado
curso                      
Excel          0          1
Python         2          1
SQL            2          0
```

---

## Leitura da saída

- no curso **Python**, 2 aprovados e 1 reprovado
- no curso **SQL**, 2 aprovados
- no curso **Excel**, 1 reprovado

---

## Quando usar

Use **tabela cruzada** quando quiser responder perguntas como:

- quantos registros existem em cada combinação de categorias?
- como uma variável está distribuída dentro de outra?
- qual grupo aparece mais em cada categoria?

pd.crosstab()
