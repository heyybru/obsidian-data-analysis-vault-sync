# O que é Data Quality

## Definição

**Data Quality** mede o quanto um conjunto de dados atende a critérios de **precisão, completude, validade, consistência, unicidade, atualidade e adequação ao propósito** (*fitness for purpose*).

> Fonte: IBM. A Databricks usa a mesma lista, acrescentando que dados de qualidade são "fit for its intended purpose".

## Ponto central

Qualidade **não é absoluta** — é sempre **relativa ao uso**.

Um CPF sem máscara pode ser "sujo" para cadastro e perfeitamente válido como chave de join.

## Três conceitos que não são a mesma coisa (IBM)

| Conceito           | O que é                                                              |
| ------------------ | -------------------------------------------------------------------- |
| **Data Quality**   | Critério amplo de avaliação                                          |
| **Data Integrity** | Subconjunto (precisão, consistência, completude) + foco em segurança |
| **Data Profiling** | O processo de revisar e limpar os dados                              |

## Analogia

Avaliar um ingrediente: a farinha é excelente para pão e péssima para bolo sem glúten. "Boa" só faz sentido com o **prato** em mente.
