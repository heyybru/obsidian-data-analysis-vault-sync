### 🔶 O que é a lib `re`?

- **Biblioteca nativa** do Python para **expressões regulares** (padrões em texto).
- **Uso principal**: Buscar, validar, substituir strings com precisão.
- **Vantagem**: Mais poderosa que `str.replace()` simples; evita loops manuais.

**Import sempre:**

```python
import re
```

---

### 1️⃣ Funções chave (pra usar no dia a dia)

- **`re.findall(padrao, texto)`**: Pega **todos** os matches.
- **`re.search(padrao, texto)`**: Pega o **primeiro** match.
- **`re.sub(padrao, substituto, texto)`**: **Substitui** padrões.
- **`re.match(padrao, texto)`**: Só no **início** da string.
- **`re.compile(padrao)`**: Compila pra reutilizar (rápido em loops).

**Flags úteis**: `re.IGNORECASE` (ignora maiúsc/minúsc), `re.MULTILINE` (múltiplas linhas).

---

### 2️⃣ Exemplos práticos (QA/RH)

**QA: Extrair códigos de erro de logs**

```python
log = "ERROR 404: falha na API. INFO 200: ok."
erros = re.findall(r'ERROR (\d+)', log)
print(erros)  # ['404']
```

**RH: Limpar e validar CPF**

```python
cpf_sujo = "CPF: 123.456.789-00 (inválido)"
cpf_limpo = re.sub(r'\D', '', cpf_sujo)  # Remove não-dígitos
print(cpf_limpo)  # 12345678900
```

**Pandas + re (top pra dados reais)**

```python
import pandas as pd
df = pd.DataFrame({'log': ['user@ex.com', 'teste123']})
df['email'] = df['log'].str.findall(r'\w+@\w+\.\w+')
print(df)
```

### 3️⃣ Dicas empáticas pro seu fluxo

- **Teste fácil**: Use [regex101.com](https://regex101.com/) – cola o texto e vê na hora.
- **Performance**: Compile em loops grandes (`padrao_compilado = re.compile(r'...')`).
- **QA**: Parse JIRA/Zephyr (`r'BUG-(\d+)'` pega ID).
- **RH**: Extrai phones (`r'(\d{2})[\s\-]?(\d{4,5}[\s\-]?\d{4})'`).
- **Cuidado**: Regex é lenta em strings gigantes; valide com dados pequenos primeiro (**Metricas Boss** alerta).
