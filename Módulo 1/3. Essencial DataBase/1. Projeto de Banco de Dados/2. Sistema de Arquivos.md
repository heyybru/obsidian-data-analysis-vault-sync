Arquivos sāo estruturas específicas de armazenamento de dados, usadas desde os anos 1950. HDs, CDs, SSDs, pendrives e fitas magnéticas — todos guardam arquivos.

🔑 **Analogia:** arquivos são como **gavetas de um armário**. Cada software tem seu formato de arquivo, como se cada gaveta tivesse uma **chave diferente**. Quem não tem a chave (o software), não abre.

---

### 🧩 O que um sistema de arquivos faz

- Define **nomes** de arquivos
- Cria **pastas** (diretórios)
- Controla **permissões**
- Gerencia **espaço em disco**
- Permite **leitura e escrita**

---

### 📂 Exemplos de Sistemas de Arquivos

| Sistema    | Sistemas de Arquivos |
| ---------- | -------------------- |
| 🪟 Windows | FAT32, NTFS, exFAT   |
| 🐧 Linux   | ext4, XFS            |
| 🍎 macOS   | APFS                 |

---

### ⚠️ Os problemas dos arquivos

- **Inconsistência e redundância:** dados repetidos em formatos diferentes
- **Dificuldade de acesso:** só dá para acessar de uma forma
- **Isolamento:** quem não tem o mesmo software não consegue ler
- **Falta de integridade:** buscas podem trazer dados duplicados ou ignorados
- **Falta de atomicidade:** um erro pode perder dados no meio do caminho
- **Falta de segurança:** proteção frágil para dados sensíveis

**Exemplo real:** muitas empresas ainda guardam dados importantes (até sensíveis) em **planilhas** — ótimo para volume pequeno, mas quebra quando a complexidade cresce.

---

### 🗄️ Sistema de Arquivos x Banco de Dados

| Sistema de Arquivos | Banco de Dados     |
| ------------------- | ------------------ |
| Arquivos soltos     | Dados estruturados |
| Pouco controle      | Alto controle      |
| Mais redundância    | Menos redundância  |
| Difícil consulta    | Consultas rápidas  |

👉 Por isso os bancos de dados substituem arquivos em sistemas grandes.

---

### 🧠 Exemplo simples

- Um `.docx` salvo no computador
- Um `.pdf` em uma pasta
- Um `.csv` em um pendrive

Tudo isso depende do sistema de arquivos.

---

### 📋 Resumindo

- **Arquivos** = gavetas com chaves diferentes (cada software abre a sua)
- **Sistema de arquivos** = o "organizador" que gerencia nomes, pastas, permissões e espaço
- **Problemas:** redundância, isolamento, falta de segurança e integridade
- **Solução:** bancos de dados — mais controle, menos redundância, consultas rápidas
- **Regra prática:** arquivos servem para dados simples; bancos de dados para sistemas grandes
