## 1. Criar o Banco

```sql
CREATE DATABASE nome_do_banco;
```

No Oracle, na prática, você também cria o **tablespace** e o **usuário** (o "banco lógico"), mas para estudo o `CREATE DATABASE` já resolve.

---

## 2. Criar as Tabelas (Entidades)

Defina as colunas e seus tipos de dados. **Pense no modelo lógico** antes: entidade → tabela, atributo → coluna.

```sql
CREATE TABLE dept1 (
    deptno NUMBER(2),
    dname  VARCHAR2(14),
    loc    VARCHAR2(10)
);
```

**Tipos mais usados no Oracle:**

|Tipo|O que armazena|
|---|---|
|`NUMBER(n)`|Número inteiro|
|`NUMBER(n,d)`|Número decimal|
|`VARCHAR2(n)`|Texto|
|`DATE`|Data|

---

## 3. Conferir a Estrutura

```sql
DESCRIBE dept1;
```

ou a forma curta: `DESC dept1;`

---

## 4. Adicionar PK e FK (integridade)

**Chave Primária (PK)** — identifica cada registro:

```sql
ALTER TABLE dept1 ADD CONSTRAINT pk_deptno PRIMARY KEY (deptno);
```

**Chave Estrangeira (FK)** — liga tabelas:

```sql
ALTER TABLE pedido ADD CONSTRAINT fk_dept
FOREIGN KEY (id_dept) REFERENCES dept1(deptno);
```

💡 **Dica de especialista:** antes de adicionar a PK, garanta que a coluna **não tem nulos nem duplicados** — senão o comando falha.

---

## 5. Caso N:N — Tabela Associativa

Quando duas entidades se relacionam em **muitos-para-muitos**, criamos uma tabela de ligação. Ex.: **PROFESSOR ↔ DISCIPLINA**.

**Passo 1 — criar as entidades:**

```sql
CREATE TABLE PROFESSOR (COD_PROF NUMBER(2), NOME_PROF VARCHAR2(50));
CREATE TABLE DISCIPLINA (COD_DISC NUMBER(3), NOME_DISC VARCHAR2(50));
```

**Passo 2 — criar a tabela associativa:**

```sql
CREATE TABLE PROF_DISC (COD_PROF NUMBER(2), COD_DISC NUMBER(3));
```

**Passo 3 — adicionar as PKs das entidades:**

```sql
ALTER TABLE PROFESSOR ADD CONSTRAINT PK_COD_PROF PRIMARY KEY (COD_PROF);
ALTER TABLE DISCIPLINA ADD CONSTRAINT PK_COD_DISC PRIMARY KEY (COD_DISC);
```

**Passo 4 — PK composta na associativa:**

```sql
ALTER TABLE PROF_DISC ADD CONSTRAINT PK_CODS PRIMARY KEY (COD_PROF, COD_DISC);
```

**Passo 5 — FKs ligando a associativa às origens:**

```sql
ALTER TABLE PROF_DISC ADD CONSTRAINT FK_COD_PROF FOREIGN KEY (COD_PROF) REFERENCES PROFESSOR(COD_PROF);
ALTER TABLE PROF_DISC ADD CONSTRAINT FK_COD_DISC FOREIGN KEY (COD_DISC) REFERENCES DISCIPLINA(COD_DISC);
```

---

## 📋 Resumindo

- **CREATE DATABASE** → cria o banco
- **CREATE TABLE** → cria as entidades (colunas + tipos)
- **DESCRIBE** → confere a estrutura
- **ALTER TABLE ADD CONSTRAINT** → adiciona PK e FK
- **N:N** → tabela associativa com **PK composta** (as duas FKs juntas)

**Regra de ouro:** entidades fortes primeiro, associativa por último — evita erro de violação de chave estrangeira.
