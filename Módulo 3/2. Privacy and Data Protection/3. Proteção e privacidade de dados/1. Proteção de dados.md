### 🛡️ O que é Proteção de Dados?

É o conjunto de medidas técnicas e administrativas utilizadas para garantir que o dado pessoal seja tratado de forma segura, evitando acessos não autorizados, destruição, perda ou alteração.

#### A Diferença que você precisa saber:

- **Privacidade**: É o conceito ético e o direito (ex: "Eu decido quem vê meu currículo").
- **Proteção**: É a execução técnica (ex: "O banco de dados de currículos está criptografado").

### 💼 Aplicação Prática: QA e Recrutamento

#### 1. No Quality Assurance (QA)

Sua missão é garantir a **Integridade** e a **Confidencialidade**:

- **Teste de API**: Validar se os dados sensíveis (como CPF) estão sendo mascarados no retorno da requisição.
- **Segurança**: Garantir que o sistema não permita "SQL Injection" para roubar a base de dados.
- **Ambiente de Homologação**: Nunca use dados reais de candidatos em testes. Use dados sintéticos (fakes) para proteger a privacidade real.

#### 2. No Recrutamento Global

Você lida com a **Custódia** do dado:

- **Retenção**: Por quanto tempo você guarda o currículo? A proteção de dados exige que, se o dado não tem mais utilidade, ele deve ser excluído.
- **Compartilhamento**: Se você manda um currículo por WhatsApp para um gestor, você está quebrando um protocolo de proteção de dados? (Dica: Sim, o ideal é usar sistemas centralizados e seguros).

### 🧪 Insight do Especialista (Metodologia & Dados)

- **Snaq.co**: No ecossistema de startups, a proteção de dados é vista como um **ativo de mercado**. Empresas que têm certificações de segurança (como ISO 27001) valem mais em rodadas de investimento.
- **Preditiva.ai**: Modelos de IA precisam de dados protegidos para evitar o "vazamento de atributos", onde a IA acaba revelando indiretamente dados sensíveis de pessoas.
- **Data Literacy (Cappra)**: Proteger dados não é só tarefa da TI. É uma mudança cultural. Todos na empresa, do RH ao QA, devem entender que o dado é uma responsabilidade.
