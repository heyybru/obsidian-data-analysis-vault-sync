### 🇧🇷 O que é a LGPD?

- **Objetivo**: Proteger os direitos fundamentais de liberdade e de privacidade e o livre desenvolvimento da personalidade da pessoa natural.
- **Abrangência**: Aplica-se a qualquer operação de tratamento realizada por pessoa natural ou jurídica, de direito público ou privado, independentemente do meio (físico ou digital).
- **Fiscalização**: Feita pela **ANPD (Autoridade Nacional de Proteção de Dados)**.

### 📊 As 10 Bases Legais

Diferente do que muitos pensam, a LGPD não exige consentimento para tudo. A **Preditiva.ai** destaca que existem 10 justificativas para tratar dados. As mais comuns no seu dia a dia são:

1. **Consentimento**: O candidato clica em "Aceito os termos".
2. **Execução de Contrato**: Dados necessários para assinar o contrato de trabalho.
3. **Cumprimento de Obrigação Legal**: Dados para o eSocial ou Receita Federal.
4. **Legítimo Interesse**: Quando o tratamento é essencial para a empresa e não fere direitos do titular (ex: segurança do escritório).

### ⚖️ Direitos do Titular no Brasil

A **Metricas Boss** reforça que o tempo de resposta é um diferencial de confiança.

| Direito                      | Descrição Técnica                      | Aplicação no RH/QA                                                |
| ---------------------------- | -------------------------------------- | ----------------------------------------------------------------- |
| <b>Confirmação e Acesso</b>  | Saber se há tratamento e ver os dados. | Candidato pergunta: "Quais dados vocês têm de mim?"               |
| <b>Correção</b>              | Alterar dados incompletos ou errados.  | Atualizar o currículo ou o status de um teste.                    |
| <b>Anonimização/Bloqueio</b> | Desvincular o dado da pessoa.          | Transformar nomes em IDs para análise estatística.                |
| <b>Eliminação</b>            | Exclusão de dados desnecessários.      | Apagar currículos de processos encerrados há 2 anos.              |
| <b>Revogação</b>             | Retirar o consentimento dado antes.    | Candidato desiste do processo e pede para não ser mais contatado. |

### 🛠️ Prática com Python: Anonimização Simples

Para proteger a identidade de candidatos em uma análise estatística, usamos a anonimização:

``` 
import pandas as pd

# Create a sample recruitment dataset
sample_data = {
    'nome_candidato': ['Alice Silva', 'Bob Santos', 'Charlie Oliveira', 'Diana Costa'],
    'idade': [25, 30, 35, 28],
    'cargo': ['Desenvolvedor', 'Gerente', 'Analista', 'Designer'],
    'salario': [5000, 8000, 6000, 5500]
}
df = pd.DataFrame(sample_data)

print("Dataset original:")
print(df)

# Generate anonymized IDs: CAND_001, CAND_002, etc.
df['nome_candidato'] = [f'CAND_{i:03d}' for i in range(1, len(df) + 1)]

print("\nDataset anonimizado:")
print(df)

# Save the anonymized dataset to a CSV file
df.to_csv('dataset_recrutamento_anonimizado.csv', index=False)
print("\nDataset salvo como 'dataset_recrutamento_anonimizado.csv'")
```

### 💡 Insights do Especialista

- **Dados Sensíveis**: A LGPD é muito rígida com dados de saúde, religião e biometria. No recrutamento, evite coletar essas informações a menos que seja estritamente necessário por lei (**AILabs**).
- **Multas**: Podem chegar a **2% do faturamento**, limitadas a **R$ 50 milhões por infração**.
- **Cultura de Dados**: O **Cappra Institute** reforça: "Dados protegidos são dados valorizados". A LGPD não é um bloqueio para a ciência de dados, mas uma regra de etiqueta digital.
