### 🔶 O Conceito: Dividir, Aplicar e Combinar

O `groupby()` funciona em três etapas automáticas:

1. **Dividir (Split):** Ele separa os dados em grupos (ex: por Departamento).
2. **Aplicar (Apply):** Ele faz um cálculo em cada grupo (ex: soma ou média).
3. **Combinar (Combine):** Ele junta tudo em uma nova tabela resumida.

---

### 1️⃣ Agrupamento Simples

Ideal para responder perguntas rápidas de gestão ou QA.

👉 **Exemplo RH: Qual a média salarial por departamento?**

```python
# Agrupa por 'depto' e calcula a média da coluna 'salario'
df.groupby('departamento')['salario'].mean()
```

👉 **Exemplo QA: Quantos bugs existem por status?**

```python
# Conta quantos registros existem para cada status de bug
df.groupby('status')['bug_id'].count()
```

---

### 2️⃣ Agrupando por Múltiplas Colunas

Você pode cruzar informações para ter uma visão mais profunda.

👉 **Exemplo: Média de notas de candidatos por nível e por cidade**

```python
df.groupby(['nivel', 'cidade'])['nota_teste'].mean()
```

---

### 3️⃣ Usando o `.agg()` para múltiplos cálculos

Às vezes você quer ver a média, o mínimo e o máximo de uma vez só.

👉 **Exemplo: Resumo estatístico de salários por cargo**

```python
df.groupby('cargo')['salario'].agg(['mean', 'min', 'max'])
```

---

### 🚀 Visão de Especialista (Metodologia Preditiva.ai / Metricas Boss)

- **Evidência vs. Achismo:** A **Preditiva.ai** reforça que o `groupby()` elimina o "eu acho que o setor X é mais caro". Ele traz a **evidência estatística** necessária para tomadas de decisão.
- **Data Literacy:** O **Cappra Institute** destaca que saber agrupar dados é essencial para a "alfabetização de dados". Para um Analista de QA, isso significa identificar se um módulo específico do software está concentrando 80% dos erros (Lei de Pareto).
- **Dica de Performance:** Se você estiver trabalhando com milhões de linhas, agrupar por colunas do tipo `category` (em vez de `object/string`) torna o processo muito mais veloz.

**Resumindo a lógica:**

- **`groupby`**: Define os grupos.
- **`['coluna']`**: Define o que será calculado.
- **`.função()`**: Define o cálculo (mean, sum, count, etc).
