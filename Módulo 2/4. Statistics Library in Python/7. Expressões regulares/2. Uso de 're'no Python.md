### 🔶 O que é `re`?

- Módulo nativo do Python para **expressões regulares** (regex).
- Serve pra **buscar, validar, substituir** padrões em strings.
- Por quê? Acelera ETL (Extract, Transform, Load) sem loops manuais.

**Import básico:**

```python
import re
```

---
### 1️⃣ Funções principais (as mais usadas)

- **`re.search()`**: Busca o **primeiro** padrão na string.
- **`re.findall()`**: Retorna **todos** os padrões encontrados.
- **`re.sub()`**: **Substitui** padrões por algo novo.
- **`re.match()`**: Busca só no **início** da string.
- **`re.compile()`**: Compila regex pra reutilizar (mais rápido em loops).

---

### 2️⃣ Exemplo prático: Extrair e-mails de logs (QA)

```python
texto = "Erro no teste: user@exemplo.com falhou. Contato: suporte@site.com.br"

# Encontra todos os e-mails
emails = re.findall(r'\w+@\w+\.\w+', texto)
print(emails)  # ['user@exemplo.com', 'suporte@site.com.br']
```

---

### 3️⃣ Exemplo: Limpar CPF (RH)

```python
cpf_sujo = "Meu CPF é 123.456.789-00 com espaços"

# Remove tudo que não é dígito
cpf_limpo = re.sub(r'\D', '', cpf_sujo)
print(cpf_limpo)  # 12345678900
```

---

### 4️⃣ Exemplo no Pandas (integração top!)

```python
import pandas as pd

df = pd.DataFrame({'log': ['bug123@email.com', 'teste456 ok']})

# Extrai e-mails da coluna
df['email'] = df['log'].str.findall(r'\w+@\w+\.\w+')
print(df['email'])
```

---

### 5️⃣ Símbolos chave pra decorar

- `\d+`: 1 ou mais dígitos.
- `\w+`: Letras, dígitos ou `_`.
- `.*`: Qualquer coisa (0 ou mais).
- `re.IGNORECASE`: Ignora maiúsculas/minúsculas.
- `re.MULTILINE`: Para múltiplas linhas.
