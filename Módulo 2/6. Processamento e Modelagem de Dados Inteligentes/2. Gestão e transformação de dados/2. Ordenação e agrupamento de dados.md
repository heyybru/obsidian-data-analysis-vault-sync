# O que é? 

Duas operações que respondem perguntas diferentes sobre o mesmo conjunto.
## sort_values — organizar a ordem das linhas

**O que é:** reorganiza as linhas por uma ou mais colunas.

     fruta  preco
1   banana   1.99
0     maçã   2.99
2  morango   3.49
3      uva   4.99

👉 **Repare nos índices à esquerda:** 1, 0, 2, 3. A ordenação **não renumera** — ela carrega o índice original junto com cada linha. Isso é intencional: o índice é a identidade do registro. Para renumerar, usa-se reset_index(drop=True).

Invertendo a ordem: ascending=False. Para ordenar por duas colunas, by=['categoria', 'preco'] — ordena pela primeira e usa a segunda para desempatar.

**Onde se aplica:** apresentação e exploração. **Quando usar:** para ver o topo da distribuição — maiores vendas, menores preços, registros mais recentes.

## groupby — resumir por categoria

**O que é:** separa os dados em grupos por uma coluna e aplica um cálculo dentro de cada grupo.

Nome Produto
Calça Jeans           9.828571
Camisa Gola Polo      9.772727
Camisa Manga Longa    9.655738
Camiseta Básica       9.833333
Sapato Social         9.826923
Name: Quantidade Vendida, dtype: float64

👉 **Leia como uma frase:** "para cada Nome Produto, calcule a média de Quantidade Vendida". O Pandas fatia, calcula e empilha o resultado.

**Dois detalhes importantes:**

1. O retorno é uma **Series** (índice = produto), não um DataFrame. Para voltar a DataFrame: .reset_index().
2. As médias estão todas entre ~9,65 e ~9,83 — **quase idênticas**. Isso é um gatilho de EDA: vale conferir se essa coluna é realmente a quantidade vendida ou se já é uma média pré-calculada. Distribuições reais raramente são tão uniformes.

**Onde se aplica:** agregação e análise — o coração de um relatório de BI. **Quando usar:** para responder "por categoria", "por mês", "por região".

## A diferença conceitual

**sort_values não muda o volume de dados** — só reordena. **groupby reduz o volume** — 10.000 linhas podem virar 5 grupos. Um reorganiza; o outro resume.
