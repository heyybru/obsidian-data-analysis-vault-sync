## 1. O que faz o SELECT DISTINCT?

O `DISTINCT` **remove valores repetidos** da coluna que você seleciona. Em vez de trazer a lista inteira (com milhares de linhas repetidas), ele traz **cada valor diferente uma única vez**.

> 🧩 **Analogia:** é como organizar as roupas de um guarda-roupa bagunçado — você não quer ver as 30 camisetas, só quer saber **quais tipos de roupa existem** (camiseta, calça, casaco...). O `DISTINCT` faz isso com dados.

## 2. Como funciona (passo a passo)

```sql
SELECT DISTINCT country
FROM customers;
```

**Linha por linha:**

- `SELECT DISTINCT country` → pega a coluna `country` (país) e **elimina os repetidos**.
- `FROM customers` → de onde vêm os dados (tabela de clientes).
- `;` → fim da instrução.

**Pseudocódigo:**

```
PEGUE a coluna country
DA tabela customers
REMOVA os valores repetidos
MOSTRE cada país apenas uma vez
```

**Resultado:** em vez de 91 linhas (uma por cliente, com países repetidos), você recebe uma lista curta com cada país **uma única vez** — tipo `Germany`, `Mexico`, `UK`, `Brazil`, `Sweden`...

## 3. Por que é útil?

O `DISTINCT` responde perguntas de **"quais valores existem?"**:

- 📍 Quais países têm clientes cadastrados?
- 🏷️ Quais categorias de produto a loja vende?
- 👔 Quais cargos existem na empresa?

No seu universo de People Analytics: `SELECT DISTINCT job_title FROM employees;` devolve a **lista de cargos únicos** da organização — ótimo para entender a estrutura antes de análises mais profundas (como agrupar com `GROUP BY`, que vem no Módulo 4).

## 4. Atenção: múltiplas colunas

```sql
SELECT DISTINCT country, city
FROM customers;
```

Aqui o `DISTINCT` age sobre a **combinação** das duas colunas: remove linhas onde `country` + `city` se repetem juntos. Se dois clientes são de `Brazil/São Paulo`, uma das linhas some. Cuidado: ele **não** remove duplicatas de uma coluna isolada — a combinação completa é que conta.

## 5. O que NÃO confundir

- **DISTINCT ≠ LIMIT** — o `LIMIT` corta a quantidade de linhas (as 5 primeiras); o `DISTINCT` remove duplicatas. São coisas diferentes.
- **DISTINCT ≠ GROUP BY** — os dois eliminam repetidos, mas o `GROUP BY` vem preparado para **agregar** (contar, somar). O `DISTINCT` só lista. Ex.: "quantos clientes por país" é `GROUP BY`; "quais países existem" é `DISTINCT`.
- **Valores NULL** — se a coluna tiver campos vazios, o `DISTINCT` trata todos os `NULL` como um único valor na lista.

## Resumindo

- `SELECT DISTINCT coluna` retorna **cada valor diferente uma única vez**, removendo duplicatas.
- É perfeito para responder **"quais valores existem?"** (países, categorias, cargos).
- Com várias colunas, ele elimina linhas duplicadas na **combinação completa**.
- Não confunda: `LIMIT` corta linhas, `GROUP BY` agrega, `DISTINCT` só lista únicos.
