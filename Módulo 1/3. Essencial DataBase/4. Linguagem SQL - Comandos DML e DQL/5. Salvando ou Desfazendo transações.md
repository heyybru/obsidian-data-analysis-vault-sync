### 🔹 O que é uma transação?

👉 Uma **transação** é um conjunto de comandos SQL que devem ser **confirmados ou desfeitos juntos**.

📌 Muito usada com **INSERT, UPDATE e DELETE**.

---

## 🔹 COMMIT – Salvar alterações

O **COMMIT** confirma definitivamente as mudanças feitas no banco.

```sql
COMMIT;
```

👉 Depois do COMMIT:

- As alterações são salvas
    
- **Não podem ser desfeitas**

---

## 🔹 ROLLBACK – Desfazer alterações

O **ROLLBACK** cancela as alterações **ainda não confirmadas**.

```sql
ROLLBACK;
```

👉 Volta o banco ao estado anterior ao último COMMIT.

---

## 🔹 Exemplo prático

```sql
UPDATE COLABORADOR
SET salario = salario + 500
WHERE id_colaborador = 1;
```

🔸 Se der certo:

```sql
COMMIT;
```

🔸 Se perceber erro:

```sql
ROLLBACK;
```

---

## 🔹 SAVEPOINT – Ponto de salvamento

Cria um ponto intermediário dentro da transação.

```sql
SAVEPOINT ponto1;
```

Voltar até o ponto:

```sql
ROLLBACK TO ponto1;
```

---

## ⚠️ Atenções importantes

- `DELETE` pode ser desfeito com ROLLBACK (antes do COMMIT)
    
- `TRUNCATE` e `DROP` **não permitem ROLLBACK**
    
- Alguns SGBDs usam **auto-commit**
    

---

## 🧠 Resumo rápido

- COMMIT → salva
    
- ROLLBACK → desfaz
    
- SAVEPOINT → marca ponto
    
- DDL não volta atrás
