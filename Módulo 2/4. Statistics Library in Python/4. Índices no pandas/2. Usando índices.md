### 🔶 Como usar os índices no Pandas

- **Acesso por Rótulo (`loc`):** Você usa o nome que deu ao índice.
- **Acesso por Posição (`iloc`):** Você usa o número da linha (começando do 0).
- **Slicing (Fatiamento):** Selecionar um intervalo de dados de uma vez só.

---

### 1️⃣ Localizando Dados com `loc` e `iloc`

Esta é a maior dúvida de quem começa, mas para você que já lida com PostgreSQL, a lógica de "onde" (WHERE) ajuda muito.

👉 **Exemplo: Buscar um candidato específico pelo ID (Rótulo)**

```python
# Supondo que o ID do candidato seja o índice
candidato = df.loc['ID_550'] 
```

👉 **Exemplo: Buscar a primeira linha da tabela (Posição)**

```python
primeira_linha = df.iloc[0]
```

---

### 2️⃣ Definindo e Trocando o Índice

Às vezes, o índice numérico padrão (0, 1, 2...) não ajuda. Você pode querer indexar por "Email" ou "CPF".

👉 **Exemplo: Transformar a coluna 'Email' no novo índice**

```python
df.set_index('email', inplace=True)
```

👉 **Exemplo: Voltar ao índice numérico (limpeza de dados)**

```python
# O drop=True evita que o índice antigo vire uma coluna extra
df.reset_index(drop=True, inplace=True)
```

---

### 3️⃣ Ordenando pelo Índice

Muito útil para organizar cronogramas de testes ou listas de chamadas por ordem alfabética de IDs.

👉 **Exemplo: Colocar os índices em ordem crescente**

```python
df.sort_index(ascending=True, inplace=True)
```

---

### 4️⃣ Seleção de Intervalos (Slicing)

Como coordenador de talentos, você pode querer ver do candidato 10 ao 20 rapidamente.

👉 **Exemplo: Pegar um intervalo de posições**

```python
# Pega da linha 10 até a 19
recorte = df.iloc[10:20]
```

---

### 🚀 Visão de Especialista (Metodologia Preditiva.ai / Metricas Boss)

- **Integridade de Dados:** Segundo a **Preditiva.ai**, o uso correto de índices evita o erro de "dados desalinhados" ao fazer merges (junções) de tabelas. Se você juntar dados de performance de QA com dados de RH, o índice deve ser a chave primária comum.
- **Performance:** A **Metricas Boss** reforça que, em grandes conjuntos de dados, buscar por um índice (`index`) é computacionalmente muito mais barato do que fazer um filtro comum (`df[df['coluna'] == valor]`).
- **Dica de QA:** Use o índice para marcar registros que falharam em testes automatizados. Assim, você pode dar um `df.loc[indices_falha]` e ter um relatório instantâneo de erros.

**Resumindo a "caixa de ferramentas":**

- `df.set_index()`: Define quem manda na linha.
- `df.reset_index()`: Organiza a numeração após deletar linhas.
- `df.loc[]`: Busca pelo "nome" do apartamento.
- `df.iloc[]`: Busca pelo "andar" do prédio.
