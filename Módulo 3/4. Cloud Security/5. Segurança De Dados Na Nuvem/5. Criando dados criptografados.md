O material sugere que a aplicação da criptografia deve ser nativa no desenvolvimento (Security by Design).

1. **Sanitização de Mídias:** Antes de descartar qualquer hardware, os dados devem ser destruídos permanentemente para que não possam ser recuperados.
2. **Uso de Ferramentas de Nuvem:** Provedores como a AWS oferecem serviços como o **KMS (Key Management Service)**, que automatiza a criação e rotação de chaves para seus bancos de dados e arquivos.
3. **Cultura de Segurança:** Treinar a equipe para que a criptografia seja a regra, não a exceção.

---

### 🎯 Conexão com seu perfil (RH + QA)

- **No RH:** A segurança protege a privacidade dos candidatos. Dados de pretensão salarial e avaliações técnicas devem estar criptografados **em repouso** no seu banco de dados.
- **No QA:** Seus testes devem validar se os dados sensíveis estão sendo mascarados ou criptografados nas respostas das APIs, garantindo que informações privadas não vazem nos logs do sistema.
