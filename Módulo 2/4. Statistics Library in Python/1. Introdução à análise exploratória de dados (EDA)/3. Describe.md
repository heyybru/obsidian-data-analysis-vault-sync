O **`describe()`** serve para gerar um **resumo estatístico rápido** de um DataFrame ou de uma coluna.  
Ele é um dos comandos mais usados na **análise exploratória de dados (EDA)** porque mostra, de forma automática, as principais medidas descritivas.

---
## O que ele mostra

Quando você roda:

```python
df.describe()
```

o Pandas retorna, para as colunas numéricas:

- **count** → quantidade de valores não nulos
- **mean** → média
- **std** → desvio padrão
- **min** → valor mínimo
- **25%** → primeiro quartil
- **50%** → mediana
- **75%** → terceiro quartil
- **max** → valor máximo

---

## Exemplo prático

```python
import pandas as pd

df = pd.DataFrame({
    "idade": [22, 25, 30, 35, 40],
    "salario": [2000, 2500, 3000, 4000, 5000]
})

print(df.describe())
```

### Saída esperada

```python
           idade      salario
count   5.000000     5.000000
mean   30.400000  3300.000000
std     7.300685  1208.304597
min    22.000000  2000.000000
25%    25.000000  2500.000000
50%    30.000000  3000.000000
75%    35.000000  4000.000000
max    40.000000  5000.000000
```

---

## Como interpretar

### `count`

- Quantos valores válidos existem
- Se o total de linhas for 100 e o `count` for 92, então existem **8 valores nulos**

### `mean`

- Média dos valores
- Boa para entender tendência central, mas pode ser afetada por **outliers**

### `std`

- Mede a dispersão
- Quanto maior, mais espalhados os dados estão em relação à média

### `min` e `max`

- Mostram os extremos
- Úteis para detectar valores suspeitos

### `25%`, `50%`, `75%`

- Quartis
- `50%` é a **mediana**
- Bons para entender distribuição e possíveis assimetrias

---

## Em colunas categóricas

Se você fizer só:

```python
df.describe()
```

o padrão é analisar apenas colunas **numéricas**.

Para incluir colunas de texto/categóricas, use:

```python
df.describe(include='object')
```

ou:

```python
df.describe(include='all')
```

---

## O que aparece em colunas categóricas

Para texto, o resultado costuma trazer:

- **count** → quantidade de valores não nulos
- **unique** → quantidade de valores únicos
- **top** → valor mais frequente
- **freq** → frequência do valor mais frequente

### Exemplo

```python
df = pd.DataFrame({
    "cidade": ["SP", "RJ", "SP", "BH", "SP"]
})

print(df.describe(include='object'))
```

### Saída esperada

```python
       cidade
count       5
unique      3
top        SP
freq        3
```

---

## Aplicação prática na EDA

O `describe()` ajuda a responder rapidamente:

- os dados têm valores faltantes?
- a média faz sentido?
- existe valor muito alto ou muito baixo?
- os dados estão muito dispersos?
- há indícios de outliers?

---

## Exemplo com o seu fluxo de estudo

Se você estiver analisando uma base de recrutamento ou QA:

```python
df.describe()
```

pode mostrar, por exemplo:

- tempo médio de contratação
- salário médio
- idade média
- variação entre tempos ou valores

E:

```python
df.describe(include='all')
```

pode mostrar:

- departamento mais frequente
- cidade mais comum
- categoria que mais aparece

---

## Comandos úteis junto com `describe()`

### Estatística só de uma coluna

```python
df["idade"].describe()
```

### Incluir tudo

```python
df.describe(include='all')
```

### Transpor para facilitar leitura

```python
df.describe().T
```

Esse `.T` é muito útil porque coloca cada coluna em uma linha, ficando mais fácil de ler.

---

## Exemplo recomendado

```python
print(df.describe().T)
```

---

## Resumindo

- **`describe()`** gera um resumo estatístico automático
- para numéricos, mostra:
    - `count`, `mean`, `std`, `min`, `25%`, `50%`, `75%`, `max`
- para categóricos:
    - `count`, `unique`, `top`, `freq`
- é um dos primeiros comandos da **análise exploratória de dados**

---
## Exemplo direto para usar agora

Se seu DataFrame já está carregado:

```python
df.describe()
```

Se quiser ver tudo:

```python
df.describe(include='all')
```

Se quiser facilitar leitura:

```python
df.describe(include='all').T
```
