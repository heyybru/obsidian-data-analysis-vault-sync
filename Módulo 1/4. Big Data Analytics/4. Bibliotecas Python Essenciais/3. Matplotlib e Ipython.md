## 🔷 Matplotlib e IPython/Jupyter: Visualização e Ambiente Interativo

**Matplotlib é como um "caderno de desenhos" para dados**, e **IPython/Jupyter é como um "laboratório digital" onde você experimenta**.  
Juntos, permitem criar gráficos e analisar dados de forma interativa, perfeita para explorar dados de RH e QA. 

✅ **No seu contexto (RH + QA)**:

- **RH**: Gráficos de salários, distribuição de idade, turnover por departamento

## 🔷 Gráficos Básicos com Matplotlib

### ✅ **Linha (tendências)**:

```python
# Bugs por mês (QA)
import pandas as pd
import matplotlib.pyplot as plt

# Dados simulados
meses = ['Jan', 'Fev', 'Mar', 'Abr', 'Mai']
bugs = [45, 52, 38, 61, 49]

plt.figure(figsize=(10, 6))
plt.plot(meses, bugs, marker='o', linewidth=2, color='red')
plt.title('Bugs Reportados por Mês')
plt.xlabel('Mês')
plt.ylabel('Número de Bugs')
plt.grid(True, alpha=0.3)
plt.show()
```

### ✅ **Barras (comparações)**:

```python
# Candidatos por departamento (RH)
departamentos = ['TI', 'RH', 'Vendas', 'Marketing']
candidatos = [25, 15, 20, 12]

plt.figure(figsize=(8, 5))
plt.bar(departamentos, candidatos, color=['blue', 'green', 'orange', 'red'])
plt.title('Candidatos por Departamento')
plt.xlabel('Departamento')
plt.ylabel('Número de Candidatos')
plt.show()
```

### ✅ **Histograma (distribuições)**:

```python
# Distribuição de salários (RH)
import numpy as np

salarios = np.random.normal(6000, 1000, 1000)  # Dados simulados

plt.figure(figsize=(8, 5))
plt.hist(salarios, bins=30, edgecolor='black', alpha=0.7)
plt.title('Distribuição de Salários')
plt.xlabel('Salário (R$)')
plt.ylabel('Frequência')
plt.axvline(np.mean(salarios), color='red', linestyle='--', label='Média')
plt.legend()
plt.show()
```

### ✅ **Pizza (proporções)**:

```python
# Bugs por severidade (QA)
severidades = ['Baixo', 'Médio', 'Alto', 'Crítico']
quantidades = [30, 45, 20, 5]
cores = ['green', 'yellow', 'orange', 'red']

plt.figure(figsize=(8, 6))
plt.pie(quantidades, labels=severidades, colors=cores, autopct='%1.1f%%', startangle=90)
plt.title('Distribuição de Bugs por Severidade')
plt.axis('equal')  # Círculo perfeito
plt.show()
```

## 🔷 Integração com Pandas

### ✅ **Gráficos diretos do DataFrame**:

```python
import pandas as pd
import matplotlib.pyplot as plt

# Carregar dados
candidatos = pd.read_csv('candidatos.csv')

# Gráfico direto
candidatos['departamento'].value_counts().plot(kind='bar', figsize=(8, 5))

plt.xticks(rotation=45)
plt.show()

# Scatter plot
candidatos.plot.scatter(x='experiencia', y='salario', figsize=(8, 5))
plt.title('Salário vs Experiência')
plt.show()
```

### ✅ **Exemplo completo em Jupyter**:

```python
# Célula 1: Importar bibliotecas
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns  # Para gráficos mais bonitos

# Célula 2: Carregar dados
candidatos = pd.read_csv('candidatos.csv')
bugs = pd.read_csv('bugs.csv')

# Célula 3: Análise RH
print("=== ANÁLISE RH ===")
print(candidatos.describe())

# Célula 4: Gráfico salários
plt.figure(figsize=(10, 6))
candidatos.boxplot(column='salario', by='departamento')
plt.title('Distribuição Salarial por Departamento')
plt.suptitle('')  # Remove título automático
plt.show()

# Célula 5: Análise QA
print("\n=== ANÁLISE QA ===")
bugs_por_severidade = bugs['severidade'].value_counts()
print(bugs_por_severidade)

# Célula 6: Pizza bugs
plt.figure(figsize=(8, 6))
bugs_por_severidade.plot.pie(autopct='%1.1f%%')
plt.title('Bugs por Severidade')
plt.ylabel('')  # Remove label automático
plt.show()

# Célula 7: Correlação
plt.figure(figsize=(8, 6))
plt.scatter(candidatos['experiencia'], candidatos['salario'], alpha=0.6)
plt.title('Correlação: Experiência vs Salário')
plt.xlabel('Anos de Experiência')
plt.ylabel('Salário (R$)')
plt.grid(True, alpha=0.3)
plt.show()
```

## 🔷 Projeto Prático: Dashboard RH+QA

### ✅ **Estrutura do notebook**:

**Célula 1: Setup**

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

plt.style.use('seaborn-v0_8')
sns.set_palette('husl')

# Carregar dados
candidatos = pd.read_csv('dados/candidatos.csv')
bugs = pd.read_csv('dados/bugs.csv')
```

**Célula 2: Análise Exploratória**

```python
print("📊 DASHBOARD RH + QA")
print("=" * 50)

print("\n🔍 RH - Candidatos:")
print(f"Total: {len(candidatos)}")
print(f"Departamentos: {candidatos['departamento'].nunique()}")
print(f"Salário médio: R$ {candidatos['salario'].mean():.2f}")

print("\n🔍 QA - Bugs:")
print(f"Total: {len(bugs)}")
print(f"Módulos afetados: {bugs['modulo'].nunique()}")
print(f"Tempo médio resolução: {bugs['horas_resolucao'].mean():.1f}h")
```

**Célula 3: Visualizações RH**

```python
fig, axes = plt.subplots(2, 2, figsize=(15, 10))
fig.suptitle('📈 Análise de Recursos Humanos', fontsize=16)

# Salários por departamento
candidatos.groupby('departamento')['salario'].mean().plot(
    kind='bar', ax=axes[0,0], color='skyblue')
axes[0,0].set_title('Salário Médio por Departamento')
axes[0,0].tick_params(axis='x', rotation=45)

# Distribuição etária
axes[0,1].hist(candidatos['idade'], bins=10, edgecolor='black', alpha=0.7)
axes[0,1].set_title('Distribuição Etária')
axes[0,1].set_xlabel('Idade')

# Status dos candidatos
candidatos['status'].value_counts().plot(
    kind='pie', ax=axes[1,0], autopct='%1.1f%%')
axes[1,0].set_title('Status dos Candidatos')
axes[1,0].set_ylabel('')

# Experiência vs Salário
axes[1,1].scatter(candidatos['experiencia'], candidatos['salario'], alpha=0.6)
axes[1,1].set_title('Experiência vs Salário')
axes[1,1].set_xlabel('Anos de Experiência')
axes[1,1].set_ylabel('Salário (R$)')

plt.tight_layout()
plt.show()
```

**Célula 4: Visualizações QA**

```python
fig, axes = plt.subplots(1, 3, figsize=(18, 6))
```
