### **O Que São KPIs Estratégicos?**

- **Definição curta**: Métricas-chave alinhadas a objetivos de alto nível (visão/estratégia da empresa). Não operacionais (dia a dia), mas guias de direção.
- **Diferença**: KPI operacional = taxa de erro hoje; Estratégico = crescimento da receita anual (Métricas Boss** benchmarks).

### **Por Que Usar?**

- Alinha time/dados à meta grande (ex.: +20% market share).
- Monitora progresso real-time, evita viés (**Snaq.co** análise: +50% decisões assertivas).
- Ex: Empresa tech → KPI "Customer Lifetime Value" (CLV) pra retenção.

### **Como Criar/Selecionar (Passos)**

1. **Defina OKRs**: Objetivo (crescer 30%) + Key Result (KPI mensurável).
2. **SMART**: Specific, Measurable, Achievable, Relevant, Time-bound.
3. **Fontes de dados**: CRM/DBs (SQL: `SELECT AVG(receita)/COUNT(clientes) AS CLV`).
4. **Dashboard**: Tableau/Power BI pra track.

### **Exemplos Estratégicos Comuns**

- **Financeiro**: ROAS (Return Ad Spend) = Receita / Custo Ads (**Preditiva.ai** ex: R$5 por R$1 investido).
- **Cliente**: NPS (Net Promoter Score) = %Promotores - %Detratores (meta >50).
- **Operacional Estratégico**: Churn Rate = (Clientes Perdidos / Total) x 100 (<5% anual).
- **Dados**: Data Maturity Score = %Dados limpos/úteis (meta 90%, **Cappra**).

### **Exemplo Prático (SQL/Pandas)**

```python
import pandas as pd

df = pd.read_csv('clientes.csv')  # Cols: receita, data_inicio, data_fim

# KPI CLV estratégico
df['dias_cliente'] = (pd.to_datetime(df['data_fim']) - df['data_inicio']).dt.days
clv = df['receita'].sum() / len(df)
print(f"CLV Estratégico: R${clv:.2f}")
```

**Insight**: CLV R$2k → invista retenção pra crescimento sustentável.

### **Dicas e Cuidados**

- **Menos é mais**: 5-7 KPIs max (evite overload).
- **Atualize**: Review trimestral (**AILabs** tip).
- **Ação**: KPI sem ação = inútil.
