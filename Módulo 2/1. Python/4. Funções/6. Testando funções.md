Testar função é garantir que ela:

- **retorna o que deveria** (casos comuns),
- **não quebra** em entradas ruins (casos de borda),
- **mantém o comportamento** quando você muda o código (regressão).

Vou te mostrar 3 níveis: **teste manual**, **assert**, e **pytest** (o mais usado).

---

## 🔷 1) Teste manual (rápido, mas frágil)

Você chama a função e confere no olho:

```python
def soma(a, b):
    return a + b

print(soma(2, 3))   # esperado: 5
print(soma(-1, 1))  # esperado: 0
```

✅ Bom pra começar.  
❌ Ruim pra manter: você precisa “lembrar” do esperado e conferir sempre.

---

## 🔷 2) `assert` (mínimo profissional, ótimo pra aprender)

`assert` falha automaticamente se a condição não for verdadeira.

```python
def soma(a, b):
    return a + b

assert soma(2, 3) == 5
assert soma(-1, 1) == 0
assert soma(0, 0) == 0
print("✅ Todos os testes passaram!")
```

### ✅ Testar exceções (entrada inválida)

```python
def fatorial(n):
    if n < 0:
        raise ValueError("n deve ser >= 0")
    return 1 if n == 0 else n * fatorial(n - 1)

try:
    fatorial(-1)
    assert False, "Era para ter lançado ValueError"
except ValueError:
    assert True
```

## 🔷 3) `pytest` (padrão de mercado em QA)

### ✅ Instalação

```bash
pip install pytest
```

### ✅ Exemplo: arquivo `test_funcoes.py`

```python
import pytest

def soma(a, b):
    return a + b

def test_soma_basico():
    assert soma(2, 3) == 5

def test_soma_negativos():
    assert soma(-1, 1) == 0

def test_soma_zero():
    assert soma(0, 0) == 0
```

### ✅ Rodar

```bash
pytest -q
```

## 🔷 4) Testando função com múltiplos casos (parametrização)

Isso é bem “QA”: muitos inputs, um mesmo teste.

```python
import pytest

def status_ok(status_code):
    return 200 <= status_code <= 299

@pytest.mark.parametrize("status, esperado", [
    (200, True),
    (201, True),
    (204, True),
    (301, False),
    (404, False),
    (500, False),
])
def test_status_ok(status, esperado):
    assert status_ok(status) == esperado
```

## 🔷 5) Testando funções de manipulação de dados (lista/dict)

### ✅ Exemplo QA: filtrar bugs críticos abertos

```python
def filtrar_criticos_abertos(bugs):
    return [
        b for b in bugs
        if b.get("severidade") == "CRITICO" and b.get("status") == "ABERTO"
    ]

def test_filtrar_criticos_abertos():
    bugs = [
        {"id": 1, "severidade": "CRITICO", "status": "ABERTO"},
        {"id": 2, "severidade": "ALTO", "status": "ABERTO"},
        {"id": 3, "severidade": "CRITICO", "status": "FECHADO"},
    ]
    saida = filtrar_criticos_abertos(bugs)
    assert len(saida) == 1
    assert saida[0]["id"] == 1
```

## 🔷 6) Boas práticas de teste (bem direto)

✅ Teste:

- **caso feliz** (input esperado)
- **caso de borda** (0, vazio, None)
- **entrada inválida** (string quando deveria ser número)
- **exceções** (se a função deve levantar erro)

✅ Estruture assim:

- Arrange (preparar dados)
- Act (executar)
- Assert (verificar)
