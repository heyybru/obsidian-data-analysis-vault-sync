O material aponta para onde o mercado está indo:

- **Serverless (Computação sem Servidor):** O desenvolvedor foca no código (funções) e o provedor cuida de toda a infraestrutura.
- **Edge Computing:** Processar dados mais perto de onde eles são gerados (sensores, celulares) para reduzir a latência.
- **Multi-Cloud:** Uso de mais de um provedor (ex: AWS + Azure) para evitar dependência de um único fornecedor (_vendor lock-in_).
