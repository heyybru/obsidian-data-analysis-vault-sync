# O que é:** 

Identificar e tratar dados faltantes, duplicados ou incorretos. O material apresenta o dropna() com um exemplo e o np.nan:

```python 
import pandas as pd
import numpy as np

data = pd.DataFrame({
    'A': [1, 2, np.nan],
    'B': [4, np.nan, np.nan],
    'C': [7, 8, 9]
})
data.dropna()
```

## O que esse código realmente faz

np.nan cria um valor ausente. O dropna() **remove qualquer linha que tenha pelo menos um valor ausente**. Rastreando linha por linha:

Sobra **apenas a linha 0**. Esse comportamento agressivo é o padrão (how='any').

## ⚠️ Problema no exemplo do material

O material escreve data.dropna() **sem atribuição e sem print**. Isso não altera o DataFrame e não mostra nada — a linha parece não ter efeito nenhum. O motivo é que dropna() **retorna um novo DataFrame** em vez de modificar o original.

```python
# correto: atribuir o resultado
data = data.dropna()
print(data) 
```

> **Sobre inplace=True:** versões antigas recomendavam data.dropna(inplace=True). A documentação atual do Pandas marca esse parâmetro como **descontinuado desde a versão 3.1, com remoção prevista na 4.0**. A forma recomendada hoje é a atribuição.

## Complementos que o material não traz

A limpeza real precisa de quatro ferramentas, não uma:

```python 
df.isna().sum()                      # diagnóstico: quantos ausentes por coluna
df.dropna(subset=['preco'])          # remove só se faltar na coluna crítica
df.dropna(thresh=3)                  # mantém linhas com ao menos 3 valores válidos
df.fillna(0)                         # preenche em vez de remover
```

👉 **A decisão central da limpeza:** remover ou preencher? Remover perde informação; preencher inventa informação. A regra prática: se falta pouco e a coluna é essencial, remova. Se falta muito e a coluna é acessória, preencha com um valor explícito ('Não informado') ou com a mediana.

**Onde se aplica:** imediatamente após carregar os dados — antes de qualquer cálculo. **Quando usar:** sempre. É a etapa obrigatória do EDA que a Etapa 1 da Avaliação Prática exige.
