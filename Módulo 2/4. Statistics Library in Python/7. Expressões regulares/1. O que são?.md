### 🔶 O que são expressões regulares?

- **Definição curta**: São **padrões de busca** para encontrar, validar ou substituir texto em strings. Pense como um "filtro inteligente" que usa símbolos especiais para caçar padrões.
- **Por quê usar?** Acelera limpeza de dados (ex: remover ruídos em logs de QA ou nomes de candidatos). Sem regex, você faria loops manuais – chato e lento.
- **Onde?** No Pandas: `str.contains()`, `str.replace()`, `str.extract()`. Em Python puro: módulo `re`.

### 1️⃣ Símbolos básicos (mini dicionário)

Aqui os mais usados, pra você decorar rápido:

|Símbolo|Significado|Exemplo|
|---|---|---|
|`.`|Qualquer caractere|`a.c` → acha "abc", "a1c"|
|`*`|0 ou mais repetições|`a*` → "a", "aa", "aaa"|
|`+`|1 ou mais repetições|`a+` → "a", "aa" (não vazio)|
|`?`|0 ou 1 ocorrência|`col?r` → "cor", "color"|
|`\d`|Dígito (0-9)|`\d{3}` → "123" (3 dígitos)|
|`\w`|Letra, dígito ou _|`\w+` → palavras|
|`^`|Início da string|`^Bruno` → começa com "Bruno"|
|`$`|Fim da string|`com$` → termina com "com"|
|`\|`|OU|`SP\|RJ` → "SP" ou "RJ"|
|`()`|Grupo (captura)|`(\d{2})` → pega "11" de "11/2024"|

### 2️⃣ Exemplo prático no Pandas (QA/RH)

Imagine um DF com logs de bugs ou e-mails sujos:

```python
import pandas as pd

df = pd.DataFrame({
    'texto': ['bug123@email.com falhou', 'teste456 ok', 'erro789@site.com.br']
})

# Extrair só e-mails
df['email'] = df['texto'].str.extract(r'(\w+@\w+\.\w+)')
print(df['email'])
```

**Saída**:

```
0    bug123@email.com
1                NaN
2    erro789@site.com
```

- Outro: Validar CPF (`\d{3}\.\d{3}\.\d{3}-\d{2}`).

### 3️⃣ Dicas empáticas pro seu dia a dia

- **Comece simples**: Teste no [regex101.com](https://regex101.com/) – grátis e visual.
- **Cuidado com performance**: Em dados grandes, regex é lenta; use só o essencial (fonte: **Cappra Institute**, análise exploratória).
- **No seu QA**: Use pra parsear logs de API (`r'ERROR: (\d+)'` pega código de erro).
- **RH**: Extrair "anos exp" de currículos (`r'(\d+) anos'`).
