Processamento em **lotes (batches)** — os dados são coletados, transformados e carregados em **intervalos programados** (a cada 1h, 6h, 1x ao dia, etc.), e não em tempo real.

### ✅ Vantagens

|Vantagem|Por que|
|:--|:--|
|**Mais simples de construir**|Lógica linear, mais fácil de debugar|
|**Menor custo**|Processa uma vez, não fica consumindo recursos 24h|
|**Ideal para grandes volumes**|Pode processar milhões de registros de uma vez|
|**Fácil de auditar**|Cada execução gera um log, um arquivo, um checkpoint|
|**Tolerante a falhas**|Se falha, roda de novo o lote inteiro|

### ❌ Desvantagens

|Desvantagem|Por que|
|:--|:--|
|**Latência**|Dados só ficam prontos na próxima execução|
|**Pico de processamento**|Consome muitos recursos de uma vez|
|**Reprocessamento caro**|Se algo der errado no final, roda tudo de novo|
|**Não serve para tempo real**|Impossível para alertas imediatos ou dashboards ao vivo|
