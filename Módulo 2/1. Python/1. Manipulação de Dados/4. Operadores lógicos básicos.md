
- **Aritméticos** → fazem **conta** (números)
- **Relacionais** → fazem **comparação** (vira True/False)
- **Lógicos** → **combinam** comparações (True/False com True/False)

---

## 🔷 1) Operadores **Aritméticos** (matemática)

- **`+`** soma
- **`-`** subtração
- **`*`** multiplicação
- **`/`** divisão (sempre dá float)
- **`//`** divisão inteira (descarta casas)
- **`%`** módulo (resto da divisão)
- **`**`** potência

```python
a = 10
b = 3

print(a + b)   # 13
print(a - b)   # 7
print(a * b)   # 30
print(a / b)   # 3.333...
print(a // b)  # 3
print(a % b)   # 1
print(a ** b)  # 1000
```

👉 Exemplo QA: calcular % de testes que falharam  
👉 Exemplo RH: calcular média salarial

---

## 🔷 2) Operadores **Relacionais** (comparação)

Eles comparam valores e retornam **True** ou **False**:

- **`==`** igual
- **`!=`** diferente
- **`>`** maior
- **`>=`** maior ou igual
- **`<`** menor
- **`<=`** menor ou igual

```python
idade = 17
print(idade >= 18)  # False
print(idade == 17)  # True
print(idade != 20)  # True
```

👉 Exemplo RH: `anos_exp >= 2`  
👉 Exemplo QA: `tempo_resposta_ms > 500`

---

## 🔷 3) Operadores **Lógicos** (combinação de condições)

- **`and`** ou `&&` (E) → True se **todas** forem True
- **`or`** ou `|| `(OU) → True se **pelo menos uma** for True
- **`not`** ou `! `(NÃO) → inverte True/False

```python
idade = 25
tem_python = True

print(idade >= 18 and tem_python)  # True
print(idade < 18 or tem_python)    # True
print(not tem_python)              # False
```

---

## 🔷 4) Como eles trabalham juntos (exemplo completo)

### ✅ RH: critério de triagem de candidato

Regra: **(idade >= 18) E (experiência >= 2 OU tem_portfolio)**

```python
idade = 22
experiencia = 1
tem_portfolio = True

aprovado = (idade >= 18) and (experiencia >= 2 or tem_portfolio)
print(aprovado)  # True
```

### ✅ QA: priorização de bug

Regra: bug é prioridade máxima se **(é CRÍTICO) E (está ABERTO)**

```python
severidade = "CRITICO"
status = "ABERTO"

prioridade_maxima = (severidade == "CRITICO") and (status == "ABERTO")
print(prioridade_maxima)  # True
```

---

## 🔷 5) Ordem de prioridade (precedência) — importante!

Quando mistura tudo, o Python segue esta ordem (simplificando):

1. **Aritméticos** (`**` depois `* / // %` depois `+ -`)
2. **Relacionais** (`> >= < <= == !=`)
3. **Lógicos** (`not` depois `and` depois `or`)

⚠️ Melhor prática: **use parênteses** para ficar claro.

```python
# Pode confundir sem parênteses
resultado = 10 > 5 and 3 < 1 or 2 == 2

# Melhor (mais legível)
resultado = ((10 > 5) and (3 < 1)) or (2 == 2)
print(resultado)  # True
```
