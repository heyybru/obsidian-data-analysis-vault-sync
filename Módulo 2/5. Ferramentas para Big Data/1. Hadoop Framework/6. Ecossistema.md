### 🔶 Pré-requisitos

- **Homebrew**: Se não tem, rode no Terminal: `/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"`
- **Java 8 ou 11 (ARM)**: Essencial pro Hadoop.
    
    ```bash
    brew install openjdk@11  # Ou openjdk@8
    echo 'export PATH="/opt/homebrew/opt/openjdk@11/bin:$PATH"' >> ~/.zshrc
    source ~/.zshrc
    java -version  # Confirma ARM (aarch64)
    ```
    

### 1️⃣ **Instalação via Homebrew (mais fácil – recomendado pra QA testes)**

```bash
brew install hadoop  # Instala Hadoop 3.x nativo pro M1
```

- **Verifica**: `hadoop version` (deve mostrar 3.3.x ou +).

### 2️⃣ **Config Pseudo-Distributed (pra simular cluster local)**

Edite arquivos em `~/hadoop-3.x.x/etc/hadoop/` (ou via brew path):

```bash
# core-site.xml
<configuration>
  <property>
    <name>fs.defaultFS</name>
    <value>hdfs://localhost:9000</value>
  </property>
</configuration>

# hdfs-site.xml (replication=1 pra single node)
<configuration>
  <property>
    <name>dfs.replication</name>
    <value>1</value>
  </property>
  <property>
    <name>dfs.namenode.name.dir</name>
    <value>file:///tmp/hadoop/dfs/name</value>
  </property>
</configuration>

# mapred-site.xml
<configuration>
  <property>
    <name>mapreduce.framework.name</name>
    <value>yarn</value>
  </property>
</configuration>

# yarn-site.xml
<configuration>
  <property>
    <name>yarn.nodemanager.aux-services</name>
    <value>mapreduce_shuffle</value>
  </property>
</configuration>
```

- **Env vars** em `~/.zshrc`:
    
    ```bash
    export HADOOP_HOME=/opt/homebrew/Cellar/hadoop/3.3.x  # Ajuste path
    export PATH=$PATH:$HADOOP_HOME/bin:$HADOOP_HOME/sbin
    export HADOOP_CONF_DIR=$HADOOP_HOME/etc/hadoop
    source ~/.zshrc
    ```
    

### 3️⃣ **Iniciar e testar**

```bash
# Formata HDFS
hdfs namenode -format

# Inicia HDFS + YARN
start-dfs.sh
start-yarn.sh

# Testa (UI: http://localhost:9870 pra HDFS, :8088 pra YARN)
hdfs dfs -mkdir /input
hdfs dfs -put $HADOOP_HOME/etc/hadoop/*.xml /input/
hadoop jar $HADOOP_HOME/share/hadoop/mapreduce/hadoop-mapreduce-examples-*.jar wordcount /input/ /output/
hdfs dfs -cat /output/*
```

- **Para**: `stop-yarn.sh && stop-dfs.sh`
