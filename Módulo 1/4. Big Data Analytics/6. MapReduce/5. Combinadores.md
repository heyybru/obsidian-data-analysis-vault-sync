## 🔷 A Otimização Inteligente do MapReduce

**Combinadores são como "pré-processadores locais" que reduzem o tráfego de dados antes do shuffle**.  
Em vez de enviar milhões de pares (chave, 1) pela rede, você soma localmente e envia apenas (chave, 1000).

✅ **No seu contexto (RH + QA)**:

- **RH**: Somar candidatos por estado localmente antes de enviar para o reducer
- **QA**: Contar bugs por módulo em cada máquina antes de agregar globalmente

---

## 🔷 1. O Problema que Combinadores Resolvem

### ❌ **Sem combinador (ineficiente)**:

```
Máquina 1: ("python", 1), ("python", 1), ("python", 1), ("java", 1)
Máquina 2: ("python", 1), ("java", 1), ("java", 1), ("c++", 1)

Shuffle envia pela rede:
("python", [1, 1, 1, 1])  → 4 elementos
("java", [1, 1, 1])       → 3 elementos  
("c++", [1])              → 1 elemento

Total: 8 elementos pela rede
```

### ✅ **Com combinador (eficiente)**:

```
Máquina 1 (localmente):
("python", 1), ("python", 1), ("python", 1), ("java", 1)
→ Combinador soma: ("python", 3), ("java", 1)

Máquina 2 (localmente):
("python", 1), ("java", 1), ("java", 1), ("c++", 1)
→ Combinador soma: ("python", 1), ("java", 2), ("c++", 1)

Shuffle envia pela rede:
("python", [3, 1])  → 2 elementos
("java", [1, 2])    → 2 elementos
("c++", [1])        → 1 elemento

Total: 5 elementos pela rede (37.5% menos!)
```

**Economia**: Quanto mais repetições locais, maior a economia!

---

## 🔷 2. Como Funcionam os Combinadores

### ✅ **Localização**:

- Rodam **na mesma máquina** do mapper
- Após o mapper, **antes do shuffle**
- Processam **apenas os dados locais** daquela máquina

### ✅ **Funcionalidade**:

- Recebem saída do mapper: `(chave, valor)`
- Agregam valores **com mesma chave** localmente
- Emitem: `(chave, valor_agregado)`
- Reduzem dados enviados pela rede

### ✅ **Restrições**:

- **Devem ser comutativos**: `f(a, b) = f(b, a)`
- **Devem ser associativos**: `f(f(a, b), c) = f(a, f(b, c))`
- **Não podem mudar a chave**
- **Não podem ter efeitos colaterais**

## 🔷 3. Exemplos de Combinadores Válidos

### ✅ **Soma (válido)**:

```python
def combiner_soma(chave, valores):
    """Soma valores - COMUTATIVO E ASSOCIATIVO"""
    return (chave, sum(valores))

# Teste:
# f(2, 3) = 5, f(3, 2) = 5 ✓ Comutativo
# f(f(1, 2), 3) = f(3, 3) = 6
# f(1, f(2, 3)) = f(1, 5) = 6 ✓ Associativo
```

### ✅ **Contagem (válido)**:

```python
def combiner_contagem(chave, valores):
    """Conta ocorrências - COMUTATIVO E ASSOCIATIVO"""
    return (chave, len(valores))

# Cada valor é 1, contar é como somar
```

### ✅ **Média (INVÁLIDO como combinador)**:

```python
def combiner_media(chave, valores):
    """Média - NÃO PODE SER COMBINER!"""
    return (chave, sum(valores) / len(valores))

# ❌ PROBLEMA: Média de médias ≠ média real
# Exemplo: [(10, 20), (30, 40)]
# Média local 1: (10+20)/2 = 15
# Média local 2: (30+40)/2 = 35  
# Média das médias: (15+35)/2 = 25
# Média real: (10+20+30+40)/4 = 25 ✓ (funciona por coincidência?)

# ❌ REAL PROBLEMA: Tamanhos diferentes
# [(10, 20), (30)] → Médias: 15 e 30 → Média das médias: 22.5
# Real: (10+20+30)/3 = 20 ❌ DIFERENTE!
```

### ✅ **Solução para média**:

```python
def combiner_media_correto(chave, valores):
    """Emite (soma, contagem) para reducer calcular média final"""
    return (chave, (sum(valores), len(valores)))

def reducer_media(chave, pares_soma_contagem):
    """Reducer calcula média global"""
    soma_total = 0
    contagem_total = 0
    
    for soma, contagem in pares_soma_contagem:
        soma_total += soma
        contagem_total += contagem
    
    return (chave, soma_total / contagem_total)
```

## 🔷 4. Implementação em Hadoop

### ✅ **Java - WordCount com Combinador**:

```java
import java.io.IOException;
import org.apache.hadoop.conf.Configuration;
import org.apache.hadoop.fs.Path;
import org.apache.hadoop.io.IntWritable;
import org.apache.hadoop.io.Text;
import org.apache.hadoop.mapreduce.Job;
import org.apache.hadoop.mapreduce.Mapper;
import org.apache.hadoop.mapreduce.Reducer;
import org.apache.hadoop.mapreduce.lib.input.FileInputFormat;
import org.apache.hadoop.mapreduce.lib.output.FileOutputFormat;

public class WordCountWithCombiner {

    // MAPPER (igual)
    public static class TokenizerMapper 
        extends Mapper<Object, Text, Text, IntWritable> {
        
        private final static IntWritable one = new IntWritable(1);
        private Text word = new Text();
        
        public void map(Object key, Text value, Context context
                       ) throws IOException, InterruptedException {
            
            String[] words = value.toString().split(" ");
            for (String w : words) {
                word.set(w.toLowerCase());
                context.write(word, one);  // Emite (palavra, 1)
            }
        }
    }
    
    // COMBINER (igual ao Reducer!)
    public static class IntSumCombiner 
        extends Reducer<Text, IntWritable, Text, IntWritable> {
        
        private IntWritable result = new IntWritable();
        
        public void reduce(Text key, Iterable<IntWritable> values,
                          Context context
                          ) throws IOException, InterruptedException {
            
            int sum = 0;
            for (IntWritable val : values) {
                sum += val.get();  // Soma localmente
            }
            result.set(sum);
            context.write(key, result);  // Emite (palavra, soma_local)
        }
    }
    
    // REDUCER (igual ao Combiner!)
    public static class IntSumReducer 
        extends Reducer<Text, IntWritable, Text, IntWritable> {
        
        private IntWritable result = new IntWritable();
        
        public void reduce(Text key, Iterable<IntWritable> values,
                          Context context
                          ) throws IOException, InterruptedException {
            
            int sum = 0;
            for (IntWritable val : values) {
                sum += val.get();  // Soma globalmente
            }
            result.set(sum);
            context.write(key, result);
        }
    }
    
    // CONFIGURAÇÃO DO JOB
    public static void main(String[] args) throws Exception {
        Configuration conf = new Configuration();
        Job job = Job.getInstance(conf, "word count with combiner");
        
        job.setJarByClass(WordCountWithCombiner.class);
        job.setMapperClass(TokenizerMapper.class);
        
        // ⭐⭐ AQUI ESTÁ A MÁGICA! ⭐⭐
        job.setCombinerClass(IntSumCombiner.class);  // Usa mesma classe do Reducer
        
        job.setReducerClass(IntSumReducer.class);
        
        job.setOutputKeyClass(Text.class);
        job.setOutputValueClass(IntWritable.class);
        
        FileInputFormat.addInputPath(job, new Path(args[0]));
        FileOutputFormat.setOutputPath(job, new Path(args[1]));
        
        System.exit(job.waitForCompletion(true) ? 0 : 1);
    }
}
```

**Ponto crucial**: O combinador é **exatamente a mesma classe** do reducer quando a operação é comutativa e associativa!

## 🔷 5. Implementação em Python (Simulação)

### ✅ **Simulação completa**:

```python
from collections import defaultdict
import random

class MapReduceWithCombiner:
    def __init__(self, num_mappers=3):
        self.num_mappers = num_mappers
    
    def split_data(self, data):
        """Divide dados entre mappers"""
        chunk_size = len(data) // self.num_mappers
        chunks = []
        
        for i in range(self.num_mappers):
            start = i * chunk_size
            end = start + chunk_size if i < self.num_mappers - 1 else len(data)
            chunks.append(data[start:end])
        
        return chunks
    
    def mapper(self, chunk):
        """Processa um pedaço dos dados"""
        results = []
        for line in chunk:
            words = line.lower().split()
            for word in words:
                results.append((word, 1))
        return results
    
    def combiner(self, mapper_output):
        """Agrega localmente na máquina do mapper"""
        local_counts = defaultdict(int)
        
        for word, count in mapper_output:
            local_counts[word] += count
        
        # Converte para lista de pares
        return [(word, count) for word, count in local_counts.items()]
    
    def shuffle(self, all_combined_outputs):
        """Agrupa por chave (simulação de rede)"""
        grouped = defaultdict(list)
        
        for combined_output in all_combined_outputs:
            for word, count in combined_output:
                grouped[word].append(count)
        
        return grouped
    
    def reducer(self, shuffled_data):
        """Soma final global"""
        final_counts = {}
        
        for word, counts in shuffled_data.items():
            final_counts[word] = sum(counts)
        
        return final_counts
    
    def run(self, data):
        """Executa pipeline completo"""
        print("🚀 INICIANDO MAPREDUCE COM COMBINER")
        print(f"Dados: {len(data)} linhas, {sum(len(l.split()) for l in data)} palavras")
        print(f"Mappers: {self.num_mappers}")
        
        # 1. Split
        chunks = self.split_data(data)
        print(f"\n📂 Split: {len(chunks)} chunks")
        
        # 2. Map (paralelo simulado)
        mapper_outputs = []
        for i, chunk in enumerate(chunks):
            output = self.mapper(chunk)
            mapper_outputs.append(output)
            print(f"  Mapper {i+1}: {len(output)} pares (chave, 1)")
        
        # 3. Combine (local em cada mapper)
        combined_outputs = []
        total_before_combine = 0
        total_after_combine = 0
        
        for i, mapper_output in enumerate(mapper_outputs):
            total_before_combine += len(mapper_output)
            combined = self.combiner(mapper_output)
            combined_outputs.append(combined)
            total_after_combine += len(combined)
            print(f"  Combiner {i+1}: {len(mapper_output)} → {len(combined)} pares")
        
        # 4. Shuffle
        shuffled = self.shuffle(combined_outputs)
        print(f"\n🔀 Shuffle: {len(shuffled)} chaves únicas")
        
        # 5. Reduce
        final_result = self.reducer(shuffled)
        
        # Estatísticas
        economia = (1 - (total_after_combine / total_before_combine)) * 100
        print(f"\n📊 ESTATÍSTICAS:")
        print(f"  Antes do combinador: {total_before_combine} pares")
        print(f"  Depois do combinador: {total_after_combine} pares")
        print(f"  Economia de rede: {economia:.1f}%")
        print(f"  Palavras únicas: {len(final_result)}")
        
        return final_result

# Teste

    "java scala kotlin python",
    "python python python java",
    "scala kotlin kotlin",
    "python java scala python java",

    print(f"  {word}: {count}")
```

## 🔷 6. Quando Usar Combinadores

### ✅ **Use quando**:

1. **Operação comutativa e associativa**: soma, contagem, máximo, mínimo
2. **Muitas repetições locais**: mesma chave aparece muitas vezes no mesmo mapper
3. **Dados grandes**: economia de rede significativa
4. **Shuffle caro**: muita transferência de dados entre máquinas

### ✅ **Exemplos perfeitos**:

```python
# 1. Soma de valores
def combiner_soma(chave, valores):
    return (chave, sum(valores))

# 2. Contagem
def combiner_contagem(chave, valores):
    return (chave, len(valores))

# 3. Máximo
def combiner_maximo(chave, valores):
    return (chave, max(valores))

# 4. Mínimo  
def combiner_minimo(chave, valores):
    return (chave, min(valores))

# 5. Concatenação de strings (se ordem não importa)
def combiner_concat(chave, valores):
    return (chave, ''.join(sorted(valores)))  # Ordena para ser determinístico
```

### ❌ **NÃO use quando**:

1. **Média simples** (use soma+contagem)
2. **Mediana** (não é associativa)
3. **Moda** (pode perder informação local)
4. **Operações que dependem de ordem**
5. **Operações com estado global**

### ✅ **Média com combinador**:

```python
def mapper_media(dado):
    """Emite (chave, (valor, 1))"""
    chave = extrair_chave(dado)
    valor = extrair_valor(dado)
    yield (chave, (valor, 1))

def combiner_media(chave, pares):
    """Soma valores e contagens localmente"""
    soma_local = 0
    contagem_local = 0
    
    for valor, contagem in pares:
        soma_local += valor
        contagem_local += contagem
    
    yield (chave, (soma_local, contagem_local))

def reducer_media(chave, pares_soma_contagem):
    """Calcula média global"""
    soma_total = 0
    contagem_total = 0
    
    for soma, contagem in pares_soma_contagem:
        soma_total += soma
        contagem_total += contagem
    
    media = soma_total / contagem_total
    yield (chave, media)
```

```python
    """Mantém conjunto de hashes únicos localmente"""
```
