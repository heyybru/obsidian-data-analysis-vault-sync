# **1. Tabelas para organizar dados simples**

Quando você só precisa listar informações de forma clara.

**• Tabela Simples**  
Linhas e colunas básicas.  
**Ex.:** nome, área, idade, salário.

**• Tabela de Frequência Simples**  
Mostra quantas vezes algo aparece.  
**Ex.:** quantidade de funcionários por área.

# **2. Tabelas para comparar categorias**

Quando você quer cruzar informações.

**• Tabela de Dupla Entrada (Cruzada)**  
Cruzamento de duas variáveis.  
**Ex.:** área × tipo de contrato.

**• Tabela de Contingência**  
Tipo de tabela cruzada usada para análises estatísticas.  
**Ex.:** gênero × aprovação em treinamento.

# **3. Tabelas para análises mais detalhadas**

Quando você precisa aprofundar ou estruturar análises.

**• Tabela de Frequência Absoluta e Relativa**  
Mostra quantidade (absoluta) e porcentagem (relativa).  
**Ex.:** % de colaboradores por faixa etária.

**• Tabela de Distribuição de Classes**  
Divide dados numéricos em faixas (classes).  
**Ex.:** idades de 20–25, 26–30, 31–35…

# **4. Tabelas usadas em estatística descritiva**

Para mostrar medidas importantes.

**• Tabela com Medidas de Tendência Central**  
Média, mediana, moda.  
**Ex.:** salário médio por área.

**• Tabela com Medidas de Dispersão**  
Desvio padrão, variância, amplitude.  
**Ex.:** variação salarial dentro de uma área.

# **5. Tabelas usadas em análises temporais**

Quando os dados mudam com o tempo.

**• Séries Temporais (tabela temporal)**  
Uma coluna de tempo e outra com valores.  
**Ex.:** headcount mês a mês.

# **Resumo rápido**

- **Listar dados:** tabela simples
- **Contar ocorrências:** frequência
- **Cruzar variáveis:** dupla entrada / contingência
- **Distribuições:** classes
- **Estatísticas:** média, mediana, dispersão
- **Tempo:** séries temporais
