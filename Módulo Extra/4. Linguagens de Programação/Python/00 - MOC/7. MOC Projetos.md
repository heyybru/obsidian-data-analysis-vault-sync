# MOC — Projetos e RH

## Projetos do curso
```dataview
TABLE WITHOUT ID
  file.link AS "Nota",
  status AS "Status"
FROM ""
WHERE contains(file.name, "Projeto")
SORT file.name ASC
```

## Aplicações de RH por área

```dataview
TABLE WITHOUT ID
  key AS "Área de RH",
  length(rows) AS "Notas",
  length(filter(rows.status, (s) => s = "concluído")) AS "Feitas"
FROM "06 - RH e Dados"
GROUP BY area_rh
SORT key ASC
```

## Aplicações por tipo de vaga

```dataview
TABLE WITHOUT ID
  key AS "Tipo de vaga",
  length(rows) AS "Notas"
FROM "06 - RH e Dados"
WHERE tipo_vaga
GROUP BY tipo_vaga
SORT length(rows) DESC
```

## Recrutamento e Seleção - visão de funil

```dataview
TABLE WITHOUT ID
  file.link AS "Prática",
  tipo_vaga AS "Vaga",
  status AS "Status"
FROM "06 - RH e Dados"
WHERE area_rh = "recrutamento"
SORT status ASC, file.name ASC
```
## People Analytics

## Todas as aplicações de RH

## Pendentes de RH

```dataview
LIST WITHOUT ID file.link
FROM "06 - RH e Dados"
WHERE status != "concluído"
SORT file.name ASC
```
