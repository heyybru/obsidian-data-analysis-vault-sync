**Herança** é quando uma classe (**filha/subclasse**) reaproveita e estende uma classe (**pai/superclasse**).  
A filha **herda atributos e métodos** do pai e pode:

- usar do jeito que está
- **sobrescrever** (override) para mudar comportamento
- **adicionar** novas coisas

---

## 1) Por que usar herança?

Use herança quando existe uma relação clara de **“é um(a)”**:

- `TesteManual` **é um** `Teste`
- `TesteAutomatizado` **é um** `Teste`
- `Funcionario` **é uma** `Pessoa`

Se for mais “**tem um(a)**” (composição), aí herança pode não ser a melhor.

---

## 2) Exemplo prático (QA): `Teste` → `TesteManual` e `TesteAutomatizado`

```python
class Teste:
    def __init__(self, nome):
        self.nome = nome
        self.passou = None

    def executar(self):
        raise NotImplementedError("Implemente em uma subclasse")

    def resumo(self):
        return f"{self.nome} | passou={self.passou}"
```

### Subclasses herdando e implementando `executar()`

```python
class TesteManual(Teste):
    def executar(self, resultado):
        self.passou = bool(resultado)

class TesteAutomatizado(Teste):
    def executar(self):
        # aqui seria a automação real
        self.passou = True
```

Uso:

```python
t1 = TesteManual("Login")
t1.executar(True)

t2 = TesteAutomatizado("Cadastro")
t2.executar()

print(t1.resumo())
print(t2.resumo())
```

✅ `TesteManual` e `TesteAutomatizado` **herdam** `nome`, `passou` e `resumo()` de `Teste`.

## 3) `super()` (reutilizar o construtor do pai)

Quando a subclasse tem atributos extras, você chama o `__init__` do pai:

```python
class Bug:
    def __init__(self, bug_id, severidade):
        self.bug_id = bug_id
        self.severidade = severidade

class BugComponente(Bug):
    def __init__(self, bug_id, severidade, componente):
        super().__init__(bug_id, severidade)  # inicializa parte do pai
        self.componente = componente          # parte nova

b = BugComponente(101, "CRITICO", "Login")
print(b.bug_id, b.severidade, b.componente)
```

---

## 4) Sobrescrevendo (override) um método do pai

```python
class TesteAutomatizado(Teste):
    def resumo(self):
        return f"[AUTO] {super().resumo()}"
```

✅ Aqui a subclasse muda o comportamento de `resumo()`, mas ainda reaproveita a versão do pai com `super()`.

---

## 5) Como saber a “cadeia” de herança (debug/estudo)

```python
print(TesteAutomatizado.mro())
```

Isso mostra a ordem em que o Python procura métodos/atributos (Method Resolution Order).

---

## 📋 Resumindo

- Herança = subclasse reaproveita e estende a superclasse.
- Útil quando é relação **“é um(a)”**.
- Use `super()` para aproveitar o construtor/métodos do pai.
- Subclasse pode **sobrescrever** métodos para mudar comportamento.
