## **1. Média Simples**

É o valor mais conhecido: a **soma de todos os valores dividida pela quantidade**.

### **Fórmula**

Média = soma dos valores / quantidade de valores
(x = soma de xi numeros / n)

"xi"​ são os elementos;  
"n" é a quantidade de elementos
**"x"** é a média.

### **Exemplo**

Salários: 2.000, 3.000, 4.000

x = 2000 + 3000 + 4000 / 3
x = 3000

📌 A média simples é **3.000**.

---

## **2. Média Ponderada**

É usada quando **alguns valores têm mais peso (importância)** do que outros.

### **Fórmula**

x = (x1* p1) + (x2 * p2) + ... / p1 + p2 + ...

"xi"​ são elementos;  
"pi" são pesos;
"x" é a média.
### **Exemplo**

Notas de um aluno:

- Prova: 8 (peso 2)
    
- Trabalho: 6 (peso 1)
    

x = (8 * 2) + (6 * 1) / 2 + 1
x = 16 + 6 / 3
x = 7,33

📌 A média ponderada é **7,33**.

---

## **Resumo rápido**

- **Média simples:** todos os valores têm o mesmo peso
    
- **Média ponderada:** alguns valores valem mais que outros

Podemos calcular a média a partir da tabela de distribuição de frequência, a ideia é a mesma, neste caso teremos sempre uma média ponderada, onde o ∫i será sempre o peso, e a informação analisada serão os elementos.
