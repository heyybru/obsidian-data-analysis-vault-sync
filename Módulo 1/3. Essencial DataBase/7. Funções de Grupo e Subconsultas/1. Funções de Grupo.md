## O que são?

São funções que **trabalham com várias linhas** e retornam **um único resultado**.

👉 Muito usadas para **análise de dados**.

---

## 🔹 Principais Funções de Grupo

### 🔢 `COUNT()`

Conta registros.

```sql
SELECT COUNT(*) 
FROM employee;
```

📌 Conta todas as linhas (inclusive com NULL).

```sql
SELECT COUNT(salary)
FROM employee;
```

📌 Conta apenas salários **não nulos**.

---

### ➕ `SUM()`

Soma valores numéricos.

```sql
SELECT SUM(salary)
FROM employee;
```

---

### ➗ `AVG()`

Calcula a média.

```sql
SELECT AVG(salary)
FROM employee;
```

---

### 🔽 `MIN()`

Retorna o menor valor.

```sql
SELECT MIN(salary)
FROM employee;
```

---

### 🔼 `MAX()`

Retorna o maior valor.

```sql
SELECT MAX(salary)
FROM employee;
```

---

## 🔹 Usando Funções de Grupo com `GROUP BY`

Usado quando queremos **resumo por categoria**.

```sql
SELECT department_id, COUNT(*)
FROM employee
GROUP BY department_id;
```

📌 Quantidade de funcionários por departamento.

---

### ⚠ Regra de ouro do `GROUP BY`

👉 Todo campo no `SELECT` que **não é função de grupo** deve estar no `GROUP BY`.

❌ Errado:

```sql
SELECT department_id, name, COUNT(*)
FROM employee
GROUP BY department_id;
```

✅ Certo:

```sql
SELECT department_id, COUNT(*)
FROM employee
GROUP BY department_id;
```

---

## 🔹 Filtrando grupos com `HAVING`

`WHERE` → filtra linhas  
`HAVING` → filtra grupos

```sql
SELECT department_id, AVG(salary)
FROM employee
GROUP BY department_id
HAVING AVG(salary) > 5000;
```

---

## 🧠 Pegadinha 

- ❌ Não usar `HAVING` sem `GROUP BY`
    
- ❌ Misturar campo comum sem agrupar
    
- ✔ `COUNT(*)` conta tudo
    
- ✔ `COUNT(campo)` ignora NULL

---

## 📘 Resumo Rápido

- Funções de grupo resumem dados
    
- `GROUP BY` agrupa
    
- `HAVING` filtra grupos
