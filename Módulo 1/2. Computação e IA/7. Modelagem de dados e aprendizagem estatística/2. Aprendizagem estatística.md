> [!info] 
> **O que é:** a união da **estatística com o machine learning**. As máquinas aprendem com dados de experiências passadas, e a análise estatística desses dados é o que permite fazer **previsões**. 

🔑 **Analogia:** é como **prever o tempo**. Você não observa todos os dias do ano — usa os dados dos dias passados (estatística) para prever se vai chover amanhã.

**Ponto-chave (do material):** a **quantidade e a qualidade** dos dados e da estatística determinam a **acurácia** (precisão) das previsões. Dados ruins = previsões ruins.

**Dois tipos de aprendizado supervisionado (do material):**

- **Classificação:** mapeia entradas em **categorias** (ex.: "aprovado" ou "reprovado")
- **Regressão:** prevê um **número** (ex.: salário esperado)

**Regressão linear:** busca uma função que determina o valor de **Y** (resultado) a partir de um conjunto de variáveis **X** (entradas). Se a reta não ajusta bem os dados, usa-se regressão **não linear**.

**Ferramentas (do material):** as linguagens mais usadas são **R e Python**.
