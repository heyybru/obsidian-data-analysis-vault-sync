# MOC — Trilha Geral

Painel de entrada do vault. Progresso, pendências e atalhos.

## Progresso por pasta

```dataview
TABLE WITHOUT ID
  file.folder AS "Pasta",
  length(rows) AS "Notas"
WHERE contains(file.folder, "0") OR contains(file.folder, "9")
GROUP BY file.folder
SORT file.folder ASC
```

## Notas por status

```` dataview
TABLE WITHOUT ID status AS "Status", length(rows) AS "Qtd"
WHERE contains(file.folder, "0")
GROUP BY status
SORT status ASC
````

## Precisam de atenção

```dataview
TABLE WITHOUT ID file.link AS "Nota", status AS "Status"
WHERE contains(file.folder, "0")
WHERE status != "concluído"
SORT file.name ASC
LIMIT 25
```
## Marcadas para revisar

```dataview
TABLE WITHOUT ID file.link AS "Nota", file.mtime AS "Editada"
WHERE file.mtime >= date(today) - dur(2 days)
SORT file.mtime DESC
```

## Editadas nos últimos 7 dias

```dataview
TABLE WITHOUT ID
  file.link AS "Nota",
  file.mtime AS "Quando"
FROM ""
WHERE file.mtime >= date(today) - dur(7 days)
SORT file.mtime DESC
LIMIT 15
```
