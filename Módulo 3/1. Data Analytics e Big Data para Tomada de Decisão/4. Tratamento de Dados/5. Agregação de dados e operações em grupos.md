### **O Que é Agregação e Grupos?**

- **Agregação**: Calcular resumos (soma, média, count, max/min) em dados.
- **Grupos**: Dividir dataset por categoria (ex: vendas por produto) e agregar.
- **Por quê?**: Resume big data pra decisões (ex: média vendas/mês, **Metricas Boss** benchmarks: +50% eficiência análise).

### **Operações Comuns**

- **Soma/Count**: Total vendas/produto.
- **Média/Mediana**: Preço médio por categoria.
- **Max/Min**: Pico baixo por grupo. Ex: Dataset vendas → Grupo "produto": soma valor, média preço.

### **Como Fazer no Google Sheets (Manual)**

1. Selecione dados.
2. Inserir > Tabela Dinâmica.
3. Linhas: Produto; Valores: Soma Valor, Média Preço. Ex: Vendas → "Produto | Soma Valor | Média Preço" (Laptop: 50k soma, 5k média).

### **Exemplo Prático em Pandas (Python)**

```python
import pandas as pd

df = pd.read_csv('vendas.csv')  # Cols: produto, valor, mes

# Agregação por grupo
agregado = df.groupby('produto').agg({
    'valor': ['sum', 'mean', 'count'],
    'mes': 'nunique'  # Únicos
}).round(2)

print(agregado)
```

**Saída exemplo**:

```
       valor             mes
         sum   mean count nunique
produto                       
Laptop  50000  5000    10       3
Mouse    5000   500     10       3
```

**Insight**: Laptop domina soma – estoque foco (**Snaq.co** análise).

### **Dicas e Cuidados**

- **Pré-agregue**: Limpe nulls (df.fillna(0)).
- **Multi-nível**: groupby(['produto', 'mes']).
- **Performance**: Dados grandes? Use SQL GROUP BY (**AILabs** tip).
