[Apache Sqoop](https://docs.aws.amazon.com/pt_br/emr/latest/ReleaseGuide/emr-sqoop.html)

**Apache Sqoop** (SQL-to-Hadoop) é uma ferramenta da família Apache para **migrar dados entre bancos relacionais (SQL)** e o **ecossistema Hadoop/HDFS**. O nome já diz tudo: leva dados do seu banco relacional pro Hadoop e vice-versa.

### ⚠️ Ponto crítico que o material destaca

O Sqoop está **aposentado** — foi movido para o **Apache Attic** (o "cemitério" de projetos Apache que não recebem mais atualizações). Isso significa:

|Status|O que muda|
|:--|:--|
|**Projetos existentes**|Continuam funcionando normalmente|
|**Novos projetos**|⚠️ Não recomendado — prefira alternativas modernas|
|**Atualizações**|Zero — sem correções de segurança, sem novas features|
|**Suporte**|Nenhum — se quebrar, você está por conta própria|

> 💡 O material deixa claro: Sqoop ainda aparece em conteúdo educacional porque tem **projetos legados rodando**, mas a indústria já migrou pra ferramentas mais modernas.

### Como ele funciona

Sqoop usa o **paradigma MapReduce** pra fazer a conversão e movimentação dos dados. Ele pega uma tabela SQL, divide o trabalho em mapeadores paralelos, e escreve no HDFS (ou vice-versa).

```text
┌──────────────────┐      ┌──────────────┐      ┌──────────────────┐
│  Banco Relacional │ ──→  │  Apache Sqoop│ ──→  │   HDFS/Hadoop    │
│  (MySQL, Postgres)│ ←──  │  (MapReduce) │ ←──  │   (Hive, HBase)  │
└──────────────────┘      └──────────────┘      └──────────────────┘
```

### Por que precisa de uma ferramenta específica?

O material usa uma analogia muito boa: abrir uma imagem `.jpg` no Bloco de Notas. O sistema de arquivos relacional (MySQL, Postgres) organiza os dados de um jeito, o HDFS organiza de outro completamente diferente — **não é só copiar o arquivo**, precisa converter a estrutura inteira.

### A Tabela 1 do material: HDFS vs Sistema de Arquivos Relacional

|Característica|HDFS|Sistema Relacional|
|:--|:--|:--|
|Propósito|Armazenamento distribuído para Big Data|Armazenamento estruturado com relações|
|Escrita|Append-only (só adiciona)|Update, Delete, Insert|
|Esquema|Schema-on-read (lê e interpreta)|Schema-on-write (esquema rígido ao inserir)|
|Formato|Arquivos (CSV, Parquet, Avro)|Tabelas com colunas e linhas|
