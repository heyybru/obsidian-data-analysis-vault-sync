## Introdução

Depois de instalar o PostgreSQL, você precisa de um jeito prático de **conversar com o banco**. É aí que entra o **==pgAdmin 4==** — a ferramenta que vamos usar no curso inteiro. Vamos ver o que ele é e como acessar o banco **`Northwind`** por ele, passo a passo.

## O que é o pgAdmin 4?

O **pgAdmin 4** é a **interface gráfica oficial do PostgreSQL**. Em vez de digitar comandos numa tela preta de terminal, você usa janelas, menus e botões para:

- **Conectar** ao servidor do banco.
- **Visualizar** bancos, tabelas e colunas de forma organizada.
- **Escrever e executar** consultas SQL com um editor de texto.
- **Ver os resultados** das consultas em formato de tabela.

💡 **Analogia:** se o PostgreSQL é o "motor" do carro, o pgAdmin 4 é o **painel** — é onde você vê o que está acontecendo e controla tudo sem abrir o capô.

## Passos para abrir e acessar o PostgreSQL

**1. Abra o pgAdmin 4** Procure no menu Iniciar (Windows) ou no Launchpad (macOS) pelo ícone do pgAdmin 4 e clique para abrir. Ele abre no navegador ou em uma janela própria, dependendo da versão.

**2. Conecte ao servidor local** Na tela inicial, no painel à esquerda, você verá o item **Servers** (Servidores). Clique no sinal de **+** ao lado dele para expandir, e depois clique com o botão direito em **PostgreSQL 18** e escolha **Connect Server** (ou **Connect**).

**3. Digite a senha do `postgres`** Será pedida a **senha do superusuário** que você definiu durante a instalação. Digite e clique em **OK**. Se quiser, marque a opção de salvar a senha para não digitar toda vez.

**4. Explore a árvore de objetos** Com a conexão feita, expanda **Databases** → **postgres**. Você verá os itens: **Schemas** (esquemas), **Tables** (tabelas), **Views**, entre outros. É aqui que você "navega" pelo banco.

**5. Visualize as tabelas** Para ver as tabelas, expanda **Schemas** → **public** → **Tables**. Clique com o botão direito em uma tabela (ex.: `products`) e escolha **View/Edit Data** → **All Rows**. As linhas da tabela aparecem na tela.

**6. Abra o Query Tool para escrever SQL** Clique com o botão direito em **Databases → postgres** e escolha **Query Tool** (Ferramenta de Consulta). Um editor de texto abre — é nele que você vai escrever comandos como:

```sql
SELECT * FROM products;
```

Para executar, pressione **F5** ou clique no botão ▶️ **Execute**. O resultado aparece no painel inferior.

## Conclusão

O pgAdmin 4 é a sua **porta de entrada** para o PostgreSQL: ele conecta, mostra os dados e permite rodar consultas sem complicação. O fluxo essencial é: **abrir → conectar com a senha → navegar nas tabelas → usar o Query Tool para rodar SQL**. Dominar esses passos agora deixa os próximos módulos (queries, filtros, joins) muito mais tranquilos.
