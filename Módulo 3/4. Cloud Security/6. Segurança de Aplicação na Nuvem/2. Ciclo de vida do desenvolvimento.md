Como você atua em **QA**, este tópico é a sua "casa". O material destaca que sistemas complexos exigem metodologias estruturadas.

- **Metodologia Cascata (Waterfall):** A forma clássica onde cada etapa (Planejamento → Análise → Projeto → Implementação → **Testes** → Implantação → Manutenção) é entrada para a próxima.
- **Foco em QA:** A fase de **Integração e Testes** é onde você atua para evitar bugs, erros de interoperabilidade e vulnerabilidades antes que o software vá para produção.
- **Segurança no Ciclo:** O material reforça que a segurança deve ser validada em cada uma dessas etapas, não apenas no final.
