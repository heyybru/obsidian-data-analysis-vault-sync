O **AWS IAM (Identity and Access Management)** é a ferramenta central da AWS para gerenciar esse ecossistema.

- **Privilégio Mínimo:** O IAM permite aplicar o princípio de conceder ao usuário apenas os privilégios estritamente necessários para sua função.
- **Gestão de Perfis:** Permite criar grupos e funções (Roles) para facilitar a gestão de grandes volumes de usuários.
- **Conformidade:** Ajuda a cumprir exigências de auditoria ao centralizar o controle de quem pode operar os recursos da nuvem (servidores, bancos de dados, buckets S3).
