[Apache Kafka](https://kafka.apache.org/)

O Apache Kafka é uma plataforma de **streaming de eventos distribuída** projetada para lidar com fluxos de dados em tempo real com alta taxa de transferência e baixa latência.

### 🧠 Conceitos Fundamentais do Material

- **Dados Unbounded (Ilimitados):** Dados que não têm fim (ex: cliques em um site, logs de sistema, novas candidaturas entrando). O Kafka foi feito para processar esse fluxo contínuo.
- **Desacoplamento de Sistemas:** Em arquiteturas antigas, cada sistema conversava diretamente com o outro, gerando uma teia complexa. O Kafka funciona como um "hub central", onde quem produz dados não precisa saber quem vai consumi-los.
- **Tópicos (Topics):** É como o Kafka organiza as mensagens. Pense neles como "pastas" ou "canais" específicos (ex: um tópico chamado `novas_candidaturas`).

### ⚙️ Características Técnicas do Kafka

- **Escalabilidade:** Os tópicos são divididos em **partições** distribuídas por vários servidores (Brokers).
- **Retenção Configurável:** As mensagens não somem após serem lidas; elas ficam guardadas pelo tempo que você definir (ex: 7 dias).
- **Múltiplos Consumidores:** Vários sistemas podem ler o mesmo tópico ao mesmo tempo sem que um atrapalhe o outro.
- **Replicação Automática:** Garante tolerância a falhas. Se um servidor cair, outro assume com os mesmos dados.
- **Protocolo Binário sobre TCP:** Garante extrema rapidez no envio das mensagens.
