### 🔶 Como funciona?

- Pandas usa regex via métodos **`.str`** (ex: `str.contains()`, `str.replace()`).
- Internamente, chama o módulo `re` do Python.
- **Vantagem**: Vetorizado (rápido em DataFrames grandes), sem loops manuais.

**Import básico:**

```python
import pandas as pd
import re  # Opcional, Pandas usa internamente
```

---

### 1️⃣ **Busca/Validação: `str.contains()`**

Verifica se o padrão existe (retorna True/False/NaN).

👉 **Exemplo QA: Detectar erros em logs**

```python
df = pd.DataFrame({'log': ['ERROR 404', 'OK 200', 'WARNING 500']})
df['tem_erro'] = df['log'].str.contains(r'ERROR|WARNING', case=False)
print(df)
```

**Saída:**

```
         log  tem_erro
0   ERROR 404      True
1      OK 200     False
2  WARNING 500      True
```

---

### 2️⃣ **Substituição: `str.replace()`**

Troca padrões por algo novo.

👉 **Exemplo RH: Limpar CPFs**

```python
df = pd.DataFrame({'texto': ['123.456.789-00', 'Meu CPF 987.654.321-11']})
df['cpf_limpo'] = df['texto'].str.replace(r'\D', '', regex=True)  # Remove não-dígitos
print(df['cpf_limpo'])
```

**Saída:** `12345678900` e `98765432111`

---

### 3️⃣ **Extração: `str.extract()`**

Pega grupos de padrões (ótimo pra capturar dados).

👉 **Exemplo: Extrair e-mails**

```python
df = pd.DataFrame({'mensagem': ['Contato: user@ex.com', 'E-mail: teste@site.br']})
df['email'] = df['mensagem'].str.extract(r'(\w+@\w+(?:\.\w+)+)')
print(df['email'])
```

**Saída:**

```
0    user@ex.com
1  teste@site.br
```

---

### 4️⃣ **Dicas práticas pro seu dia a dia**

- **Flags**: Use `case=False` pra ignorar maiúsc/minúsc; `regex=True` (padrão).
- **Múltiplas colunas**: `df.filter(like='coluna').apply(lambda x: x.str.replace(...))`.
- **Performance**: Em dados grandes, compile com `re.compile()` e use vetorizado.
- **QA**: `r'BUG-(\d+)'` pra extrair IDs de JIRA.
- **RH**: `r'(\d{2})\.(\d{3})\.(\d{3})-(\d{2})'` pra validar CPF.
- **Teste**: [regex101.com](https://regex101.com/) + Pandas playground.
