### **O Que é Plotagem e Visualização?**

- **Plotagem**: Gerar gráficos (linhas, barras, scatter) de dados tratados.
- **Visualização**: Comunicar padrões (tendências, outliers) pra negócios.
- **Por quê?**: Humanos processam visuals 60k x mais rápido que texto (**Metricas Boss** benchmarks).

### **Tipos Principais de Plots**

- **Linha**: Tendências tempo (ex: vendas por mês).
- **Barra**: Comparações categóricas (ex: vendas por produto).
- **Scatter**: Correlações (ex: preço x quantidade).
- **Histograma**: Distribuições (ex: idades).

### **Como Fazer em Python (Matplotlib/Seaborn)**

```python
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv('dados.csv')  # Ex: cols 'mes', 'vendas'

# Linha simples
plt.plot(df['mes'], df['vendas'])
plt.title('Vendas por Mês')
plt.show()

# Seaborn avançado (scatter com cor)
sns.scatterplot(data=df, x='preco', y='quantidade', hue='produto')
plt.show()
```

**Exemplo saída**: Linha subindo → tendência crescimento!

### **Dicas e Cuidados**

- **Pré-plot**: Limpe dados (nulls, outliers) – use `df.dropna()`.
- **Estilo**: Labels, cores, temas (sns.set_style('darkgrid')).
- **Interativo**: Plotly pra zoom (df.plotly()).
- **Insight**: Visual revela clusters ocultos (**Snaq.co** análise: +50% detecção padrões).
