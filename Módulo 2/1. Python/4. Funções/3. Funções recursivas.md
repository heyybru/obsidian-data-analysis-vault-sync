Uma **função recursiva** é uma função que **chama ela mesma** para resolver um problema em partes menores.

Pense assim: você resolve “o problema grande” reduzindo para um “problema menor do mesmo tipo”, repetindo até chegar num caso simples.

---

## 🔷 1) As 2 regras obrigatórias da recursão

1. **Caso base**: condição que **para** a recursão (senão vira loop infinito).
2. **Passo recursivo**: chamada da função com um problema **menor**.

Sem caso base, você tende a cair em `RecursionError`.

---

## 🔷 2) Exemplo clássico: fatorial

$$n! = n \cdot (n-1)! \quad \text{e} \quad 0! = 1$$

```python
def fatorial(n):
    if n < 0:
        raise ValueError("n deve ser >= 0")
    if n == 0:
        return 1  # caso base
    return n * fatorial(n - 1)  # passo recursivo

print(fatorial(5))  # 120
```

---

## 🔷 3) Exemplo: soma de uma lista (recursivo)

```python
def soma_lista(nums):
    if not nums:
        return 0
    return nums[0] + soma_lista(nums[1:])

print(soma_lista([1, 2, 3, 4]))  # 10
```

⚠️ Observação: usar `nums[1:]` cria novas listas e pode ficar lento em listas grandes.

## 🔷 4) Recursão com “árvore” (muito comum em dados/JSON)

👉 Cenário real: você recebe um JSON com vários níveis e quer contar quantos “bugs” existem em qualquer nível.

```python
def contar_bugs(dado):
    if isinstance(dado, dict):
        total = 0
        for v in dado.values():
            total += contar_bugs(v)
        return total

    if isinstance(dado, list):
        return sum(contar_bugs(item) for item in dado)

    # caso base: não é lista nem dict
    return 1 if dado == "BUG" else 0

exemplo = {
    "release": "1.0",
    "modulos": [
        {"nome": "login", "itens": ["OK", "BUG", "OK"]},
        {"nome": "pagamento", "itens": ["BUG", "BUG"]},
    ]
}

print(contar_bugs(exemplo))  # 3
```

---

## 🔷 5) Recursão vs laço (quando usar de verdade)

✅ Recursão faz sentido quando:

- o problema é naturalmente **hierárquico** (árvores, pastas, JSON aninhado)
- você quer uma solução curta e clara

⚠️ Evite recursão quando:

- é uma simples repetição que um `for/while` resolve
- o volume pode ser grande (limite padrão de recursão em Python costuma ser ~1000 chamadas)

## 🔷 6) Pegadinha: esquecimento do caso base

```python
def ruim(n):
    return ruim(n-1)  # ❌ nunca para
```

Isso estoura a pilha e dá `RecursionError`.
