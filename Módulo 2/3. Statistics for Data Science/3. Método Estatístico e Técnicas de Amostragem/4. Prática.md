## Prática com Python: 3 tipos de amostragem em um DataFrame

### O que você vai fazer

- criar um dataset exemplo (candidatos)
- tirar:
    - **amostra aleatória simples**
    - **amostra estratificada** (por etapa do funil)
    - **amostra sistemática** (cada k-ésimo)
- comparar a distribuição de “etapa” em cada amostra

### Código

```python
import pandas as pd
import numpy as np

rng = np.random.default_rng(42)

# Dataset exemplo: 500 candidatos
n = 500
df = pd.DataFrame({
    "candidate_id": np.arange(1, n+1),
    "etapa_funil": rng.choice(
        ["Triagem", "Entrevista Técnica", "Final", "Oferta"],
        size=n,
        p=[0.45, 0.35, 0.15, 0.05]  # distribuição desigual de propósito
    ),
    "canal_origem": rng.choice(["LinkedIn", "Indicação", "Site", "Outro"], size=n),
    "tempo_para_primeiro_contato_horas": rng.gamma(shape=2.0, scale=6.0, size=n).round(1)
})

# Função para ver distribuição (para checar representatividade)
def distribuicao_etapa(nome, amostra):
    dist = amostra["etapa_funil"].value_counts(normalize=True).mul(100).round(1)
    print(f"\n{nome} | n={len(amostra)}")
    print(dist.to_string())

print("Distribuição na população (df):")
distribuicao_etapa("População", df)

# 1) Amostragem aleatória simples
amostra_aleatoria = df.sample(n=80, random_state=42)
distribuicao_etapa("Amostra aleatória simples", amostra_aleatoria)

# 2) Amostragem estratificada (por etapa_funil) - proporcional ao tamanho do estrato
# Define o tamanho total desejado e distribui proporcionalmente
tamanho_total = 80
proporcoes = df["etapa_funil"].value_counts(normalize=True)

# calcula n por estrato e ajusta arredondamento
n_por_estrato = (proporcoes * tamanho_total).round().astype(int)

# ajuste para garantir soma = tamanho_total
diff = tamanho_total - n_por_estrato.sum()
if diff != 0:
    # corrige adicionando/removendo 1 nos estratos mais frequentes
    for etapa in proporcoes.sort_values(ascending=False).index[:abs(diff)]:
        n_por_estrato.loc[etapa] += 1 if diff > 0 else -1

amostra_estratificada = (
    df.groupby("etapa_funil", group_keys=False)
      .apply(lambda g: g.sample(n=n_por_estrato.loc[g.name], random_state=42))
)

distribuicao_etapa("Amostra estratificada (proporcional)", amostra_estratificada)

# 3) Amostragem sistemática (cada k-ésimo)
# Recomenda-se embaralhar primeiro para reduzir viés de ordenação
df_embaralhado = df.sample(frac=1, random_state=42).reset_index(drop=True)

k = len(df_embaralhado) // 80  # passo aproximado para pegar ~80 linhas
inicio = 3  # ponto de início (poderia ser aleatório)
amostra_sistematica = df_embaralhado.iloc[inicio::k].head(80)

distribuicao_etapa("Amostra sistemática (com embaralhamento)", amostra_sistematica)
```

## O que observar (bem importante)

- **Aleatória simples**: pode distorcer um pouco a proporção dos grupos menores (ex.: “Oferta” é rara).
- **Estratificada**: tende a manter a proporção dos estratos (boa representatividade).
- **Sistemática**: funciona bem **se** você reduzir viés de ordenação (por isso o embaralhamento antes).

⚠️ Pegadinha clássica: se você fizer sistemática em uma lista ordenada (por etapa, por data, por recrutador), pode sair uma amostra “tendenciosa” sem perceber.

---

## Resumindo

- Com `pandas`, a aleatória simples é `sample`.
- A estratificada é `groupby + sample` com tamanho por estrato.
- A sistemática é `iloc[inicio::k]`, idealmente após embaralhar.
