### O padrão NIST

O material descreve as características que definem o que é cloud computing de verdade:

| Característica               | O que significa                                         | Exemplo                                                                          |
| :--------------------------- | :------------------------------------------------------ | :------------------------------------------------------------------------------- |
| **Self-service sob demanda** | Você provisiona recursos sozinho, sem falar com ninguém | Criar uma VM na AWS em 2 minutos pelo console ou API                             |
| **Acesso amplo pela rede**   | Acessível de qualquer dispositivo com internet          | Acessar o sistema de recrutamento do celular, tablet ou desktop                  |
| **Pool de recursos**         | Recursos compartilhados dinamicamente entre clientes    | Seu banco de dados e o de outra empresa rodam no mesmo servidor físico, isolados |
| **Elasticidade rápida**      | Recursos escalam pra cima e pra baixo automaticamente   | Na Black Friday, sobe 50 servidores; no dia seguinte, volta pra 5                |
| **Serviço mensurado**        | Tudo é medido e cobrado pelo uso real                   | Pagou R$ 47,32 esse mês porque usou 200h de processamento                        |

### 🎯 Conexão direta com seu dataset

Pense no `dataset_recrutamento`:

|Característica|Aplicação direta|
|:--|:--|
|**Self-service**|Você mesmo sobe uma instância PostgreSQL na AWS pra armazenar os candidatos|
|**Pool de recursos**|Seu banco roda no mesmo hardware que outros clientes, mas isolado por VPC|
|**Elasticidade**|Em período de muitas inscrições, o banco escala automaticamente|
|**Mensurado**|Paga pelo storage usado: 100 candidatos vs 100.000 candidatos — a conta muda|
