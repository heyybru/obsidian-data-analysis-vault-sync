Quando temos **muitos dados** (por exemplo, muitas idades diferentes), fica ruim listar tudo um por um.  Então usamos **intervalos de classe**, que agrupam os dados em faixas.

---

## **1️⃣ O que são Classes**

**Classes** são as **faixas de valores** onde os dados são agrupados.

Exemplo de classes de idade:

- 17 a 19
    
- 20 a 22
    
- 23 a 25
    
- 26 a 28
    
- 29 a 31
    
- 32 a 34
    
- 35 a 37
    

👉 Cada faixa dessas é **uma classe**.

---

## **2️⃣ Amplitude de Classe**

A **amplitude de classe** é o **tamanho de cada intervalo**.

### Fórmula simples:

```
Amplitude da classe = Limite superior − Limite inferior
```

No seu exemplo, todas as classes têm o mesmo tamanho:

- 1ª classe: 20 − 17 = **3** → (17, 18, 19)
    
- 2ª classe: 23 − 20 = **3** → (20, 21, 22)
    
- 3ª classe: 26 − 23 = **3** → (23, 24, 25)
    
- …
    

👉 Portanto, a **amplitude de classe é 3**.

⚠️ Importante: **todas as classes devem ter a mesma amplitude**.

---

## **3️⃣ Amplitude Total**

A **amplitude total** mostra o “tamanho geral” dos dados.

### Fórmula:

```
Amplitude total = Maior valor − Menor valor
```

No exemplo:

- Maior idade = 37
    
- Menor idade = 17
    

```
Amplitude total = 37 − 17 = 20
```

---

## **4️⃣ Número de Classes (k)**

Para decidir quantas classes usar, há regras.  
Nesta matéria, você usa a **regra da raiz quadrada**:

### Fórmula:

```
k = √n
```

Onde **n** é a quantidade de dados.

No exemplo, o resultado foi aproximadamente **7**, então:  
👉 **Usamos 7 classes**

---

## **5️⃣ Cálculo da Amplitude de Classe (h)**

Depois de saber a amplitude total e o número de classes, calculamos:

### Fórmula:

```
h = Amplitude total ÷ Número de classes
```

Aplicando:

```
h = 20 ÷ 7 ≈ 2,85
```

⚠️ Regra importante:

- Sempre **arredondar para cima**
    
- Mesmo que dê número inteiro, usa o próximo
    

👉 Resultado final:  
**Amplitude de classe = 3**

### Passo 1 — Amplitude Total

Dados de `experiencia_anos` dos 100 candidatos:

- Valor mínimo: 0 anos
- Valor máximo: 16 anos

AT = 16 − 0 = 16

### Passo 2 — Número de Classes (Regra de Sturges)

K = 1+3,322⋅log10​(n)

Onde:

- k = número de classes (o que queremos descobrir)
- n = número total de observações (no seu caso, 100 candidatos)
- log₁₀ = logaritmo na base 10 (não se assuste, é mais fácil do que parece)

Temos n = 100 candidatos.

#### Passo 1: Calcular log⁡10(100)

> [!note] 
> > 🤔 "O que é log₁₀ de 100?" Pergunte-se: "10 elevado a quanto dá 100?"  - 10x10 = 100, ou seja, 10 elevado a 2.  


#### Passo 2: Multiplicar por 3,322

3,322 × 2 = 6,644

#### Passo 3: Somar 1

6,644 + 1 = 7,644

#### Passo 4: Arredondar

k = 8 classes

### Passo 3 — Amplitude do Intervalo

H = 16 / 8 = 2

Cada classe terá amplitude de 2 anos.

### 💡 E Se Eu Não Quiser Usar Sturges?

Existem outras formas de definir o número de classes:

- Regra da Raiz Quadrada: k=nk = \sqrt{n}k=n​ → Para 100 dados: k=100=10k = \sqrt{100} = 10k=100​=10 classes
- Regra de Scott: Mais usada para dados com distribuição normal
- Critério prático: Entre 5 e 20 classes costuma funcionar bem para a maioria dos casos

> 🎯 Dica do Expert: Sturges funciona muito bem para n até 200. Acima disso, prefira a Regra de Scott ou a Raiz Quadrada.

## **Resumo bem direto**

- **Classe** → faixa de valores

- **Amplitude de classe (h)** → tamanho de cada faixa
    
- **Amplitude total** → maior valor − menor valor
    
- **Número de classes (k)** → √n
    
- **Todas as classes precisam ter o mesmo tamanho**
