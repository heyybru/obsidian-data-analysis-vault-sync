### 🔶 O que é redução?

- **Simples**: Função que recebe grupos **(chave, lista de valores)** e computa um resultado único (soma, média, etc.).
- **Objetivo**: Finaliza o processamento paralelo (fonte: **Cappra Institute**, reduz dados em 90% pra relatórios).

### 1️⃣ Como funciona (passo a passo)

1. **Input**: Do Shuffle: ("erro404", [1,1,1]).
2. **Processo**: Sua função Reduce() itera a lista.
3. **Output**: ("erro404", 3) → salva no HDFS.

### 2️⃣ Exemplo prático (QA: logs JIRA)

**Código Java/Reduce simples:**

```java
public class Reduce {
  public void reduce(Text key, Iterable<IntWritable> values, Context context) {
    int soma = 0;
    for (IntWritable val : values) {
      soma += val.get();  // Soma valores
    }
    context.write(key, new IntWritable(soma));  // ("erro404", 3)
  }
}
```
