## 🔷 O que é Python? 

- **Linguagem de programação** criada em 1991 por Guido van Rossum
- **Fácil de aprender** (sintaxe simples, como escrever em português)
- **Versátil**: Web, dados, automação, IA
- **Grátis** e roda em Windows, Mac, Linux

## 🔷 Variáveis 

**Variável** = **caixinha** para guardar valores. Você dá um nome e ela guarda qualquer coisa (número, texto, etc.).

### ✅ **Regras de nome**

- Comece com letra ou `_` (não número)
- Só letras, números, `_`
- Case-sensitive: `nome` ≠ `Nome`
- Exemplos válidos: `candidato_id`, `bug_count`, `taxa_turnover`
- Exemplos inválidos: `1bug`, `bug-count` (traço não vale)

### ✅ **Sintaxe: criar variável**

```python
# Sintaxe básica
nome_variavel = valor

# Exemplos
candidato_nome = "Bruno Silva"
idade = 30
salario = 5000.50
eh_contratado = True
```

## 🔷 Tipos de dados simples (os básicos)

Python tem **tipos automáticos** (não precisa declarar como em outras linguagens).

### ✅ **1. Inteiro (int)** - Números inteiros

```python
bugs_abertos = 15
candidatos_ativos = 120
```

**Operações**:

```python
total_bugs = bugs_abertos + 5  # 20
diferenca = candidatos_ativos - 20  # 100
```

### ✅ **2. Ponto flutuante (float)** - Números decimais

```python
taxa_sucesso = 85.5  # percentual
custo_medio = 4500.75  # reais
```

**Operações**:

```python
taxa_final = taxa_sucesso + 2.3  # 87.8
custo_total = custo_medio * 3  # 13502.25
```

### ✅ **3. String (str)** - Texto

```python
nome = "Bruno Silva"
status = 'Em processo seletivo'
mensagem = "Candidato aprovado!"
```

**Operações úteis**:

```python
# Concatenar (juntar)
nome_completo = nome + " - QA Analyst"  # "Bruno Silva - QA Analyst"

# Formatar (moderno)
mensagem = f"Bem-vindo, {nome}!"  # "Bem-vindo, Bruno Silva!"

# Métodos
email = "bruno@email.com"
dominio = email.split("@")[1]  # "email.com"
```

### ✅ **4. Booleano (bool)** - Verdadeiro/Falso

```python
candidato_aprovado = True
bug_critico = False
```

**Uso em condições**:

```python
if candidato_aprovado:
    print("Parabéns!")
else:
    print("Tente novamente")
```

## 🔷 Exemplos práticos (seu perfil RH + QA)

### ✅ **Exemplo 1: Cálculo simples de RH**

```python
# Dados de contratação
candidatos_inscritos = 150
aprovados = 45
taxa_aprovacao = (aprovados / candidatos_inscritos) * 100

print(f"Taxa de aprovação: {taxa_aprovacao}%")  # 30.0%
```

### ✅ **Exemplo 2: Controle de bugs em QA**

```python
# Status de bugs
bugs_totais = 200
bugs_criticos = 25
bugs_resolvidos = 180

# Cálculos
taxa_resolucao = (bugs_resolvidos / bugs_totais) * 100
eh_critico = bugs_criticos > 20  # True

print(f"Resolução: {taxa_resolucao}%")  # 90.0%
print(f"Precisa atenção: {eh_critico}")  # True
```

### ✅ **Exemplo 3: Automação de relatório**

```python
# Dados de candidato
candidato = {
    "nome": "Bruno Silva",
    "cargo": "QA Analyst",
    "salario": 6500.00,
    "ativo": True
}

# Relatório simples
relatorio = f"""
Candidato: {candidato['nome']}
Cargo: {candidato['cargo']}
Salário: R$ {candidato['salario']}
Status: {'Ativo' if candidato['ativo'] else 'Inativo'}
"""

print(relatorio)
```

## 🔷 Pegadinhas comuns (para não errar)

- **Indentação**: Python usa espaços/indentação para blocos (não chaves {})
- **Case-sensitive**: `Nome` ≠ `nome`
- **Aspas**: Use `"` ou `'` para strings (consistente)
- **Divisão**: `5/2` = `2.5` (float), `5//2` = `2` (int)
