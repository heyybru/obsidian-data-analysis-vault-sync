## Uso de filtros no Pandas

Os **filtros** servem para **selecionar apenas as linhas** que atendem a uma condição.

Pense assim:

- você tem uma tabela inteira
- mas quer ver só uma parte dos dados
- o filtro faz exatamente isso

---

## Estrutura básica

A forma mais comum é:

```python
df[condicao]
```

Exemplo:

```python
df[df["idade"] > 30]
```

Isso significa:

- pegue o DataFrame `df`
- mostre apenas as linhas em que a coluna **idade** é maior que `30`

---

## Exemplo simples

```python
import pandas as pd

df = pd.DataFrame({
    "nome": ["Ana", "Bruno", "Carla", "Diego"],
    "idade": [22, 35, 29, 41],
    "cidade": ["SP", "RJ", "SP", "BH"]
})

df[df["idade"] > 30]
```

### Resultado esperado

Vai mostrar só:

- Bruno
- Diego

---

## Tipos mais comuns de filtro

### 1. Maior que

```python
df[df["idade"] > 30]
```

### 2. Menor que

```python
df[df["idade"] < 30]
```

### 3. Igual a

```python
df[df["cidade"] == "SP"]
```

### 4. Diferente de

```python
df[df["cidade"] != "RJ"]
```

### 5. Maior ou igual / menor ou igual

```python
df[df["idade"] >= 30]
df[df["idade"] <= 30]
```

---

## Filtros com mais de uma condição

### Usando `&` = **e**

```python
df[(df["idade"] > 25) & (df["cidade"] == "SP")]
```

Significa:

- idade maior que 25
- **e**
- cidade igual a SP

### Usando `|` = **ou**

```python
df[(df["cidade"] == "SP") | (df["cidade"] == "RJ")]
```

Significa:

- cidade igual a SP
- **ou**
- cidade igual a RJ

### Usando `~` = negação

```python
df[~(df["cidade"] == "SP")]
```

Significa:

- tudo que **não** for SP

---

## Atenção importante com parênteses

Quando usar mais de uma condição, coloque cada condição entre parênteses:

✅ Correto:

```python
df[(df["idade"] > 25) & (df["cidade"] == "SP")]
```

❌ Errado:

```python
df[df["idade"] > 25 & df["cidade"] == "SP"]
```

---

## Filtrar textos

### Igualdade

```python
df[df["nome"] == "Ana"]
```

### Contém uma palavra

```python
df[df["nome"].str.contains("a", case=False, na=False)]
```

Esse filtro:

- procura a letra `"a"`
- ignora maiúsculas/minúsculas com `case=False`
- evita erro com nulos usando `na=False`

---

## Filtrar por lista de valores com `isin()`

Muito útil quando você quer filtrar vários valores de uma vez.

```python
df[df["cidade"].isin(["SP", "RJ"])]
```

Isso é equivalente a:

- cidade é SP
- ou cidade é RJ

---

## Filtrar valores nulos

### Linhas com nulos

```python
df[df["idade"].isna()]
```

### Linhas sem nulos

```python
df[df["idade"].notna()]
```

---

## Filtrar intervalo de valores

Você pode fazer assim:

```python
df[(df["idade"] >= 25) & (df["idade"] <= 35)]
```

Ou usar `between()`:

```python
df[df["idade"].between(25, 35)]
```

---

## Filtrar e selecionar colunas ao mesmo tempo

Exemplo:

```python
df.loc[df["idade"] > 30, ["nome", "idade"]]
```

Isso significa:

- filtre idade maior que 30
- mostre apenas as colunas `nome` e `idade`

---

## Exemplo prático completo

```python
import pandas as pd

df = pd.DataFrame({
    "nome": ["Ana", "Bruno", "Carla", "Diego", "Eva"],
    "idade": [22, 35, 29, 41, 30],
    "cidade": ["SP", "RJ", "SP", "BH", "RJ"],
    "salario": [2500, 4000, 3200, 5000, 3500]
})

# pessoas com idade maior que 30
print(df[df["idade"] > 30])

# pessoas de SP
print(df[df["cidade"] == "SP"])

# pessoas com idade maior que 25 e cidade RJ
print(df[(df["idade"] > 25) & (df["cidade"] == "RJ")])

# pessoas de SP ou RJ
print(df[df["cidade"].isin(["SP", "RJ"])])
```

---

## Filtro com variável

Você também pode guardar a condição em uma variável:

```python
filtro = df["idade"] > 30
df[filtro]
```

Isso ajuda muito quando o código fica maior.

---

## Erros comuns

### 1. Usar `and` em vez de `&`

❌ Errado:

```python
df[(df["idade"] > 25) and (df["cidade"] == "SP")]
```

✅ Correto:

```python
df[(df["idade"] > 25) & (df["cidade"] == "SP")]
```

### 2. Esquecer parênteses

❌ Errado:

```python
df[df["idade"] > 25 & df["cidade"] == "SP"]
```

✅ Correto:

```python
df[(df["idade"] > 25) & (df["cidade"] == "SP")]
```

### 3. Escrever nome da coluna errado

```python
df["idade"]
```

precisa ser exatamente igual ao nome real da coluna.

Você pode conferir com:

```python
print(df.columns)
```

---

## Resumindo

### Filtros mais usados

- `df[df["coluna"] > valor]`
- `df[df["coluna"] == valor]`
- `df[(cond1) & (cond2)]`
- `df[(cond1) | (cond2)]`
- `df[df["coluna"].isin([...])]`
- `df[df["coluna"].isna()]`

---

## Mini cola para decorar

```python
# igual
df[df["cidade"] == "SP"]

# maior que
df[df["idade"] > 30]

# duas condições
df[(df["idade"] > 25) & (df["cidade"] == "RJ")]

# vários valores
df[df["cidade"].isin(["SP", "RJ"])]

# nulos
df[df["idade"].isna()]
```

---

## Exemplo aplicado à EDA

Depois de importar um arquivo, você pode fazer perguntas como:

- quais registros têm salário acima de `3000`?
- quantas pessoas são de SP?
- quais linhas têm idade nula?
- quais candidatos vieram de um canal específico?

Tudo isso é resolvido com **filtros**.
