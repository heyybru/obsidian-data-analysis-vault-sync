“Funções nativas” são as que já vêm no Python, sem precisar importar nada. Elas aceleram muito a vida em **manipulação de dados**, **validação**, **loops** e **QA**.

Abaixo vão as mais importantes, com exemplos curtos.

---

## 🔷 1) Conversão de tipos: `int()`, `float()`, `str()`, `bool()`

```python
int("10")        # 10
float("3.14")    # 3.14
str(123)         # "123"
bool("")         # False
bool("ok")       # True
```

⚠️ `bool()` tem uma “regra prática”:

- `0`, `0.0`, `""`, `[]`, `{}`, `None` → **False**
- o resto → **True**

---

## 🔷 2) Entrada/Saída básica: `input()`, `print()`

```python
nome = input("Nome: ")
print("Olá,", nome)
```

---

## 🔷 3) Tamanho e contagem: `len()`, `sum()`

```python
bugs = ["CRITICO", "ALTO", "CRITICO"]
len(bugs)  # 3

nums = [1, 2, 3]
sum(nums)  # 6
```

👉 Em QA/dados, `sum()` é ótimo para contar com condição:

```python
sum(1 for b in bugs if b == "CRITICO")  # 2
```

---

## 🔷 4) Mínimo/Máximo: `min()`, `max()`

```python
tempos = [120, 95, 200]
min(tempos)  # 95
max(tempos)  # 200
```

✅ Com `key=` (muito usado em lista de dict):

```python
bugs = [
    {"id": 1, "sev": "ALTO"},
    {"id": 2, "sev": "CRITICO"}
]

pesos = {"CRITICO": 1, "ALTO": 2, "MEDIO": 3, "BAIXO": 4}
mais_grave = min(bugs, key=lambda b: pesos.get(b["sev"], 99))
print(mais_grave)  # bug de severidade CRITICO
```

---

## 🔷 5) Ordenação: `sorted()`

```python
sorted([3, 1, 2])  # [1, 2, 3]
```

✅ Ordenando lista de dict:

```python
bugs_ordenados = sorted(bugs, key=lambda b: pesos.get(b["sev"], 99))
```

---

## 🔷 6) Iteração com índice: `enumerate()`

```python
testes = ["Login", "Cadastro", "Pagamento"]
for i, nome in enumerate(testes, start=1):
    print(i, nome)
```

---

## 🔷 7) Iterar “em paralelo”: `zip()`

```python
esperado = [200, 201, 500]
obtido =   [200, 400, 500]

for e, o in zip(esperado, obtido):
    print(e == o)
```

---

## 🔷 8) Verificações lógicas: `any()` e `all()`

- `any()` → True se **algum** for True
- `all()` → True se **todos** forem True

```python
resultados = [True, True, False]

any(resultados)  # True (tem pelo menos um True)
all(resultados)  # False (nem todos são True)
```

👉 QA real:

```python
tem_critico_aberto = any(
    b["sev"] == "CRITICO" and b["status"] == "ABERTO"
    for b in [{"sev":"CRITICO","status":"ABERTO"}]
)
```

## 🔷 9) Funções de sequência: `range()`, `list()`, `tuple()`, `set()`, `dict()`

```python
list(range(5))  # [0, 1, 2, 3, 4]
set([1, 1, 2])  # {1, 2}
```

✅ `set()` é ótimo para remover duplicados:

```python
usuarios = ["ana", "ana", "bruno"]
usuarios_unicos = set(usuarios)
```

## 🔷 10) Ajuda e inspeção: `type()`, `isinstance()`, `help()`

```python
type(10)  # <class 'int'>
isinstance("x", str)  # True
# help(str)  # mostra documentação
```

## 🔷 11) Valores absolutos e arredondamento: `abs()`, `round()`

```python
abs(-10)       # 10
round(3.14159, 2)  # 3.14
```

---

## 🔷 12) Map/Filter (existem, mas use com consciência): `map()`, `filter()`

✅ Exemplos:

```python
nums = [1, 2, 3]
list(map(lambda x: x * 2, nums))  # [2, 4, 6]

list(filter(lambda x: x > 1, nums))  # [2, 3]
```

👉 Na prática, muita gente prefere **list comprehension** por legibilidade:

```python
[x * 2 for x in nums]
[x for x in nums if x > 1]
```
