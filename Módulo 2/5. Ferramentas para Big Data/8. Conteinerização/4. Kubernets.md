[Kubernetes](https://kubernetes.io/pt-br/)
### 🔶 O que é? (Simples)

- **Definição**: Plataforma open-source pra **orquestrar containers** (Docker). Auto-escala, deploy, heal e balanceia apps em clusters (fonte: **Metricas Boss**, gerencia 1M+ pods em enterprise).
- **Por quê?** Evita caos manual: "um pod caiu? K8s recria em segs".

### 1️⃣ Componentes chave (tópicos curtos)

- **Pods**: Unidade mínima (1+ containers). Ex: Seu Pytest QA rodando isolado.
- **Deployments**: Gerencia réplicas/pods. Ex: 5 pods de Selenium pra testes paralelos.
- **Services**: Exposição de pods (load balance). Ex: Acesso ao Kafka via Service.
- **Nodes**: Máquinas no cluster (Master gerencia Workers).
- **Helm**: "Pacotes" prontos (charts pra Kafka/Spark).

### 2️⃣ Exemplo prático pro seu QA

- **Seu caso**: Orquestre testes Zephyr: YAML simples pra deploy.
    
    ```yaml
    apiVersion: apps/v1
    kind: Deployment
    metadata:
      name: qa-selenium
    spec:
      replicas: 3  # 3 pods paralelos
      template:
        spec:
          containers:
          - name: selenium
            image: selenium/standalone-chrome
    ```
    
    Rode: `kubectl apply -f qa.yaml`. Logs vão pro workbook_v1.xlsx via volume!

### 🚀 Vantagens rápidas (Preditiva.ai)

- Escala auto (HPA: +pods em pico de testes).
- Zero downtime (rolling updates).
- Multi-cloud (AWS EKS, GCP GKE).

Desvantagens: Curva íngreme inicial (20% time extra, **Cappra**).
