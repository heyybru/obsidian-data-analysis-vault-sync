## 🔷 Laços avançados em Python

Vamos além do básico com técnicas que tornam seus loops mais eficientes, legíveis e "Pythonicos". Esses padrões são essenciais para análise de dados e automação de testes.

## 🔷 1) **`enumerate()` - Índice + Valor**

### ✅ **Problema comum**:

```python
bugs = ["CRITICO", "ALTO", "MEDIO"]
for i in range(len(bugs)):
    print(f"Bug {i}: {bugs[i]}")
```

### ✅ **Solução elegante**:

```python
bugs = ["CRITICO", "ALTO", "MEDIO"]
for indice, severidade in enumerate(bugs, start=1):
    print(f"Bug {indice}: {severidade}")
```

### ✅ **Exemplo QA: Log de execução**:

```python
testes = ["Login", "Cadastro", "Pagamento", "Perfil"]

for numero_teste, nome_teste in enumerate(testes, start=1):
    print(f"[{numero_teste}/{len(testes)}] Executando: {nome_teste}")
```

## 🔷 2) **`zip()` - Iterar múltiplas listas simultaneamente**

### ✅ **Comparar resultados esperados vs obtidos**:

```python
resultados_esperados = [200, 404, 500]
resultados_obtidos = [200, 200, 500]

for esperado, obtido in zip(resultados_esperados, resultados_obtidos):
    if esperado == obtido:
        print(f"✅ Status {esperado} correto")
    else:
        print(f"❌ Esperado {esperado}, obtido {obtido}")
```

### ✅ **RH: Cruzar dados de candidatos**:

```python
nomes = ["Ana", "Bruno", "Carla"]
idades = [25, 30, 28]
experiencias = [3, 5, 2]

for nome, idade, exp in zip(nomes, idades, experiencias):
    print(f"{nome}: {idade} anos, {exp} anos de experiência")
```

## 🔷 4) **`sorted()` - Iterar em ordem específica**

### ✅ **Ordenar bugs por severidade**:

```python
bugs = [
    {"id": 1, "severidade": "BAIXO"},
    {"id": 2, "severidade": "CRITICO"},
    {"id": 3, "severidade": "ALTO"},
]

# Ordenar por severidade (custom key)
def peso_severidade(severidade):
    pesos = {"CRITICO": 0, "ALTO": 1, "MEDIO": 2, "BAIXO": 3}
    return pesos.get(severidade, 99)

for bug in sorted(bugs, key=lambda x: peso_severidade(x["severidade"])):
    print(f"Bug {bug['id']}: {bug['severidade']}")
```

### ✅ **Processar até condição complexa**:


## 🔷 8) **Geradores com `yield` (laços "preguiçosos")**

### ✅ **Processar grandes volumes sem carregar tudo na memória**:

```python
def processar_bugs_lote(bugs, tamanho_lote=100):
    """Processa bugs em lotes para economizar memória"""
    for i in range(0, len(bugs), tamanho_lote):
        lote = bugs[i:i + tamanho_lote]
        print(f"Processando lote {i//tamanho_lote + 1}: {len(lote)} bugs")
        yield lote

# Simulação: 1000 bugs
bugs_grandes = [f"Bug {i}" for i in range(1000)]

for lote in processar_bugs_lote(bugs_grandes, tamanho_lote=250):
    # Processar cada lote
    print(f"  Lote com {len(lote)} bugs processado")
```

## 🔷 9) **Compreensão de listas (list comprehension) - Laços "inline"**

### ✅ **Transformar dados rapidamente**:

```python
# Tradicional
bugs = ["critico", "alto", "medio", "baixo"]
bugs_upper = []
for bug in bugs:
    bugs_upper.append(bug.upper())

# Com list comprehension (mais Pythonic)
bugs_upper = [bug.upper() for bug in bugs]

# Com condição
bugs_criticos = [bug for bug in bugs if bug in ["critico", "alto"]]
```

## 🔷 10) **Padrão: Laço com acumulador**

### ✅ **RH: Calcular estatísticas**:

```python
salarios = [5000, 6000, 7000, 5500, 6500]

# Acumuladores
total = 0
maior = float('-inf')
menor = float('inf')
contagem = 0

for salario in salarios:
    total += salario
    maior = max(maior, salario)
    menor = min(menor, salario)
    contagem += 1

print(f"Total: R$ {total}")
print(f"Média: R$ {total/contagem:.2f}")
print(f"Maior: R$ {maior}")
print(f"Menor: R$ {menor}")
```

## 🔷 **Exercício avançado: Sistema de monitoramento QA**

```python
from datetime import datetime, timedelta

class MonitorQA:
    def __init__(self):
        self.logs = []
    
    def simular_execucao(self, horas=24):
        """Simula execução de testes por N horas"""
        inicio = datetime.now()
        
        for hora in range(horas):
            # Simular execução a cada hora
            timestamp = inicio + timedelta(hours=hora)
            sucesso = hora % 3 != 0  # Falha a cada 3 horas
            
            self.logs.append({
                "timestamp": timestamp,
                "hora": hora,
                "sucesso": sucesso,
                "testes_executados": 100,
                "falhas": 0 if sucesso else 5
            })
    
    def analisar_tendencia(self):
        """Analisa tendência de falhas usando laços avançados"""
        if not self.logs:
            return "Sem dados"
        
        # Usando enumerate para análise temporal
        falhas_consecutivas = 0
        max_falhas_consecutivas = 0
        
        for i, log in enumerate(self.logs):
            if not log["sucesso"]:
                falhas_consecutivas += 1
                max_falhas_consecutivas = max(max_falhas_consecutivas, falhas_consecutivas)
            else:
                falhas_consecutivas = 0
        
        # Usando list comprehension para estatísticas
        horas_com_falha = [log["hora"] for log in self.logs if not log["sucesso"]]
        total_falhas = sum(1 for log in self.logs if not log["sucesso"])
        
        return {
            "total_horas": len(self.logs),
            "horas_com_falha": horas_com_falha,
            "total_falhas": total_falhas,
            "max_falhas_consecutivas": max_falhas_consecutivas,
            "taxa_sucesso": (len(self.logs) - total_falhas) / len(self.logs) * 100
        }

# Executar
monitor = MonitorQA()
monitor.simular_execucao(12)
analise = monitor.analisar_tendencia()

print("📊 Análise de Monitoramento QA:")
for chave, valor in analise.items():
    print(f"  {chave}: {valor}")
```
