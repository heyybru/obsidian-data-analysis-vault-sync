### 🔶 O que é MapReduce?

- **Definição simples**: Modelo de programação pra processar **dados massivos** em clusters, dividindo em 2 fases: **Map** (divide e transforma) e **Reduce** (agrega resultados).
- **Por quê?** Paraleliza jobs em milhares de máquinas, lidando com TB/PB (fonte: **Cappra Institute**, benchmarks de throughput).

### 1️⃣ Fases principais

- **Map**: Pega input bruto, gera pares **chave-valor** (ex: texto → palavras contadas).
- **Shuffle/Sort**: Hadoop organiza por chave.
- **Reduce**: Soma/agrega por chave.

### 2️⃣ Exemplo prático (WordCount – contagem de palavras)

Imagine logs QA: "erro1 erro2 ok erro1".

**Código Java/MapReduce simples:**

```java
// Map: divide em (palavra, 1)
"erro1" → ("erro1", 1)
"erro2" → ("erro2", 1)

// Reduce: soma por palavra
("erro1", 1+1=2)
("erro2", 1)
```

**Comando Hadoop:**

```bash
hadoop jar hadoop-mapreduce-examples.jar wordcount /input/logs_qa.txt /output/contagem_erros
```

### 3️⃣ Vantagens e dicas

- **Prós**: Escala infinita, tolerante a falhas (um nó cai? Reprocessa).
- **Contras**: Latência alta pra jobs pequenos (use Spark pra isso, per **Metricas Boss**).
- **Dica**: Teste local com Pseudo-Distributed.
