# O que é Data Profiling

## Definição

Análise **estatística e estrutural** de um conjunto de dados para descobrir o que ele realmente contém — **antes** de usá-lo.

## As perguntas que ele responde

- Quantas linhas e colunas existem?
- Quais colunas têm nulos, e em que percentual?
- Quais são mínimos, máximos e a distribuição de cada campo?
- Existem duplicatas?
- Os tipos de dados batem com o esperado?
- Há valores fora de domínio (idade negativa, data no futuro)?
- Os relacionamentos entre tabelas se sustentam?

## Ponto central

Profiling **descreve**, não corrige. Ele produz um **retrato** da base. A limpeza vem depois.

## Distinção (IBM)

| Conceito | O que é |
|---|---|
| **Data Quality** | O critério amplo de avaliação |
| **Data Profiling** | O **processo** de revisar e limpar para manter esse padrão |

Um é o alvo, o outro é o caminho.

## Analogia

É o **check-up antes da cirurgia**. Nenhum médico opera sem exames. Nenhum time de dados deveria limpar uma base sem antes perfilá-la.
