### 🔹 Para que serve?

O comando **INSERT** é usado para **inserir novos dados** em uma tabela.

---

## 🧩 Sintaxe básica

```sql
INSERT INTO nome_tabela (coluna1, coluna2, coluna3)
VALUES (valor1, valor2, valor3);
```

📌 A ordem dos valores deve seguir a ordem das colunas.

---

## 🔹 Exemplo simples

Tabela: **COLABORADOR**

```sql
INSERT INTO COLABORADOR (id_colaborador, nome, cargo)
VALUES (1, 'Bruno', 'Assistente');
```

---

## 🔹 Inserção sem informar as colunas

⚠️ **Não recomendado**, mas pode cair em prova.

```sql
INSERT INTO COLABORADOR
VALUES (2, 'Ana', 'Analista', 1);
```

👉 Deve seguir **exatamente a ordem das colunas** da tabela.

---

## 🔹 Inserindo apenas algumas colunas

As colunas não informadas ficam **NULL** (se permitido).

```sql
INSERT INTO COLABORADOR (id_colaborador, nome)
VALUES (3, 'Carlos');
```

---

## 🔹 Inserção de múltiplos registros (Oracle)

```sql
INSERT ALL
  INTO COLABORADOR (id_colaborador, nome, cargo) VALUES (4, 'João', 'Dev')
  INTO COLABORADOR (id_colaborador, nome, cargo) VALUES (5, 'Maria', 'QA')
SELECT * FROM dual;
```

---

## 🔹 Inserção com SELECT (copiar dados)

```sql
INSERT INTO COLABORADOR_BACKUP
SELECT * FROM COLABORADOR;
```

---

## ⚠️ Erros comuns (cai em prova)

- Inserir **texto sem aspas**
    
- Inserir **valor duplicado em PK**
    
- Violar **FK**
    
- Inserir `NULL` em coluna `NOT NULL`
    

---

## 🧠 Resumo rápido

- `INSERT` adiciona dados
    
- Texto → aspas simples `' '`
    
- Números → sem aspas
    
- PK não pode repetir
    
- FK precisa existir na tabela referenciada
