Vamos simular a execução de um fluxo prático de migração de dados de candidatos do seu `dataset_recrutamento` de um banco de dados de origem para um destino.

### 📝 Passo 1: Configurar o Controller Service (JDBC Connection Pool)

Antes de puxar os dados, você precisa configurar a conexão com o banco de dados na interface do NiFi:

- Adicione um serviço do tipo `DBCPConnectionPool`.
- Configure a **Database Connection URL** (ex: `jdbc:mysql://localhost:3306/rh_db`).
- Defina o **Database Driver Class Name** (ex: `com.mysql.cj.jdbc.Driver`).
- Informe o caminho do arquivo `.jar` do driver JDBC no servidor.

### 📝 Passo 2: Configurar o Processador de Extração (`ExecuteSQL`)

- Arraste um processador `ExecuteSQL` para a tela.
- Associe-o ao `DBCPConnectionPool` criado no Passo 1.
- Insira a query SQL de extração:
    
    ```sql
    SELECT id_candidato, nome_candidato, cargo_pretendido, experiencia_anos 
    FROM candidatos 
    WHERE status_candidatura = 'Contratado'
    ```
    
- Configure o agendamento (Run Schedule) para rodar a cada 10 segundos (simulando streaming/micro-batch).

### 📝 Passo 3: Configurar o Processador de Carga (`PutDatabaseRecord`)

- Arraste um processador `PutDatabaseRecord` para a tela.
- Conecte a saída do `ExecuteSQL` na entrada dele.
- Configure o pool de conexões JDBC apontando para o banco de destino (ex: PostgreSQL).
- Defina a tabela de destino (ex: `candidatos_contratados`).
- O NiFi mapeará automaticamente as colunas do fluxo com as colunas da tabela de destino.

### 📝 Passo 4: Iniciar o Fluxo

- Clique com o botão direito na tela e selecione **Start** para ativar todos os processadores.
- Você verá os dados fluindo em tempo real pelas conexões, com contadores visuais mostrando o volume de dados trafegados.
