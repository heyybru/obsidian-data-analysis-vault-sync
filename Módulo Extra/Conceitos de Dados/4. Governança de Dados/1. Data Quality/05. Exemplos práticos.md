# Exemplos práticos — funil de recrutamento

## Tabela de falhas por dimensão

| Dimensão | Falha real | Impacto |
|---|---|---|
| Precisão | `data_admissao` digitada errada | Time-to-hire errado |
| Completude | 40% sem `fonte` | Relatório de canais inviável |
| Consistência | ATS ≠ folha no headcount | Duas verdades na mesma reunião |
| Unicidade | Candidato duplicado 3x | Funil inflado, conversão falsa |
| Temporalidade | Dashboard com D-7 | Gestor decide com dado velho |
| Relevância | 200 campos, 8 usados | Custo de coleta sem retorno |
| Interpretabilidade | `status = 'A'` sem dicionário | Cada área lê diferente |
| Coerência | Admissão antes da aplicação | Registro logicamente impossível |
| Acessibilidade | Métrica existe, ninguém acha | Retrabalho e sombra de dados |

## Analogia

Dado ruim no recrutamento é como **contar passageiros sem conferir a lista de embarque**. O número final existe, é preciso, tem duas casas decimais — e está errado.
