**Exceções** em Python são **eventos de erro** (ou situações inesperadas) que ocorrem durante a execução e **interrompem o fluxo normal** do programa.

Em vez do programa “quebrar” sem controle, o Python **lança (raise)** uma exceção. Aí você pode **capturar e tratar** com `try/except`.

---

## Como pensar (bem simples)

- Se deu um problema: Python **lança uma exceção**
- Se você quiser lidar com isso: você **trata a exceção**

---

## Exemplos comuns de exceções

### `ZeroDivisionError`

```python
10 / 0
```

### `ValueError`

```python
int("abc")
```

### `FileNotFoundError`

```python
open("arquivo_que_nao_existe.txt", "r")
```

---

## Como tratar uma exceção (exemplo)

```python
try:
    n = int("abc")
except ValueError:
    print("Não deu pra converter para número.")
```

- `try`: tenta executar
- `except`: se der o erro especificado, executa esse bloco

---

## Por que exceções existem?

- Evitam que você tenha que checar “deu certo?” a cada linha
- Permitem centralizar o tratamento de erros
- Ajudam a criar programas mais robustos (principalmente com arquivo, rede, banco, API)
