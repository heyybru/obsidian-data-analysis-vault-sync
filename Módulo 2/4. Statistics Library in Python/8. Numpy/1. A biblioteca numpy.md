### 🔶 O que é a NumPy?

- **Definição curta**: Biblioteca Python para computação numérica. Cria **arrays** (matrizes) eficientes e faz cálculos vetorizados (sem loops lentos).
- **Por quê usar?** Arrays NumPy são **50-100x mais rápidos** que listas Python (fonte: **Cappra Institute**, benchmarks de performance).
- **Instalação**: `pip install numpy`.
- **Import**: `import numpy as np`.

### 1️⃣ Arrays (o coração da NumPy)

- Substitui listas por estruturas fixas e rápidas.

👉 **Exemplo básico (dados de testes QA):**

```python
import numpy as np

# Lista Python lenta
testes = [85, 92, 78, 95]

# Array NumPy rápido
notas = np.array([85, 92, 78, 95])
print(notas.mean())  # Média: 87.5 (rápido!)
```

### 2️⃣ Operações vetorizadas (sem loops!)

- Aplica funções em todo array de uma vez.

👉 **Exemplo RH: Normalizar salários**

```python
salarios = np.array([3000, 4500, 6000, 12000])
salarios_normalizados = (salarios - salarios.mean()) / salarios.std()
print(salarios_normalizados)  # Z-score pronto!
```

### 3️⃣ Funções estatísticas (prontas pra análise)

- `mean()`, `median()`, `std()`, `min()`, `max()`.

👉 **Exemplo QA: Stats de tempos de teste**

```python
tempos = np.array([2.1, 3.5, 1.8, 4.2, 2.9])
print(f"Média: {tempos.mean():.2f}s")  # Ex: 2.90s
print(f"Desvio: {tempos.std():.2f}s")  # Variância
```

### 4️⃣ Arrays 2D (tabelas simples)

- Como mini-DataFrames.

👉 **Exemplo: Matriz de candidatos x critérios**

```python
candidatos = np.array([[90, 85, 95],  # Ana: nota, exp, teste
                       [88, 92, 80]]) # Bruno
print(candidatos.mean(axis=1))  # Média por candidato
```

### 🚀 Dicas pro seu dia a dia (Metricas Boss / AILabs)

- **QA**: Use pra simular cenários de testes (`np.random.normal()` gera dados reais).
- **RH**: Calcule percentiles pra ranquear candidatos (`np.percentile(salarios, 75)`).
- **Performance**: NumPy é base do Pandas (dados: **Metricas Boss**, acelera 10x em grandes datasets).
- **Cuidado**: Arrays têm tipo fixo (ex: só números), diferente de listas flexíveis.

**Resumindo:**

- **NumPy** = Arrays rápidos + stats vetorizadas.
- Base pro Pandas/SciPy – essencial pra automação QA.
