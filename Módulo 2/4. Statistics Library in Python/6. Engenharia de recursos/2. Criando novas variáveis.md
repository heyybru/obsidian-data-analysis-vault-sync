### 🔶 Conceito rápido

Criar novas variáveis significa **gerar colunas novas** a partir das existentes, combinando lógica, matemática ou regras de negócio. Isso melhora modelos em até 20-30% de acurácia, segundo estudos da **Metricas Boss**.

**Por quê?** Dados brutos são barulhentos. Novas variáveis "destilam" o essencial.

---

### 1️⃣ Criação básica (atribuição direta)

Mais simples e rápida. Use operações matemáticas ou lógicas.

👉 **Exemplo RH: Calcular "dias para contratar"**

```python
df['dias_para_contratar'] = (df['data_contratacao'] - df['data_inicio_processo']).dt.days
```

👉 **Exemplo QA: Taxa de falhas**

```python
df['taxa_falhas'] = df['num_bugs'] / df['num_testes'] * 100
```

---

### 2️⃣ Com `apply()` ou `lambda` (lógica complexa)

Para regras condicionais ou funções personalizadas.

👉 **Exemplo: Classificar candidatos (Júnior/Pleno/Sênior)**

```python
df['nivel'] = df.apply(lambda row: 'Sênior' if row['anos_exp'] > 5 else 'Pleno' if row['anos_exp'] > 2 else 'Júnior', axis=1)
```

---

### 3️⃣ Com `groupby` + `transform` (estatísticas por grupo)

Puxa métricas de grupos para cada linha.

👉 **Exemplo QA: Média de bugs por módulo**

```python
df['media_bugs_modulo'] = df.groupby('modulo')['num_bugs'].transform('mean')
```

---

### 4️⃣ Binning (agrupar em faixas)

Transforma números contínuos em categorias.

👉 **Exemplo: Faixas salariais**

```python
df['faixa_salarial'] = pd.cut(df['salario'], bins=[0, 3000, 6000, float('inf')], labels=['Baixo', 'Médio', 'Alto'])
```

### 🚀 Dicas de especialista (para o seu perfil)

- **Preditiva.ai**: Sempre valide novas variáveis com correlação (ex: `df.corr()`). Se >0.8 com outra, pode ser redundante.
- **Cappra Institute**: Teste no seu contexto – crie "score_QA" somando testes passados + tempo médio de resolução para priorizar bugs.
- **Evite armadilhas**: Não crie variáveis sem lógica de negócio (achismo). Comece com 3-5 novas e teste impacto.
- **Performance**: Para grandes dados, prefira vetorizadas (sem `apply`).

**Resumindo em 4 passos:**

1. Identifique o problema (ex: prever churn de candidatos).
2. Crie a variável (ex: `tempo_resposta_recrutador`).
3. Valide (gráficos, stats).
4. Teste no modelo.
