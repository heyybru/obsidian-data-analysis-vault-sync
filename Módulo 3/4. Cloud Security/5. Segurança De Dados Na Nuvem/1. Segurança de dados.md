O material define a segurança de dados na nuvem como um modelo de **responsabilidade compartilhada**.

- **Responsabilidade do Provedor (ex: AWS):** Segurança da infraestrutura física, hardware e software básico.
- **Responsabilidade do Usuário (Você):** Configuração correta, controle de acessos (IAM), proteção das aplicações e, principalmente, a segurança dos dados inseridos.
- **A Tríade da Segurança:** Todo o esforço visa garantir três pilares:
    1. **Confidencialidade:** Apenas pessoas autorizadas acessam o dado.
    2. **Integridade:** O dado não foi alterado nem corrompido.
    3. **Disponibilidade:** O dado está disponível quando necessário.
