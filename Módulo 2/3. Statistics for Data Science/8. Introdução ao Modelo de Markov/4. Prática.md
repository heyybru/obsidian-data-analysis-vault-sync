## Prática com Python: estado estável (steady-state) em Cadeias de Markov

A ideia é: dado uma **matriz de transição** $$P$$, queremos o vetor $$\pi$$ (distribuição estacionária) tal que:

$$\pi = \pi P \quad \text{e} \quad \sum_i \pi_i = 1$$

### Exemplo 1 — Recrutamento (com estados absorventes)

Aqui, “Contratado” e “Reprovado” são absorventes. Isso é útil para **probabilidade de absorção** (chance final de contratação), mas **não** para “estado estável” no sentido clássico (porque a cadeia converge para ficar toda em estados finais).

```python
import numpy as np

# Estados: [Triagem, Entrevista, Oferta, Contratado, Reprovado]
P = np.array([
    [0.20, 0.50, 0.00, 0.00, 0.30],  # Triagem
    [0.00, 0.30, 0.40, 0.00, 0.30],  # Entrevista
    [0.00, 0.00, 0.10, 0.80, 0.10],  # Oferta
    [0.00, 0.00, 0.00, 1.00, 0.00],  # Contratado (absorvente)
    [0.00, 0.00, 0.00, 0.00, 1.00],  # Reprovado (absorvente)
])

# Vetor inicial: 1000 candidatos começam em Triagem
v0 = np.array([1000, 0, 0, 0, 0], dtype=float)

# Evolução em k passos
k = 10
vk = v0.copy()
for _ in range(k):
    vk = vk @ P

print("Distribuição após 10 semanas (aprox.):")
print(vk)

print("\nProbabilidade aproximada de contratação após 10 semanas:")
print(vk[3] / v0.sum())
```

**Como interpretar:** ao final de algumas iterações, quase todo mundo vai estar em **Contratado** ou **Reprovado**. Isso responde perguntas como:

- “Se eu começo com 1000 candidatos, quantos devem virar contratados em ~10 ciclos?”
- “Qual a taxa final de contratação implícita nessas transições?”

### Exemplo 2 — QA / Operação (cadeia ergódica) e estado estável de verdade

Para “estado estável” clássico, precisamos de uma cadeia **sem absorção** e “bem misturada” (ergódica). Exemplo de estados de saúde de um módulo:

Estados: `OK`, `Bugs Leves`, `Bugs Críticos`, `Em Correção`

```python
import numpy as np

# Estados: [OK, Leves, Críticos, EmCorreção]
P = np.array([
    [0.70, 0.20, 0.05, 0.05],  # OK
    [0.40, 0.40, 0.10, 0.10],  # Leves
    [0.10, 0.20, 0.40, 0.30],  # Críticos
    [0.60, 0.25, 0.05, 0.10],  # EmCorreção
])

# Método 1: "power method" (iterar até estabilizar)
pi = np.array([1, 0, 0, 0], dtype=float)  # começa tudo em OK (só pra iniciar)
for _ in range(200):
    pi = pi @ P

print("Distribuição estacionária (aprox.):")
print(pi)
print("Soma:", pi.sum())
```

**Leitura prática:** $$\pi$$ te diz o “percentual de tempo” (ou proporção no longo prazo) que o sistema passa em cada estado. Ex.:

- Se $$\pi_{\text{Críticos}}$$ for alto, você tem um problema sistêmico de qualidade.
- Se $$\pi_{\text{EmCorreção}}$$ for alto, pode ser gargalo de correção/reteste.

### Exemplo 3 — Encontrar $$\pi$$ resolvendo sistema linear (mais “exato”)

A equação $$\pi = \pi P$$ pode ser reescrita como:

$$(P^T - I)\pi^T = 0 \quad \text{com} \quad \sum_i \pi_i = 1$$

```python
import numpy as np

P = np.array([
    [0.70, 0.20, 0.05, 0.05],
    [0.40, 0.40, 0.10, 0.10],
    [0.10, 0.20, 0.40, 0.30],
    [0.60, 0.25, 0.05, 0.10],
])

n = P.shape[0]
A = (P.T - np.eye(n))
A[-1, :] = 1.0  # substitui uma equação por sum(pi)=1
b = np.zeros(n)
b[-1] = 1.0

pi = np.linalg.solve(A, b)
print("Distribuição estacionária (linear solve):")
print(pi)
print("Soma:", pi.sum())
```

## Resumindo

- **Estado estável** é $$\pi$$ tal que $$\pi = \pi P$$ (distribuição estacionária).
- Em cadeias **ergódicas**, $$\pi$$ representa a **proporção no longo prazo** em cada estado.
- Se a cadeia tiver **estados absorventes** (ex.: Contratado/Reprovado), o mais útil costuma ser **probabilidade de absorção**, não “steady-state” clássico.
