👉 Servem para **tomar decisões dentro da consulta**, como _SE / SENÃO_.

---
## 🔹 CASE 

### Sintaxe básica

```sql
CASE
   WHEN condição THEN resultado
   ELSE resultado
END
```

### Exemplo

```sql
SELECT nome,
       salario,
       CASE
          WHEN salario >= 5000 THEN 'ALTO'
          WHEN salario >= 3000 THEN 'MÉDIO'
          ELSE 'BAIXO'
       END AS faixa_salarial
FROM EMP;
```

📌 Avalia condições em ordem.

---

## 🔹 CASE simples

Usado quando compara **um único valor**.

```sql
SELECT nome,
       CASE cargo
          WHEN 'GERENTE' THEN 'NÍVEL 1'
          WHEN 'ANALISTA' THEN 'NÍVEL 2'
          ELSE 'OUTROS'
       END AS nivel
FROM EMP;
```

---

## 🔹 DECODE (específica do Oracle)

👉 Parecida com IF simples.

### Sintaxe

```sql
DECODE(valor, valor1, resultado1, valor2, resultado2, resultado_padrao)
```

### Exemplo

```sql
SELECT nome,
       DECODE(sexo, 'M', 'Masculino', 'F', 'Feminino', 'Não informado') AS genero
FROM PESSOA;
```

📌 Limitação: só compara **igualdade**.

---

## 🔹 NVL

👉 Trata valores **NULL**

```sql
SELECT nome,
       NVL(comissao, 0) AS comissao
FROM EMP;
```

Se for NULL → substitui por 0.

---

## 🔹 NVL2

👉 Decide com base em NULL ou NÃO NULL

```sql
SELECT nome,
       NVL2(comissao, 'TEM COMISSÃO', 'SEM COMISSÃO') AS status
FROM EMP;
```

---

## 🔹 COALESCE

👉 Retorna o **primeiro valor não NULL**

```sql
SELECT COALESCE(telefone_res, telefone_cel, telefone_com) AS telefone
FROM CLIENTE;
```

---

## ⚠ Pegadinhas de prova

- CASE → mais flexível que DECODE
    
- DECODE → só igualdade
    
- NVL substitui NULL
    
- COALESCE aceita **vários campos**

---

## 📘 Resumo rápido

|Função|Uso|
|---|---|
|CASE|Decisões complexas|
|DECODE|Decisão simples|
|NVL|Substitui NULL|
|NVL2|Decide se é NULL|
|COALESCE|Primeiro não NULL|

---

## 🧠 Minha opinião

👉 **Aprenda bem CASE e NVL**, são as que mais caem e mais usadas no mercado.
