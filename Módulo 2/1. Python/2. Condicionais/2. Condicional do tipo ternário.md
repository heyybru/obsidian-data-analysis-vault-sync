## 🔷 Condicional do tipo ternário (Python)

O **operador ternário** é uma forma curta de escrever um `if/else` quando a decisão é simples e você quer **atribuir um valor** a uma variável.

### ✅ Sintaxe

```python
valor_se_verdadeiro if condicao else valor_se_falso
```

---

## 🔷 1) Exemplo básico

```python
idade = 17
msg = "Maior de idade" if idade >= 18 else "Menor de idade"
print(msg)
```

Equivalente ao `if/else` normal:

```python
idade = 17
if idade >= 18:
    msg = "Maior de idade"
else:
    msg = "Menor de idade"
print(msg)
```

---

## 🔷 2) Exemplos práticos (RH + QA)

### ✅ RH: classificar candidato

```python
anos_exp = 2
nivel = "Pleno" if anos_exp >= 2 else "Júnior"
print(nivel)
```

### ✅ QA: status de execução do teste

```python
passou = True
resultado = "PASSOU" if passou else "FALHOU"
print(resultado)
```

---

## 🔷 3) Com operadores lógicos (and/or)

```python
idade = 22
tem_portfolio = False

msg = "Aprovado" if (idade >= 18 and tem_portfolio) else "Reprovado"
print(msg)
```

---

## 🔷 4) Boas práticas (pra não virar bagunça)

✅ Use ternário quando:

- for **curto**
- tiver **uma condição simples**
- você quiser **atribuir valor** ou **retornar valor**

⚠️ Evite quando ficar grande:

```python
# ❌ Evite (fica difícil de ler)
msg = "A" if cond1 else ("B" if cond2 else ("C" if cond3 else "D"))
```

Nesses casos, é melhor `if/elif/else`.
