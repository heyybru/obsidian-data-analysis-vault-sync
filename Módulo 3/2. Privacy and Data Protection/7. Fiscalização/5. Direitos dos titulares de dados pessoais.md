### 🛡️ Os Direitos Essenciais do Titular

- **Confirmação e Acesso**: O titular pode perguntar: "Você tem dados meus?" e "Quais dados são esses?".
    - 👉 _Exemplo_: Um candidato pede para ver tudo o que o seu sistema de RH guardou sobre as entrevistas dele.
- **Correção**: Direito de atualizar dados incompletos, inexatos ou desatualizados.
    - 👉 _Exemplo_: O candidato mudou de telefone ou tirou uma nova certificação e quer que o sistema reflita isso.
- **Anonimização, Bloqueio ou Eliminação**: Se o dado for desnecessário ou excessivo, o titular pode pedir para "sumir" com ele.
    - 👉 _Exemplo_: Um candidato que não foi aprovado pede para você excluir o currículo dele da base após o fim do processo.
- **Portabilidade**: Como já vimos, levar os dados para outro fornecedor.
- **Informação sobre Compartilhamento**: Saber com quais entidades (públicas ou privadas) a empresa dividiu os dados.
    - 👉 _Exemplo_: O candidato quer saber se você mandou o currículo dele para uma empresa parceira de _background check_.
- **Revisão de Decisões Automatizadas**: Direito de pedir que um humano revise uma decisão feita apenas por robôs/algoritmos.
    - 👉 _Exemplo_: O sistema de IA reprovou o candidato automaticamente por "falta de experiência". Ele tem o direito de pedir que **você (Bruno)** revise isso manualmente.

### 📊 Tabela: O Papel do QA na Garantia de Direitos

A **Metricas Boss** reforça que a transparência gera conversão. Veja como você testa isso:

|Direito|O que o QA testa?|Validação Técnica|
|:--|:--|:--|
|**Acesso**|O botão "Baixar meus dados" funciona?|Verificar se o JSON gerado via API está completo.|
|**Correção**|O formulário de perfil atualiza o banco?|SQL: `SELECT * FROM candidatos WHERE id = X` pós-edição.|
|**Eliminação**|O dado some mesmo ou só fica "escondido"?|Checar se o registro foi deletado ou anonimizado no DB.|
|**Revisão de IA**|Existe um fluxo para intervenção humana?|Testar o workflow de "Contestação de Resultado" no sistema.|

### 🧪 Insight do Especialista (Metodologia & Inovação)

- **Preditiva.ai**: O direito à **revisão de decisões automatizadas** é o maior desafio atual da Ciência de Dados. Como QA, você deve garantir que o sistema tenha "explicabilidade" (saber por que a IA tomou aquela decisão).
- **Snaq.co**: Startups que adotam o _Privacy by Design_ (privacidade desde o desenho do código) gastam menos com suporte jurídico e ganham mais tração no mercado global.
- **Data Literacy (Cappra)**: Educar o time de recrutamento sobre esses direitos evita que eles prometam algo que o sistema não consegue cumprir tecnicamente.

### 💡 Dica de Ouro

O direito à **Eliminação** não é absoluto. Se você contratou o candidato, não pode apagar os dados dele imediatamente por causa de obrigações trabalhistas e fiscais. A lei sempre equilibra direitos com deveres.
