## Prática 1: classificar variáveis (tipo + nível de mensuração)

### ✅ O que você vai treinar

- **Qualitativa vs Quantitativa**
- **Nominal / Ordinal / Intervalar / Razão**
- E um “plus” de **Data Quality**: padronizar categorias para não virar bagunça

### Código (pode rodar direto)

```python
import pandas as pd
import numpy as np
from datetime import date

# Dataset exemplo (Candidate Experience / Recrutamento)
df = pd.DataFrame({
    "candidate_id": [101, 102, 103, 104, 105],
    "canal_origem": ["LinkedIn", "linkedin", "Indicação", "Site", "N/A"],
    "status_funil": ["Triagem", "Entrevista", "Oferta", "Triagem", "Entrevista"],
    "prioridade_vaga": ["Alta", "Média", "Baixa", "Alta", "Média"],
    "data_nascimento": ["1994-06-10", "1990-01-20", None, "1988-12-01", "1996-03-15"],
    "tempo_para_primeiro_contato_horas": [12.5, 8.0, 36.0, np.nan, 5.0],
    "nota_satisfacao_1a5": [5, 4, 2, 3, 5],
    "temperatura_celsius": [22.0, 23.5, 21.0, 22.2, 24.0],
    "qtd_entrevistas": [2, 3, 1, 2, 4]
})

df
```

### 1) Classificação “teórica” (gabarito comentado)

```python
classificacao = {
    "candidate_id": ("qualitativa (identificador)", "nominal"),
    "canal_origem": ("qualitativa", "nominal"),
    "status_funil": ("qualitativa", "ordinal (se você definir uma ordem do funil)"),
    "prioridade_vaga": ("qualitativa", "ordinal"),
    "data_nascimento": ("quantitativa (tempo, após conversão)", "razão (idade/tempo com zero absoluto)"),
    "tempo_para_primeiro_contato_horas": ("quantitativa contínua", "razão"),
    "nota_satisfacao_1a5": ("qualitativa (escala)", "ordinal (na maioria dos cursos)"),
    "temperatura_celsius": ("quantitativa contínua", "intervalar"),
    "qtd_entrevistas": ("quantitativa discreta", "razão"),
}

for col, (tipo, nivel) in classificacao.items():
    print(f"{col:35} | {tipo:28} | {nivel}")
```

**Pontos que caem muito:**

- `candidate_id` é número, mas **não é quantitativo**: é **identificador nominal**.
- `temperatura em °C` é **intervalar** (0°C não é “ausência de temperatura”).
- Escalas 1–5 (satisfação) são geralmente tratadas como **ordinais** no básico.

## Prática 2 (Data Quality): padronizar categorias + converter tipos

Agora vamos limpar “linkedin” vs “LinkedIn” e trocar “N/A” por nulo.

```python
df2 = df.copy()

# padronizar canal_origem
df2["canal_origem"] = (
    df2["canal_origem"]
    .replace({"N/A": None})
    .str.strip()
    .str.title()
)

# converter data_nascimento para datetime
df2["data_nascimento"] = pd.to_datetime(df2["data_nascimento"], errors="coerce")

# criar idade (campo calculado) -> variável quantitativa (razão)
hoje = pd.Timestamp(date.today())
df2["idade"] = ((hoje - df2["data_nascimento"]).dt.days / 365.25).round(1)

df2[["candidate_id", "canal_origem", "data_nascimento", "idade"]]
```

## Prática 3: checar inconsistências rápidas (validação simples)

```python
# 1) Quais colunas têm nulos?
print(df2.isna().sum())

# 2) Domínio de prioridade (esperado: Baixa, Média, Alta)
valid_prioridade = {"Baixa", "Média", "Alta"}
invalid = df2[~df2["prioridade_vaga"].isin(valid_prioridade)]

# 3) Tempo para primeiro contato não pode ser negativo
negativos = df2[df2["tempo_para_primeiro_contato_horas"] < 0]

print(negativos[["candidate_id", "tempo_para_primeiro_contato_horas"]])
```

## Resumindo

- **Classificar variável** = dizer se é qualitativa/quantitativa e o **nível** (nominal/ordinal/intervalar/razão).
- Nem todo número é quantitativo: **ID é nominal**.
- Em prática de dados, vale combinar classificação + **padronização** + **validações básicas**.
