**Conjunto (set)** é uma coleção **sem ordem** e **sem itens repetidos**.  
Ele é ótimo para: **remover duplicados**, **verificar existência rápido**, e fazer operações tipo **união/interseção/diferença** (bem útil em dados e QA).

---

## 🔷 1) Como criar um conjunto

```python
s1 = {1, 2, 3}
s2 = set([1, 1, 2, 3])  # vira {1, 2, 3}
vazio = set()           # ⚠️ {} é dict, não set
```

⚠️ Pegadinha:

```python
tipo = type({})     # dict
tipo2 = type(set()) # set
```

---

## 🔷 2) Remover duplicados (caso mais comum)

```python
usuarios = ["ana", "ana", "bruno", "carla", "carla"]
unicos = set(usuarios)
print(unicos)  # {'ana', 'bruno', 'carla'}
```

Se precisar voltar pra lista:

```python
lista_unicos = list(set(usuarios))
```

---

## 🔷 3) Verificar se existe (muito rápido)

```python
severidades_validas = {"CRITICO", "ALTO", "MEDIO", "BAIXO"}

sev = "ALTO"
print(sev in severidades_validas)  # True
```

👉 Em QA, isso vira validação de input/payload.

---

## 🔷 4) Operações de conjuntos (as mais importantes)

### ✅ União (A ∪ B): tudo sem repetir

```python
a = {"Login", "Cadastro"}
b = {"Cadastro", "Pagamento"}

print(a | b)  # {'Login', 'Cadastro', 'Pagamento'}
```

### ✅ Interseção (A ∩ B): o que tem nos dois

```python
print(a & b)  # {'Cadastro'}
```

### ✅ Diferença (A − B): o que tem em A e não tem em B

```python
print(a - b)  # {'Login'}
```

### ✅ Diferença simétrica: o que é exclusivo de cada lado

```python
print(a ^ b)  # {'Login', 'Pagamento'}
```

---

## 🔷 5) Exemplo real (QA): comparar testes planejados vs executados

```python
planejados = {"Login", "Cadastro", "Pagamento", "Perfil"}
executados = {"Login", "Pagamento", "Busca"}

nao_executados = planejados - executados
extras = executados - planejados
ok = planejados & executados

print("✅ Executados e planejados:", ok)
print("⚠️ Não executados:", nao_executados)
print("❌ Executados fora do plano:", extras)
```

---

## 🔷 6) Métodos úteis: `add`, `update`, `remove`, `discard`

```python
s = set()

s.add("Login")                 # adiciona 1
s.update(["Cadastro", "Perfil"])  # adiciona vários

s.remove("Login")   # ❌ dá erro se não existir
s.discard("Busca")  # ✅ não dá erro se não existir
```

---

## 🔷 7) `set` vs `list` (diferença rápida)

- **list**: mantém ordem, aceita repetidos
- **set**: não tem ordem garantida, **não aceita repetidos**, membership (`in`) geralmente é mais rápido

---

## 🔷 8) `frozenset` (conjunto imutável)

Se você precisar de um set que **não pode mudar** (e pode ser chave de dict):

```python
fs = frozenset(["QA", "API"])
# fs.add("x")  # ❌ não existe (imutável)
```
