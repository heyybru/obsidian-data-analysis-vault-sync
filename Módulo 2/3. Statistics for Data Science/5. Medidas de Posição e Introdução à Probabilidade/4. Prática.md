## 1) Conceitos básicos de probabilidade em Python

```python
import random
from collections import Counter
import numpy as np

# Exemplo 1: Probabilidade clássica (teórica)
# Qual é a chance de tirar um número par em um dado?

espaco_amostral = [1, 2, 3, 4, 5, 6]
casos_favoraveis = [2, 4, 6]  # números pares

prob_par = len(casos_favoraveis) / len(espaco_amostral)
print(f"Probabilidade de tirar par: {prob_par:.2%}")  # 50.00%
```

## 2) Probabilidade frequentista (baseada em dados observados)

```python
# Simulando: em quantos candidatos recebem feedback em até 24h?

# Dados históricos: tempo para primeiro contato (horas)
tempos = [2, 4, 6, 8, 12, 15, 18, 24, 30, 36, 48, 72]

# Quantos receberam feedback até 24h?
ate_24h = sum(1 for t in tempos if t <= 24)
total = len(tempos)

prob_ate_24h = ate_24h / total
print(f"Probabilidade de feedback até 24h: {prob_ate_24h:.2%}")  # 58.33%

# Interpretação: com base nos dados históricos, 58% dos candidatos 
# recebem feedback em até 24h
```

## 3) Simulação de experimentos (Lei dos Grandes Números)

A ideia: quanto mais você repete um experimento, mais a frequência se aproxima da probabilidade teórica.

```python
import matplotlib.pyplot as plt

# Simulando: lançar uma moeda 1000 vezes
# Probabilidade teórica de cara = 50%

repeticoes = 1000
caras = sum(random.choice([0, 1]) for _ in range(repeticoes))
freq_cara = caras / repeticoes

print(f"Frequência de caras em {repeticoes} lançamentos: {freq_cara:.2%}")
# Resultado esperado: próximo a 50%

# Agora vamos ver como a frequência converge conforme aumentamos repetições
tamanhos = range(10, 1001, 10)
frequencias = []

for n in tamanhos:
    caras_n = sum(random.choice([0, 1]) for _ in range(n))
    freq = caras_n / n
    frequencias.append(freq)

# Plotar convergência
plt.figure(figsize=(10, 5))
plt.plot(tamanhos, frequencias, label="Frequência observada", alpha=0.7)
plt.axhline(y=0.5, color='r', linestyle='--', label="Probabilidade teórica (50%)")
plt.xlabel("Número de lançamentos")
plt.ylabel("Frequência de caras")
plt.title("Lei dos Grandes Números: Moeda")
plt.legend()
plt.grid()
plt.show()
```

## 4) Probabilidade aplicada a QA (exemplo real)

```python
# Cenário: qual é a chance de um bug crítico passar para produção?
# Baseado em histórico de testes

bugs_encontrados_em_teste = 45
bugs_encontrados_em_prod = 5
total_bugs = bugs_encontrados_em_teste + bugs_encontrados_em_prod

# Probabilidade de um bug crítico passar (não ser detectado em teste)
prob_bug_passar = bugs_encontrados_em_prod / total_bugs

print(f"Probabilidade de bug crítico passar: {prob_bug_passar:.2%}")  # 10%

# Interpretação: com base no histórico, há 10% de chance de um bug 
# crítico não ser detectado em teste e chegar à produção
```

## 5) Probabilidade condicional (mais avançado)

```python
# Cenário: qual é a chance de um candidato aceitar a oferta, 
# DADO QUE ele passou na entrevista técnica?

# Dados históricos
passou_tecnica = 80  # candidatos que passaram na técnica
aceitaram_oferta = 60  # desses, quantos aceitaram

# Probabilidade condicional: P(aceita | passou técnica)
prob_aceita_dado_passou = aceitaram_oferta / passou_tecnica

print(f"P(aceita | passou técnica) = {prob_aceita_dado_passou:.2%}")  # 75%

# Comparar com probabilidade geral
total_candidatos = 200
total_aceitaram = 70

prob_aceita_geral = total_aceitaram / total_candidatos
print(f"P(aceita) geral = {prob_aceita_geral:.2%}")  # 35%

# Insight: passar na técnica aumenta muito a chance de aceitar (75% vs 35%)
```

## 6) Combinações e permutações (quando importa a ordem)

```python
from math import comb, perm

# Cenário: em uma equipe de 10 candidatos, quantas formas diferentes 
# posso escolher 3 para um projeto?

n = 10  # total de candidatos
k = 3   # quantos escolher

combinacoes = comb(n, k)
print(f"Formas de escolher 3 de 10: {combinacoes}")  # 120

# Se a ordem importasse (ex.: 1º, 2º, 3º lugar em um ranking):
permutacoes = perm(n, k)
print(f"Formas de ordenar 3 de 10: {permutacoes}")  # 720
```

## Resumindo

- **Probabilidade clássica**: teórica, quando você conhece todos os casos.
- **Frequentista**: baseada em dados observados (muito mais comum na prática).
- **Lei dos Grandes Números**: quanto mais repetições, mais a frequência se aproxima da probabilidade real.
- **Condicional**: probabilidade de A **dado que** B aconteceu.
