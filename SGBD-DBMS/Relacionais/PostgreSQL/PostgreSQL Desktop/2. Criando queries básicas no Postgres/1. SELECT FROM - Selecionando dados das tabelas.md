## 🔍 O que é o SELECT?

O `SELECT` é o comando que diz ao banco: **"quero ver os dados"**. Ele é a forma de _ler_ informações guardadas nas tabelas.

Pense assim: o banco é um **armário com gavetas** (lembra do Módulo 1?). Cada gaveta é uma tabela. O `SELECT` é você dizendo ao banco _"quero ver o que tem dentro"_.

## 📂 O que é o FROM?

O `FROM` é o comando que diz **de onde** você quer os dados — ou seja, **qual gaveta** (tabela) você vai abrir.

Sozinhos, eles não fazem nada. **Juntos**, eles formam a consulta mais básica e mais usada do SQL:

```sql
SELECT company_name
FROM customers;
```

**Linha por linha:**

- `SELECT company_name` → "quero ver a coluna **company_name**" (nome da empresa do cliente).
- `FROM customers` → "de onde? Da tabela **customers**" (clientes).
- `;` → o ponto final. Toda instrução SQL termina com `;`.

**Pseudocódigo:**

```
ESCOLHA as colunas que você quer ver   →  SELECT
DE dentro da tabela onde elas moram    →  FROM
```

## ⭐ O asterisco: querendo ver tudo

Se você quiser ver **todas as colunas** de uma tabela de uma vez, use o `*` (asterisco). Ele significa "tudo":

```sql
SELECT *
FROM customers;
```

Isso retorna **todas as colunas** da tabela `customers` — nome, contato, país, telefone, etc. É ótimo para dar uma primeira olhada nos dados.

## 💡 Exemplo prático com o Northwind

Imagine que você quer ver só os **nomes dos produtos** da loja:

```sql
SELECT product_name
FROM products;
```

- O banco **abre a gaveta** `products`.
- **Pega apenas a etiqueta** `product_name` (nome do produto).
- Devolve uma lista com todos os nomes de produtos.

Agora, pensando no seu universo de People Analytics: se quiser ver os **nomes dos funcionários**:

```sql
SELECT first_name
FROM employees;
```

O mesmo princípio — escolhe a coluna, indica a tabela, pronto. É assim que toda análise começa: **lendo os dados**.

## 🧠 Por que isso é tão importante?

- É a **base de tudo**: filtrar (`WHERE`), juntar tabelas (`JOIN`) e agrupar (`GROUP BY`) só funcionam depois que você sabe ler dados com `SELECT`.
- É o comando que você vai **digitar todos os dias** como analista.
- Entender `SELECT` e `FROM` é entender **como o banco pensa**: primeiro ele descobre _de onde_ vem (FROM), depois decide _o que mostrar_ (SELECT).

> 💡 **Curiosidade:** na prática, o banco processa o `FROM` **antes** do `SELECT` — ele primeiro localiza a tabela e só depois escolhe as colunas. Mas para escrever, a ordem é `SELECT ... FROM ...`.

## 📋 Resumindo

- `SELECT` escolhe **quais colunas** você quer ver; `FROM` indica **de qual tabela**.
- A ordem é sempre `SELECT ... FROM ...;` — o `;` é o ponto final da instrução.
- O `*` mostra **todas as colunas** da tabela de uma vez.
- É o comando mais usado do SQL e a base de tudo que vem pela frente no curso.
