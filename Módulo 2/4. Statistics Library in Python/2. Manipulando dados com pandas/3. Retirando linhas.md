## Retirando linhas no Pandas

Retirar linhas significa **remover registros** do DataFrame.  
Você pode fazer isso de algumas formas, dependendo do que quer excluir:

- por **índice**
- por **condição**
- por **valores nulos**
- por **duplicidade**

---

## 1. Remover linha pelo índice com `drop()`

### Exemplo

```python
df = df.drop(0)
```

Isso remove a linha de índice **0**.

### Remover mais de uma linha

```python
df = df.drop([0, 2, 5])
```

---

## 2. Remover linhas por condição

Na prática, muitas vezes você não “remove” diretamente.  
Você **filtra e mantém só o que interessa**.

### Exemplo: remover pessoas com idade menor que 18

```python
df = df[df["idade"] >= 18]
```

Esse código:

- mantém apenas quem tem idade maior ou igual a 18
- remove o restante

### Exemplo: remover registros de uma cidade

```python
df = df[df["cidade"] != "SP"]
```

---

## 3. Remover linhas com valores nulos

### Remover linhas com qualquer nulo

```python
df = df.dropna()
```

Isso remove toda linha que tenha pelo menos **um valor ausente**.

### Remover linhas com nulo em coluna específica

```python
df = df.dropna(subset=["idade"])
```

Remove apenas as linhas em que a coluna **idade** está nula.

---

## 4. Remover linhas duplicadas

```python
df = df.drop_duplicates()
```

Remove linhas repetidas.

### Remover duplicadas com base em uma coluna

```python
df = df.drop_duplicates(subset=["email"])
```

Mantém apenas um registro por email.

---

## 5. Remover linhas e resetar o índice

Depois de excluir linhas, o índice pode ficar “quebrado”, por exemplo:

- 0
- 1
- 4
- 7

Para reorganizar:

```python
df = df.reset_index(drop=True)
```

O `drop=True` evita que o índice antigo vire coluna.

---

## 6. Exemplo prático completo

```python
import pandas as pd

df = pd.DataFrame({
    "nome": ["Ana", "Bruno", "Carla", "Diego"],
    "idade": [22, 17, 29, None],
    "cidade": ["SP", "RJ", "SP", "BH"]
})

# remover menor de idade
df = df[df["idade"] >= 18]

# remover nulos
df = df.dropna(subset=["idade"])

# resetar índice
df = df.reset_index(drop=True)

print(df)
```

---

## 7. Diferença entre `drop()` e filtro

### `drop()`

Usa quando você sabe o **índice** da linha:

```python
df = df.drop(3)
```

### Filtro

Usa quando quer remover com base em **regra**:

```python
df = df[df["idade"] >= 18]
```

Na análise de dados, o mais comum é usar **filtro**.

---

## 8. Remover linhas “na mesma variável” com `inplace=True`

Você pode fazer assim:

```python
df.drop(0, inplace=True)
```

Ou:

```python
df.dropna(inplace=True)
```

Mas, para quem está aprendendo, eu recomendo usar:

```python
df = df.drop(0)
```

porque fica mais claro e mais fácil de depurar.

---

## 9. Erros comuns

### Tentar remover linha usando valor da célula em vez de índice

❌ Errado:

```python
df.drop("Ana")
```

Isso só funciona se `"Ana"` for o índice.

### O certo seria filtrar:

```python
df = df[df["nome"] != "Ana"]
```

## 10. Resumo das formas principais

### Remover por índice

```python
df = df.drop(0)
```

### Remover várias linhas

```python
df = df.drop([0, 1, 2])
```

### Remover por condição

```python
df = df[df["idade"] >= 18]
```

### Remover nulos

```python
df = df.dropna()
```

### Remover duplicados

```python
df = df.drop_duplicates()
```

### Resetar índice

```python
df = df.reset_index(drop=True)
```

## Dica prática

Na **EDA**, normalmente você remove linhas quando:

- há muitos **valores nulos**
- existem **duplicidades**
- você quer excluir registros inválidos
- está limpando a base antes da análise

A sequência comum é:

```python
df.info()
df.isna().sum()
df = df.dropna()
df = df.drop_duplicates()
df = df.reset_index(drop=True)
```
