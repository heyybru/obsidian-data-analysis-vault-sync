No **Mac M1**, você deve instalar a versão para **Apple Silicon (ARM64)**. Isso evita problemas de compatibilidade e melhora desempenho.
### Passo a passo

1. **Baixe o instalador correto**
    
    - Acesse o site oficial da Anaconda.
    - Procure pela versão **macOS ARM64 / Apple Silicon**.
    - Evite a versão **Intel x86_64**, a menos que tenha um motivo específico.
2. **Execute o instalador**
    
    - Abra o arquivo `.pkg` baixado.
    - Siga o assistente padrão:
        - continuar
        - aceitar termos
        - escolher local de instalação
        - instalar
3. **Feche e abra o Terminal** Depois da instalação, reinicie o Terminal para que os comandos do Anaconda sejam reconhecidos.
    
4. **Verifique se instalou corretamente** No Terminal, rode:

```bash
conda --version
```

Se tudo deu certo, você verá algo como:

```bash
conda 24.x.x
```

5. **Atualize o conda** Recomendo atualizar logo após instalar:

```bash
conda update -n base -c defaults conda
```

---

## Teste rápido criando um ambiente

Depois da instalação, teste assim:

```bash
conda create -n teste python=3.11
conda activate teste
python --version
```

Se aparecer a versão do Python, está funcionando.

---

## Dicas importantes no Mac M1

- **Use pacotes ARM64** sempre que possível.
- Se algum pacote antigo não funcionar, pode haver dependência só para Intel.
- Em geral, **Miniconda** ou **Miniforge** costuma ser mais leve que Anaconda completo, mas se você quer tudo pronto, o **Anaconda** funciona bem.

---

## Problemas comuns

### “conda: command not found”

Isso normalmente significa que o terminal não carregou o caminho do Anaconda.

Tente:

```bash
source ~/.zshrc
```

Se ainda não funcionar, inicialize o conda manualmente:

```bash
~/anaconda3/bin/conda init zsh
source ~/.zshrc
```

### Erro de permissão ou bloqueio do macOS

Vá em:

- **System Settings**
- **Privacy & Security**
- permita a execução do instalador, se o macOS bloquear
